# ServerDeck v0.1 实施计划

基线：PRD v1.0，按 §19 六阶段推进。本轮按用户明确授权扩展 PRD 的 P1 主机运维能力：Docker、日志、进程、端口和 systemd 已交付；网络诊断、显式批量命令和单文件分发已交付。命令/脚本库、持久任务历史及本地计划已交付。本轮按追加授权进行产品整合、交互优化和非敏感备份恢复，不引入 DAG 或云端调度。
表中“验收”为完成标准。既有记录保留于 `VALIDATION.md`、`VALIDATION_STAGE2.md`；SSH 基础见 `VALIDATION_STAGE3.md`，SSH 增强阶段见 `VALIDATION_SSH_USABILITY.md`，SFTP 阶段见 `VALIDATION_STAGE4.md`，监控阶段见 `VALIDATION_STAGE5.md`，当前主机运维见 `VALIDATION_OPERATIONS.md`，网络与批量见 `VALIDATION_NETWORK_BATCH.md`，本地自动化见 `VALIDATION_AUTOMATION.md`。

## 当前状态

- S4 已交付；S5 当前完成真实 Agentless 采集、差分、任务管理、Monitor 页面和 Linux 交叉验证，保留完整发布矩阵门禁。

- S1/S2 已交付；保留原配置和数据、SSH 信任表及已有 v3→v4 SSH 选项迁移；本轮新增 v4→v5 自动化迁移。
- S2.1–S2.3 主机/单层分组/标签/收藏/搜索/排序/复制/确认删除及详情已实现。
- S3.1–S3.5 中的凭据使用、TOFU 信任/变更阻断、SSH 认证、PTY、流式 IPC、背压、多标签和手动重连已实现；真实 Windows → Ubuntu OpenSSH Shell、vim/top/htop/less、Ctrl+C/Z 已通过。本轮分屏已实现；系统 known_hosts 哈希/撤销/CA 导入未实现。
- S6.3 中 OpenSSH 预览、重复识别、选择导入及非敏感 JSON 导出按本轮授权提前交付；完整备份恢复仍未实现。
- S0.3 已覆盖授权真实 Ubuntu、密码认证与隔离 Windows named-pipe Agent 签名认证；系统 Agent 实际加载身份、其他平台/发行版及 20 会话性能矩阵未完成。S0.4 RSA 门禁保留，本地 RSA 私钥签名明确拒绝。

```text
S0 SSH 技术探针 ───────────────→ S3 真实 SSH 接入门禁
S1 项目骨架 → S2 主机管理 → S3 SSH/凭据 → S4 SFTP
                                      └────→ S5 监控
S2 / S3 / S4 / S5 + P1 补齐 ───────────→ S6 整合发布
```
