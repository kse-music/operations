# 禁用系统右键菜单验收

日期：2026-11-02。范围：移除应用内容区出现的浏览器/WebView 系统右键菜单。

## 实现与完成标准

`apps/desktop/src/App.vue` 在挂载时、后端初始化前注册 document 捕获阶段监听，仅对 contextmenu 调用 preventDefault，卸载时移除。捕获阶段覆盖 xterm 等会停止冒泡的子节点，document 覆盖 Teleport 到 body 的弹窗。既有自定义菜单继续接收事件，键盘、copy 和 paste 事件不被该监听取消。

主要修改：`App.vue`、`App.test.ts`、`tools/native-ui-e2e.mjs`、本记录及 `IMPLEMENTATION_PLAN.md`。没有新增依赖、IPC 或存储变更，保留工作区其他既有修改。
