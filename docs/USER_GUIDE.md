# ServerDeck 测试版使用说明

## 安装与升级

Windows x64 安装包为 `ServerDeck_0.1.0-beta.1_x64-setup.exe`，当前用户安装，不要求管理员权限。需要 Windows 10/11 和 Microsoft WebView2；安装器在缺失时可能需联网下载官方运行时。当前包未做 Authenticode 签名，可能触发 Windows 信任提示；核对项目随包 SHA256，勿使用未知镜像。该校验只能发现文件损坏，不能替代发布者签名。

退出旧程序再安装。先导出非敏感备份；需要完整回滚时，在退出程序后备份整个用户数据目录，并保留系统凭据库。SQLite 旧版按事务迁移到 schema 5，不支持旧程序直接打开新 schema。失败不会自动清库。安装目录不保存业务数据库。

从系统应用列表卸载，默认保留数据；不要选择清除数据，除非已完成备份并确认不再使用。系统凭据库秘密需要先在应用内删除，否则移走数据库后无法再通过引用管理残留条目。

macOS Apple Silicon/Intel、Linux x64 暂无本轮可用安装包，仅准备 CI 配置；不宣称已构建、签名、公证或通过兼容性验证。

## 第一次连接

1. 在凭据管理创建密码引用或私钥路径及解锁口令；Agent 认证须自行启动系统 Agent 并加载密钥。安全存储不可用时先解决系统服务，不存在明文保存选项。
2. 新建主机，填地址、端口、账号和凭据引用；可设置标签、分组、超时、Keepalive、受管跳板和代理。全局默认值只影响新主机。
3. 打开终端，通过服务器控制台等可信渠道核对 SHA256 指纹再确认。变化密钥会被阻止，先核查服务器身份。
4. 同一主机的终端、文件、监控、运维共享上下文；顶部显示当前主机和端点。编辑主机配置后已有连接仍代表旧端点，需显式断开并重新打开对应模块。

## 日常操作

终端支持独立标签、重排/改名、分屏和拖动尺寸。Ctrl+C/Z 发往远端；复制/粘贴/查找和全局快捷键可在设置查看。大文本粘贴先确认。重连总是新 Shell，不恢复旧远端程序。内容只在用户选择导出时落盘。服务器 MaxSessions 会限制单条 SSH Transport 的 Channel 数，客户端不会修改 sshd 配置。

从终端打开同主机 SFTP。左本地右远程，多选上传/下载支持后台队列，默认每主机 3 个任务。冲突须选择策略；取消在安全边界结束，失败可手动重试。页面关闭不等于取消后台任务。远程编辑仅 UTF-8 小文本，保存检查外部变化；有未保存内容时先保存或明确丢弃。文件可复制绝对路径、在终端查看或 tail。目录联动依赖 OSC 7，未提供时不猜测 Shell 输出。

Monitor 按 /proc 连续差值显示 CPU/网络，首次采样无速率正常；错误、过期与权限不足会单独显示。关闭视图暂停采样。Docker、进程、端口、systemd 和日志入口都使用当前主机的独立模块会话；权限不足不自动提权。删除、停止和发送信号前核对目标，尤其注意 PID/容器 ID。日志可暂停、搜索和导出可见部分，缓存有上限。

Network 显示本机/远端来源，缺工具或权限会明确报错。ICMP 不通不能据此认定服务器宕机。批量命令/文件分发执行前逐台核对完整目标，并选择有限并发和超时；有副作用的命令不自动重试。超时或取消运行中任务可能显示 Unknown，需自行核实远端状态。

Automation 命令/脚本库可查看实际 Shell 文本，参数使用位置参数，秘密参数不保存且不采集输出。执行历史可查询。计划只在桌面程序运行且已有认证连接时工作，睡眠/退出/断线时不保证触发。错过计划可跳过或请求确认，危险计划每次批准，不自动补跑。

## 偏好、备份与故障

设置可保存主题、终端、默认连接、Keepalive、采样、下载目录、传输并发、日志级别、代理和快捷键。日志级别重启生效；当前完整翻译只有简体中文。

备份导出主机、分组/标签、命令/脚本及公开偏好。导入先预览，支持跳过/复制，偏好覆盖单独选择，不会覆盖原 SSH Config。秘密和信任需另行恢复；认证代理主机在预览阻止自动恢复，需手动重新配置。备份内容可能含用户写入正文/备注的秘密，分享前自行检查。

关闭窗口前处理未完成传输、任务和未保存文件。若操作失败，保留错误码、任务 ID 和去敏日志；不要贴出密码、私钥或未遮蔽环境变量。测试版限制及本轮验收见 `TEST_REPORT.md`、`SECURITY.md` 和 `RELEASE_CHECKLIST.md`。
