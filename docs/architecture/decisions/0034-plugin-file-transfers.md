# ADR 0034：文件版本预览与宿主流式传输

日期：2026-11-10。状态：已实施第二阶段。补充 [0033](0033-assistant-tools-tasks.md) 的文件/传输阶段；原有框架选择、内存任务与授权边界继续有效。

## 背景与选项

助手需要局部修改远程文件、本机上传和双端服务器中转。可由模型拼接 Shell/scp、在 Guest/前端搬运文件，或扩展现有 SFTP 原语。前两种会重复连接、凭据、目录和提交机制，且大文件超出插件桥与模型预算。

## 选择

工具与局部原文行修改在 Rust/WASM 插件实现；通用 SDK 5.1 提供明确本机/远程端点、owner 绑定的传输预览/启动/状态/取消/关闭，Native 复用既有 SFTP 队列、登录租约、指纹及宿主授权。准备和启动分别确认，冻结完整端点、大小、覆盖和源/目标属性；文本保存复用原文摘要、原子替换并增加提交后读回。大文件使用固定缓冲流式中转，不经模型或 WASM。

长任务从 Guest 动作分离但不脱离权限和生命周期。后台持续及提交前后复验修订、配置和授权，取消仅能控制本 owner 句柄，可绕开忙碌 Guest；它不释放另一个动作的 busy 标记。已观察终态先缓存再异步释放句柄，避免中断清理导致丢失提交事实。提交不确定显式报告，不自动重试或回滚。无数据库或持久格式变化。

## 后果与验证

文件读取/保存≤32 KiB，传输单个普通文件，无目录、链接、断点续传、跨重启恢复或 YAML 语义校验。SFTP v3 不具备服务端 CAS，冻结属性不能杜绝同属性并发改写；原子替换沿用 inode/ACL/xattr 限制。当前验证证据见[第二阶段报告](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md#2026-11-10-第二阶段文件编辑与传输)，真实模型、外部服务器及非 Windows 客户端继续保留门禁。
