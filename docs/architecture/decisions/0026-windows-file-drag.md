# ADR 0026：以 Windows 虚拟文件协议交付 SFTP 下载

原决策日期：2026-11-07。状态：有效；完整实体拖动手势和目标环境仍须验收。

## 背景与选项

远程条目没有可直接交给资源管理器的本地路径。窗口内双栏拖动可预填现有传输确认，窗口外需要由 Windows Shell 决定真实落点和重名处理，不能猜测目标目录或伪造已经下载的本地文件。

## 选择与后果

仅窗口外拖动交给 OLE 文件描述符和按索引读取的虚拟文件流；Shell 请求内容时通过现有 SFTP 队列下载并校验到专用暂存，数据对象/流释放后清理。Windows FFI 收敛在专用 crate，其他模块保留原安全 lint；非 Windows 不能据此宣称支持跨窗口拖放。

只对普通文件及显式选中的普通文件链接提供该行为；链接以自身名称保存目标内容，在规划、读取前和提交前复验解析路径。目录链接和递归扫描中的链接不跟随，窗口内拖动仍走明确的双栏传输流程。

代价是 Shell 可能异步索取内容，需要有界流、取消、暂存生命周期和恢复诊断。Shell 协议夹具或浏览器拖动不能替代 WebView2 跨桌面/资源管理器的实体手势验收。

基础文件安全见[ADR 0007](0007-safe-files.md)，范围和未验证项见[SFTP 验证](../../validation/files/VALIDATION_STAGE4.md)。
