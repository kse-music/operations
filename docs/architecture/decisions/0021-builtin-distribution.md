# ADR 0021：从完整源码目录生成内置分发

日期：2026-11-08。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

手工维护插件构建清单、Rust 注册和 CI 下载列表容易遗漏，并把新增独立插件变成修改宿主的工作。选择在构建时稳定扫描 `plugins/system` 完整直接子目录，以 manifest 为单一输入，校验链接/重复 ID/缺失源码与锁文件后生成包和 Rust 嵌入注册。

全部输入和构建成功后才发布注册；旧产物、输出 `packages` 和测试夹具不参与自动分发。不在运行时扫描可写目录获得 system 身份。系统和上传均使用标准校验/仓库，来源只控制分发及预置授权；用户禁用、配置和卸载选择保留。

## 取舍

新增完整目录无需维护宿主服务白名单，代价是桌面 Cargo 编译前须先生成插件输入。源码发现不绕过[ADR 0016](0016-plugin-platform.md)的公开 SDK 边界，不增加热安装。删除目录只停止新构建分发，用户既有数据遵循[ADR 0022](0022-feature-retirement.md)。

证据见[自动发现验证](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-08-内置插件自动发现)；构建命令与独立开发包见[开发指南](../../plugins/PLUGIN_DEVELOPMENT.md)。
