# ADR 0027：有界助手计划与最小上下文

来源日期：2026-11-05、2026-11-09。状态：计划边界和最小上下文策略已实施并补充专项回归；真实账号与完整跨平台验收仍按实施计划跟踪。此记录归并原智能体/按需上下文的重要取舍，当前业务归属遵循[ADR 0016](0016-plugin-platform.md)。

## 背景与选择

固定全量采集会放大请求、外发不相关资产并触发预算错误；直接开放模型 Shell 又无法约束实际目标。选择本地领域规则按问题采集，保留失败/未知/省略，模型只能请求有限只读类型并为已查询目标生成计划。规则无法完全理解自然语言，证据不足明确说明，不回退无差别全量采集。

单主机智能体最多六轮、十二次只读查询、每轮三项；最多 32 个真实计划目标。容器/服务动作必须有完整成功查询，镜像只清理全部无标签且无带标签别名的实际 ID，不接受模型从摘要猜清单，不强制、不删卷、不清理额外父镜像。多主机建议不能隐式选择一台执行，仅供人工审阅。

插件冻结完整证据和计划、绑定 SSH/模型修订，当前预览/计划从准备时刻起五分钟、单次消费；执行超过 100 秒不再启动后续项。Native 仍对每个实际请求确认真实目标和命令，不能把插件确认文字作为宿主已授权。执行前复验，执行后查询状态，失败/未知停止后续操作，不自动重试，取消不承诺撤销已提交动作。

## 上下文约束与实施

原要求保留：先脱敏后截短；完整记录统计后限制明细；匹配后诊断只携带命中资产；超预算优先削减可选明细和较早完整历史，并保留统计、错误及省略说明。保守 UTF-8 估算不是提供方精确分词，实际 Token 只取响应；任一轮用量缺失不伪造完整累计。

SDK5 `workflow::prepare` 已按上述顺序处理原值，诊断仅带命中主机，明确资产清单问题才附目录。准备及每轮补全共用预算压缩，先缩减可选明细，再丢弃最早完整历史，保留问题、统计、归属、失败和省略说明；不足时明确失败，不改变本地完整计划证据。前端按编码后请求大小丢弃整轮，避免在脱敏前切断敏感值。长敏感值、无关资产隔离、满历史、多主机与工具结果预算的实际回归见[上下文验证](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md#2026-11-09-上下文脱敏范围与预算修复)，未关闭门禁见[实施计划](../../product/IMPLEMENTATION_PLAN.md#剩余工作与验收门禁)。

原设计及阶段证据见[智能体与上下文验证](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md)，当前业务归属见[SDK5 验证](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-sdk5-平台边界与插件闭环)。旧 Native 智能体的十分钟计划等数值不覆盖当前插件实现，历史测试也不替代当前真实服务验收。
