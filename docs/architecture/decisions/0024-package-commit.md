# ADR 0024：受限 JSON 包与原子安装指针

原决策日期：2026-11-03。状态：有效；当前 SDK5/UI4 沿用包格式 1。此记录补回包协议和落盘方式的原始取舍。

## 背景与选项

当前插件体积有限，需要可审查的跨平台路径和提交语义。ZIP 需要处理解压路径、链接和压缩比；选择严格 JSON/base64，以约三分之一的编码开销换取更小的解析和路径校验面，不把 `.sdplugin` 当 ZIP 解包。

## 选择与后果

包限制原始/解码大小、文件数、单文件和路径，拒绝重复字段、路径别名/链接、设备名、未知字段及摘要不一致。开发包 ZIP 与安装包 `.sdplugin` 是两种产物，安装入口的权威校验始终在 Rust。

代码代与数据/缓存分开，先完成候选内容校验及落盘，再原子切换安装记录指针；提交失败不替换当前版本，正常升级保留回滚载荷。无需为插件包增加另一套 SQLite schema。卸载默认保留用户数据，停止分发不自动卸载，参见[退役决策](0022-feature-retirement.md)。

当前没有可信密码学签名验证器，必须显式确认本地开发包安装风险；作者、publisher 和 SHA256 不能证明来源。system 身份只由宿主分发写入，上传包不继承系统授权。断电/跨平台文件系统保证仍须分别验收。

精确格式与限制见[包格式](../../plugins/PLUGIN_PACKAGE_FORMAT.md)，原安装/升级/回滚证据见[插件验证记录](../../validation/plugins/PLUGIN_TEST_REPORT.md)。
