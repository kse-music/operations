# ADR 0033：助手工具目录与运行期任务

日期：2026-11-10。状态：已实施第一阶段；文件/传输范围由[0034](0034-plugin-file-transfers.md)补充。补充 0016 的插件业务边界和 0027 的有界执行策略，不替代既有宿主审批。

## 背景与选项

助手已有 Rust/WASM 查询、冻结计划和复查，但工具说明、参数和结果分散，缺少可查询任务状态。后续需要文件、传输、规程及外部系统。可以继续扩展提示词分支，引入独立框架/运行时，或整理现有插件基础。前者易漂移，独立运行时需要额外部署及可信执行桥接。

## 选择

采用插件内工具目录、严格参数、统一结果和有界内存任务；复用 SDK5 与 Native 的 SSH/模型、权限、原 Future 审批和修订绑定。目录直接提供模型参数说明，完整批次校验后才能请求平台。任务状态不构成授权，查询也复验原绑定，终态不可重放。

第一阶段不引入框架、Skill/MCP、持久格式或数据库迁移。后续内置能力通过通用 SDK 增加，Skill 提供规程，MCP 接入外部系统，均不能隐式授予权限。

## 后果与验证

现有严格 JSON 和业务语义保持，宿主不增加领域枚举。需要维护目录与类型一致性并验证真实 WASM 预算。运行期最多 32 个任务，不提供跨重启恢复或实时状态事件；文件与长传输仍属后续阶段。
