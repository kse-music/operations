# ADR 0018：主机工作区与资源生命周期分离

日期：2026-11-08。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

顶部模块、页面分组、主机标签和设置标签的重复层级使当前目标和关闭范围难以判断。选择常驻主机树、单排工作区及独立设置窗口；每个主机保存运行内上下文，导航切换不重绑已有资源的真实身份。设置分类共用偏好草稿，模型/插件独立保存。

启动只显示欢迎页，显式选择主机才连接当前空闲 Shell。会话、名称、编号和分屏只在本次运行中存在，不恢复旧 Shell 或重放输入。PTY 按 PaneKey 持续挂载，布局变化不重建会话；侧栏收起只改可见性。

关闭主机意味着审核 dirty 文档/插件草稿、确认取消传输、等待安全提交，再释放所属文件/终端/插件资源。关闭失败保留工作区及诊断，其他主机不受影响；成功后清除本主机临时记录。切页不执行关闭，页面 owner 关闭只取消自己的工作，后台不得新发起变更审批。

## 取舍与替代关系

用户可以稳定保留当前操作上下文，代价是须显式协调多个租约及在途提交，不能用卸载组件代替资源释放。此决策替代 ADR 0006 的布局持久化、ADR 0007 的旧目录跟随/关闭范围、ADR 0012 的旧导航/备份布局和 0013–0015 的早期界面入口。错误通知文本可复制，安全确认继续由可信父窗口处理。
