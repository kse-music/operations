# ADR 0039：完全访问会话生命周期

日期：2026-11-11。状态：已实施。部分替代 [0038](0038-three-approval-modes.md) 的完全访问10分钟期限及切换撤销规则；首次可信宿主授权、基础权限与冻结计划保护继续有效。

## 背景与选项

用户明确要求完全访问选中后一直生效，直到主动切换模式或关闭会话。保留10分钟到期会在同一对话重新弹窗；仅移除超时但不撤销旧句柄，会让退出Full后的旧计划继续使用完全访问授权。永久写入配置则会跨重启保留授权，超出当前需求。

## 选择

- Full授权仅在运行内绑定插件、owner和VM代，不设计时过期。隐藏/返回同一页面保留；切换到request/assist、新建对话、关闭owner、撤权或插件停止/升级时撤销，不持久化、不自动恢复。新建对话默认request。
- request/assist清除同owner的Full句柄和待批准项。启用Full的随机会话标识纳入原生首次批准摘要，签发句柄时在同一锁内复验，撤销前的迟到批准不能恢复授权。request降权允许在取消或Guest忙碌时发起，不能生成Full。
- 前端退出Full即冻结旧Full计划，等待Native撤销确认后再提交新请求；撤销失败显示错误、阻止新动作并支持明确重试。已提交远端操作仍按既有提交边界安全收尾，不承诺回滚。
- 模型/主机等修订句柄仍为10分钟，单次批准60秒、预览/计划5分钟等限额不变；首次指纹、目录/权限/原文复验及固定请求限次消费不变。

## 后果与验证

助手2.4.1、Host/Rust/Vue SDK5.3.1，助手声明`^5.3.1`；复用现有approval_mode请求，没有新增持久字段、数据库或配置迁移，不恢复旧授权。会话内可能持续执行已授予的修改/删除，这是用户明确选择Full的语义。

验证见[完全访问会话生命周期](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md#2026-11-11-完全访问会话生命周期)。
