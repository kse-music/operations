# ADR 0025：定位文件与确认启动后清理数据源

原决策日期：2026-11-05。状态：有效。此记录保留用户主动数据根迁移的理由，不恢复已删除的旧身份/格式自动迁移。

## 背景与选项

数据库、插件、日志和 WebView 需要统一的本机数据根，下载位置独立，系统秘密继续由凭据库保护。路径不能从尚未定位的数据库读取，也不应随普通业务配置搬到其他机器，因此保留默认 app_config_dir 下的小型定位文件。

在程序运行中移动 SQLite/WebView 可能遇到占用或不一致；简单复制后立刻删除源又无法判断新目录是否能正常启动。选择正常退出排空后，在重启期间复制与校验，启动成功确认后才清理源副本，支持跨磁盘。

## 选择与后果

复制使用目标磁盘专用暂存、文件清单/摘要及数据库只读校验；目标必须是空的专用目录，不合并或覆盖用户现有目录，不接受源/目标嵌套、链接或重解析点。中断可按清单核对续传，候选启动未确认时可回退源，失败副本保留诊断。

先持久化 Committed 状态再逐文件复核并清理源，只删除已核对的副本对应项；未知/变化文件保留，清理失败报告并可重试，不能回退到已部分删除的旧目录。定位与清理状态机增加了少量本机元数据，换取明确的失败恢复边界；不把复制成功误认为用户已确认新目录可用。
