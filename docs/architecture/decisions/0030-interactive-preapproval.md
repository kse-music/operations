# ADR 0030：交互会话采用独立预授权

日期：2026-11-09。状态：已实施。部分替代 [0020](0020-command-preapproval.md) 的流/PTY 必须逐次确认限制。

## 背景与选项

用户要求 Docker 日志和 Shell 点击直接打开，停止和删除仅保留一次“确认/取消”。日志和 Shell 命令含动态容器 ID，不能匹配 Execute 的完整固定命令清单。按内置插件 ID 绕过审批会破坏统一授权边界；为 Shell 脚本增加参数模板和业务解析会扩大宿主职责。

## 选择

新增通用可选 `ssh.interactive.preapproved` 权限及同名 operation，清单必须同时声明 `ssh.execute`。仅在当前包摘要、版本、安装修订及基础 SSH 授权均有效，且清单、权限和 operation 明确包含此能力时，对 StreamOpen/Terminal 免除单次审批。它允许任意交互命令，不声称只读，也不借用固定命令清单。

Docker 内置分发预置此权限；上传包默认不选，由用户单独授予。容器启动、停止、删除和镜像删除继续以 Execute 发起，复用宿主一次确认；移除插件要求输入目标 ID 的重复弹窗。固定命令精确预授权、文件保存和本机 TCP 确认规则保持各自契约。

## 后果与验证

减少重复交互的代价是当前版本获得较宽的流/终端启动授权；权限页明确展示任意交互命令范围。不能因插件声明已确认就免审，不能用此权限免除 Execute 审批。隐藏/关闭/撤权/升级清理和目标复验仍由现有平台统一执行。无数据库或配置格式迁移，不继承旧上传包授权。

验证见 [Docker 操作确认](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-docker-操作确认简化)；回环 SSH 与单元测试不能代替截图服务器或跨平台验收。
