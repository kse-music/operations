# ADR 0019：本地模型授权与有界外部运行时

日期：2026-11-07。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

用户希望复用本机 Codex/Claude Code 的配置和登录，不把订阅 token 复制成模型 API Key。选择由 Native 调用官方 CLI，登录/刷新由其管理；两种来源独立授权和撤销，快照只保存路径、账户身份及配置摘要。注册 HTTP 模型继续保留独立 Key、真实连接测试和修订。

未授权不读取配置或运行推理。每次推理使用临时目录/会话、有界管道、超时和取消；进程级禁用 Shell/hooks/MCP/外部工具等并核对协议结果，避免额外执行通路。来源、账户或配置变化失效旧请求，停止终止本次子进程，不改写用户配置。

缺失工具从固定官方源下载原生程序到应用目录，大小/摘要/启动校验成功才原子提交，取消不发布半成品；不执行远程安装脚本、不改全局 PATH、不覆盖用户安装，安装不等于访问授权。

## 取舍与当前边界

复用 CLI 避免自行保管登录凭据，代价是依赖 CLI 版本/协议及用户账号状态，不能把某版本 Windows 验证推广到所有环境。SDK5 下 Native 提供通用模型传输，助手插件负责提示词、脱敏、匹配、query/plan/answer 和复查；早期“只有内置助手可调用私有业务接口”的设计已由[ADR 0016](0016-plugin-platform.md)替代。

证据见[本地来源与安装](../../validation/ai/VALIDATION_AI_ASSISTANT.md)、[对话/有界智能体历史](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md)和[当前 SDK5](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-sdk5-平台边界与插件闭环)。CLI 登录服务及使用条件仍由各提供方管理，本文不作账号兼容承诺。
