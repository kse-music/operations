# ADR 0032：内置文本编辑默认原子保存

日期：2026-11-10；状态：已接受。部分替代 [ADR 0007](0007-safe-files.md) 中内置编辑器保存前的额外勾选确认。

## 背景与选项

用户要求移除远程文本编辑器的原子替换确认及保存限制整行，默认采用该保存行为。可保留独立勾选，或将用户点击保存/使用保存快捷键作为提交意图；选择后者，避免每次打开编辑器重复确认。

## 选择与后果

内置编辑器移除确认状态、整行控件及专用样式，按钮与快捷键均默认向现有保存接口传入 `confirmReplace: true`。原子扩展缺失时仍只读，忙碌时拒绝重复保存；后端内容/属性冲突检测、权限、临时文件校验和 uid/gid/mode 保留继续有效。不改变 IPC、持久配置或外部编辑回传确认。

原子替换改变 inode，不保证完整保留 ACL/xattr/硬链接关系，也不能消除 SFTP v3 最终检查与 rename 之间的竞态。限制保留于[使用说明](../../guides/USER_GUIDE.md)，内置编辑器不再单独展开说明。关闭/重载丢弃未保存内容仍须确认。
