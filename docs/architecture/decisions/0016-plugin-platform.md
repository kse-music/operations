# ADR 0016：插件拥有业务，宿主只提供通用原语

日期：2026-11-09。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

早期插件将系统查询、Docker/助手语义放进宿主 SDK，新增服务需要同步发布平台，且存在按内置 ID 提供业务特权的路径。选择由插件拥有页面、命令/SQL、DTO、解析、脱敏、提示词、工具循环和计划；宿主只管理身份/凭据、SSH/SFTP、模型传输、审批及资源。

Host/Rust/TS SDK 统一 5.0.0，UI v4、ABI/wire 1。独立 Vue + WASM 只依赖公开 SDK；所有插件使用同一 Platform 协议、目标复验、配额和 owner 隔离。审批保存原 Future，批准/拒绝后原地续接，避免重放已开始的变更。新增服务不增加宿主领域枚举、私有 Store 或插件 ID 特判。

## 取舍与替代关系

平台接口保持稳定且插件可独立开发，代价是插件负责业务校验、脱敏、解析与完整结果处理，Native 不能宣称识别全部业务风险。宿主私有 Ops/Monitor 可以保留，不作为旧公开领域接口复活。此决策替代 ADR 0009 的公开运维能力边界，以及早期 13A 声明式 UI/领域 SDK 方案；旧包不做兼容转换。

验证见[SDK5 闭环](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-sdk5-平台边界与插件闭环)和[业务归属修正](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-08-插件业务归属修正)。接口和资源限额只在[SDK](../../plugins/PLUGIN_SDK.md)维护。
