# ADR 0035：任务审批模式与单次计划确认

日期：2026-11-10。状态：已实施。补充[0034](0034-plugin-file-transfers.md)的逐次确认体验；文件/传输及提交保护继续有效。

## 背景与选项

用户实测删除远程文本一行，经历读取确认、插件审核/文字输入、宿主保存确认。用户选择“自动读取，文件修改/传输及其他变更合并为一次确认”，不要求全自动写入或额外AI审批模型。可以仅隐藏插件弹窗、直接绕过宿主确认，或把明确读取预授权及精确计划授权下沉到通用平台；仅隐藏弹窗无法减少实际确认，绕过宿主会破坏权限边界。

## 选择

输入区提供默认请求批准与帮我审批，发送时固定，仅当前页面内保留。通过独立 `operations.read.preapproved` 授予文件读取、传输预检及清单完整固定命令的免确认，基础权限/目录范围仍复验。模型不能修改策略或用readOnly声明获得任意SSH免审。

变更由Native预检完整请求集合与次数并统一确认，再沿同一个WASM Future按摘要消费；操作/参数/绑定变化或重放拒绝并撤销剩余集合。保留逐项目标、原文/配置复验及执行后校验。删除插件重复审核和文字输入，权限由宿主确认取得。SDK5.2增加通用原语，不增加助手ID特权、框架或持久格式。

## 后果与验证

动态详情/日志等未列入清单的命令仍会确认；首次主机指纹、未知结果和外部服务门禁保持。计划受既有消息/动作预算限制，过大明确失败，不能在传输时扩大批准集合。预览较长时标明省略。验证见[审批模式报告](../../validation/ai/VALIDATION_ASSISTANT_CHAT.md#2026-11-10-审批模式与单次计划确认)，其中区分UI夹具、真实Native/WASM/回环SSH/SFTP及未覆盖环境。
