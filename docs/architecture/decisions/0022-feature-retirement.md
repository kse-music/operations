# ADR 0022：移除产品能力时保留共享基础与用户数据

日期：2026-11-09。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

用户已要求移除批量/自动运维、本地调度、网络诊断、系统服务插件、任务中心、主机/应用 JSON 归档，以及后续的内置 Nginx。选择覆盖页面、路由、专属执行器、IPC/ACL、SDK、构建和测试的完整调用链，不用隐藏入口伪装删除，也不为旧开发包保留服务特判。

仍被 SSH/SFTP、插件或 AI 使用的受限执行、日志/监控及安全文件提交继续保留。内置分发当前只有 Docker 与助手，MySQL 独立上传。删除源码不自动卸载持久安装、不重置配置/授权、不清理历史附加表，更不卸载远端服务；用户可以使用既有显式卸载流程。

## 历史与取舍

早期曾采用退役 ID/目录归档与权限转换，当前已随[ADR 0017](0017-current-data-contract.md)删除兼容层；不能根据旧记录重新增加启动迁移或黑名单。ADR 0010/0011 的完整诊断/调度设计保留为历史，ADR 0009/0012 的旧页面和备份部分被替代。

减少无当前需求的维护面，代价是旧功能不再可用且旧上传包需重新开发。功能退役不构成数据清理授权，原始设计/验证不再覆盖当前 PRD。

证据见[批量/自动化移除](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-05移除自动运维与批量运维)、[诊断移除](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-05完整移除网络诊断)、[系统服务移除](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-05完整移除系统服务插件)及[Nginx 移除](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-移除-nginx-内置插件)。
