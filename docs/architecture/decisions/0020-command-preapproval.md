# ADR 0020：完整命令预授权独立于业务风险判断

日期：2026-11-09。状态：已实施。

本记录整理自原技术决策中的相关条目，保留设计依据和替代关系；不是本次文档整理新增的功能。

## 背景与选择

Docker 页面初始化、切换和刷新使版本/容器/镜像三条固定查询逐次审批，重复打断导航。选择清单声明完整命令，另授予 `ssh.execute.preapproved` 权限及 operation；保留 `ssh.execute`。只有当前包摘要/安装修订及 program、args、timeoutSecs 全部匹配的 Execute 可使用预授权。

上传包在权限页展示原始完整命令并单独选择，默认不授予；系统来源可预置，但不能作为命令只读的证明。没有参数模板/通配符、不相信 Guest 自报 readOnly/confirmed，也不增加 Docker 服务白名单。流、PTY、写文件、本机 TCP 及未声明命令继续单次确认，配置/owner/权限变化拒绝旧请求。

## 取舍

减少固定查询的重复确认，同时让用户批准的执行范围可审阅。宿主不判断任意命令是否只读；误授予危险固定命令仍有风险，必须在权限页呈现完整内容并绑定版本。执行槽、超时、输出、取消及目标前后复验保持一致。

证据见[Docker 预授权验证](../../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-09-docker-列表查询免重复确认)。回环 SSH 的解析/审批断言不等于真实服务器 Docker 业务或跨平台验收。
