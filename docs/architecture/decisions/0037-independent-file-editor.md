# ADR 0037：单文档独立 SFTP 编辑器

- 日期：2026-11-10
- 状态：接受

## 背景与选项

HTML dialog 受主 WebView 边界限制，无法拖到窗口外或第二屏。可选方案为继续内嵌、直接独立窗口，或支持拖出/拖回及多文档窗口。当前需求是解除窗口边界并保护未保存内容。

## 选择

直接使用无原生 parent/owner 的 Tauri 顶层窗口，复用 Monaco 和 SFTP token/冲突检测/原子保存；保持一次编辑一个文件，不增加多文档、拖回和几何持久化。Rust 单例登记实际窗口标签及文档，专用 capability 和按窗口解析的 IPC 共同限制权限，独立窗口不能获得主窗口的主机、凭据、终端或任意文件访问能力。

原生关闭交由该窗口审核，保存失败保留草稿，保存中阻止关闭/退出。主程序退出保持整个应用退出且明确放弃修改；不增加后台驻留。打开编辑器期间阻止主动关闭所属连接/主机、切换身份、迁移数据和页面重载，避免清理租约或内存草稿。窗口加载、销毁和几何事件与主窗口的全局处理隔离。

## 后果

支持跨屏和终端并排使用，保留原保存安全边界；增加一个 WebView/Monaco 的资源成本。窗口偏好采用打开时快照并跟随系统主题，主窗口后续设置在下次打开时应用。草稿仍在内存中，进程/渲染器崩溃不提供恢复；首版不承诺多窗口或全平台验收。
