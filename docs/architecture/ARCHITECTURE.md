# ServerDeck 总体架构

本文描述当前模块、数据流、安全边界和资源生命周期。功能见[产品基线](../product/PRD.md)，精确插件契约见[公开 SDK](../plugins/PLUGIN_SDK.md)，候选产物验收见[发布检查表](../release/RELEASE_CHECKLIST.md)。

## 系统边界与工程结构

应用为本地 Tauri 2 + Vue 3/TypeScript/Pinia 客户端，Rust Cargo Workspace 使用 Tokio。通过 SSH/SFTP 管理远端，无 HTTP 业务服务端、云账号或远端 Agent；前端不直接访问 SQLite、凭据库或任意本地 Shell。

| 位置                                        | 职责                                             |
| ------------------------------------------- | ------------------------------------------------ |
| `apps/desktop/src`                          | 页面、组件、工作区、状态、类型化 IPC、主题与交互 |
| `apps/desktop/src-tauri`                    | 组合根、capability、原生交互、窗口和退出协调     |
| `crates/core`                               | 宿主 DTO、配置、校验和安全错误                   |
| `crates/application`                        | 用例编排、资源所有权、有界阻塞工作和关闭协调     |
| `crates/storage` / `security`               | SQLite 与配置升级；系统凭据及秘密生命周期        |
| `crates/ssh` / `sftp`                       | 信任、认证、连接/Channel；文件、传输和原子编辑   |
| `crates/monitor` / `ops`                    | 宿主内部监控与运维服务                           |
| `crates/tasks` / `ai`                       | 有界单次 SSH 执行；模型传输、本地 CLI 与安装器   |
| `crates/plugin-core` / `plugin-runtime`     | 包、仓库、授权与 Wasmi 运行时                    |
| `crates/plugin-sdk` / `packages/plugin-sdk` | 公开协议、WASM async 执行器、TS 客户端和通用 UI  |
| `plugins/system/{assistant,docker}`         | 独立 Vue/WASM 业务，只依赖公开 SDK 和普通库      |
| `crates/windows-file-drag`                  | Windows 文件/磁盘互操作，必要 FFI 收敛于专用模块 |
| `crates/windows-terminal`                   | Windows 本地终端提权与私有进程通信互操作         |
| `tools` / `tests/fixtures`                  | 构建、隔离 QA、探针及不分发的测试夹具            |

主要依赖方向为 `desktop → application → 具体服务 → core`，SSH 读取 storage/security 中的受管配置与秘密，文件/监控/执行复用独立 SSH 租约。模块不反向依赖 UI。

产品版本只在根 `Cargo.toml` 声明。Tauri、平台 Rust 包和关于页继承工作区版本；桌面 dev/build 检查来源并同步工作区锁记录。SDK、插件包和持久格式独立管理版本。关于页发布时间由前端构建生成，按北京时间显示。

## 启动、IPC 与错误

1. 单实例检查并聚焦已有窗口。
2. 在打开数据库/WebView 前解析存储定位及用户明确登记的目录迁移。
3. 初始化安全日志，打开数据库并完成必要升级，加载严格配置后创建 Application 和有界引擎。
4. 逐包分发内置插件，隔离并聚合单插件问题；bootstrap 返回真实状态。
5. 前端初始化工作区并显示欢迎页，不恢复终端或自动连接。

初始化失败保留原数据并提供诊断，不创建空库伪装成功；模型配置故障按需隔离，不阻断主机启动。

```text
Vue / Pinia → 类型化 invoke → Tauri capability → Application
  → DTO / 权限 / 目标 / 修订校验 → 具体服务或有界 spawn_blocking
  → 结果 DTO / IpcError → 状态与通知
```

Rust/TS 显式维护 camelCase DTO，拒绝未知字段。秘密读取不开放给前端；浏览器预览显示后端未连接，不提供假数据。`IpcError = {code,message}` 提供安全文案，Rust 保留 source 原因链，不把 SQL、输入正文或敏感参数写入日志。已提交变更和待清理警告分别表达。

错误通过有界通知 Store 去重展示，弹窗中仍可交互；状态、重试、原始业务输出和安全确认独立保留。

## 工作区、设置和语言

Workspace 按打开顺序保存本地终端、主机和全局插件标签。HostId 是持久目标，活动页变化不能修改已有资源的目标。`HostTools` 平铺 SSH/SFTP 和启用插件，主机保存本次打开期间的最近工具、会话和路径。

没有活动工作区时，`WelcomeView` 以限宽卡片展示本地终端、新建主机和 SSH 配置导入，发出事件由 `App` 复用已有导航与弹窗流程；组件不创建连接或维护业务状态。键盘提示读取已保存的搜索快捷键并展示连接选中主机的 Enter 键，布局按工作区容器宽度改为单列。主机标题只保留收起按钮，新建入口保留在欢迎页和文件夹右键菜单。

主窗口默认 1280×820，最小 960×600 逻辑像素；恢复时按当前最小尺寸及显示器约束放大已存尺寸。resize/显示缩放事件在保存普通窗口尺寸前复核内容区域最小尺寸，纠正无系统装饰窗口的原生边框偏差，不保存低于限制的尺寸；最小化、全屏和最大化不执行该纠正。`HostSidebar` 在主机标题右侧提供收起入口，`AppNavigation` 将本地终端和设置固定在树下方，列表独立滚动。侧栏收起为 52px 图标栏，展开入口在顶部，本地终端和设置在底部；树保持挂载以保留搜索和展开，切换后将焦点移到对应入口，窄窗口使用浮层。

主窗口关闭系统窗口装饰，由 `AppHeader` 合并标题栏与工具栏，沿用主题变量。Windows WebView 使用 `app-region: drag` 识别原生拖动区域，按钮显式使用 `no-drag`；Tauri 的 `data-tauri-drag-region="deep"` 为其他运行时提供非交互区域拖动与双击最大化，按钮由运行时排除。`useWindowControls` 通过当前窗口 API 最小化、切换最大化和请求关闭，并监听 resize 同步最大化/还原图标，卸载时释放监听；调用失败进入统一错误通知，浏览器预览不创建窗口 API。主窗口 capability 只增加所需窗口权限，不向插件或独立编辑器开放；关闭调用 `Window.close()` 触发已有 Rust `CloseRequested` 审核，再由确认退出用例排空资源，不直接销毁窗口或退出进程。

主窗口与独立编辑窗口创建时，通过 Tauri `initialization_script_for_all_frames` 在文档脚本执行前向顶层页面及所有子框架注入统一的 `contextmenu` 捕获监听。监听只调用 `preventDefault`，不阻止事件传播，屏蔽浏览器默认菜单并保留业务菜单；覆盖受限插件 iframe，无需修改或重装插件包。主界面保留前端监听以支持浏览器预览。

设置窗口独立于活动工作区。通用/终端/快捷键/存储共用草稿，模型和插件分别保存；忙碌和未保存保护控制关闭及分类切换。模型的本地/远程 Tab 持续挂载，不因切换中断下载。工作区插件设置使用独立弹窗，不改变底层业务页可见性；配置写入成功只向同插件推送运行期 `settingsRevision`，不广播配置正文或刷新业务列表。

已保存的 `zh-CN`/`en-US` 驱动响应式界面语言，桌面、SDK 和内置插件各自维护字典。只翻译 UI，用户内容和原始诊断保持原文。插件通过公开 context 接收语言，不重挂载页面或重新授权；独立编辑器下次打开读取偏好。配置不可读的启动错误采用双语。

关闭主机先禁止新提交，审核文档/草稿、确认取消传输，再排空提交与清理，关闭文件租约、终端和插件 owner；成功后清除该主机临时记录，失败保留工作区。切页仅隐藏，不执行关闭流程。

## 主机与凭据

### 主机目录、测试和导入

SQLite 持久化 HostId、多级文件夹及 SSH 参数。文件夹防环，删除时事务性提升主机和直接子文件夹。主机按名称/地址/用户名搜索，保留现存数据库附加数据但不将其作为当前 DTO。

`host_test` 使用完整草稿和实际路由握手、核验指纹并认证，完成即断开。五分钟单次结果绑定草稿、原主机、路由和凭据修订；tested 创建/更新提交前复验。移动、复制和导入使用各自受控用例。

OpenSSH Config 解析限 1 MiB、10000 行、500 个明确别名。支持 Host/HostName/Port/User/IdentityFile/超时/Keepalive 和受管 ProxyJump，遵循 first-value-wins。通配符不展开资产，不执行 ProxyCommand；Include/Match、多身份或未知关键项无法安全确定时拒绝。跳板最多四层，拒绝循环、缺失和冲突。提交重新解析并按依赖事务导入，重复跳过，不覆盖或写回原文件。

### 秘密与一致性

NativeStore 使用系统凭据库，服务名 `cn.hiboot.desktop.credentials.v1`；SQLite 只存 opaque 引用、类型和 revision，秘密 DTO 不实现 Debug/Serialize，Rust 使用 Zeroizing。

新秘密先登记 `secret_gc` 意图，再写新系统 entry；SQLite 事务切换引用，提交后清理旧 entry，失败补偿或保留重试意图。主机认证变更创建独立凭据，不改写其他主机仍在使用的共享认证；显式共享凭据不自动删除。系统库不可用明确失败。

## SSH 和终端

持久 HostId 与运行期 ConnectionId/SessionId/TaskId 分离。Transport 复用键包括主机、端点、用户、认证/秘密修订、跳板链、代理和超时；配置变化不能复用旧认证上下文。

```text
连接：Disconnected → Connecting → AwaitingHostTrust → Authenticating → Connected
      → Disconnecting → Disconnected / Failed
会话：Creating → Running → Closing → Closed / Failed
```

应用自己的 known-hosts 按规范 hostname+port 保存完整公钥、SHA-256 和信任时间。未知主机认证前等待用户核验，challenge 60 秒；已知密钥变化硬拒绝，证书默认拒绝。系统 known_hosts 哈希/CA/撤销未接入。本地 RSA 私钥签名被禁用。

每终端拥有独立 PTY、取消令牌和任务；文件、Monitor、执行分别持租约。关闭一个 Channel 不误关其他租约，无引用时释放 Transport。同步锁只覆盖短注册表操作，不跨 await。

Windows 管理员本地终端由 `crates/windows-terminal` 封装 `ShellExecuteExW(runas)`、进程令牌查询、命名管道身份校验和 Job Object。宿主只通过主窗口专用 IPC 请求启动当前 EXE 的固定 PTY 代理模式；代理在 Tauri、单实例、存储、凭据和插件初始化前分流，仅运行既有本地终端引擎。系统 UAC 只提升该代理及其 PowerShell，主程序不重启、不提权，不接受自定义程序、命令或 Shell 路径。

每个代理使用独占随机命名管道，拒绝远程客户端，ACL 仅允许当前用户、管理员和 Local System。宿主以 UAC 返回的进程句柄核验管道客户端 PID，代理核验服务端 PID 与宿主 EXE 路径，且使用 identification 级连接禁止宿主模拟管理员令牌。协议有版本与帧长上限，输入、尺寸、序号沿用本地引擎校验；输出继续按 xterm ACK 背压。代理先确认实际提权，再建立 PTY；断线、取消、超时与退出触发清理，Job Object 在代理退出时回收受管后代，主程序等待代理退出后完成会话回收。UAC 提示尚未响应时不能强行关闭系统授权窗口，应用退出须先等待用户允许或取消；等待超时保留工作区并报告失败。该能力不开放给插件。

PTY 每块最多 16 KiB，经 Tauri Channel 送入 xterm，写入回调 ACK 后读取下一块；输入/resize 独立且有界，resize 合并。russh 内部仍有非全有界队列，不承诺恶意服务器下进程硬内存限额。

前端 Tab、PaneKey、Session 分离，分屏二叉树只算几何，固定 PaneKey 保持 xterm；每标签最多八窗格，全应用最多 32。generation 隔离迟到输出、剪贴板和连接结果。重连先安全关闭旧 Session，再按序列清空终端状态并开新 Shell，不重放动作/票据；断开保留画面，非连接状态禁输入并停止光标闪烁。

后台窗格及离开终端页后的工作区保持挂载，移出视口并以 visibility 隐藏，使用 inert 和 aria-hidden 禁止交互及辅助技术访问；继续处理输出、协议和 ACK，不重建 Shell。保留可测量的字体布局，避免 display:none 下 xterm DOM 选区刷新反复得到零字符宽度、无法缓存并挤占前台线程；视口外的常规绘制由 xterm 自身暂停。回到前台后重新适配几何与焦点。

状态栏只订阅当前可见窗格，从 SSH 握手读取目标实际算法，从 xterm 读取行列和光标，不额外执行远程命令。HTTP/HTTPS 链接经专用 IPC 校验后交系统浏览器。剪贴板仅用户动作触发，单次最多 2 MiB，大粘贴先确认。窗口 resize 可强制可见普通缓冲到底部，其他布局适配保留用户历史阅读。终端内容、布局与会话不持久恢复。

首跳支持 SOCKS5/HTTP CONNECT，跳板通过嵌套 SSH 逐跳信任。底层转发归 Session 所有，默认回环、公共绑定确认、断线释放，不自动恢复；当前 UI 无管理入口。

rz 经原生选择器发放绑定终端的一次性文件句柄，分块上传、不阻塞输出 ACK，与普通输入隔离。当前 Shell 拖放使用原生一次性授权、受限扫描和临时 tar，经原 PTY 的固定接收脚本继承真实用户/目录；随机 nonce、逐块 ACK、SHA-256、私有暂存及不覆盖提交约束范围，与 rz 互斥。仅确认接收端恢复后解除输入隔离，未知结果要求关闭会话；容量/速度只统计已确认字节，恢复焦点前复验原窗格。拒绝链接和特殊文件，不保证断线清理或跨重启恢复。

## SFTP、传输和编辑

普通 Files 租约请求 SFTP 子系统，各传输独立 Channel，请求、扫描和响应有界。文件页导航和历史按主机隔离，请求代号丢弃旧响应，失败保留原目录。Windows 磁盘枚举通过专用原生接口，不启动 Shell；目录下拉只是规范路径提示，不授予权限。桌面和插件共用 SDK `paths.displayLocalPath`，仅在本地路径的展示与复制时将扩展盘符/UNC 路径转换为普通形式；原生插件传输确认采用相同显示规则。Store、授权、传输及未修改的目录输入继续使用原始路径，不处理远程路径或其他 Windows 命名空间。

`files_switch_user` 仅主窗口可用，通过当前 SSH 账号 sudo 权限运行目标用户外部 sftp-server，不复用其他 Files 租约。候选通道读取成功且原连接无传输/文档才切换；失败释放候选并保留原连接。固定包装、唯一密码提示、无 PTY、超时/关闭清理，sudo 密码只留租约内存；插件只使用登录用户租约。

传输状态为 queued/scanning/running/verifying/completed 或 cancelling/cancelled/failed。默认每主机三个活动任务、可配置 1–6，全局最多 12 活动；降低并发不抢占已开始任务。界面冲突策略为 fail/skip/overwrite，底层还支持 rename；任务不跨进程恢复。

上传/下载在目标同目录独占暂存、流式写入并回读 SHA-256，复验源和目标后受控提交。递归不跟随链接，显式文件链接在读取及提交前复核。提交临界区等待结果，取消不撤销已提交内容，清理失败给出恢复路径。Windows 窗口外拖放用 Shell 虚拟文件按需读取，共用传输校验。

### 编辑器边界

Monaco/worker 本地按需加载，桌面一次打开一个内置或外部文档；底层八文档配额不代表桌面多窗口编辑。内置文本限严格 UTF-8 普通文件 2 MiB。保存核对原始 hash、大小、时间和 uid/gid/mode，暂存后保留并复核基础元数据，使用 OpenSSH posix-rename；失败不降级 unlink 或原地截断。

`editor_open` 绑定唯一文档并创建独立顶层 WebviewWindow。专用 capability 仅允许实际调用窗口绑定文档的加载、dirty、保存、重读、关闭和剪贴板；主窗口只接收摘要，不同步正文。读取/保存/关闭互斥，失败保留草稿。编辑器打开期间阻止所属连接关闭、切用户、数据目录迁移和页面重载；意外关闭没有持久草稿恢复。

Windows 外部编辑下载至独立 `external-edits/edit-*`，属性与哈希校验后才交系统选择器；原生 token 固定远程身份/路径及本地副本，回传须用户确认并复用冲突/原子保存。外部会话持续计入关闭保护，副本结束后保留，不自动恢复授权。二进制不转换编码。

原子替换改变 inode，SFTP v3 无服务端 CAS，ACL/xattr/硬链接及最终检查至 rename 竞态不能完整保证；提交后断线可能未知，须重新核对。插件文件请求另受更小配额和授权根约束，见 SDK。

## 插件和模型

Host/Rust/TS SDK 5.6.0，UI 4、ABI/wire 1。独立前端在受限 iframe，通过认证 MessageChannel 调用本包 action 和通用平台能力；WASM 无 WASI，受 fuel、内存、消息和并发限额。完整包、权限和生命周期见[插件架构](../plugins/PLUGIN_ARCHITECTURE.md)及[公开 SDK](../plugins/PLUGIN_SDK.md)。

一个安装修订共享有界 VM，每页有可信 owner；资源绑定插件/安装/VM/owner，目标另绑定 SSH 或模型修订。审批保存原 Future/请求，批准或拒绝从原等待点续接，不重跑动作。固定命令、交互会话和任务读取预授权是独立权限，不能互相替代或推断只读；完全访问由宿主首次批准并在当前会话持续有效，撤销不得被迟到批准恢复。

system 来源由发行流程写入，仅影响分发和预置授权；上传包默认禁用/未授权，同 ID 不继承来源。构建自动发现完整源码目录，统一校验和安装；单插件记录故障隔离，原件保留。用户明确备份重装后新记录默认禁用且不继承旧授权。包尚无密码学签名验证。

Docker 管理页面、Compose、解析和日常容器/镜像命令归 Docker 插件；资产匹配、脱敏、提示词、连续工具循环、计划及按需 Skill 加载归助手。匹配与执行都使用成对对话历史及明确的入口主机上下文，任务需要来源且未另行指定时采用当前工作区；保留运维所需的主机地址和原始匹配 ID，凭据继续脱敏。两个插件复用独立的镜像归档脚本模块，导出使用固定脚本与受限 argv，宿主的普通执行和长任务通道共用严格模板及审批模式校验。助手由模型组合镜像导出/导入、普通传输等工具并复查目标镜像 ID/标签，不在执行器中固定迁移流程。宿主只提供连接/执行/文件/模型/审批等原语，不按插件 ID 提供业务后门。助手工具、任务、局部文件修改、传输、流式脱敏和限额见[助手架构](ASSISTANT_AGENT.md)。

Docker 镜像归档由插件编排本机选择、SFTP 队列及受主机修订绑定的长命令流，使用独立的 `sftp.transfer.preapproved` 与交互预授权，使点击操作后无需逐次确认，不受单次 Execute 的 30 秒限额限制。命令流在 `/tmp/serverdeck-image-<nonce>/` 创建私有目录，导入等待原子上传文件后 load，导出复核标签指向完整 ID 后 save 并等待下载；完成标记绑定随机 nonce。UI 先取消并排空文件传输，再停止命令流；远端脚本跟踪并终止子 CLI，退出时仅删除已知归档并尝试移除空目录，不递归清理未知内容。SSH 断线与异常退出无法保证远端收尾，失败显示暂存位置，Docker daemon 已接受的变更不保证回滚。通用下载原语复用 SFTP 的暂存、双端 SHA-256 和不覆盖提交，并持续校验 owner、安装、权限、SSH 及配置修订；宿主不理解镜像或执行 Docker 专用逻辑。镜像页面按原生传输状态与实际字节数区分传输、校验提交、Docker 加载及清理；字节传完即隐藏吞吐速度，收到已校验的 completed 后才继续下一阶段，清理返回后才报告整体成功。远端 SHA-256 通过 SFTP 回读，可能在字节进度已满后继续占用网络和磁盘。

远程模型注册/关键修改先测试，300 秒单次凭证绑定配置、Key 和编辑身份；Key 不回显，更改地址须新输入或明确清除。模型修订变化使旧请求/计划失效。流式传输只承载真实上游增量，由插件解析和最终校验；片段不能批准执行。

本地 Codex/Claude Code 独立授权，由 CLI 管理登录；Native 保存授权/版本和配置摘要，不导入登录秘密。临时目录、会话、有界 I/O、禁用工具/hooks/MCP 及进程取消控制执行面。安装器单并发，从固定官方源校验并原子安装到应用专用目录，不改 PATH 或覆盖用户程序；自动下载覆盖 Windows x64/ARM64，其他平台手动准备。

## 持久化、日志与退出

当前 SQLite schema 为 11，应用偏好和模型注册为 v2。数据升级是现行能力，连续 SQL、固定配置转换、迁移历史及备份规则见[数据升级契约](DATA_MIGRATIONS.md)。数据库内保留的兼容数据不自动加载为功能或授权。应用设置不保存密码、私钥、模型 Key 或对话正文。

SQLite/系统库阻塞工作进入有界 `spawn_blocking`；元数据单任务，最多 16 个在途/等待，等待三秒后 BUSY。数据库 busy timeout 五秒，业务连接启用外键，不引入连接池或主动 WAL 模式。

数据根由默认配置位置的 `storage-location.json` 定位。用户主动搬迁时正常退出，再在目标专用暂存复制、核对清单/摘要/数据库并启动确认，随后逐文件核验清理源；链接、非空/嵌套目标拒绝，变化或未知源文件保留。Copied 未确认可回到源，Committed 不回退部分清理的源；系统凭据不复制。Windows 等待源写句柄释放后再快照，持续占用或校验失败保留原数据和失败证据。

迁移 IPC 成功仅表示登记并安排重启，不能显示为搬迁完成；`app_storage_ready` 返回本次启动的新结果用于通知，持久结果留设置页，不在普通启动重复弹出。准备失败解除忙碌并保留草稿。

tracing 只记安全类别，不记敏感载荷，依赖日志默认关闭；数据库升级前以 Info 初始化，之后读取保存级别。队列 512 条，当前及三个轮转文件各 1 MiB，总量 4 MiB，超额日志丢弃不吞业务错误。

确认退出后拒绝新用例，取消并排空安装、插件/VM、模型、上传及本地终端，再释放执行、Ops、Monitor、文件和 SSH/转发，最后等待元数据并刷新日志。取消退出保留原状态，不通过强杀代替正常退出。
