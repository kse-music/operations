# 桌面工作区与设置

本文说明窗口、工作区、设置和界面资源的实现。系统入口见[总体架构](ARCHITECTURE.md)，日常操作见[使用说明](https://ops.hiboot.cn/docs/)。

## 工作区、设置和语言

Workspace 将全局入口 `area`（首页、本地终端、批量命令、设置）与运行期设备/插件标签分开管理；切换入口只改变可见性，保留首页活动标签、本地最近会话、批量命令状态及设置分类。`homeTabs` 从运行期标签中过滤本地工作区，首页标签渲染、批量关闭范围与关闭后的相邻选择均使用该列表；本地会话保留于本地终端入口，无首页标签时回到“首页”欢迎页。HostId 是持久目标，活动页变化不能修改已有资源的目标。`HostTools` 显示概览、SSH、SFTP、端口转发和启用插件，主机保存本次打开期间的最近工具、会话和路径。

`HostOverviewView` 为打开的主机工作区按 HostId 和连接配置在内存中保存最近一次样本和最近一次有效的 CPU 使用率及其时间。主窗口用 Terminal Channel 处理 SSH 状态和指纹确认，以会话 ID、HostId 和修订读取采样快照。界面保留最近使用的一个已连接 Monitor 租约，隐藏时调用 `monitor_visible` 暂停采样和前端轮询，再次可见时继续使用该租约。切换采样目标、变更连接配置、隐藏尚未完成的连接或关闭对应工作区会排队释放旧租约，下一次开启等待之前的清理。关闭工作区时清除其样本，主窗口重载由宿主排空旧租约。手动刷新唤醒现有采样循环并保留差分计数，连接结束后重新打开。挂载入口携带主机和原始路径，校验主机连接配置后切到 SFTP；文件 Store 对未就绪连接保留最近一次显式请求，按实际 SFTP 会话完成列表读取与目录记录。

`BatchCommandsView` 首次进入时挂载，切换入口后保持实例。命令列表通过第二栏专用挂载点显示，第三栏直接渲染可滚动的内容区。编辑时将名称、SSH 文本、目标和并发上限作为统一草稿保存，也可从已保存的快照还原草稿。目录筛选复用 `HostFolderPicker`，将根选项显示为「全部目录」。目录及标签筛选仅影响可见主机。并排布局按主机列表高度伸展 SSH 输入框，使两者底部对齐。

列表和编辑页通过同一入口运行已保存的命令，取得宿主票据后直接启动批次。包含生产目标或重试连接失败时先进入确认页，生产确认标记由宿主复验。每次发送仅消费宿主返回的票据，页面不自行构造 SSH 连接。右侧轮询按批次 ID 和修订跳过未变化的快照。执行结果按内容区宽度切换并排和上下布局，所选主机的标准输出与错误输出使用同一滚动区，切换主机时回到该区顶部。切换入口保留轮询与编辑草稿，界面最多保留八条命令各自的最近结果。

首页没有活动工作区或选择“首页”标签时，`WelcomeView` 展示本地终端主卡片、新建和导入入口、主机工具及快速上手。目标列表复用 `filterHosts` 的名称排序。主机 Store 在内存中分别保存首页工具目标 `homeTargetId` 和主机列表选中项 `selectedId`，目录刷新时清除失效的 ID。首页目标为空或失效时使用排序后的首台有效主机。零主机、单主机和多主机分别展示添加引导、目标名称和选择器。主机目录未加载、加载中及读取失败与成功空目录分开，重试复用主机 Store。

首页的 Docker 与助手卡片只读取本地插件 Store，复用 `primaryPluginPage` 和 `extensions` 的当前版本 UI 授权判定；未安装、未启用、授权不可用分别路由到插件管理或现有配置页，不自动改变授权。插件刷新失败时保留状态和重试，禁用插件快捷打开，SFTP 仍可独立访问。模型绑定通过助手的设置贡献进入，不为首页执行插件、读取模型秘密或探测远端能力。`WelcomeView` 发出目标明确的文件、插件、配置及管理事件，由 `App` 复用现有导航、工作区和弹窗流程；选择目标和渲染首页不创建连接或 Shell。键盘提示读取已保存快捷键，布局按工作区容器宽度换行或改为单列，使用既有主题和界面字号。新建入口保留在欢迎页和文件夹右键菜单。

### 窗口与原生交互

主窗口默认 1280×820，最小 960×600 逻辑像素；恢复时按当前最小尺寸及显示器约束放大已存尺寸。resize/显示缩放事件在保存普通窗口尺寸前复核内容区域最小尺寸，纠正无系统装饰窗口的原生边框偏差，不保存低于限制的尺寸；最小化、全屏和最大化不执行该纠正。`AppNavigation` 固定在第一栏，主机、本地会话、批量命令与设置的菜单共用第二栏，第三栏为内容工作区。

`useWorkspaceSidebar` 独立记录主机栏与本地保存会话栏在本次运行中的固定状态，两栏初始均为固定展开。自动隐藏时第二栏网格轨道宽度为零，短线作为窗内的独立触发按钮。预览复用第二栏实例并以绝对定位覆盖内容区，切换工作区时取消定时器和预览。侧栏内的键盘焦点、编辑控件及其通过 Teleport 渲染的菜单可以保持预览。键盘主动开合和固定切换时将焦点交给可见按钮。固定后显示拖动柄，常驻栏和预览都使用 `sidebarWidth` 对应的显示宽度。`v-show` 保留列表实例、搜索、目录和滚动位置。

`TerminalsView` 共用横向会话标签。本地标签渲染在工作区终端上方，SSH 标签通过 Teleport 放入主机工具栏下方。第二栏的本地 `SavedTerminalSessions` 与主机右键子菜单共用保存记录组件。预览和固定切换保留 PaneKey、xterm 实例及 PTY。浮层预览保持终端尺寸，固定状态或栏宽引起的尺寸变化沿用 `ResizeObserver` 调整终端。

主窗口由 `AppHeader` 合并标题栏和工具栏。macOS 在 Rust 创建主窗口时启用系统装饰和 `TitleBarStyle::Overlay`，将系统按钮与 44px 工具栏对齐，并隐藏系统标题。`AppHeader` 在 macOS 非全屏时为左侧系统按钮留位，全屏时收起留位。Windows 和 Linux 使用右侧自绘按钮与无系统装饰的窗口。Windows WebView 使用 `app-region: drag` 识别原生拖动区域，按钮显式使用 `no-drag`。Tauri 的 `data-tauri-drag-region="deep"` 提供非交互区域拖动与双击最大化，按钮由运行时排除。

`useWindowControls` 挂载后和收到原生 resize 事件时读取窗口状态，macOS 读取全屏状态，Windows 和 Linux 同步最大化/还原图标。卸载时释放监听，调用失败进入统一错误通知。macOS 系统按钮和自绘按钮的 `Window.close()` 都经由主窗口的 Rust `CloseRequested` 进入退出审核，确认后排空资源。窗口控制权限限于主窗口，其中前端全屏查询仅授予 macOS 主窗口。独立 SFTP 编辑器使用系统标题栏显示文件名，关闭进入编辑器的未保存审核。

品牌标识使用 `apps/desktop/src/assets/serverdeck.svg`，标题栏直接引用同一矢量源；`npm run icons:generate` 通过已有 Tauri CLI 生成桌面 PNG、Windows 多尺寸 ICO 和 macOS ICNS 到 `src-tauri/icons/`，任务栏和打包资源由现有 Tauri 图标配置引用。`build.rs` 显式跟踪 `icons/` 目录，图标变更时开发与发布构建都会重新编译原生图标资源，避免复用旧的 Windows 资源缓存。

主窗口与独立编辑窗口创建时，通过 Tauri `initialization_script_for_all_frames` 在文档脚本执行前向顶层页面及所有子框架注入统一的 `contextmenu` 捕获监听。监听只调用 `preventDefault`，不阻止事件传播，屏蔽浏览器默认菜单并保留业务菜单；覆盖受限插件 iframe，无需修改或重装插件包。主界面保留前端监听以支持浏览器预览。

### 设置与偏好保存

`HostSidebar` 在主窗口 WebView 的本地存储中保存已收起的文件夹 ID，初始化时恢复，首次使用时默认全部展开。成功读取主机目录后清理失效 ID。搜索渲染临时展开匹配分支，选择其他主机或新建文件夹时沿用祖先展开行为。读取失败回到默认状态，写入失败时当前窗口仍可展开和收起。

`SettingsView` 在第三栏按需挂载并在全局切换时保持。`useSettingsAutosave` 管理偏好草稿和已保存基线：通用、终端、快捷键、数据与存储的普通偏好在修改后以 300ms 防抖校验并串行保存，写入使用独立快照，保存期间的新修改继续排队；外部配置更新合并未编辑字段。下载目录、传输并发和日志级别直接复用同一自动保存链路。数据根目录由迁移状态独立维护，不进入偏好写入载荷，也不参与普通偏好的表单有效性校验；仅独立的“迁移并重启”入口校验完整表单并打开迁移预览，确认后沿用既有迁移和重启协议。校验失败不写入，存储失败保留草稿并允许重试。关闭设置先尝试提交有效的待保存偏好，再复用剩余修改的放弃确认；界面字号即时预览，成功后持久生效。模型和插件分别保存，模型的本地/远程 Tab 不因切换全局入口中断下载。设置忙碌状态阻止入口与分类切换。工作区插件配置统一进入设置页面；业务页隐藏时 `active=false`，返回时复用原 owner 和页面。配置写入成功只向同插件推送运行期 `settingsRevision`，不广播正文或强制刷新业务列表。

设置成功反馈留在页面内。普通偏好保存与插件管理不写入全局通知；插件配置页的桥接通知仅展示标记为错误的消息，配置页继续维护自己的状态。数据目录迁移在确认框内显示准备和重启进度，启动时由 `storageReady` 返回的一次性结果进入全局通知。

环境标签设置与主机右键菜单共用主机目录 Store。侧栏、工作区标签和宿主确认框以各自的目标 HostId 读取当前标签，跨主机复制和多主机插件审批可同时展示多个已打标的目标。插件审批的身份由原生请求、文档或传输绑定解析，宿主展示层消费这些 ID，标签数据不进入插件 iframe。标签只作显示，未参与授权、信任、会话重连、任务路由或审批摘要校验。

### 语言与控件

已保存的 `zh-CN`/`en-US` 驱动响应式界面语言，桌面、SDK 和内置插件各自维护字典。只翻译 UI，用户内容和原始诊断保持原文。插件通过公开 context 接收语言，不重挂载页面或重新授权；独立编辑器下次打开读取偏好。配置不可读的启动错误采用双语。

桌面和内置插件共享 SDK 基础控件样式。按钮与表单控件的 `:focus-visible` 统一关闭额外描边，保留控件常规边框和键盘聚焦、激活行为；主机树、菜单及搜索结果沿用背景定位提示，分隔条保留独立焦点样式。单选下拉框在支持 `appearance: base-select` 的运行时使用浏览器可定制选项层，以主题 `--accent-bg` 显示选中、悬停及键盘定位状态，保留原生 select 的值、禁用、校验与 Vue 绑定；旧运行时沿用原生控件。目录等自定义选择器复用同一背景色，全局搜索独立维护未选择或活动结果索引，输入焦点不自动选择第一项。

### 关闭与后台任务

关闭主机先禁止新提交，审核文档/草稿、确认取消传输，再排空提交与清理，关闭文件租约、终端和插件 owner；成功后清除该主机临时记录，失败保留工作区。切页仅隐藏，不执行关闭流程。宿主为仍打开的工作区保留插件命令流和运行期任务；Assist/Full 仅继续符合精确自动审批规则的步骤，高风险计划等待返回可见页。交互 PTY仍在隐藏时关闭，关闭 owner或撤权释放自有命令流和传输。
