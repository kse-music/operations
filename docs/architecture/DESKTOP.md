# 桌面工作区与设置

本文说明窗口、工作区、设置和界面资源的实现。系统入口见[总体架构](ARCHITECTURE.md)，日常操作见[使用说明](https://ops.hiboot.cn/docs/)。

## 工作区、设置和语言

Workspace 将全局入口 `area`（首页、本地终端、设置）与运行期设备/插件标签分开管理；切换入口只改变可见性，保留首页活动标签、本地最近会话及设置分类。`homeTabs` 从运行期标签中过滤本地工作区，首页标签渲染、批量关闭范围与关闭后的相邻选择均使用该列表；本地会话保留于本地终端入口，无首页标签时回到“首页”欢迎页。HostId 是持久目标，活动页变化不能修改已有资源的目标。`HostTools` 显示 SSH、SFTP、端口转发和启用插件，主机保存本次打开期间的最近工具、会话和路径。

首页没有活动工作区或选择“首页”标签时，`WelcomeView` 展示工具启动台：本地终端主卡片、新建/导入入口、主机工具和快速上手。目标列表复用 `filterHosts` 的名称排序与 `HostSidebar` 共用的 `selectedId`，不新增持久配置；当前选择无效时回落至首台有效主机。零主机、单主机和多主机分别展示添加引导、目标名称和选择器。主机目录未加载、加载中及读取失败与成功空目录分开，重试复用主机 Store。

首页的 Docker 与助手卡片只读取本地插件 Store，复用 `primaryPluginPage` 和 `extensions` 的当前版本 UI 授权判定；未安装、未启用、授权不可用分别路由到插件管理或现有配置页，不自动改变授权。插件刷新失败时保留状态和重试，禁用插件快捷打开，SFTP 仍可独立访问。模型绑定通过助手的设置贡献进入，不为首页执行插件、读取模型秘密或探测远端能力。`WelcomeView` 发出目标明确的文件、插件、配置及管理事件，由 `App` 复用现有导航、工作区和弹窗流程；选择目标和渲染首页不创建连接或 Shell。键盘提示读取已保存快捷键，布局按工作区容器宽度换行或改为单列，使用既有主题和界面字号。主机标题右侧提供收起按钮，新建入口保留在欢迎页和文件夹右键菜单。

### 窗口与原生交互

主窗口默认 1280×820，最小 960×600 逻辑像素；恢复时按当前最小尺寸及显示器约束放大已存尺寸。resize/显示缩放事件在保存普通窗口尺寸前复核内容区域最小尺寸，纠正无系统装饰窗口的原生边框偏差，不保存低于限制的尺寸；最小化、全屏和最大化不执行该纠正。`AppNavigation` 固定在第一栏，`HostSidebar`、本地会话列表和 `SettingsNavigation` 共享第二栏；第三栏为内容工作区。第二栏展开时复用 `sidebarWidth` 配置及拖动保存。`App` 分别管理主机栏和本地会话栏的运行期收起状态，标题与窄栏共用 `SidebarToggle`，收起后列宽为 36px 且隐藏拖动柄；切到设置时保持菜单展开，不变更配置格式。列表使用 `v-show` 保留实例、搜索、展开目录与滚动位置，切换收起/展开后将键盘焦点移至可见的对应按钮。`TerminalsView` 将本地会话头通过 Teleport 放入常驻的第二栏目标，复用原会话行为；收起不更改终端可见性或销毁 PTY，内容区尺寸变化沿用 `ResizeObserver` 调整终端。本地第三栏不渲染工作区工具栏，终端填满内容区；SSH 会话头仍在第三栏工具栏，所有 PaneKey 和 xterm 实例保持。

主窗口关闭系统窗口装饰，由 `AppHeader` 合并标题栏与工具栏，沿用主题变量。品牌标识使用 `apps/desktop/src/assets/serverdeck.svg`，标题栏直接引用同一矢量源；`npm run icons:generate` 通过已有 Tauri CLI 生成桌面 PNG、Windows 多尺寸 ICO 和 macOS ICNS 到 `src-tauri/icons/`，任务栏和打包资源由现有 Tauri 图标配置引用。`build.rs` 显式跟踪 `icons/` 目录，图标变更时开发与发布构建都会重新编译原生图标资源，避免复用旧的 Windows 资源缓存。Windows WebView 使用 `app-region: drag` 识别原生拖动区域，按钮显式使用 `no-drag`；Tauri 的 `data-tauri-drag-region="deep"` 为其他运行时提供非交互区域拖动与双击最大化，按钮由运行时排除。`useWindowControls` 通过当前窗口 API 最小化、切换最大化和请求关闭，并监听 resize 同步最大化/还原图标，卸载时释放监听；调用失败进入统一错误通知，浏览器预览不创建窗口 API。主窗口 capability 只增加所需窗口权限，不向插件或独立编辑器开放；关闭调用 `Window.close()` 触发已有 Rust `CloseRequested` 审核，再由确认退出用例排空资源，不直接销毁窗口或退出进程。

主窗口与独立编辑窗口创建时，通过 Tauri `initialization_script_for_all_frames` 在文档脚本执行前向顶层页面及所有子框架注入统一的 `contextmenu` 捕获监听。监听只调用 `preventDefault`，不阻止事件传播，屏蔽浏览器默认菜单并保留业务菜单；覆盖受限插件 iframe，无需修改或重装插件包。主界面保留前端监听以支持浏览器预览。

### 设置与偏好保存

`SettingsView` 在第三栏按需挂载并在全局切换时保持。`useSettingsAutosave` 管理偏好草稿和已保存基线：通用、终端、快捷键、数据与存储的普通偏好在修改后以 300ms 防抖校验并串行保存，写入使用独立快照，保存期间的新修改继续排队；外部配置更新合并未编辑字段。下载目录、传输并发和日志级别直接复用同一自动保存链路。数据根目录由迁移状态独立维护，不进入偏好写入载荷，也不参与普通偏好的表单有效性校验；仅独立的“迁移并重启”入口校验完整表单并打开迁移预览，确认后沿用既有迁移和重启协议。校验失败不写入，存储失败保留草稿并允许重试。关闭设置先尝试提交有效的待保存偏好，再复用剩余修改的放弃确认；界面字号即时预览，成功后持久生效。模型和插件分别保存，模型的本地/远程 Tab 不因切换全局入口中断下载。设置忙碌状态阻止入口与分类切换。工作区插件配置统一进入设置页面；业务页隐藏时 `active=false`，返回时复用原 owner 和页面。配置写入成功只向同插件推送运行期 `settingsRevision`，不广播正文或强制刷新业务列表。

设置成功反馈留在页面内。普通偏好保存与插件管理不写入全局通知；插件配置页的桥接通知仅展示标记为错误的消息，配置页继续维护自己的状态。数据目录迁移在确认框内显示准备和重启进度，启动时由 `storageReady` 返回的一次性结果进入全局通知。

### 语言与控件

已保存的 `zh-CN`/`en-US` 驱动响应式界面语言，桌面、SDK 和内置插件各自维护字典。只翻译 UI，用户内容和原始诊断保持原文。插件通过公开 context 接收语言，不重挂载页面或重新授权；独立编辑器下次打开读取偏好。配置不可读的启动错误采用双语。

桌面和内置插件共享 SDK 基础控件样式。按钮与表单控件的 `:focus-visible` 统一关闭额外描边，保留控件常规边框和键盘聚焦、激活行为；主机树、菜单及搜索结果沿用背景定位提示，分隔条保留独立焦点样式。单选下拉框在支持 `appearance: base-select` 的运行时使用浏览器可定制选项层，以主题 `--accent-bg` 显示选中、悬停及键盘定位状态，保留原生 select 的值、禁用、校验与 Vue 绑定；旧运行时沿用原生控件。目录等自定义选择器复用同一背景色，全局搜索独立维护未选择或活动结果索引，输入焦点不自动选择第一项。

### 关闭与后台任务

关闭主机先禁止新提交，审核文档/草稿、确认取消传输，再排空提交与清理，关闭文件租约、终端和插件 owner；成功后清除该主机临时记录，失败保留工作区。切页仅隐藏，不执行关闭流程。宿主为仍打开的工作区保留插件命令流和运行期任务；Assist/Full 仅继续符合精确自动审批规则的步骤，高风险计划等待返回可见页。交互 PTY仍在隐藏时关闭，关闭 owner或撤权释放自有命令流和传输。
