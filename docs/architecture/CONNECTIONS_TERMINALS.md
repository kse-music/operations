# 主机连接、凭据与终端

本文说明 SSH 信任、连接复用、终端与上传协议。系统边界见[总体架构](ARCHITECTURE.md)，日常操作见[使用说明](https://ops.hiboot.cn/docs/)。

## 主机与凭据

### 主机目录、测试和导入

主机侧栏的“全部”和“收藏”视图共享 Hosts Store 的筛选和排序结果。“收藏”只渲染已收藏的主机，两种视图复用主机行和菜单。侧栏跳过虚拟根节点的标题，直接渲染未分组主机。列表空白处的右键菜单和聚焦列表后的键盘菜单使用顶层目标（文件夹 ID 为 null），主机和文件夹的菜单使用各自行目标，Esc 恢复触发点焦点。拖动分组仅在目录视图发起，放到列表空白处时移至顶层。星标使用主窗口私有 `host_set_favorite` 原位更新已有 `hosts.favorite`，成功后刷新星标；不改认证、分组、更新时间或已打开连接，不需重新测试 SSH。

共用 `Modal` 只处理 `<dialog>` 自身的 `cancel` 事件，忽略从文件输入等子控件冒泡的同名事件；取消私钥或 OpenSSH 配置文件选择不关闭外层表单。自身取消继续阻止浏览器直接关闭，并沿用 busy 守卫交由业务层处理，关闭按钮使用同一守卫。

SQLite 持久化 HostId、多级文件夹及 SSH 参数。文件夹防环，删除时事务性提升主机和直接子文件夹。主机按名称/地址/用户名搜索，保留现存数据库附加数据但不将其作为当前 DTO。

目录行是可聚焦容器，展开/收起由独立的左侧按钮处理，按钮携带当前 `aria-expanded` 和展开/收起名称，并阻止点击事件冒泡；目录名称、文件夹图标与计数点击聚焦并选中目录行，避免点击后立即隐藏待重命名的目标。`HostSidebar` 使用运行期目录选择状态，让目录与主机共享同一高亮样式且互斥；保留 Store 的主机目标，点击主机或外部切换主机目标时清除目录高亮，目录删除后同步清除失效选择。主机图标的左缘在各级目录下均与所属目录名称左缘对齐。行与箭头按钮上的 F2、Delete 和菜单键沿用同一目标与守卫，行内编辑期间禁用展开/收起按钮。

`HostSidebar` 将文件夹与主机的“重命名”菜单和行上 F2 路由到同一行内编辑状态，输入控件复用 `TreeRenameInput`。Enter/失焦提交、Esc 取消，输入法组合期间不提交；输入事件不冒泡到连接、目录展开、拖动或删除入口。根目录、非活动侧栏、忙碌、拖动、弹窗及带修饰键/连发的 F2 不启动编辑。`Hosts Store` 的名称更新沿用 `group_save` 和 `host_update`，从当前目录读取其他字段并保留；主机更新只更改 `name`，不传认证输入。成功后以服务端返回对象替换对应目录项，保留选择、筛选和连接；失败不修改原条目，行内保留草稿及错误，列表刷新、筛选变化或侧栏隐藏取消未提交编辑。`GroupManager` 仅负责新建文件夹。

`HostSidebar` 在主机和文件夹行处理 Delete，与右键菜单共用删除确认入口；目标取事件所在行，不依赖已选主机或活动工作区。仅处理可见主机树上无修饰键、非连发、非输入法组合的 Delete，弹窗、拖动或忙碌期间忽略；不在窗口注册全局删除键，搜索输入和终端不受影响。主机删除继续由 `HostTreeControls` 复用现有 IPC，文件夹删除沿用 `groupRemove`，均经确认后执行。行焦点用主题背景色提示。主机树菜单在窗口捕获阶段监听 `contextmenu` 关闭旧菜单，保留事件继续到达右键目标；外部 `pointerdown` 关闭时不抢回焦点，不设置全屏遮罩。与 SFTP 菜单互相切换时先关闭旧菜单，再由新目标打开菜单。菜单内按键及操作仍按原目标执行，Esc 恢复触发点焦点，滚动、窗口失焦和尺寸变化关闭菜单；组件卸载时移除全部监听。

`host_test` 使用完整草稿和实际路由握手、核验指纹并认证，完成即断开。五分钟单次结果绑定草稿、原主机、路由和凭据修订；tested 创建/更新提交前复验。移动、复制和导入使用各自受控用例。

桌面在导航到内置主机工具之前检查主机目录中的认证类型和凭据引用。密码或私钥认证缺少引用时，复用 `HostDialog` 并聚焦对应认证输入框。保存成功且主机目录刷新后继续原导航；关闭弹窗取消该次导航。已绑定的凭据、文件路径私钥及 SSH Agent 的验核继续由原生连接层执行。

`HostDialog` 在表单底部同一反馈元素中显示测试进度、成功或失败，不创建测试结果弹窗；失败使用 `error-text` 和 `role="alert"`，其他状态使用 `role="status"`，保留多行错误和长文本换行。重试或草稿修改清除旧测试状态，成功后启用保存，凭证过期后替换表单状态并禁用保存。首次指纹确认继续复用独立 `Modal`，拒绝或关闭不提交信任。

OpenSSH Config 解析限 1 MiB、10000 行、500 个明确别名。支持 Host/HostName/Port/User/IdentityFile/超时/Keepalive 和受管 ProxyJump，遵循 first-value-wins。通配符不展开资产，不执行 ProxyCommand；Include/Match、多身份或未知关键项无法安全确定时拒绝。跳板最多四层，拒绝循环、缺失和冲突。提交重新解析并按依赖事务导入，重复跳过，不覆盖或写回原文件。

导入目标由 `HostFolderPicker` 复用 `hostFolderRows` 和祖先路径计算渲染目录树，仅管理选择与展开状态；`ImportDialog` 继续将选中目录 ID（根目录为 null）传入原导入接口。目录菜单使用弹窗内的原生 Popover 顶层显示，按视口空间选择向上或向下展开并限制高度，避免受弹窗滚动区域裁剪；忙碌时禁用选择并关闭菜单。

### 秘密与一致性

主机树空白处的导入入口打开 `ImportDialog`，由对话框切换 SSH 配置和主机备份。备份导入和菜单中的导出调用主窗口的 `host_backup` 命令，通过原生文件对话框选择路径，仅向界面返回数量。`.sdhosts` 是上限 64 MiB 的版本化 JSON。v1 保存主机树、实际引用的主机和代理凭据以及树中端点的信任记录。v2 导出从同一个 SQLite 读事务获取目录与环境标签，增加必填的 `environmentTags`，保存全部定义和分配列表。导入仅接受既有结构的 v1 或带完整标签对象的 v2，并拒绝重复标签、重复分配和悬空引用。备份文件包含可直接用于认证的秘密；旧式文件私钥在导出时通过原连接解析器读取并用已保存口令转换，导入文件中不接受私钥路径。读取系统凭据或私钥失败时保留原备份，完整写入同目录临时文件并同步后才替换目标。

导入校验版本、配置、关联与公钥指纹。导入在同一 SQLite 写事务内按父目录和跳板依赖顺序映射记录。名称比较沿用 SQLite 的 NOCASE 规则；同名且映射后的父目录相同才复用，其他路径上的同名目录受全局唯一约束而阻止导入。主机按地址、端口和用户名查找，再比较规范化的完整配置（含映射后的目录和跳板）及登录、代理凭据的已保存内容。跳过的主机保留本地标识，并可作为新主机的跳板。同一备份凭据在新主机之间共享；只被跳过条目引用的凭据不会写入系统库。目录、主机、凭据引用和信任记录在同一事务提交，信任冲突整批回滚。系统库写入前持久登记清理意图，写入失败或中断可补偿清理。导入只恢复备份中已信任的端点，连接仍按当前服务器公钥逐跳校验。

环境标签定义与主机分配存于同一本机 SQLite 数据库。分配以主机 ID 为主键，并引用标签 ID；删除标签或主机时由外键在同一事务清理对应分配。标签名去除首尾空白，按 SQLite NOCASE 唯一，颜色使用固定枚举。“主机目录”在同一读取事务返回定义与分配，标签修改原子返回更新后的目录快照，不改写主机连接记录或时间戳。主机复制与分配复制同事务提交。

v2 导入在目录写事务内同时恢复标签定义和分配。无主机且仅含迁移写入的三条原始定义时，恢复备份里的完整定义。其他情况按 SQLite NOCASE 匹配定义，复用同名同色标签，同名异色则整批回滚。v2 为每条主机记录独立匹配可复用主机，避免丢失配置相同的主机各自的分配。优先匹配同标签主机，再考虑未打标主机。分配映射到本地的主机和标签 ID，仅为空白分配补上备份标签。v1 沿用原有去重规则和本机环境标签。

NativeStore 使用系统凭据库，服务名 `cn.hiboot.desktop.credentials.v1`。SQLite 只存 opaque 引用、类型和 revision。IPC 的秘密输入类型不实现 Debug/Serialize，原生备份编码器只向选定的文件序列化凭据，Rust 使用 Zeroizing。

Windows 单条系统凭据最多容纳 2560 字节。分配新秘密引用时，超过此长度的内容使用 `chunked:v1:<uuid>:<字节数>` 布局，每块不超过 2560 字节，以 `<引用>:<从零开始的块序号>` 保存到同一系统凭据服务；总长度限制为 1 MiB。引用在写入前确定完整块范围，既有 `secret_gc` 意图可清理写到一半的内容，删除中断后可重试。读取逐块校验长度，缺块或损坏明确失败，不把残缺私钥用于认证。未带分块版本前缀的已有引用继续按原始单条布局读取，不重写原凭据，也不改变数据库或配置版本；未知分块版本拒绝处理。新引用的凭据不支持由尚未识别该布局的旧客户端读取。

新秘密先登记 `secret_gc` 意图，再写新系统 entry；SQLite 事务切换引用，提交后清理旧 entry，失败补偿或保留重试意图。主机认证变更创建独立凭据，不改写其他主机仍在使用的共享认证；显式共享凭据不自动删除。系统库不可用明确失败。

## SSH 和终端

持久 HostId 与运行期 ConnectionId/SessionId/TaskId 分离。Transport 复用键包括主机、端点、用户、认证/秘密修订、跳板链、代理和超时；配置变化不能复用旧认证上下文。

```text
连接：Disconnected → Connecting → AwaitingHostTrust → Authenticating → Connected
      → Disconnecting → Disconnected / Failed
会话：Creating → Running → Closing → Closed / Failed
```

应用自己的 known-hosts 按规范 hostname+port 保存完整公钥、SHA-256 和信任时间。未知主机认证前等待用户核验，challenge 60 秒；已知密钥变化硬拒绝，证书默认拒绝。系统 known_hosts 哈希/CA/撤销未接入。私钥导入与路径认证共用解析和解锁，支持 Ed25519/ECDSA/RSA；RSA 按服务器 `server-sig-algs` 协商 SHA-512 或 SHA-256，未声明 SHA-2 时返回 `SSH_RSA_SHA2_REQUIRED`，不使用 SHA-1。工作区固定 russh 上游提交以使用已修复 RUSTSEC-2023-0071 的 `rsa 0.10.0`，具体依赖及审计边界见[安全说明](../release/SECURITY.md#日志依赖与发布)。

每终端拥有独立 PTY、取消令牌和任务；文件、Monitor、执行分别持租约。关闭一个 Channel 不误关其他租约，无引用时释放 Transport。同步锁只覆盖短注册表操作，不跨 await。

### 批量命令

主窗口专用 IPC 从版本化命令列表读取已保存的命令及修订。原生预览冻结目标身份、环境标签和 SSH 路由签名，五分钟内可单次确认。发送时复验命令和目标清单，队列中的每台主机再按冻结的路由签名核对连接计划。命令文本经非交互 SSH exec 发送，不拼接本地 Shell 命令。

批次使用独立 SSH 租约与已有所有跳板的主机密钥校验，首次未知密钥由主机连接处理。租约可复用匹配的已验证传输，从插件运维连接列表隔离。全应用一个活动批次，最多五个执行工作者，命令共享有界执行槽。每台主机完成后释放自己的租约，连接、执行、输出及取消状态分开。退出取消批次并等待工作者释放租约，再关闭通用 SSH 引擎。应用内日志仅记录安全错误类别。

### 本地目录与手动保存

Windows 本地 PowerShell 启动时通过固定的 UTF-16 编码脚本安装进程内提示符钩子，不改用户配置文件。提示符以带本会话随机标识的 OSC 报告 `$PWD.ProviderPath`；宿主按字节流有界解析，支持跨 PTY 帧的 UTF-8，仅接受绝对文件系统路径，并按会话去重。指定目录以 `CommandBuilder.cwd` 传入，PowerShell 从专用启动环境变量以 `Set-Location -LiteralPath` 设置 provider 位置并移除该变量，按字面处理含方括号等字符的目录。对于 Windows 扩展盘符及 UNC 路径，常规形式在传统路径长度内且解析为同一目录时，PowerShell 使用常规形式设置位置。恢复已保存会话时，目录失效后回到用户主目录。从文件页启动时，显式指定的目录须可访问，否则报告启动失败。嵌套 Shell 和自定义提示符不作为可靠报告源。

本地目录报告只写入对应运行期 Control 的内存快照，不读取全局最近路径，也不触发数据库写入。普通新建、复制和新增分屏保持主目录启动；`terminal_local_open` 接受文件页传入的可选起始目录，`terminal_local_open_saved` 按持久会话 ID 与窗格索引读取已保存目录。非文件系统提示符清空该窗格的可保存目录，未知目录或已结束的未保存 Shell 拒绝生成快照。保存输入只接受运行期本地 SessionId 与索引布局，由宿主取目录和真实提权状态，不允许前端提交任意 Shell 或恢复旧授权。

Windows PowerShell 从当前子进程的环境读取应用内置的初始化脚本，固定长度的启动命令先移除脚本环境变量，再执行脚本。目录与命令密文通过独立环境变量传递。PowerShell 的 `PSConsoleHostReadLine` 钩子在交给 Shell 执行前报告最近提交的命令。只收集允许写入历史的单行输入，禁用历史、使用自定义历史策略或命令超过 4096 个 UTF-8 字节时清除候选。命令先由 Windows DPAPI 按当前用户加密，再通过带本会话标识的 OSC 更新窗格快照。重开时 Shell 移除启动变量并在原目录解密，文本一次性预填至 PSReadLine 的空编辑缓冲区，或在行编辑器首次读取输入前通过 `PSConsoleHostReadLine` 提交。自动提交沿用快照校验及加密，Shell 历史由 PSReadLine 在交互输入时更新。目录失效时跳过命令，权限模式沿用原有启动和 UAC 流程。

手动保存使用独立 `application_settings.local_terminal_sessions` v3（会话 ID、名称、可选的默认命名窗格索引、各窗格目录/提权模式、可选命令密文与索引布局）。v1 与 v2 在存储事务内备份并升级，v1 原窗格的命令为空，旧名称按既有名称保留。首次加载与每次写入严格校验版本、未知字段、唯一 ID、数量、路径及布局完整性；元数据复用 Application 有界阻塞执行器，事务读取后只更新目标记录，失败回滚并保留名称草稿。旧 `local_terminal_directory` v1 原样保留；损坏的保存列表只影响列表及保存操作，普通新建本地终端仍可用。

Terminals Store 按本地和 SSH 主机索引保存记录，运行期标签独立管理。终端导航优先复用已打开的会话，首次进入本地终端或打开空的 SSH 终端时可启动普通 Shell。`TerminalsView` 在本地会话栏空白处的菜单提供普通新建和 Windows 管理员新建，选中后按对应模式打开新会话。标签和会话栏空白处的“已保存会话”子菜单是保存项的恢复入口。恢复按保存 ID 复用对应标签，或者在检查窗格配额后建立运行期标签，保存来源绑定持久 ID 和窗格索引。保存记录加载时只读取元数据。右键“保存”和 Ctrl+S 共用保存入口，行内改名仅更新快照名称。

只有从“已保存会话”发起的新 Shell 启动会传入显式恢复标记，原生层同时检查已保存的终端偏好 `autoRunSavedCommand`，默认关闭。已连接标签直接复用，普通重连按预填模式恢复。命令由原生层按保存 ID 和窗格索引取得。SSH Bash 使用一次性 Readline 绑定，在成功切换到保存目录且有命令时插入并提交一次。

关闭窗格、标签或工作区只释放运行期会话，最后一个窗格关闭成功后才移除标签，保存记录保留。点击子菜单的删除按钮直接调用本地或 SSH 删除 IPC，成功才移除对应行并清除关联标签的保存标记及恢复来源。子菜单保持打开，运行期 Shell 和分屏继续保留。失败通过通知报告，可重试。删除期间同一保存项不能恢复或重连，保存与删除串行，避免使用已删除的快照或重新覆盖记录。

SSH 保存记录按主机延迟加载。每个认证传输通过独立 SSH 通道识别一次 Bash 4.2+。兼容的普通交互终端加载随应用提供的 Bash 初始化脚本，原始配置文件保持完整，固定命令、插件终端和不兼容的 Shell 沿用各自启动路径。Bash 在提示符报告目录。Bash 4.4+ 使用 PS0 报告本次提交且进入历史的单行命令。Bash 4.2–4.3 使用 DEBUG trap 在每次提交后的首次执行前报告历史条目，未触发 trap 的命令在下一次提示符前比对历史。若启动配置已有 DEBUG trap，则保留原钩子并仅报告目录。SSH 引擎分片解析带该 PTY 标识的有界报告，按运行中的 SessionId 和主机归属取快照。

`application_settings.ssh_terminal_sessions:<HostId>` v2 保存 ID、名称、可选的默认命名窗格索引、布局、窗格数量和快照引用。旧记录首次写入前备份，原快照引用保持。各窗格的 SSH 身份及可用的目录和命令保存于系统凭据库。其他远端 Shell 仍支持保存标签和布局，元数据标记受限窗格数量。仅能保存布局时拒绝覆盖已有的完整快照。替换记录时先登记新快照的清理意图，事务提交时切换引用并登记旧引用待清理。读取列表、改名和删除均无需读取命令。恢复按记录 ID 和窗格索引取数据，验证实际连接的主机 ID、密钥、端点和账户后，通过关闭回显的启动握手传入数据。Bash 切换目录后通过固定的 Readline 编辑绑定写入缓冲，旧版 Readline 通过固定按键映射调用一次性的编辑绑定。目录失效时回到主目录并清空候选命令。

默认命名的保存项在界面按需显示对应窗格的最近命令。存储只保留默认名称和窗格索引，原命令仍由 DPAPI 或系统凭据库保护；用于显示的截断命令单独返回主窗口。显式改名清除命名索引，保留实际命令和目录快照。

### Windows 管理员终端

Windows 管理员本地终端由 `crates/windows-terminal` 封装 `ShellExecuteExW(runas)`、进程令牌查询、命名管道身份校验和 Job Object。宿主只通过主窗口专用 IPC 请求启动当前 EXE 的固定 PTY 代理模式；代理在 Tauri、单实例、存储、凭据和插件初始化前分流，仅运行既有本地终端引擎。系统 UAC 只提升该代理及其 PowerShell，主程序不重启、不提权，不接受自定义程序、命令或 Shell 路径。

每个代理使用独占随机命名管道，拒绝远程客户端，ACL 仅允许当前用户、管理员和 Local System。宿主以 UAC 返回的进程句柄核验管道客户端 PID，代理核验服务端 PID 与宿主 EXE 路径，且使用 identification 级连接禁止宿主模拟管理员令牌。协议有版本与帧长上限。启动帧携带尺寸、目录、报告标识和受 DPAPI 保护的已保存命令及恢复模式。代理启动内置 PowerShell，输入、尺寸和序号沿用本地引擎校验，输出继续按 xterm ACK 背压。目录由未提权宿主保存，代理不打开应用数据库。代理先确认实际提权，再建立 PTY；断线、取消、超时与退出触发清理，Job Object 在代理退出时回收受管后代，主程序等待代理退出后完成会话回收。UAC 提示尚未响应时不能强行关闭系统授权窗口，应用退出须先等待用户允许或取消；等待超时保留工作区并报告失败。该能力不开放给插件。

### PTY、分屏与交互

Windows 本地 PowerShell 的行编辑钩子在等待输入和提交非空命令时分别发送带会话标识的 OSC 活动报告，普通和管理员终端共用该钩子。普通 SSH Bash 通过现有会话集成从 PS0（Bash 4.4+）或内置 DEBUG 钩子（Bash 4.2–4.3）报告执行开始，在提示符钩子中报告恢复空闲。宿主按会话维护运行状态，独立于命令历史和目录快照。终端 Store 在关闭窗格、标签或全部会话前通过主窗口 IPC 查询目标状态，无需向远端追加探测命令。前台活动与拖放上传共用一次确认，确认后复验运行期会话 ID 再进入正常关闭流程。

PTY 每块最多 16 KiB，经 Tauri Channel 送入 xterm，写入回调 ACK 后读取下一块；输入/resize 独立且有界，resize 合并。russh 内部仍有非全有界队列，不承诺恶意服务器下进程硬内存限额。

前端 Tab、PaneKey、Session 分离，分屏二叉树只算几何，固定 PaneKey 保持 xterm；每标签最多八窗格，全应用最多 32。generation 隔离迟到输出、剪贴板和连接结果。重连先安全关闭旧 Session，再按序列清空终端状态并开新 Shell，不重放动作/票据。光标闪烁由连接状态控制，已连接时开启，断开保留画面并禁用输入和闪烁。

`TerminalPane` 通过 xterm 的键盘处理器读取已保存终端快捷键；仅可见窗格且没有阻挡该窗格的对话框时处理。主终端将分屏、会话切换、新建、关闭和字号动作交给 `TerminalsView`，复制、粘贴及查找在窗格内完成。独立插件终端在本地调整字号，以 `close` 事件请求关闭自身；分屏、新建和会话切换只提示不支持，不发往远端或改动主终端。应用全局搜索和设置由 `App` 的捕获阶段监听处理，对话框及快捷键录入框中不触发导航。全局快捷键匹配和录入共用 `globalKey`，逗号优先识别物理键码 `Comma`，兼容输入法或键盘布局返回的不同标点字符。全局动作仅监听 `keydown`，不从孤立的抬键事件执行导航。输入法及系统快捷键可能在 WebView2 原生加速键回调之前消费按下事件，页面无法可靠地接管这些组合键；应在设置中更换冲突绑定。当前默认设置键为 Ctrl+Shift+P，左右分屏为 Ctrl+Shift+L，以避开搜狗输入法的 Ctrl+逗号与 Ctrl+Shift+E。新默认值只用于新配置及恢复默认；已有偏好和历史升级默认值保留原绑定，不自动重写。输入法组合期间及长按重复事件仍不触发全局动作。快捷键字段及持久配置格式保持不变。

后台窗格及离开终端页后的工作区保持挂载，移出视口并以 visibility 隐藏，使用 inert 和 aria-hidden 禁止交互及辅助技术访问；继续处理输出、协议和 ACK，不重建 Shell。保留可测量的字体布局，避免 display:none 下 xterm DOM 选区刷新反复得到零字符宽度、无法缓存并挤占前台线程；视口外的常规绘制由 xterm 自身暂停。回到前台后重新适配几何与焦点。

状态栏只订阅当前可见窗格，从 SSH 握手读取目标实际算法，从 xterm 读取行列和光标，不额外执行远程命令。HTTP/HTTPS 链接经专用 IPC 校验后交系统浏览器。文本剪贴板单次最多 2 MiB，大粘贴先确认。窗口 resize 可强制可见普通缓冲到底部，其他布局适配保留用户历史阅读。终端正文与运行进程不持久恢复；只有用户手动保存的本地会话启动信息和布局可恢复为待启动条目。

`TerminalPane` 注册同步 OSC 52 handler，`osc52Text` 只解码空选择器或 `c`/`s` 选择器的非空 Base64 UTF-8 文本，预检编码长度并限制解码后大小至 2 MiB；无效编码、其他选区、清空与 `?` 读取请求均消费但不执行，不读取或回传本机剪贴板。仅当前可见、聚焦、已连接且无阻挡弹窗或上传的窗格可直接调用原生剪贴板写入，不弹确认，不依赖本地 quickCopyPaste 偏好，也不产生待批准状态。handler 不等待剪贴板 IPC，输出解析和 ACK 继续推进；原生写入失败沿用安全错误通知，generation 隔离迟到失败，不记录剪贴板正文。

本地复制在选区为空时直接返回，不向原生剪贴板写入空字符串，因此 Claude 已通过 OSC 52 复制的内容不会被随后的 Ctrl+Shift+C 清空。鼠标被终端程序接管时，其内部选区不等于 xterm 本地选区，可用 Shift 拖选取得本地选区。“选中即复制”同时处理 xterm 选区变化和本窗格开始的鼠标松开；选区变化已复制则消费当前手势，避免重复写入，仍能处理粘贴后重选同一坐标时 xterm 未再次通知的情况。断线、切页及重连清除未完成手势。复制/粘贴继续通过 xterm 键盘处理器使用已保存绑定，粘贴保留连接与 generation 校验、2 MiB 上限及大文本确认。剪贴板服务将原生插件的 `ContentNotAvailable` 消息转换为空文本，终端跳过空文本粘贴。其他读取错误由终端提示。

首跳支持 SOCKS5/HTTP CONNECT，跳板通过嵌套 SSH 逐跳信任。终端不提供按目录打开 SFTP 或正文导出入口。

### 本地端口转发

主机工作区的“端口转发”通过 `forward_open` 创建独立的 `Forwarding` SSH 会话，复用连接规划、传输层和指纹确认，单独拥有监听生命周期与关闭事件，不创建 PTY。主窗口的 `forward_start` 仅接收 `LocalForwardInput`，在原生层固定为 IPv4 回环地址和本地转发。监听成功后按需为每个本机连接建立 `direct-tcpip` Channel，全局最多 16 个活动转发，每条最多 32 个活动连接。启动就绪只确认监听已建立，远端连接失败在状态中反馈。

`forward_rules`、`forward_add_rule` 和 `forward_remove_rule` 按 HostId 读取或写入独立版本的本地规则。持久记录只含本地端口、远端地址和远端端口，按主机校验本地端口唯一；主机删除和规则清理同事务提交。加载只读取本地设置，前端为每条规则创建“已停止”状态，启动动作再创建 SSH 会话和监听。

前端按 HostId 保留当前工作区的会话和运行状态，页面只在可见时查询 `forward_list`，会话关闭事件负责更新断线状态。`forward_stop` 等待监听和子任务清理。停止最后一条规则时释放转发会话，关闭主机工作区、应用重载或退出时复用会话清理；传输层仍可被该主机其他工具共享。

### rz 上传

rz 经原生选择器发放绑定终端的一次性文件句柄，与普通输入隔离。文件按 64 KiB 读取，每批复验大小和修改时间，使用二进制 IPC 返回前端；最多预读下一块，与当前批次发送重叠。`ZmodemUpload` 将编解码器同步产生的子包合并为有序二进制批次，每批上限 256 KiB，通过主窗口专用 IPC 提交；请求头绑定原终端和文件授权，拒绝拖放授权、过期授权及同一授权的并发写入。Rust 在原 SSH 输入队列中按 16 KiB 分次等待容量，保留普通终端输入的大小限制和输出 ACK。取消先停止读取，再等待在途批次和取消帧按序发送，最后释放文件授权；发送超时或在途授权失效时关闭原会话，隔离未确认的数据。文件载荷不经 JSON 数字数组，不新增 SSH 连接或 SFTP 身份。

`ZmodemUpload` 将所选文件和当前文件进度交给 `TerminalZmodemUpload`，复用 `Modal` 及终端拖放上传样式。`choosing` 状态仅维持协议占用和输入隔离；选择器返回非空文件列表且离开该状态后才挂载 `Modal`，取消选择后的空列表 `finishing` 也不挂载弹窗或触发弹窗关闭后的焦点恢复。每个文件获准接收后以单调时钟计时，传输进度刷新最多每 100 毫秒一次，每秒及阶段变化强制刷新；速度只统计本次发送字节，不将远端已有偏移计入吞吐。文件结束、取消、失败及销毁停止计时，最终确认阶段保留最后一个文件统计并隐藏速度和剩余时间估算。关闭按钮、Esc 和取消按钮共用取消入口，取消中禁用重复操作，原生文件授权释放处理结束后才清除弹窗，释放失败经既有错误通知报告；恢复焦点前复验会话、可见性和其他弹窗。ZMODEM 不提供接收账户和目录，不额外执行远程命令推测。

### 当前 Shell 二进制拖放

当前 Shell 拖放使用原生一次性授权，经原 PTY 的固定接收脚本继承真实用户与目录，包括 sudo/su 切换后的身份；不创建其他身份的 SFTP 连接。单个普通文件仅校验路径与元数据并保留原文件句柄，准备阶段不读取载荷或创建副本；文件夹或多选经受限扫描生成临时 tar，打包读取持续检查取消。两种来源都由阻塞工作线程在每块读取时累计 SHA-256，不再预先通读归档；每块及最后一块发送后复验源大小和修改时间。Rust 取得该终端的独占二进制收发租约，接收期间拒绝普通输入，前端清除未发送的旧输入并只订阅进度。SSH 输出在后端路由到有界接收队列，隐藏启动回显、协议和诊断；RETURN 标记后的普通输出重新走既有 WebView ACK，并就地刷新提示符。异常退出、无效协议或无法确认终端恢复时结束原 SSH 会话，避免遗留数据进入 Shell，不影响其他窗格。拒绝链接和特殊文件，与 rz 互斥，不保证断线清理或跨重启恢复。

文件或归档由 Rust 分块读取并直接发送原始二进制，最多两个 4 MiB 分块在途；输入队列最多八个 64 KiB 消息，接收队列最多八个 SSH 数据消息，文件载荷不经过前端或 Base64。接收脚本保存终端设置后启用 raw 模式，每帧为 `D`、七位补零十进制长度及对应载荷，通过 `head -c` 精确读取头部；所有数据确认后发送 `F` 和 64 位小写十六进制 SHA-256，同样精确读取。不在原始终端流上使用 Shell `read`，避免 Bash 4.2 预读缓冲吞入后续二进制字节。使用 GNU `tee -a` 向普通文件追加并向 `wc` 传递完整输入，不要求较新版本的 `--output-error` 参数。普通文件写失败仍排空该帧，再以实际文件长度检查失败；短读或失去帧边界时隔离数据并关闭该会话。ACK 为累计确认字节数，必须匹配在途队列。取消通过帧边界的控制消息处理，先发送完已声明分块，再排空接收；校验和解包进程可单独停止并等待结束。远端 SHA-256 通过后，单文件收紧至 0644 或原 umask 所允许的更严格权限，在私有暂存中重命名，无需再次复制或解包；归档执行解包。整批冲突预检后，由客户端显式允许提交；最终结果再经释放确认和 RETURN 恢复边界交付，保留已提交项目和清理失败的恢复路径。会话关闭事件先于上传 IPC 失败返回时，仍在保留的上传弹窗中显示后端具体原因；组件卸载后不再更新旧弹窗。

接收脚本通过 `id -u`、`id -un` 和 `pwd -P` 返回实际身份与目录；单文件名称经本地校验后作为 Base64 参数传入，不拼接为 Shell 语法。仅这些少量元数据使用 Base64；账户名称查询失败只保留 UID。Rust 从 READY 后以单调时钟计算已用时间，每半秒、阶段变化及确认数据时推送快照，前端不另建计时器；容量和传输阶段的平均速度只统计远端已确认的文件或归档字节。弹窗复用文件传输的时长格式，以平均速度估算剩余数据传输时间，校验和提交不提供时间估算。吞吐仍受 PTY、加密、磁盘及多选归档开销影响，不将 SFTP 的实测速度直接作为此链路保证。

### 上传修改时间

上传元数据中的修改时间使用 Unix 整秒，不在传输层应用时区偏移。`TerminalUploadFile.modified` 从已授权文件句柄读取，rz 通过 ZMODEM 文件 offer 的 `mtime` 发送；拖放归档头取源元数据，单文件在固定接收脚本中通过 GNU `touch -m -d @秒数` 设置暂存文件修改时间，失败返回 `METADATA` 并安全恢复终端。mtime 不包含源创建时间或 Unix ctime。
