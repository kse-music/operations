# ServerDeck 产品基线（PRD）

本文以当前产品功能为基线，定义交互、能力和使用边界。实现见[总体架构](../architecture/ARCHITECTURE.md)，候选版本验收见[发布检查表](../release/RELEASE_CHECKLIST.md)。

## 产品定位与范围

ServerDeck 是面向个人开发者、DevOps 和小型团队的本地桌面服务器工作台，以安全 SSH、SFTP 和按需扩展为核心。无需云账号，不要求远端安装 Agent。主机、偏好和插件配置保存在本机，秘密交给操作系统凭据库。

应用版本以根目录 [Cargo.toml](../../Cargo.toml) 的 `[workspace.package].version` 为唯一来源，程序、安装包和关于页保持一致，发布清单从该工作区读取；修改后直接使用已有开发/打包命令，入口自动同步工作区锁文件及检查来源，不要求单独运行版本命令。尚未正式 release。SDK、插件包和数据格式独立管理版本。Windows 11 x64 是首要验收平台；macOS、Linux 和其他架构须分别验收，不能把构建配置或单项验证等同于完整支持。

| 范围         | 当前要求                                                                        |
| ------------ | ------------------------------------------------------------------------------- |
| 应用基础     | 单实例、主题、窗口偏好、设置、日志、错误提示和安全退出                          |
| 主机连接     | 多级文件夹、搜索、连接测试、密码/公钥认证、受限 OpenSSH Config 导入、代理和跳板 |
| 终端         | 本地与 SSH Shell、多会话、分屏、转发、原生文本剪贴板、rz 与当前 Shell 拖放上传  |
| 文件         | 双栏 SFTP、目录操作、可取消传输、校验和原子文本编辑                             |
| 插件         | 本地包安装、权限、启停、配置、卸载和公开 SDK；内置 Docker 与 AI 运维助手        |
| 外部扩展     | 使用公开 SDK 构建独立插件，通过本地包安装并显式授权                             |
| 宿主基础服务 | 内部监控、运维及通用执行服务；不作为独立产品页面或插件领域 API                  |

当前产品界面为主机工作区、SSH/SFTP、Docker 和 AI 助手，以及模型、插件和全局设置；后台服务不代表具有对应独立页面。

不提供云同步、团队权限、插件市场或集中式时序/日志平台。

## 桌面工作台与交互

### 导航与工作区

- 顶部显示产品标识、侧栏开关和全局搜索；不设置大模块切换或重复应用菜单。
- 本地终端固定在主机树上方，底部提供设置。主机标题显示总数和新建入口，搜索不影响总数。
- 侧栏收起后保留 52px 图标栏，提供展开、本地终端和设置；窄窗口展开主机树使用浮层。收起/展开保留搜索、树和会话状态，不创建或关闭连接。
- 本地终端、远程主机和全局插件功能按打开顺序共用一排工作区标签。设置和插件管理使用统一设置窗口，不创建工作区标签。
- 工作区功能页的「插件设置」打开只包含当前插件的独立弹窗，不进入全局设置；关闭恢复入口焦点，保留底层页面、查询结果、筛选和滚动状态，不因开关弹窗重新加载 Docker 列表。插件管理列表内的详情仍在设置窗口展示。
- 每台主机保留本次打开期间最近使用的工具、插件页面、终端会话和文件路径。SSH、SFTP 与已启用且有功能页面的插件按钮平铺，窄窗口换行；本地工作区仅提供本地终端。
- 启动显示欢迎页，不恢复终端会话或分屏，不自动连接。主机树单击只选中主机，双击打开工作区并连接当前空闲 Shell；键盘 Enter/空格及右键“连接”也可打开。重复打开复用已有连接，失败须明确重试。
- 工作区标签菜单提供关闭、关闭右侧、关闭其它、关闭所有，以右键目标和可见顺序确定范围，右键本身不切换活动页。

### 关闭与资源保护

关闭主机工作区须检查未保存文件、插件草稿及未完成传输。用户取消时保留工作区、会话和传输；确认取消传输后等待安全提交和清理，再关闭该主机的文件连接及终端。关闭失败保留工作区和记录，其他主机不受影响。成功关闭后清除本主机临时传输记录，不删除文件。

默认关闭主窗口即申请退出，确认界面说明连接/会话、未完成任务和未保存修改，短窗口正文可滚动，底部操作可达；关闭确认窗口或 Esc 取消退出。确认后取消并排空后台工作、关闭全部本地/远程终端与转发、完成必要持久化和日志刷新。取消退出保留本次状态，不提供托盘常驻。

### 显示、通知与可访问性

- 主窗口最小尺寸为 960×600 逻辑像素，默认 1280×820，重启恢复上次窗口尺寸和最大化状态。已保存的较小窗口尺寸在恢复时按当前最小尺寸放大；设置弹窗自适应可用空间，长内容内部滚动，保存、取消及关闭操作在最小窗口和超大字号下仍可访问。
- 默认深色，支持浅色及系统主题。页面铺满工作区，列表在自身区域滚动，长内容和大字号下操作仍可访问。
- 自定义右键菜单统一采用紧凑行距、内边距和分隔线，覆盖主机/目录、工作区标签、会话、终端正文及 SFTP 列表。标准字号单行约 28px，随界面字号自适应；菜单按内容确定宽度，受窗口边界约束，过长时内部滚动。主机、目录、终端会话、工作区标签和 SFTP 本地/远程列表的每项菜单操作均显示对应图标，图标列大小与间距一致；主机插件菜单使用扩展图标。图标沿用统一的深浅主题配色：连接/重连及传输用绿色，创建主机/导入/复制/属性用蓝色，目录/编辑/重命名用金色，插件/文本编辑/终端及关闭其它用紫色，删除/断开/关闭所有用错误色，关闭当前用灰色。SFTP 目录图标保留金色填充，菜单文字与禁用状态保持原有语义。
- 界面字号为小/标准/大/特大/超大，比例 95%/100%/115%/130%/145%。标准主要文字 14px，辅助信息 12px、分组标题 16px、弹窗标题 20px、页面标题 24px。终端内容字号独立。
- 标题、导航、标签和按钮禁止浏览器原生文字选择；通知正文、输入、可编辑内容和文本输出支持选择与复制，弹窗内一致。
- 错误文案统一由右下角通知呈现，支持关闭、去重和文本复制；轮询不重复提示同一失败。弹窗内通知仍可见可操作。保留业务失败状态、重试、过期标记、安全确认和原始业务输出。
- 全局搜索支持入口和可配置快捷键、方向键、Enter/Esc；只检索本地可公开目录与功能，不搜索私密终端输出。

## 主机与 SSH 认证

### 主机目录

主机配置包括可选名称、地址、端口（默认 22）、用户名、密码或公钥认证、连接超时（默认 15 秒）及高级代理/跳板设置。地址和端口须合法；名称仅空白时视为未填写。无名称时显示地址，非 22 端口追加端口号，IPv6 使用方括号避免歧义。搜索匹配名称、地址和用户名，不提供标签、备注或收藏管理。

根目录为不可重命名/删除的内置节点，支持多级文件夹、全局唯一文件夹名称、展开折叠和祖先路径。主机分组使用适配深浅主题的黄色实心文件夹图标，展开与收起时切换对应形态，保留独立的展开箭头与层级缩进。新建主机归属于入口文件夹，编辑保留原归属；拖动移动须持久化并拒绝无效父目录或循环。删除文件夹需确认，将主机和直接子文件夹提升至父目录，不递归删除内容。

主机行以蓝色渐变屏幕、灰色底座的彩色显示器图标标识主机，展示名称、地址和连接状态；已连接时图标指示灯使用主题强调色，连接状态继续提供可访问性标签，鼠标悬停不显示文案提示。图标适配深浅主题与显示缩放。编辑/复制/删除通过右键菜单进入，根目录另提供 OpenSSH Config 导入。菜单操作绑定右键目标，不因打开菜单切换工作区；支持键盘、焦点恢复和窗口边界。复制生成独立配置，不自动连接；删除需确认，失败保留数据。

### 连接测试与保存

新建/编辑表单直接填写密码、粘贴私钥或选择私钥文件，支持加密私钥解锁口令。编辑同一认证方式时留空沿用已有凭据；已有 Agent 主机可继续使用 Agent。更换认证只影响当前主机，不改写其他共享该凭据的主机。

“测试连接”使用完整草稿及实际路由完成 SSH 握手和认证，首次指纹须用户核验，密钥变化必须阻断。成功结果限五分钟、单次使用且绑定草稿、主机身份、SSH 路由及凭据版本；修改、失败或过期后重新测试才能保存。移动、复制和 OpenSSH 导入沿用各自受限流程。

### 信任、凭据与路由

- 区分未连接、连接中、等待信任、已认证、断开和失败；TCP 可达不等于 SSH 登录成功。
- 主机信任记录与凭据分开。首次连接显示算法及 SHA256 指纹，用户明确接受后继续；已知密钥变化不提供静默覆盖。系统 known_hosts 哈希、CA 和撤销语义未完成，不能宣称兼容。
- 密码、导入私钥及必要口令通过系统凭据库管理，SQLite 仅保存引用和修订；服务不可用明确失败，不回退明文。私钥算法受安全门禁约束，拒绝本地 RSA 私钥签名，不能为了兼容降低校验。
- 支持受管跳板和 SOCKS5/HTTP CONNECT 代理；逐跳验证身份。HTTP Basic/SOCKS 认证的传输边界须说明，不执行 ProxyCommand 或任意本地 Shell 拼接。
- OpenSSH Config 导入先预览选择，提交重新校验并事务去重，不覆盖已有主机。支持范围和拒绝项见[架构中的导入边界](../architecture/ARCHITECTURE.md#主机与凭据)。影响目标、认证或信任的未知配置不能静默忽略。

## 终端

### 交互与会话

基础交互包括真实本地/SSH PTY、UTF-8、ANSI、256 色/True Color、鼠标、Ctrl+C/Z、选择、查找、复制粘贴、滚动和 resize。断开后保留显示历史和原因，会话名称左侧显示红色圆形白横杠图标；分屏中任一窗格断开即显示。非连接状态停止光标闪烁并禁用输入，仍可查看和复制历史；重连成功后按原偏好恢复光标和输入，不改写保存的光标设置。用户可在会话菜单重新连接普通会话，也可新建或复制会话，不恢复远端进程或重放输入。复制不重新执行固定文件/容器动作或一次性插件终端票据，主机连接配置变化须从主机树重新打开。

本地与 SSH 终端输出中的 HTTP/HTTPS 网址及 OSC 8 网页超链接可用鼠标左键直接点击，由本机默认浏览器打开；支持 localhost、IP、端口、路径、查询参数和片段。保留拖动选择与复制，不因右键或输出到达自动打开，不允许文件、脚本或其他自定义协议；打开失败显示提示。

同一主机可有多个独立会话，支持标签排序、双击重命名、关闭及水平/垂直分屏。会话标签提供“复制、重命名、重新连接、断开连接、关闭所有、关闭”菜单，可由右键、Shift+F10 或菜单键打开；操作以菜单目标为准，关闭所有仅作用于该主机，关闭失败保留相应会话。“重新连接”仅在目标标签全部窗格均已断开、关闭或连接失败时可用；已连接、未连接、连接中、等待确认及关闭中均置灰且不可触发，分屏仍有连接中的窗格时也不可重连。断开和重连作用于目标标签的全部窗格，保留标签、名称和分屏，不影响其他标签或独立 SFTP 连接。断开保留本地显示历史；重连在新 Shell 输出前清空旧画面、滚动历史、备用屏幕、选区和查找状态，并重置旧终端控制模式，显示效果与新会话一致。关闭旧连接失败时保留原画面和连接；新连接失败可重试，仍须核验主机指纹。有待确认或进行中的拖放上传时先确认并停止上传。文件/容器动作及插件一次性终端不可由此重放，应从原入口打开；主机连接配置变化时须从主机树重新打开。复制创建普通新 Shell，不克隆 Session ID、分屏、运行进程、文件/容器动作或插件票据。每个窗格有独立会话身份，调整几何不能重建 Shell；关闭一个窗格不能误关其他窗格。终端内容区不绘制绿色焦点边框，会话标签保留选中提示。

默认“会话 N”按主机在本次运行内计数，删除中间会话不补号；最后一个会话成功关闭后重置，失败不重置。标签、名称和分屏不跨重启恢复。

应用底部右侧显示当前终端会话及当前分屏窗格的状态，左侧保留后端与主机/终端数量。远程终端显示 SSH2 和本次目标连接真实协商的加密算法，本地终端显示实际 Shell；准备连接、等待信任、失败及断开时显示对应状态，不将旧算法显示为当前连接。显示从 1 开始的光标行/列、当前终端行数/列数及 `xterm-256color` 仿真类型，随输出、窗口/字号和分屏变化更新；仿真类型不代表远端操作系统。CAP/NUM 表示本机大写/数字锁定，开启时高亮；首次打开或窗口失焦/重新聚焦后标记未知，收到键盘事件后同步，不能将未知伪装为关闭。切换会话、主机或焦点窗格时更新，非终端页面及无当前会话时隐藏；窄窗口/超大字号允许状态区独立横向滚动及键盘访问，不挤占终端正文。不额外执行远端命令，不持久化状态数据。

### 偏好与输入保护

支持字体、10–32 字号（默认 16）、行高、光标、主题、滚动缓冲和快捷键；Ctrl+滚轮每次调整字号 1，已打开终端同步更新。最大化、还原或拖动调整窗口尺寸后，当前可见的普通终端均强制滚到最新内容，包含此前手动向上翻阅历史的情况，滚动条与缓冲位置一致；仅调整侧栏、分屏或字号时保持原有历史阅读行为。不同显示缩放和字号下，末行及光标应完整可见。Linux 有效行高最低 110%，保护下划线，不改写保存值。

原生文本剪贴板由用户动作触发，无自动读取或网页接口回退。终端内容菜单只提供复制和粘贴，并显示对应快捷键。支持默认关闭的“选中即复制、右键即粘贴”，Shift+右键或键盘菜单仍可打开菜单。重连/卸载后丢弃旧剪贴板结果。单次粘贴最多 2 MiB，超过配置字符阈值或 50 行须确认并使用 Bracketed Paste；不能保证远端禁用该协议时换行不执行。

默认终端快捷键以当前 `TerminalPreferences` 为准：

| 操作         | 当前默认快捷键   |
| ------------ | ---------------- |
| 复制         | Ctrl+Shift+C     |
| 粘贴         | Ctrl+Shift+V     |
| 查找         | Ctrl+Shift+F     |
| 上下分屏     | Ctrl+Shift+H     |
| 左右分屏     | Ctrl+Shift+E     |
| 新建终端会话 | Ctrl+Shift+T     |
| 关闭当前窗格 | Ctrl+Shift+W     |
| 下一个会话   | Ctrl+Shift+Right |
| 上一个会话   | Ctrl+Shift+Left  |
| 放大字号     | Ctrl+Shift+=     |
| 缩小字号     | Ctrl+Shift+-     |

全局搜索为 Ctrl+K，设置为 Ctrl+,；macOS 按平台习惯适配，完整平台验证仍需单独完成。配置不能意外拦截远端 Ctrl+C/Z。

终端窗格不显示底部操作栏和快捷键提示，端口转发管理、按当前目录打开 SFTP 或终端文本导出不提供窗格入口；重连和断开使用会话标签菜单。内容区右键菜单只提供复制/粘贴，查找、分屏和字号调整继续使用快捷键；SFTP 从主机工具栏打开。不自动录制或持久化终端正文。

Linux 本地终端使用用户默认交互 Shell，保留启动文件、别名和提示符；AppImage 子进程只剔除包内 Python/搜索路径污染。Windows 使用系统 PowerShell。应用不修改用户 Shell 配置或重启已有会话。

Windows 本地会话栏的加号弹出“新建普通会话”和“以管理员身份运行”菜单，选择后才创建会话；Esc 或点击外部取消菜单，不创建会话。侧栏只保留本地终端入口，首次打开与新建会话快捷键默认使用普通启动方式；SSH 和非 Windows 本地会话的加号继续直接新建。管理员选项经系统 UAC 授权创建独立管理员 Shell，仍显示在本地工作区的会话标签与分屏中，ServerDeck 主进程、插件和其他终端不随之提权。会话标题与已连接状态栏标明管理员身份；普通会话继续继承主进程权限。管理员会话的分屏、复制和重连保留所选模式，每次创建新 Shell 都重新请求系统授权；取消或失败明确提示，可重试，不降级创建普通 Shell。关闭窗格、退出应用或代理连接断开时回收对应 Shell 和受管子进程，不保存提权授权。

### 转发与 rz 上传

端口转发服务保留既有会话所有权、默认回环地址、公共绑定确认和断线清理约束，当前终端界面不提供管理入口，不跨重启自动恢复。

远端 rz 握手可触发原生多文件选择，通过当前 PTY 上传，支持进度、取消、中文、二进制和空文件；每批最多 100 个普通文件，单文件小于 4 GiB。传输隔离普通输入，取消选择/断线/重连不能把旧数据发送到新会话。拒收或跳过如实显示；sz 下载不在范围，下载使用 SFTP。

### 终端拖放上传

普通 Linux SSH 终端支持从系统拖入文件、文件夹及混合多选，确认一次后上传到该 Shell 当前目录，保留目录结构与空目录。确认弹窗直接切换为准备、传输、校验和提交进度，成功后自动关闭，并将输入焦点恢复到接收拖放的原窗格，无需再次点击。不在终端显示接收命令、脚本、协议或上传状态，也不留下终端底部成功提示。失败原因保留在弹窗中，取消等待远端安全结束后关闭；接收状态不明时在弹窗提供关闭此会话的恢复入口。已隐藏、断开或被替换的会话不恢复焦点，其他打开的弹窗不被抢焦点。接收进程继承当前有效用户，sudo -i 后使用切换后的身份；不从提示符、OSC 7 或独立 SFTP 身份推断权限。

不依赖 rz 或远端安装程序，要求服务器已有兼容的 GNU 基础命令。确认前须回到空白 Shell 提示符；本地、插件、容器/固定动作会话及备用屏幕不接收拖放。拒绝链接、重解析点和特殊文件。每批 1–256 个顶层项目，递归最多 100000 项、128 层；文件使用 0644、目录使用 0755，再受远端 umask 限制，不复制本地属主或特殊权限。

上传期间只隔离该窗格输入，提供进度和取消，其他终端继续运行。弹窗以 B/KiB/MiB/GiB 显示已确认接收量与归档总量；传输阶段显示平均上传速度，从接收端就绪后计时，仅统计已确认的原始归档字节，不计 Base64 膨胀及准备、启动、校验、解包耗时。目标同目录私有暂存、SHA-256 校验和解包后才提交，整批预检同名冲突，已有文件、目录和链接一律停止提示，不合并或覆盖。提交阶段的并发冲突保留已提交项目并如实报告。关闭窗格或主机先确认、停止并等待接收端结束；退出、断线或关闭会话撤销本地授权。无法确认接收端结束或恢复终端设置时保留输入隔离，提示关闭会话，不伪报成功；可能残留临时目录并提供可用恢复信息。不提供断点续传或跨重启恢复。

## SFTP 文件与文本编辑

### 浏览与布局

本地/远程双栏填满工作区、独立滚动，按可用宽度和字号并排或上下排列；地址栏、父目录、刷新、名称搜索、表头排序、多选和右键操作可达。名称、大小、类型、修改时间及远程权限/属主按真实元数据显示。隐藏文件默认不显示，可切换；隐藏后移除选区中的隐藏条目。

切换目录先显示目标路径与列表内加载态，不展示旧条目；失败恢复旧路径和列表并提示，连续请求仅接受最新结果。两栏后退/前进历史独立，鼠标侧键作用于指针所在栏。Windows 本地路径使用盘符或 UNC 显示与复制，文件操作沿用原始路径。

本地地址栏在“上级”按钮右侧提供磁盘下拉选择，按系统实际盘符显示磁盘类型；有磁盘时列表仅包含实际磁盘，不提供“选择磁盘”占位项。每个选项的名称前显示磁盘图标，收起时显示选中项的图标与名称，不在选择器外固定放置图标。支持方向键、Home/End、盘符字母定位和 Enter/空格确认，Esc 或点击外部关闭，Tab 正常移到下一控件；长列表可滚动，菜单不超出窗口。选择后进入对应根目录并纳入本地导航历史；聚焦或展开选择器时刷新磁盘列表。盘符读取失败或磁盘不可访问时明确提示，保留原目录和列表。移除工具栏单独的“选择本地目录”入口，上传文件/文件夹选择器保留。

远程地址栏在“上级”按钮右侧提供目录层级下拉框，收起显示当前目录的文件夹图标与名称；展开按 `/ <root>`、各级父目录到当前目录逐级缩进，每项带文件夹图标并高亮当前项。入口与展开项使用和文件列表一致的实心文件夹图标、深浅色配色及随字号变化的尺寸。例如 `/home/dh` 显示根、home、dh，点选任一项进入对应目录。菜单跟随已确认的 SFTP 路径与已提交的绝对目标路径，未提交的地址栏草稿不改变菜单；相对目标解析完成前保留已确认层级。沿用目录加载、失败恢复、独立历史和键盘操作，未连接、切用户或主机关闭期间不可操作；更换连接身份关闭旧菜单。该菜单只展示当前目录的祖先层级。

两栏按可用空间自动布局，不提供手动宽度调整、仅远程模式或远程全文搜索。

### 文件用户身份

终端中的 `su`/`sudo` 不改变独立 SFTP 进程的身份。远程文件栏显示当前用户，提供确认式“切换用户”：通过当前 SSH 登录账号的 sudo 权限运行目标用户的 SFTP 服务，默认目标 root，可切回原登录用户。支持输入 sudo 密码或免密 sudo；新通道完成真实目录读取后才替换旧连接，失败保留原连接。切换后从目标用户主目录开始，无可访问主目录时使用 `/`，清空旧目录历史与选区；有未完成传输或打开的编辑文档时须先处理。

sudo 授权仅用于本次文件连接；密码不落库、不进入命令或日志、不自动继承终端认证，不跨断开或重启恢复。每个浏览/传输通道均使用该连接身份。服务器须允许无 PTY 的 sudo、固定 Shell 包装及外部 `sftp-server`；自动检查常见程序路径，也可手动填写绝对路径。不绕过 sudo/SSH 策略，不支持仅有 internal-sftp 或 requiretty 的服务器。插件不继承桌面文件页的 sudo 身份。

### 传输和文件操作

支持文件/目录上传下载、多选、递归、原生拖放上传、远程条目拖入本地栏，以及 Windows 普通文件/文件链接拖到桌面或资源管理器。目录及目录链接不参与窗口外拖放。明确选中的文件链接仅在目标为普通文件时下载，以链接名保存内容；递归扫描不跟随链接。

任务具有独立 ID、进度/速度/字节/状态、取消和重试，后台传输不阻塞终端。当前确认界面的冲突策略为停止提示、跳过和确认覆盖；底层仍有自动重命名策略，但界面没有该选项，不将其描述成当前可选操作。先同目录临时写入、校验 SHA-256，再安全提交；取消保留已提交文件，清理失败提示恢复路径。不承诺断点续传或跨重启恢复，失败重试从头传输。

当前主机有活动传输时底部面板占用有限高度，结束后列表收回空间；已结束任务从页头“传输记录”查看/重试。正常完成不弹成功通知，失败和清理异常仍提示。切换工具或主机保留任务与记录，成功关闭所属主机后清除临时记录。

新建目录、重命名、删除遵守真实权限和路径边界。删除须确认并显示对象，目录确认后递归删除；禁止删除根目录、不跟随目录中的链接，不用未转义 Shell 拼接代替 SFTP。

### 文本编辑和终端联动

内置编辑器按内容校验严格 UTF-8 普通文本，不按扩展名限制；单文件最多 2 MiB，不含 NUL。打开期间显示进度，格式、编码、大小或组件加载失败给出具体反馈和系统应用入口，不升级为全局界面异常。保存前检查内容摘要和属性，保留基本权限/属主并原子替换；冲突、权限不足、缺少原子能力或元数据保留失败时不截断原件。须说明 inode、ACL/xattr、硬链接及无服务端 CAS 的限制。

Windows 本地普通文件双击或菜单“选择应用打开”显示系统应用选择器。远程普通文件可选择“使用系统应用编辑”，经说明后下载到独立本地副本，校验成功才交给系统应用；二进制、非 UTF-8 和超过内置上限的文件不经过文本转换。外部应用保存后，由用户确认回传；保存复用上述内容/属性冲突检测及原子替换，支持取消，提交临界区等待结果，不自动上传。结束编辑、失败或退出保留本地副本，编辑期间显示副本路径，结束时用可关闭且 6 秒后自动消失的一次性通知显示保留位置；不在文件页常驻或在重开主机时重放成功提示，不自动清理副本或恢复编辑会话。编辑会话绑定原 SFTP 身份，关闭主机、切换用户和退出继续受未结束编辑保护。其他平台保留下载后自行打开的路径，不宣称具备系统应用选择器。

内置编辑器直接在独立原生窗口打开，一次编辑一个文件，不能与外部编辑同时进行。窗口可拖出主窗口、跨屏移动、独立缩放和最大化/还原；主窗口最小化不隐藏编辑器，关闭主程序仍退出整个应用。系统标题栏显示远程文件完整路径、当前 SFTP 用户及主机地址。下方一行图标提供保存、重新加载、查找和自动换行，悬停显示操作名和已有快捷键。代码区随窗口伸缩且保留文档，底部状态栏显示修改、只读、行列、行数、编码及换行格式。打开时采用当前主题与界面字号，系统主题变化继续跟随；主窗口内后续的偏好修改在下次打开编辑器时应用。点击保存或使用保存快捷键时默认采用原子替换，无需额外勾选确认，不显示确认栏和保存限制展开项；限制由使用说明提供。错误在编辑器内显示，缺少原子能力时只读。

系统关闭按钮和 Alt+F4 共用未保存审核，可返回编辑、保存后关闭或明确放弃；重新加载也需审核。保存失败保留草稿，保存/读取中阻止关闭及应用退出。打开编辑器期间须先关闭文档再主动关闭所属 SFTP 连接、主机工作区、切换身份或迁移数据目录；断线后保留本地草稿，保存失败如实提示。主程序退出明确提示关闭编辑器并放弃未保存内容；取消退出保留窗口。编辑器打开期间阻止主窗口和编辑器页面导航/刷新，避免重载清理连接或丢失草稿；不提供崩溃恢复、窗口位置持久化或拖回主窗口。

SFTP 从主机工具栏进入；文件页打开目录/less/tail 经确认后使用独立 PTY，不向已有 Shell 注入命令。

## 插件平台与内置能力

### 平台契约与管理

Host、Rust SDK、TypeScript SDK 使用 5.4.0，UI v4、WASM ABI/wire 1。插件拥有业务页面、命令/SQL、解析、脱敏、提示词、工具循环和计划；宿主提供通用 SSH/SFTP、模型传输、公开元数据、权限、确认和资源生命周期。精确接口及限额统一见[公开 SDK](../plugins/PLUGIN_SDK.md)，本文件不复制接口表。

系统插件与上传插件共用标准包、运行时和安全边界。完整 `plugins/system` 源码目录在构建时发现并嵌入，源码删除不自动卸载用户安装。系统首次安装默认启用并预置声明权限，既有禁用、配置及卸载选择保留；上传同 ID 不能获得系统来源。上传包默认禁用且未授权，启用不代替授权；安装预览、升级、回滚、禁用确认、文件访问根和卸载数据选择须保留。没有签名验证时必须说明来源信息及 SHA256 不能证明作者身份，并要求用户明确确认本地开发包安装风险。

设置的插件列表直接提供启用/禁用及状态，详情 Tab 从左到右为「基本信息、插件配置」。基本信息展示来源、版本与包信息，权限与访问范围可展开查看：内置插件只读展示系统预置能力，上传插件保留授权/撤销及远程目录编辑。插件配置使用独立页面，无配置贡献时明确说明无需单独配置。管理或保存中阻止重复操作、分类切换和关闭；失败保留状态并显示原因。列表底部提供下载开发包，包含匹配的 SDK、锁文件、文档、工具和独立样例，能在仓库外构建并上传。

旧契约或损坏的单插件记录不进入可执行列表，应显示诊断且不阻断其他插件；不重置原记录或配置。有当前内置替代包时，可由用户明确选择备份并重装；备份成功后提交，新插件默认禁用且不继承旧授权。

命令默认逐次确认真实目标与完整内容。清单可声明完整固定命令，并通过独立 `ssh.execute.preapproved` 权限获得当前安装版本的精确预授权；上传包须展示完整命令并单独选择。流和 PTY 可通过独立 `ssh.interactive.preapproved` 权限预授权当前安装版本启动任意交互命令，上传包默认不授予。两者均需 SSH 基础授权，不保证命令只读，不接受插件自报已确认；文件读取及传输预检可通过独立任务读取预授权在用户选择的模式下免确认；写入/传输启动可按固定计划合并为一次确认，本机 TCP 仍须单次确认。

### Docker

提供真实能力检测、容器/镜像列表、容器启动/停止/重启/删除、详情、日志、Shell 及 Compose 项目管理。版本及操作系统检测、容器/镜像列表以及容器详情、资源使用、环境变量、Compose 项目列表、服务快照、启动配置及 Compose 配置读取十一条固定查询使用清单预授权；内置包打开详情、启动配置及环境变量读取无需逐次命令确认，日志和 Shell 使用独立交互会话预授权直接打开。变更和其他未声明命令沿用确认。用户权限不足、工具缺失或查询失败如实显示，不自动安装 Docker、Compose、提权或修改远端权限。

容器详情包含「概览、资源使用、启动配置、环境变量」四个标签，端口映射和挂载统一并入只读的 Compose YAML 启动配置。Compose 容器读取当前项目有序配置文件合并后的完整 service，并附带其引用的顶层网络、卷、configs 和 secrets 定义；其他 service 仅保留依赖引用。普通容器依据 inspect 转换镜像、命令、端口、挂载、网络、重启策略、健康检查和可映射的运行参数，外部卷/网络保留真实名称，未转换设置明确列出。标明配置来源及当前文件可能与创建时不同、转换无法完整恢复原始命令且不保证独立部署的限制。Compose 配置读取失败显示原因，用户可明确选择容器信息转换；Compose 配置通过两条完整固定脚本预授权读取，目录、有序文件和项目成员在读取时再次校验，前端仅收到所选 service。读取前检测 Compose 支持的选项，旧版不传入不支持的 `--no-env-resolution`，启动配置按当前项目环境解析 env_file 和变量表达式；其他项目失败不阻断当前项目，不扩展宿主通配预授权。进入启动配置时直接读取并显示环境变量值，不提供查看/隐藏按钮；独立环境变量标签保留按需读取，切换或关闭时清除明文和迟到响应。容器详情标题、关闭按钮和分类标签固定，仅下方详情内容滚动，长配置滚到底后仍可直接关闭；切换标签回到内容顶部。secrets/configs 只展示引用及定义，内联内容隐藏，不读取引用文件内容。日志和 Shell 在原页面弹窗中使用，关闭释放自有流/PTY。表格填满工作区并保留表头，短窗口操作可达；容器启动、停止、删除及镜像删除由可信宿主完成一次确认，无需输入目标 ID。确认标题明确操作，正文展示对象名称、短 ID、真实主机及服务中断/数据丢失影响，按钮使用“启动”“停止”“删除”；不展示“执行详情”入口或命令脚本。操作结果与失败即时呈现在页面，不提供独立的操作反馈记录功能。

容器 Shell 弹窗显示容器名称、短 ID、Shell、真实 SSH 主机地址及连接状态；加大默认可用空间，支持最大化/还原、查找、10–32 字号调整/重置、本地清屏、右键复制粘贴和 Ctrl+滚轮缩放。尺寸及显示操作保持同一 PTY，不重新执行命令或消费票据；清屏只清理本地显示，不停止远端进程。连接中、失败和会话结束有明确提示，断开后保留输出和原因，由原 Shell 入口重新打开。深浅主题、大字号和短窗口下操作可达。

容器与 Compose 日志弹窗固定标题和工具栏，仅日志区滚动。首次打开及自动跟随时定位到最新输出，窗口尺寸或字号变化后维持末尾；向上翻阅历史时保留当前位置，新日志继续接收。“最新日志”回到末尾并恢复跟随；暂停期间不自动跳动，继续后恢复跟随。过滤切换、结果为空或不足一屏、窗口重排及字号变化保持原跟随/历史模式，不能把布局触发的滚动当成用户翻阅；真实滚轮、滚动条和键盘滚动仍正确切换跟随。保留过滤、复制、导出与有界缓存；过滤无匹配项时显示空提示，流结束或失败时如实显示状态。

“Docker信息”入口打开同名只读表单，展示安装状态、运行状态、Docker 服务端版本、客户端版本、服务端运行平台及操作系统名称。操作系统来自当前 Docker daemon 的 `OperatingSystem`，与 `linux / amd64` 等运行平台分开展示；缺失显示“不可用”，不使用本机或客户端系统代替。状态采用中文，不展开原始 JSON 或全部组件字段。

容器、镜像和 Compose 项目的搜索框宽度约 320px，随窄窗口收缩，不随宽窗口铺满；刷新按钮统一为“刷新”。容器列表上方提供「清空容器日志」「重启已退出容器」，仅作用于当前主机，不受搜索筛选影响，已退出重启仅处理 `exited` 状态，不提供全部重启。容器行内提供「重启」，仅针对该行容器，由宿主确认名称、主机和服务中断影响，已停止容器会被启动。清空日志不可恢复，仅处理当前 Docker 数据目录内的 `json-file` 当前日志，其他驱动跳过，轮转历史保留；权限不足、异常路径或符号链接明确失败，不自动提权。操作期间禁止重复执行，结束显示结果并刷新列表；批量操作显示匹配/成功/失败/跳过数量，空目标无需变更，部分失败或超时须核对实际状态，不自动重试。

「Compose 项目」与容器、镜像并列，支持发现已有项目、查看服务容器状态/镜像/退出码、项目日志和整组启动/停止/重启。整组变更由宿主一次确认，展示真实 SSH 主机、项目名称和影响。启动仅作用于已创建的容器，包含 profile 服务；不提供配置编辑、镜像更新、重新部署或删除项目/数据卷。全部容器已删除的项目不在发现范围，详情不包含一次性运行容器和未创建服务。执行前核对真实项目目录及配置文件，无法恢复必要配置时明确失败；超时等未知结果须提示刷新核对，不自动重试。切页或隐藏释放自有日志流。真实 Compose 验证与原生 SSH/UI 验收分别记录，不相互替代。

### AI 运维助手与模型

助手为全宽聊天，支持直接发送、Enter/Shift+Enter、追问、停止、新对话及受限 Markdown。提问区采用加高文本区，审批模式、快捷键提示和发送按钮靠近外框底部；文本区聚焦不显示额外内层边框，模式选择等按钮保留键盘焦点提示。快捷问题仅填草稿。模型绑定统一在助手插件设置，供各主机共用，不自动改选模型；无绑定、凭据失效或模型删除明确提示。

助手配置按本地来源和远程模型分组选择，显示就绪状态及当前绑定；未就绪项不可选，不提供“不绑定模型”选项。只有选中已就绪模型后才能保存，不允许提交空绑定；首次未配置或绑定失效时保留未绑定/不可用提示，不自动选择替代模型。顶部提供刷新，平台模型管理从全局设置进入；内容区独立滚动，底部仅保留一组取消/保存操作，切换选择不自动保存。Docker 的统计、搜索与操作分区，表格保留自身滚动和响应式布局。两个插件均跟随平台主题与字号。

注册模型通过真实、无服务器上下文的连接测试后才能保存新建或关键配置/Key 变更；测试凭证为五分钟、单次使用，绑定当前配置、Key 摘要及编辑身份，过期、篡改或重放不能保存。每模型独立系统密钥、修订和上下文窗口，已有 Key 不回显、编辑留空保留，明确清除或删除需相应确认。设置的「模型」页面负责 CRUD，与插件绑定分开保存。

变更已保存模型的 API 地址时，须重新输入 Key 或明确清除，不能自动把原 Key 发送给新地址。

输入预算采用与服务端分词器无关的保守 UTF-8 估算，并预留最大输出空间；实际 Token 用量只来自模型响应，缺失时不编造，工具循环仅在各轮均有用量时累计显示。不估算费用。

「模型」页面以「本地来源」和「远程模型」两个 Tab 分开展示，默认打开远程模型。本地来源包含安装、授权和状态刷新及登录凭据说明；远程模型包含模型数量、注册、刷新、列表和 Key 保存/插件绑定提示。切换 Tab 保留当前操作状态，不中断本地工具下载；支持方向键和 Home/End 切换。

可选择已授权的本地 Codex 或 Claude Code，复用本机 CLI 配置和登录。两种来源独立授权/撤销，未授权不能读取配置或启动推理；切换来源、配置/模型修订变化使旧请求和计划失效。缺失、未授权、未登录和配置错误分别展示。Windows x64/ARM64 可从固定官方源下载并校验原生工具到应用目录，支持取消/重试，不覆盖系统程序或自动授权；其他平台提供手动引导。

资产匹配、上下文采集/脱敏、严格 query/plan/answer 编排和执行后复查属于助手插件。全部登记主机可参与匹配，每轮最多命中八台，入口主机提供当前上下文线索；首次 SSH 指纹核验不可省略。只采集问题需要的来源，失败/省略/缺失明确标记，不能将远端文本当成指令。模型只生成建议或计划，真实变更由可信宿主按审批模式授权并绑定冻结目标、参数及修订；取消/失效后不启动后续操作，不自动重试未知结果。

单主机智能体每任务最多六轮模型调用、十二次只读查询，每轮最多三项；计划最多 32 个真实目标，仅允许已查询容器/服务操作和完整查询中全部无标签且无带标签别名的镜像清理。不允许任意模型 Shell、指定镜像子集替代全量清理、强制删除、删除卷或额外父镜像。完整清单由插件从未截断证据筛选、去重和冻结，执行前复验，执行后逐项查询确认；多主机或无单一目标的命令建议仅供人工审阅。

输入区提供“请求批准”“帮我批准”“完全访问权限”三种模式，默认请求批准，发送时冻结，不持久化到配置；切换不会升级已有任务，但退出完全访问会撤销旧授权并使旧的完全访问计划失效。请求批准对外部读取、网络及命令按宿主规则询问，计划由用户点击后一次确认；帮我批准直接执行已授权的文件读取、传输预检、固定读取和经过严格参数校验的读取模板，仅对写入、未知命令等风险操作请求批准，计划可见时自动发起一次确认。完全访问须取得当前页面的可信宿主首次授权，在已授予能力及目录范围内持续自动执行，不设时间上限，不再逐项确认；切换模式、新建对话或关闭会话时撤销。撤权、插件停止/升级同样使授权失效；隐藏页面后返回不要求重新授权。首次主机指纹、基础权限、目标/配置修订、原文检查、限次计划及取消保护保持，模式或模型声明不能获得额外权限。

工具与任务基础将现有能力统一到目录与任务流程。目录提供工具名、读写类型、权限声明及严格参数；完整批次先校验再查询，未知字段、非法参数和读写越界均拒绝，目录本身不授予权限。查询与执行共用结构化工具结果，复用原有 Docker/systemd 操作及宿主审批。

对话在模型生成时逐步显示实际回答和计划说明，无需等待整轮结束；准备与工具查询仍显示处理中。片段先脱敏并安全渲染，完整响应通过校验前不开放计划操作。结束后替换为最终回答且不重复，中断/停止保留已生成内容及失败/停止状态，片段不进入后续历史；切换对话/模型或关闭会话后不接收旧片段。不以模拟打字代替上游流式输出，服务不支持流式时明确提示且不自动重试。

成功准备创建运行期任务，聊天展示准备、查询、等待审核、执行、复查及完成/失败/停止/未确认/过期状态。任务绑定原页面、模型和 SSH 修订，终态不可重放，异常尝试读取原任务；未知变更不能显示成功或自动重试。最多保留 32 项，优先淘汰旧终态，预览和计划从准备时刻起五分钟有效；不承诺中间状态实时推送，不提供持久任务中心或跨重启恢复。

文件编辑支持远程单个 UTF-8 普通文本（≤32 KiB）：按审批模式及既有目录授权读取，按同一原文行号生成局部修改，展示真实差异、路径和原文 SHA-256；按审批模式授权后复用 SFTP 冲突检测及原子保存，读回校验结果。保留未修改原文和换行，文件变化拒绝覆盖；不提供本地文本编辑或 YAML 语义/应用校验。

传输支持本机普通文件上传及两台已匹配服务器之间经本机流式中转至目标目录，源、目标、字节数和覆盖策略冻结在预览中。准备遵循读取审批模式，启动纳入按模式授权的固定计划；复用登录身份、主机指纹、目录授权、既有传输队列、同目录临时文件及 SHA-256 校验，不自动解压或执行。展示进度、速度、校验和及取消，字节不经过模型或插件桥。仅传单文件，目录、链接、断点续传和跨重启恢复未提供；目标存在须明确重新准备覆盖，提交或复查不确定标记未确认并禁止重放。运行期任务不受启动前五分钟预览有效期截断，关闭所属页面、撤权或插件停止会取消并等待安全收尾。

当前助手不提供 Skill/MCP、步骤依赖/重新规划或跨重启恢复。

上下文先脱敏再截短，按完整成功查询统计后限制明细；诊断只发送匹配目标，普通知识问题不附资产目录，仅明确资产清单问题携带目录。准备阶段与每轮模型调用按实际 JSON 编码后的保守 UTF-8 预算预留输出，先缩减可选明细，再删除最早的完整历史轮次，保留当前问题、主机归属、完整统计、失败及省略说明；仍放不下时明确拒绝，不截断问题或半轮历史。前端发送历史时同样按完整请求编码大小删去旧轮次，避免截断敏感值后使脱敏失效。

切换工具、主机或设置保留已开始的对话与任务，后台不能发起新变更确认；关闭页面只取消自有工作，不影响其他 owner。模型消息受已授予能力和预算约束，登录数据及 Key 不进入插件，敏感载荷不记日志。

## 设置、数据与安全

统一设置窗口包含通用、终端、快捷键、数据与存储、模型、插件、关于。前四类共用草稿和统一保存，切换分类保留修改；关闭检查未保存偏好和目录修改，放弃才回滚预览，失败保持未保存状态。模型和插件配置独立保存。保存、迁移或插件操作中不能关闭或离开，关闭后焦点回到入口。

“关于”展示产品说明、真实应用版本、发布时间和本地环境，不展示技术栈。发布时间取前端打包时生成的固定时间，按北京时间显示；重新打开或检查后端不改变该值，后端未就绪时仍可查看。

各偏好分类可恢复默认，但仍须统一保存；通用恢复不改写隐藏的监控采样间隔。数据与存储包含目录、下载、传输和日志设置，不设置单独凭据维护入口。界面语言支持简体中文和 English，默认简体中文；保存成功后桌面及内置 Docker、AI 助手界面立即切换，重启沿用保存值。语言草稿、恢复默认及保存失败遵循同一保存规则，切换语言不重建连接、终端或插件页面。主机名、文件内容、命令输出、模型回答和原始技术诊断保持原文；上传插件的自有翻译由其实现负责。

数据默认存于标准用户应用目录，不写安装目录。用户可明确迁移整个数据根，先预览、确认重启，再校验复制及数据库，启动确认后安全清理已核对的源文件；故障保留原数据并可诊断。迁移结果保留在设置页作为历史，本次启动产生的迁移完成/失败结果才弹出通知，后续普通启动不重复提示；清理未完成的实际重试仍报告结果。系统凭据不复制进普通文件。

安装新版后，已支持的数据库结构和持久配置自动升级，保留主机、分组、凭据引用、主机指纹、用户偏好、插件设置及现存附加数据。升级在业务初始化前取得写锁，先保存完整一致备份，再事务性修改并校验；备份失败或升级失败停止，保留原数据和原因，不清库或恢复默认。反复启动不重复升级或备份，并发启动不执行两份迁移；有 WAL 时也必须保留已提交内容。

数据库、应用偏好和模型注册格式分别管理版本；旧配置仅按有依据的规则补充新增默认字段、转换已知字段，已有设置不得被默认值覆盖。当前配置严格校验，未知/未来版本、损坏或无版本的非空数据库明确拒绝。模型配置按需独立升级，失败不阻断主机和终端。升级不改变插件执行协议、权限及系统凭据授权，不自动迁移旧应用身份。备份可供检查恢复，但恢复或降级不能覆盖升级后新增数据，需用户另行明确选择；精确范围见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

日志分级、轮转、有界，不记录密码、私钥、Key、私密终端/文件正文或模型载荷。前端只能调用授权 IPC，不能无约束访问本地文件或 Shell；远程操作保留路径、权限、主机密钥和危险操作确认。无默认用户数据上传，自动更新若实施须另行设计可信签名。

## 性能、稳定性与验收要求

工程目标为冷启动三秒内可交互、空闲内存尽量控制在 150 MB 内、至少 20 个活动 SSH 终端，须记录实际机器、进程树及测试条件，不作为未经测量的支持承诺。输出流式且有背压，任务和缓冲有界；监控、传输、插件及单终端失败不能拖垮其他独立功能。

已有监控基础能力应使用真实 SSH 只读采样，CPU/网络采用连续计数差，首次/异常为未知，不能把失败显示为 0；内存、Swap、负载、磁盘、网卡、uptime 和系统信息遵循真实语义，隐藏暂停或降低采样，历史仅在有界内存中保存。不以保留后端能力冒充当前有独立监控/系统服务插件。

达到发布候选前须验证：主机管理与认证、主机密钥拒绝、多终端/分屏/重连、SFTP 校验/冲突/取消/编辑保护、插件安装/权限/撤权/故障隔离、模型修订与变更确认、退出资源释放及持久数据保护。终端验收包含 vim/top、Ctrl+C/Z、PTY resize 和独立会话不互扰；文件验收包含中文/空格/特殊名称、哈希一致、权限拒绝、取消及只删除已确认对象。正常、空、加载和失败流程均有真实断言。发布前须逐项满足[发布检查表](../release/RELEASE_CHECKLIST.md)；构建成功不代表候选产物及所有平台已经验收。

开发约束统一见[开发规范](../../AGENTS.md)。验证须说明实际候选产物、环境、结果和未执行项。
