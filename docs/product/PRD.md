# ServerDeck 产品功能需求说明书（PRD）

本文件按功能维护当前有效需求；实现状态和验收缺口见[实施计划](IMPLEMENTATION_PLAN.md)，设计见[总体架构](../architecture/ARCHITECTURE.md)。需求变化直接修订对应章节，逐次改动由 Git 追踪。

## 产品定位与范围

ServerDeck 是面向个人开发者、DevOps 和小型团队的本地桌面服务器工作台，以安全 SSH、SFTP 和按需扩展为核心。无需云账号，不要求远端安装 Agent。主机、偏好和插件配置保存在本机，秘密交给操作系统凭据库。

应用版本以根目录 [Cargo.toml](../../Cargo.toml) 的 `[workspace.package].version` 为唯一来源，程序、安装包和关于页保持一致，发布清单从该工作区读取；修改后直接使用已有开发/打包命令，入口自动同步工作区锁文件及检查来源，不要求单独运行版本命令。尚未正式 release。SDK、插件包和数据格式独立管理版本。Windows 11 x64 是首要验收平台；macOS、Linux 和其他架构须分别验收，不能把构建配置或单项验证等同于完整支持。

| 范围         | 当前要求                                                                        |
| ------------ | ------------------------------------------------------------------------------- |
| 应用基础     | 单实例、主题、窗口偏好、设置、日志、错误提示和安全退出                          |
| 主机连接     | 多级文件夹、搜索、连接测试、密码/公钥认证、受限 OpenSSH Config 导入、代理和跳板 |
| 终端         | 本地与 SSH Shell、多会话、分屏、转发、原生文本剪贴板和 rz 上传                  |
| 文件         | 双栏 SFTP、目录操作、可取消传输、校验和原子文本编辑                             |
| 插件         | 本地包安装、权限、启停、配置、卸载和公开 SDK；内置 Docker 与 AI 运维助手        |
| 外部扩展     | MySQL 巡检由独立工程使用下载的公开 SDK 构建，用户上传安装                       |
| 宿主基础服务 | 保留已有监控、运维和通用执行能力；不因此承诺已移除的独立页面仍存在              |

当前不提供内置 Nginx、系统服务插件、独立网络诊断、批量运维、自动运维/常用命令库、本地任务调度或任务中心，也不提供主机 JSON 导入导出、应用配置备份恢复。删除代码或停止分发不自动删除既有用户安装、配置、授权、数据库附加表或远端服务。

Kubernetes、数据库可视化客户端、远程桌面、云同步、团队 RBAC、插件市场、长期时序数据库、集中日志平台、支付和订阅授权均不在当前范围。后续版本或商业化设想须单独确认后才能成为实施任务。

## 桌面工作台与交互

### 导航与工作区

- 顶部显示产品标识、侧栏开关和全局搜索；不设置大模块切换或重复应用菜单。
- 本地终端固定在主机树上方，底部提供设置。主机标题显示总数和新建入口，搜索不影响总数。
- 侧栏收起后保留 52px 图标栏，提供展开、本地终端和设置；窄窗口展开主机树使用浮层。收起/展开保留搜索、树和会话状态，不创建或关闭连接。
- 本地终端、远程主机和全局插件功能按打开顺序共用一排工作区标签。设置和插件管理使用统一设置窗口，不创建工作区标签。
- 工作区功能页的「插件设置」打开只包含当前插件的独立弹窗，不进入全局设置；关闭恢复入口焦点，保留底层页面、查询结果、筛选和滚动状态，不因开关弹窗重新加载 Docker 列表。插件管理列表内的详情仍在设置窗口展示。
- 每台主机保留本次打开期间最近使用的工具、插件页面、终端会话和文件路径。SSH、SFTP 与已启用且有功能页面的插件按钮平铺，窄窗口换行；本地工作区仅提供本地终端。
- 启动显示欢迎页，不恢复终端会话或分屏，不自动连接。显式打开主机时只连接当前空闲 Shell；重复点击复用已有连接，失败须明确重试。
- 工作区标签菜单提供关闭、关闭右侧、关闭其它、关闭所有，以右键目标和可见顺序确定范围，右键本身不切换活动页。

### 关闭与资源保护

关闭主机工作区须检查未保存文件、插件草稿及未完成传输。用户取消时保留工作区、会话和传输；确认取消传输后等待安全提交和清理，再关闭该主机的文件连接及终端。关闭失败保留工作区和记录，其他主机不受影响。成功关闭后清除本主机临时传输记录，不删除文件。

默认关闭主窗口即申请退出，确认界面说明连接/会话、未完成任务和未保存修改，短窗口正文可滚动，底部操作可达；关闭确认窗口或 Esc 取消退出。确认后取消并排空后台工作、关闭全部本地/远程终端与转发、完成必要持久化和日志刷新。取消退出保留本次状态，不提供托盘常驻。

### 显示、通知与可访问性

- 主窗口最小尺寸为 960×600 逻辑像素，默认 1280×820，重启恢复上次窗口尺寸和最大化状态。已保存的较小窗口尺寸在恢复时按当前最小尺寸放大；设置弹窗自适应可用空间，长内容内部滚动，保存、取消及关闭操作在最小窗口和超大字号下仍可访问。
- 默认深色，支持浅色及系统主题。页面铺满工作区，列表在自身区域滚动，长内容和大字号下操作仍可访问。
- 界面字号为小/标准/大/特大/超大，比例 95%/100%/115%/130%/145%。标准主要文字 14px，辅助信息 12px、分组标题 16px、弹窗标题 20px、页面标题 24px。终端内容字号独立。
- 标题、导航、标签和按钮禁止浏览器原生文字选择；通知正文、输入、可编辑内容和文本输出支持选择与复制，弹窗内一致。
- 错误文案统一由右下角通知呈现，支持关闭、去重和文本复制；轮询不重复提示同一失败。弹窗内通知仍可见可操作。保留业务失败状态、重试、过期标记、安全确认和原始业务输出。
- 全局搜索支持入口和可配置快捷键、方向键、Enter/Esc；只检索本地可公开目录与功能，不搜索私密终端输出。

## 主机与 SSH 认证

### 主机目录

主机配置包括可选名称、地址、端口（默认 22）、用户名、密码或公钥认证、连接超时（默认 15 秒）及高级代理/跳板设置。地址和端口须合法；名称仅空白时视为未填写。无名称时显示地址，非 22 端口追加端口号，IPv6 使用方括号避免歧义。搜索匹配名称、地址和用户名，不提供标签、备注或收藏管理。

根目录为不可重命名/删除的内置节点，支持多级文件夹、全局唯一文件夹名称、展开折叠和祖先路径。新建主机归属于入口文件夹，编辑保留原归属；拖动移动须持久化并拒绝无效父目录或循环。删除文件夹需确认，将主机和直接子文件夹提升至父目录，不递归删除内容。

主机行仅展示名称、地址和连接状态。编辑/复制/删除通过右键菜单进入，根目录另提供 OpenSSH Config 导入。菜单操作绑定右键目标，不因打开菜单切换工作区；支持键盘、焦点恢复和窗口边界。复制生成独立配置，不自动连接；删除需确认，失败保留数据。

### 连接测试与保存

新建/编辑表单直接填写密码、粘贴私钥或选择私钥文件，支持加密私钥解锁口令。编辑同一认证方式时留空沿用已有凭据；已有 Agent 主机可继续使用 Agent。更换认证只影响当前主机，不改写其他共享该凭据的主机。

“测试连接”使用完整草稿及实际路由完成 SSH 握手和认证，首次指纹须用户核验，密钥变化必须阻断。成功结果限五分钟、单次使用且绑定草稿、主机身份、SSH 路由及凭据版本；修改、失败或过期后重新测试才能保存。移动、复制和 OpenSSH 导入沿用各自受限流程。

### 信任、凭据与路由

- 区分未连接、连接中、等待信任、已认证、断开和失败；TCP 可达不等于 SSH 登录成功。
- 主机信任记录与凭据分开。首次连接显示算法及 SHA256 指纹，用户明确接受后继续；已知密钥变化不提供静默覆盖。系统 known_hosts 哈希、CA 和撤销语义未完成，不能宣称兼容。
- 密码、导入私钥及必要口令通过系统凭据库管理，SQLite 仅保存引用和修订；服务不可用明确失败，不回退明文。私钥算法受安全门禁约束，拒绝本地 RSA 私钥签名，不能为了兼容降低校验。
- 支持受管跳板和 SOCKS5/HTTP CONNECT 代理；逐跳验证身份。HTTP Basic/SOCKS 认证的传输边界须说明，不执行 ProxyCommand 或任意本地 Shell 拼接。
- OpenSSH Config 导入先预览选择，提交重新校验并事务去重，不覆盖已有主机。支持范围和拒绝项见[架构中的导入边界](../architecture/ARCHITECTURE.md#主机与凭据)。影响目标、认证或信任的未知配置不能静默忽略。

## 终端

### 交互与会话

基础交互包括真实本地/SSH PTY、UTF-8、ANSI、256 色/True Color、鼠标、Ctrl+C/Z、选择、查找、复制粘贴、滚动和 resize。断开后保留显示历史和原因，提供同一窗格的明确重连入口；重连关闭旧会话并创建新 Shell，不重放输入或伪装恢复远端进程。连接中或重新执行固定文件/容器动作前须确认；一次性插件终端票据不允许重放，主机连接配置变化须从主机树重新打开。

同一主机可有多个独立会话，支持标签排序、双击重命名、关闭及水平/垂直分屏。会话标签提供“复制、重命名、关闭所有、关闭”菜单，可由右键、Shift+F10 或菜单键打开；操作以菜单目标为准，关闭所有仅作用于该主机，关闭失败保留相应会话。复制创建普通新 Shell，不克隆 Session ID、分屏、运行进程、文件/容器动作或插件票据。每个窗格有独立会话身份，调整几何不能重建 Shell；关闭一个窗格不能误关其他窗格。

默认“会话 N”按主机在本次运行内计数，删除中间会话不补号；最后一个会话成功关闭后重置，失败不重置。标签、名称和分屏不跨重启恢复。

### 偏好与输入保护

支持字体、10–32 字号（默认 16）、行高、光标、主题、滚动缓冲和快捷键；Ctrl+滚轮每次调整字号 1，已打开终端同步更新。Linux 有效行高最低 110%，保护下划线，不改写保存值。

原生文本剪贴板由用户动作触发，无自动读取或网页接口回退。终端内容菜单只提供复制和粘贴，并显示对应快捷键。支持默认关闭的“选中即复制、右键即粘贴”，Shift+右键或键盘菜单仍可打开菜单。重连/卸载后丢弃旧剪贴板结果。单次粘贴最多 2 MiB，超过配置字符阈值或 50 行须确认并使用 Bracketed Paste；不能保证远端禁用该协议时换行不执行。

默认终端快捷键以当前 `TerminalPreferences` 为准：

| 操作         | 当前默认快捷键   |
| ------------ | ---------------- |
| 复制         | Ctrl+Shift+C     |
| 粘贴         | Ctrl+Shift+V     |
| 查找         | Ctrl+Shift+F     |
| 上下分屏     | Ctrl+Shift+H     |
| 左右分屏     | Ctrl+Shift+E     |
| 新建终端会话 | Ctrl+Shift+T     |
| 关闭当前窗格 | Ctrl+Shift+W     |
| 下一个会话   | Ctrl+Shift+Right |
| 上一个会话   | Ctrl+Shift+Left  |
| 放大字号     | Ctrl+Shift+=     |
| 缩小字号     | Ctrl+Shift+-     |

全局搜索为 Ctrl+K，设置为 Ctrl+,；macOS 按平台习惯适配，完整平台验证仍需单独完成。配置不能意外拦截远端 Ctrl+C/Z。

窗格底部的“终端操作”菜单提供重连、端口转发、打开 SFTP 文件及导出终端文本，内容区右键菜单继续只提供复制/粘贴。用户确认后可主动导出当前窗格普通屏幕和滚动历史为 UTF-8 文本，不包含其他会话或备用屏幕，不默认录制或自动持久化正文。

Linux 本地终端使用用户默认交互 Shell，保留启动文件、别名和提示符；AppImage 子进程只剔除包内 Python/搜索路径污染。Windows 使用系统 PowerShell。应用不修改用户 Shell 配置或重启已有会话。

### 转发与 rz 上传

已连接 SSH 窗格从“终端操作 → 端口转发”管理归属当前会话的 Local/Remote/Dynamic 转发，默认回环地址，公共绑定须明确确认；停止、断线或关闭会话清理监听和流，遵守服务器策略，不跨重启自动恢复。本地 Shell 不提供远程转发。

远端 rz 握手可触发原生多文件选择，通过当前 PTY 上传，支持进度、取消、中文、二进制和空文件；每批最多 100 个普通文件，单文件小于 4 GiB。传输隔离普通输入，取消选择/断线/重连不能把旧数据发送到新会话。拒收或跳过如实显示；sz 下载不在范围，下载使用 SFTP。

## SFTP 文件与文本编辑

### 浏览与布局

本地/远程双栏填满工作区、独立滚动，按可用宽度和字号并排或上下排列；地址栏、父目录、刷新、名称搜索、表头排序、多选和右键操作可达。名称、大小、类型、修改时间及远程权限/属主按真实元数据显示。隐藏文件默认不显示，可切换；隐藏后移除选区中的隐藏条目。

切换目录先显示目标路径与列表内加载态，不展示旧条目；失败恢复旧路径和列表并提示，连续请求仅接受最新结果。两栏后退/前进历史独立，鼠标侧键作用于指针所在栏。Windows 本地路径使用盘符或 UNC 显示与复制，文件操作沿用原始路径。

左右宽度手动调整和仅远程视图仍为待实现需求，不能因为文档整理视为取消。MVP 不做远程全文搜索。

### 传输和文件操作

支持文件/目录上传下载、多选、递归、原生拖放上传、远程条目拖入本地栏，以及 Windows 普通文件/文件链接拖到桌面或资源管理器。目录及目录链接不参与窗口外拖放。明确选中的文件链接仅在目标为普通文件时下载，以链接名保存内容；递归扫描不跟随链接。

任务具有独立 ID、进度/速度/字节/状态、取消和重试，后台传输不阻塞终端。当前确认界面的冲突策略为停止提示、跳过和确认覆盖；底层仍有自动重命名策略，但界面没有该选项，不将其描述成当前可选操作。先同目录临时写入、校验 SHA-256，再安全提交；取消保留已提交文件，清理失败提示恢复路径。不承诺断点续传或跨重启恢复，失败重试从头传输。

当前主机有活动传输时底部面板占用有限高度，结束后列表收回空间；已结束任务从页头“传输记录”查看/重试。正常完成不弹成功通知，失败和清理异常仍提示。切换工具或主机保留任务与记录，成功关闭所属主机后清除临时记录。

新建目录、重命名、删除遵守真实权限和路径边界。删除须确认并显示对象，目录确认后递归删除；禁止删除根目录、不跟随目录中的链接，不用未转义 Shell 拼接代替 SFTP。

### 文本编辑和终端联动

编辑器只打开严格 UTF-8 普通文本，二进制、过大文件及不支持格式明确拒绝。保存前检查内容摘要和属性，保留基本权限/属主并原子替换；冲突、权限不足、缺少原子能力或元数据保留失败时不截断原件。须说明 inode、ACL/xattr、硬链接及无服务端 CAS 的限制。

未保存内容关闭/重载前确认，失败保留草稿。已连接 SSH 窗格从“终端操作 → 打开 SFTP 文件”携带其主机、已校验 OSC 7 目录及来源窗格；没有有效目录时沿用文件页导航，不解析提示符猜路径，不持续自动跟随。文件页打开目录/less/tail 经确认后使用独立 PTY，不能向已有 Shell 注入命令。

## 插件平台与内置能力

### 平台契约与管理

Host、Rust SDK、TypeScript SDK 使用 5.0.0，UI v4、WASM ABI/wire 1。插件拥有业务页面、命令/SQL、解析、脱敏、提示词、工具循环和计划；宿主提供通用 SSH/SFTP、模型传输、公开元数据、权限、确认和资源生命周期。精确接口及限额统一见[公开 SDK](../plugins/PLUGIN_SDK.md)，本文件不复制接口表。

系统插件与上传插件共用标准包、运行时和安全边界。完整 `plugins/system` 源码目录在构建时发现并嵌入，源码删除不自动卸载用户安装。系统首次安装默认启用并预置声明权限，既有禁用、配置及卸载选择保留；上传同 ID 不能获得系统来源。上传包默认禁用且未授权，启用不代替授权；安装预览、升级、回滚、禁用确认、文件访问根和卸载数据选择须保留。没有签名验证时必须说明来源信息及 SHA256 不能证明作者身份，并要求用户明确确认本地开发包安装风险。

设置的插件列表直接提供启用/禁用及状态，详情 Tab 从左到右为「基本信息、插件配置」。基本信息展示来源、版本与包信息，权限与访问范围可展开查看：内置插件只读展示系统预置能力，上传插件保留授权/撤销及远程目录编辑。插件配置使用独立页面，无配置贡献时明确说明无需单独配置。管理或保存中阻止重复操作、分类切换和关闭；失败保留状态并显示原因。列表底部提供下载开发包，包含匹配的 SDK、锁文件、文档、工具和独立样例，能在仓库外构建并上传。

旧契约或损坏的单插件记录不进入可执行列表，应显示诊断且不阻断其他插件；不重置原记录或配置。有当前内置替代包时，可由用户明确选择备份并重装；备份成功后提交，新插件默认禁用且不继承旧授权。

命令默认逐次确认真实目标与完整内容。清单可声明完整固定命令，并通过独立 `ssh.execute.preapproved` 权限获得当前安装版本的精确预授权；上传包须展示完整命令并单独选择。该机制不保证命令只读，不接受插件自报已确认，流、PTY、文件写入和本机 TCP 连接仍须单次确认。

### Docker

提供真实能力检测、容器/镜像列表、容器启动/停止/删除、详情、日志和 Shell。版本检测、容器/镜像列表以及容器详情、资源使用、环境变量六条固定查询使用清单预授权；内置包打开详情及切换详情标签直接读取，变更和未声明命令沿用确认。用户权限不足、工具缺失或查询失败如实显示，不自动安装 Docker、提权或修改远端权限。

容器详情包含概览、资源、端口映射、挂载和环境变量，字段/方向/访问模式清晰。环境变量按需读取，切换或关闭时清除明文。日志和 Shell 在原页面弹窗中使用，关闭释放自有流/PTY。表格填满工作区并保留表头，短窗口操作可达；镜像删除由可信宿主完成一次确认。操作结果与失败即时呈现在页面，不提供独立的操作反馈记录功能。

### AI 运维助手与模型

助手为全宽聊天，支持直接发送、Enter/Shift+Enter、追问、停止、新对话及受限 Markdown。快捷问题仅填草稿。模型绑定统一在助手插件设置，供各主机共用，不自动改选模型；无绑定、凭据失效或模型删除明确提示。

助手配置按本地来源和远程模型分组选择，显示就绪状态及当前绑定；未就绪项不可选，不提供“不绑定模型”选项。只有选中已就绪模型后才能保存，不允许提交空绑定；首次未配置或绑定失效时保留未绑定/不可用提示，不自动选择替代模型。顶部提供刷新，平台模型管理从全局设置进入；内容区独立滚动，底部仅保留一组取消/保存操作，切换选择不自动保存。Docker 的统计、搜索与操作分区，表格保留自身滚动和响应式布局。两个插件均跟随平台主题与字号。

注册模型通过真实、无服务器上下文的连接测试后才能保存新建或关键配置/Key 变更；测试凭证为五分钟、单次使用，绑定当前配置、Key 摘要及编辑身份，过期、篡改或重放不能保存。每模型独立系统密钥、修订和上下文窗口，已有 Key 不回显、编辑留空保留，明确清除或删除需相应确认，不保存旧价格字段。设置的「模型」页面负责 CRUD，与插件绑定分开保存。

变更已保存模型的 API 地址时，须重新输入 Key 或明确清除，不能自动把原 Key 发送给新地址。

输入预算采用与服务端分词器无关的保守 UTF-8 估算，并预留最大输出空间；实际 Token 用量只来自模型响应，缺失时不编造，工具循环仅在各轮均有用量时累计显示。不计算已经移除的单价/费用。

「模型」页面以「本地来源」和「远程模型」两个 Tab 分开展示，默认打开远程模型。本地来源包含安装、授权和状态刷新及登录凭据说明；远程模型包含模型数量、注册、刷新、列表和 Key 保存/插件绑定提示。切换 Tab 保留当前操作状态，不中断本地工具下载；支持方向键和 Home/End 切换。

可选择已授权的本地 Codex 或 Claude Code，复用本机 CLI 配置和登录。两种来源独立授权/撤销，未授权不能读取配置或启动推理；切换来源、配置/模型修订变化使旧请求和计划失效。缺失、未授权、未登录和配置错误分别展示。Windows x64/ARM64 可从固定官方源下载并校验原生工具到应用目录，支持取消/重试，不覆盖系统程序或自动授权；其他平台提供手动引导。

资产匹配、上下文采集/脱敏、严格 query/plan/answer 编排和执行后复查属于助手插件。全部登记主机可参与匹配，每轮最多命中八台，入口主机提供当前上下文线索；首次 SSH 指纹核验不可省略。只采集问题需要的来源，失败/省略/缺失明确标记，不能将远端文本当成指令。模型只生成建议或计划，真实变更由可信宿主确认并绑定冻结目标、参数及修订；取消/失效后不启动后续操作，不自动重试未知结果。

单主机智能体每任务最多六轮模型调用、十二次只读查询，每轮最多三项；计划最多 32 个真实目标，仅允许已查询容器/服务操作和完整查询中全部无标签且无带标签别名的镜像清理。不允许任意模型 Shell、指定镜像子集替代全量清理、强制删除、删除卷或额外父镜像。完整清单由插件从未截断证据筛选、去重和冻结，执行前复验，执行后逐项查询确认；多主机或无单一目标的命令建议仅供人工审阅。

上下文先脱敏再截短，按完整成功查询统计后限制明细；诊断只发送匹配目标，普通知识问题不附资产目录，仅明确资产清单问题携带目录。准备阶段与每轮模型调用按实际 JSON 编码后的保守 UTF-8 预算预留输出，先缩减可选明细，再删除最早的完整历史轮次，保留当前问题、主机归属、完整统计、失败及省略说明；仍放不下时明确拒绝，不截断问题或半轮历史。前端发送历史时同样按完整请求编码大小删去旧轮次，避免截断敏感值后使脱敏失效。

切换工具、主机或设置保留已开始的对话与任务，后台不能发起新变更确认；关闭页面只取消自有工作，不影响其他 owner。模型消息受已授予能力和预算约束，登录数据及 Key 不进入插件，敏感载荷不记日志。

外部 MySQL 巡检只使用公开 SDK，支持服务器/容器及远端默认客户端配置、登录路径或指定配置文件，提供概览、连接、语句摘要统计、锁等待、事务、复制状态和库容量七类固定只读查询。首版目标为 MySQL 8.0.22+/8.4；不保存密码，不提供任意 SQL、写入或自动修复。真实复制拓扑、登录路径认证等仍以[插件验证记录](../validation/plugins/PLUGIN_TEST_REPORT.md)的限制为准，不能由目标版本推断完整兼容。

## 设置、数据与安全

统一设置窗口包含通用、终端、快捷键、数据与存储、模型、插件、关于。前四类共用草稿和统一保存，切换分类保留修改；关闭检查未保存偏好和目录修改，放弃才回滚预览，失败保持未保存状态。模型和插件配置独立保存。保存、迁移或插件操作中不能关闭或离开，关闭后焦点回到入口。

各偏好分类可恢复默认，但仍须统一保存；通用恢复不改写隐藏的监控采样间隔。数据与存储包含目录、下载、传输和日志设置，不设置单独凭据维护入口。当前完整界面语言为简体中文，插件跟随全局语言。

数据默认存于标准用户应用目录，不写安装目录。用户可明确迁移整个数据根，先预览、确认重启，再校验复制及数据库，启动确认后安全清理已核对的源文件；故障保留原数据并可诊断。系统凭据不复制进普通文件。

安装新版后，已支持的数据库结构和持久配置自动升级，保留主机、分组、凭据引用、主机指纹、用户偏好、插件设置及未使用的历史数据。升级在业务初始化前取得写锁，先保存完整一致备份，再事务性修改并校验；备份失败或升级失败停止，保留原数据和原因，不清库或恢复默认。反复启动不重复升级或备份，并发启动不执行两份迁移；有 WAL 时也必须保留已提交内容。

数据库、应用偏好和模型注册格式分别管理版本；旧配置仅按有依据的规则补充新增默认字段、转换已知字段，已有设置不得被默认值覆盖。当前配置严格校验，未知/未来版本、损坏或无版本的非空数据库明确拒绝。模型配置按需独立升级，失败不阻断主机和终端。升级不改变插件执行协议、权限及系统凭据授权，不自动迁移旧应用身份。备份可供检查恢复，但恢复或降级不能覆盖升级后新增数据，需用户另行明确选择；精确范围见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

日志分级、轮转、有界，不记录密码、私钥、Key、私密终端/文件正文或模型载荷。前端只能调用授权 IPC，不能无约束访问本地文件或 Shell；远程操作保留路径、权限、主机密钥和危险操作确认。无默认用户数据上传，自动更新若实施须另行设计可信签名。

## 性能、稳定性与验收要求

工程目标为冷启动三秒内可交互、空闲内存尽量控制在 150 MB 内、至少 20 个活动 SSH 终端，须记录实际机器、进程树及测试条件，不作为未经测量的支持承诺。输出流式且有背压，任务和缓冲有界；监控、传输、插件及单终端失败不能拖垮其他独立功能。

已有监控基础能力应使用真实 SSH 只读采样，CPU/网络采用连续计数差，首次/异常为未知，不能把失败显示为 0；内存、Swap、负载、磁盘、网卡、uptime 和系统信息遵循真实语义，隐藏暂停或降低采样，历史仅在有界内存中保存。不以保留后端能力冒充当前有独立监控/系统服务插件。

达到发布候选前须验证：主机管理与认证、主机密钥拒绝、多终端/分屏/重连、SFTP 校验/冲突/取消/编辑保护、插件安装/权限/撤权/故障隔离、模型修订与变更确认、退出资源释放及持久数据保护。终端验收包含 vim/top、Ctrl+C/Z、PTY resize 和独立会话不互扰；文件验收包含中文/空格/特殊名称、哈希一致、权限拒绝、取消及只删除已确认对象。正常、空、加载和失败流程均有真实断言。稳定版还须关闭[实施计划中的验收缺口](IMPLEMENTATION_PLAN.md#剩余工作与验收门禁)，满足[发布检查表](../release/RELEASE_CHECKLIST.md)；构建成功或历史测试通过不代表当前版本及所有平台已经验收。

开发约束统一见[开发规范](../../AGENTS.md)。测试证据保留各自版本、环境、失败和限制，见[验证索引](../validation/README.md)。
