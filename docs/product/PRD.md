# ServerDeck 产品基线（PRD）

本文定义当前产品的功能、交互和使用边界，是后续需求的起点。实现见[总体架构](../architecture/ARCHITECTURE.md)，操作见[使用说明](https://ops.hiboot.cn/docs/)，上线验收见[发布检查表](../release/RELEASE_CHECKLIST.md)。功能已实现不等于候选安装包已经通过验收。

## 产品定位与范围

ServerDeck 面向个人开发者、DevOps 和小型团队，是通过 SSH/SFTP 管理服务器的本地桌面工作台。无需云账号或远端 Agent；主机、偏好和插件配置保存在本机，密码、私钥和模型 Key 交给操作系统凭据库。

| 产品入口         | 当前能力                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| 首页与主机工作区 | 工具启动台、主机收藏、多级主机目录、环境标签、搜索、SSH/SFTP 和插件入口 |
| 本地终端与 SSH   | 多会话、分屏、查找、剪贴板、快捷键、重连、本地端口转发、rz 和当前 Shell 拖放上传 |
| SFTP 文件        | 双栏浏览、目录操作、后台传输、校验、切换用户、内置与外部编辑             |
| Docker 插件      | 容器、镜像、Compose 项目、启动配置、环境变量、日志、Shell 和镜像归档传输 |
| AI 运维助手      | 主机关联、证据采集、流式回答、按模式审批的工具任务和执行后复查           |
| 设置             | 通用、终端、快捷键、数据与存储、标签、模型、插件、关于与软件更新     |

Windows x64 是首要发布验收平台。macOS、Linux 和其他架构须分别完成原生验收；构建配置和单项测试不构成完整平台支持承诺。界面支持简体中文和 English。应用版本以根 [Cargo.toml](../../Cargo.toml) 的工作区版本为准；SDK、插件包和持久格式独立管理版本。

发布流程默认构建同一版本的 Windows x64 安装包和 Linux x86_64 的 deb/AppImage。手动触发时可勾选 macOS 打包，同时构建 Intel 和 Apple Silicon（M 系列）的 DMG 和应用 ZIP。所选平台的附件齐全后上传到同一个 Release 草稿，经过验收再手动公开。Linux、macOS 使用手动下载安装升级，应用内自动更新仍仅面向 Windows x64 正式 NSIS 安装版。macOS 尚未接入 Apple 开发者证书签名和公证，打包与上传成功不代表已通过系统信任或安装运行验收。

当前不提供云同步、团队权限、插件在线下载安装、独立监控/系统服务页面、集中式时序或日志平台。官网的插件市场为静态展示页，支持搜索、分类与排序，下载统一提示“建设中”，不向客户端安装插件。宿主内部的监控、运维和执行能力不代表存在相应产品入口或插件领域 API。

## 桌面工作台与交互

### 导航与工作区

- 主窗口使用自定义标题栏，提供全局搜索和原生窗口控制；关闭进入退出审核。工作台使用三栏：52px 全局导航、可调宽度的菜单/会话栏、内容区，各栏独立滚动。主机栏和本地会话栏的标题右侧提供收起图标，收起后保留窄栏中的展开图标并扩展内容区；两者在本次运行中分别保留收起状态，展开恢复原宽度、搜索和列表状态，连接及终端继续运行。设置菜单保持展开。
- 全局入口为首页、本地终端和设置。首页保留固定“首页”标签及已打开的主机/全局插件标签；本地会话从独立入口访问。切换入口保留当前内容、连接、分屏、路径、筛选、滚动和设置草稿。
- 工具启动台提供本地终端、新建主机、导入 SSH 配置，以及目标主机的 SFTP、Docker、助手和模型绑定入口。零主机显示添加引导；单主机显示名称；多主机优先使用当前选择，否则按显示名称选首台。删除目标后选择仍有效的主机。未加载、加载、读取失败和成功空目录分别处理。
- 首页选择目标或渲染卡片不创建连接。插件快捷入口按实际安装、启用及当前 UI 授权路由到业务页或插件管理/配置；不自动安装、启用、授权或绑定模型。插件读取失败保留重试，SFTP 仍可使用。
- 启动只加载已保存的本地会话元数据，不自动启动 Shell 或连接主机。主机树单击选择，双击、Enter/空格或菜单连接打开工作区；重复打开复用现有连接，失败明确重试。每台主机在本次打开期间保留最近工具、会话和文件路径。
- 标签菜单支持关闭、关闭右侧、关闭其他和关闭所有，按菜单目标及可见顺序确定范围；不影响本地终端。右键不切换活动页，关闭后选中相邻标签，没有可见标签时回首页。
- 插件功能页的“插件设置”在设置页面中打开，返回首页复用原业务实例和状态。

### 关闭与资源保护

关闭主机工作区前审核未保存内容、插件草稿、文档及传输；取消保留全部工作。确认后停止接收新任务，等待传输安全提交/清理，再关闭所属文件连接、终端、端口转发和插件资源。失败保留工作区和记录；成功后清除该主机的临时传输记录，不删除用户文件。

关闭主窗口申请退出，确认页说明连接、任务和未保存内容，Esc 或关闭确认页取消退出。确认后取消并排空后台工作、终端和转发，完成持久化及日志刷新。不提供托盘常驻。独立编辑文档须按提示关闭或明确放弃，保存/读取中阻止退出。

### 显示、通知与可访问性

默认窗口为 1280×820，最小 960×600 逻辑像素，恢复尺寸与最大化状态。默认深色，支持浅色和系统主题。界面字号可在 95% 到 145% 之间按 1% 调整，默认 100%。滑动时显示当前比例并即时预览。小、标准、大、特大、超大在滑轨上等距分布，可一键选中 95%、100%、115%、130%、145%。标签以对应的正文字号显示，滑块在各段内按该段的百分比范围调节。终端字号独立。最小窗口、超大字号和弹窗中，内容可滚动且关键操作可达。

桌面和内置插件统一控件、菜单、图标与主题样式；控件保留常规边框，主机树、菜单和搜索使用背景提示键盘定位。右键菜单受视口约束，连续右键切换到新目标，同一时刻只显示一个业务菜单。所有原生窗口及插件 iframe 屏蔽浏览器默认菜单，业务菜单、文本选择和剪贴板仍可用。

右下角的错误通知显示 5 秒后自动关闭，普通通知显示 2 秒。两类通知均可提前手动关闭，支持复制、去重，并在弹窗中可操作。连接测试使用独立结果弹窗。输入、正文和输出可选择，标题、导航和按钮不使用浏览器文字选择。

全局搜索默认 Ctrl+K，设置默认 Ctrl+Shift+P，可修改。全局搜索覆盖工作区入口、设置和插件命令。已保存的主机在主机管理中搜索。初次打开和修改关键词不默认选择结果，选择后 Enter 跳转，Esc 关闭。对话框中不触发全局导航。

## 主机与 SSH 认证

### 主机目录

在“全部”或“收藏”视图中，右键主机列表空白处可选择“导入…”或“导出…”。导入对话框默认选中主机备份，可切换到 SSH 配置；主机列表尚未加载时提供备份恢复。导出范围为完整目录树及其收藏、连接参数、跳板和代理、已保存的登录凭据、对应端点已信任的服务器公钥、全部环境标签定义及主机分配。用户选择保存位置即可生成一个免口令的 `.sdhosts` 文件，持有者可以读取其中的密码和私钥。在新电脑选择可信备份文件即可恢复目录、标签和已保存的认证。SSH Agent 主机沿用新电脑的 Agent，原本缺少凭据的主机仍需补全。导入复用完整路径相同的文件夹和配置、凭据均相同的主机，并报告新增、复用和跳过数量。同名文件夹位于不同路径、同一端点的 SSH 信任记录冲突，或合并时存在同名异色的环境标签，导入整体取消。

主机包括可选名称、合法地址、端口（默认 22）、用户名、密码/公钥认证、连接超时（默认 15 秒）及代理/跳板。左侧主机列表每行显示名称，未填写名称时显示连接地址。非默认端口随地址显示，带端口的 IPv6 地址使用方括号。搜索匹配名称、地址和用户名。

在“设置 → 标签”统一新建、编辑和删除标签，查看每个标签被多少台主机使用。初始提供“生产”“预发”“测试”；名称为 1–10 个字符，颜色从六种预设中选择。每台主机可从右键菜单的“标签”子菜单选择、切换或清除一个标签，也可选择“管理标签…”进入设置。选择操作绑定右键目标。改名或换色后，所有使用该标签的主机同步更新。删除前显示受影响的主机数量，确认后清除其分配。侧栏、工作区标签、宿主的操作确认框显示对应主机的标签。标签是本地识别信息，权限、连接身份和审批规则按原有契约执行。复制主机时沿用其环境标签。

`.sdhosts` v2 恢复标签名称、颜色和打标关系，包括尚未使用的标签。没有主机且仅有原始预设标签时，采用备份里的完整标签列表。合并时复用同名同色标签，给未打标的匹配主机补上备份标签，已有打标的主机保留本机分配。仍可导入 `.sdhosts` v1 和 SSH 配置，导入时沿用本机现有标签。

“主机管理”标题栏下方从左到右依次为“全部”和“收藏”。默认选中“全部”，按目录列出所有主机。“收藏”按名称列出已收藏的主机。搜索框位于切换栏与列表之间，切换视图时保留关键词和目录展开状态。每个文件夹的展开或收起状态在重启后恢复。搜索时临时展开包含匹配主机的分支，清空搜索后恢复原状态。主机行的星标在悬停或键盘聚焦时显示，触控设备直接显示。点击星标可收藏或取消收藏，收藏跨重启保留。

根目录不可删除或重命名，支持多级文件夹、全局唯一文件夹名称和拖动移动，拒绝循环或无效父目录。目录与主机行采用紧凑垂直间距，行高随界面字号调整，过长的主机名称或地址以省略号显示。主机行在所属目录下向右缩进，主机图标左缘与所属目录名称左缘对齐。文件夹右键菜单的“删除”会打开“确认删除文件夹”弹窗，点击弹窗中的“删除”后将主机和直接子目录提升至父级。主机支持编辑、复制和删除，复制不连接。主机删除须在“确认删除主机”弹窗中点击“删除”。右键和 Delete 绑定实际行；输入框、忙碌、拖动、弹窗、组合输入及连发不触发删除，失败保留数据。

列表直接显示未分组主机和顶层文件夹。右键列表空白处可在顶层新建主机、新建文件夹或导入 SSH 配置，也可将主机拖到空白处移出当前文件夹。文件夹行从左到右显示展开箭头、黄色文件夹图标和目录名称，主机数量在最右侧对齐。点击左侧箭头可展开或收起分支。点击目录名称、文件夹图标或计数会聚焦并选中该行，使用与主机行相同的高亮。目录与主机高亮互斥，目录选中不改变当前主机工具目标或连接。右键点击目录或主机可打开该行的操作菜单，打开菜单时保留当前选择。文件夹与主机的右键菜单均提供“重命名”，聚焦对应行后按 F2 也可进入行内编辑，默认选中完整显示名称。Enter 或失焦保存，Esc 取消；保存期间禁止重复提交，失败保留输入并在行内显示原因。文件夹名称仍须全局唯一，根目录不可编辑；主机名称可清空，清空后显示地址。重命名仅更新名称，保留目录关系、排序、主机连接参数和凭据引用，不新建或重连会话。

### 连接测试与保存

新建/编辑直接填写密码、粘贴或选择私钥，支持加密私钥口令；取消文件选择保留表单和草稿。编辑同一认证方式留空沿用原凭据；已有 Agent 配置可继续使用。认证变更不改写其他共享凭据的主机。

通过主机列表连接或直接打开内置主机工具时，若密码或私钥认证的主机尚未绑定凭据，先打开该主机的编辑弹窗，将焦点放在对应的密码或私钥输入框。测试通过后可以保存并打开原先请求的工具；取消留在原工作区。

测试使用完整草稿及真实路由完成握手、指纹核验和认证。成功凭证五分钟有效、单次消费，绑定主机、草稿、路由与凭据修订；修改、失败或过期后重新测试才能保存。首次指纹通过独立弹窗展示目标、算法及 SHA-256，须带外核对后信任；拒绝保留草稿。密钥变化硬拒绝。测试进度、成功和失败原因统一显示在表单底部、操作按钮上方，不弹结果提示；失败以错误样式显示并保持保存禁用，成功后允许直接保存。

### 信任、凭据与路由

- 密码、导入私钥及口令在系统凭据库，SQLite 仅保留引用和修订；不可用时失败，不回退明文。支持 Ed25519/ECDSA/RSA；RSA 要求服务器声明 SHA-2 签名，不回退 SHA-1。
- 每跳验证主机身份，支持受管跳板及 SOCKS5/HTTP CONNECT。HTTP CONNECT 本身不提供 TLS，代理认证仅适合可信网络。不执行 ProxyCommand。
- OpenSSH Config 导入支持文件/粘贴、预览、目标目录树和选择确认；提交重新校验、事务去重，不覆盖已有主机。支持明确别名和受限 ProxyJump，无法安全判断的配置拒绝。精确范围见[连接实现](../architecture/CONNECTIONS_TERMINALS.md#主机目录测试和导入)。
- 系统 known_hosts 的哈希、CA、证书和撤销语义未接入。TCP 可达不能显示为认证成功。

## 终端

### 交互与会话

提供真实本地/SSH PTY、UTF-8、ANSI、256 色/True Color、鼠标、Ctrl+C/Z、选择、查找、滚动和 resize。同一主机可有多个会话，可排序、改名和分屏；每标签最多八窗格，全应用最多 32 窗格，几何变化不重建 Shell。

终端会话名称前用绿色勾号表示所有窗格已连接，用红底白减号表示有窗格已断开、已关闭或连接失败。分屏会话显示窗格数。

会话菜单提供复制、保存（Ctrl+S）、重命名（F2）、重新连接、断开连接、已保存会话和关闭所有。本地和 SSH 会话末尾的 × 关闭会话；关闭最后一个窗格或关闭所有会话也会移除相应标签。这些操作均保留保存记录，关闭所有只处理本地或右键目标所在的 SSH 主机。右键会话标签或会话栏空白处，在“已保存会话”子菜单点击名称即可恢复或切换到对应的打开标签，点击右侧 × 直接删除快照，运行中的会话继续使用并变为未保存。

已保存会话子菜单在删除条目后保持展开。保存默认命名的会话时，名称后显示焦点窗格可恢复的最近命令，较长命令截断；自定义名称和旧保存项沿用各自名称。双击名称、按 F2 或选择“重命名”进入行内编辑，Enter 或失焦提交，Esc 取消。已保存会话改名只更新名称。断开保留显示历史、禁输入并停止光标闪烁；重连仅在目标标签全部窗格已结束/失败时可用，保留名称和分屏，创建新 Shell 前清空旧终端状态。复制创建普通新 Shell，不克隆进程、分屏、固定动作或一次性票据；主机配置变化须从主机树重新打开。关闭失败保留会话，不误关其他终端或 SFTP。

输出中的 HTTP/HTTPS 和 OSC 8 网页链接经校验由本机默认浏览器打开；拖动仍选择文本，其他协议拒绝。底部状态栏显示当前可见窗格的真实 SSH 算法或本地 Shell、光标、行列尺寸、仿真类型及本机 CAP/NUM 状态；未知不伪装为关闭，不额外执行远程命令。

Windows 本地 PowerShell 和支持 Shell 集成的普通 SSH Bash 会话中有前台命令运行时，关闭会话、窗格或批量关闭会先提示可能中断命令。分屏、批量关闭和拖放上传的影响在同一次确认中提示。取消保留会话，返回输入提示符后可直接关闭。SSH 前台识别支持 Bash 4.4 及以上，也支持能安装内置 DEBUG 钩子的 Bash 4.2–4.3。其他 Shell 和未加载集成的会话直接沿用关闭流程。

### 偏好与输入保护

支持字体、10–32 字号（默认 16）、行高、光标、主题、缓冲和快捷键。剪贴板无可粘贴文本时，终端粘贴无操作、无提示。文本剪贴板单次最多 2 MiB；超过字符阈值或 50 行的粘贴先确认并使用 Bracketed Paste，但不能保证远端禁用该协议时换行不执行。“选中即复制、右键即粘贴”默认关闭，仅控制本地选区和右键交互；无本地选区时复制不会清空剪贴板。当前可见、聚焦、已连接的终端程序通过 OSC 52 请求复制 UTF-8 文本时直接写入本机剪贴板，不弹确认，也不依赖本地“选中即复制”开关，使 Claude 等程序可在自身选中后直接复制。后台、其他弹窗或上传期间的请求忽略；不响应剪贴板读取、清空、无效编码或其他选区请求。Ctrl+Shift+C/V 等快捷键继续使用已保存的按键绑定。内容菜单提供复制/粘贴，分屏、查找和会话操作使用快捷键；默认值和改键步骤见[使用说明](https://ops.hiboot.cn/docs/terminal.html#默认快捷键)。

右键本地会话列表空白处可选择“新建”，Windows 上还可选择“新建(管理员)”。Windows 使用 PowerShell，Linux 使用用户交互 Shell，不修改用户启动配置。管理员会话每次创建、分屏、复制或重连均重新经 UAC，只提升专用 Shell 代理。取消或失败不降级为普通 Shell，关闭回收受管进程，插件无提权入口。

“设置 → 终端”的显示设置在宽窗口排为两列，窄窗口排为一列。终端连接时光标闪烁。“终端行为”集中设置粘贴确认阈值、选中即复制和右键即粘贴，以及打开已保存会话时是否自动执行命令。自动执行默认关闭，适用于本地和 SSH。关闭时，命令出现在可编辑的输入行，按回车执行。开启时，从“已保存会话”主动打开并新建 Shell 的窗格各执行一次保存的命令。切换到已连接的会话只激活现有标签，通过“重新连接”重开 Shell 时仍预填命令。缺少有效目录或命令的窗格跳过自动执行。

Windows 本地会话通过右键“保存”或 Ctrl+S 记录名称、分屏布局、每个窗格的当前目录和 PowerShell 最近提交的命令，包括仍在运行的命令。仅保存允许写入历史的单行命令（UTF-8 最多 4096 字节），子程序内的输入不计入命令。

最多保存 32 项，再次手动保存时才更新快照。首次进入本地终端时优先复用已打开会话，无打开会话时新建普通会话。保存项由用户从右键“已保存会话”菜单选择恢复。新建/复制/新增分屏从主目录启动。保存目录不可用时回主目录并留空输入行，原记录保留。

重开使用新的 Shell 进程，管理员会话重新请求授权。Linux/macOS 不提供本地会话保存，自定义提示符和嵌套 Shell 内部目录不保证可追踪。

普通 SSH 终端在远端登录 Shell 为 Bash 4.2 及以上、可使用 Readline 和 base64 时，支持同样的保存操作。每台主机最多保存 32 项，每项记录名称、分屏布局、各窗格的远端目录及最近一次可记录的单行命令。Bash 4.2–4.3 已配置 DEBUG 钩子时保留原钩子，仍可保存目录和布局。打开 SSH 终端时复用已打开的会话或新建普通会话，保存项通过右键菜单恢复。恢复时核对主机密钥、地址、端口和登录用户，并按会话恢复设置处理命令。其他远端 Shell 可保存会话名称与分屏布局，保存结果提示受限窗格数量。嵌套 Shell 和交互程序内部的输入不参与快照。

### 本地端口转发

主机工作区工具栏的“端口转发”可填写本地端口、远端地址和远端端口，添加规则后手动启动或停止。监听固定为 `127.0.0.1`，从 SSH 服务端访问目标地址。启动沿用主机配置、认证及逐跳指纹校验，无需打开终端窗格。列表显示监听地址、目标、活动连接数和失败原因。本机入口和远端目标的地址及端口可拖选复制。“正在监听”表示本地端口已就绪，远端连接在本地客户端接入时建立。

规则按主机保存在本机。关闭工作区或重启后，进入端口转发页读取已保存的规则，均显示为“已停止”，由用户点击“启动”连接 SSH 并监听端口。移除已停止的规则会删除其本地记录；删除主机时一并清理该主机的规则。

切换工作区或工具时，运行中的转发继续。停止单条规则会释放其监听及活动连接。SSH 断线会停止所属转发并保留配置供手动重试。关闭主机工作区、重载或退出应用会停止相应转发。

### rz 上传

远端 rz 握手触发原生多文件选择，经当前 PTY 上传；每批最多 100 个普通文件，单文件小于 4 GiB。选择期间只显示系统选择器，选好后显示进度；不推测 ZMODEM 未提供的账户和目录。取消停止读取、排空在途批次及取消帧并释放授权，无法确认时关闭原会话。支持中文、二进制和空文件，不提供 sz 下载。

### 终端拖放上传

普通 Linux SSH 窗格可接收文件、目录及混合多选，确认后经原 PTY 上传到当前 Shell 真实身份与目录，支持 sudo/su 后的用户。须处于空白提示符，要求兼容 GNU 基础工具，无需 rz。本地、插件、容器/固定动作和备用屏幕不接收；拒绝链接、重解析点及特殊文件。

每批 1–256 个顶层项目，递归最多 100000 项、128 层。单文件直接分块读源并累计 SHA-256；多选/目录先准备临时 tar，保留结构与空目录并可取消。普通文件 0644、目录 0755，再受 umask 限制，不复制本地属主或特殊权限。

上传隔离原窗格输入，显示真实接收用户/UID、目录、阶段、确认字节和速度；协议与接收脚本不进入终端显示。私有暂存经校验后提交，同名文件、目录或链接均停止，不合并/覆盖。取消排空数据并恢复终端，无法确认恢复则关闭会话，保留已提交项目和恢复路径；其他窗格继续工作。不支持续传或跨重启恢复。

拖放和 rz 均保留源文件修改时间至 Unix 秒，拖放归档保留目录时间；不复制创建时间或 ctime。时间无效或设置失败明确拒绝，拖放不提交暂存文件。传输速度和剩余时间不包含后续校验、解包及提交，不承诺固定带宽。

## SFTP 文件与文本编辑

### 浏览与布局

本地/远程双栏按空间并排或上下布局，各自提供地址、父目录、刷新、排序、多选、隐藏文件、属性和业务菜单。按主机记住界面最后成功打开的远程目录。新建 SFTP 连接时用已认证的登录用户重新读取该目录，关闭工作区或重启后再次打开仍可恢复；首次打开、目录已失效或权限不足时打开 SFTP 默认目录。实际连接故障照常提示。后台跨主机复制连接不覆盖记录。切换文件用户仍先打开该用户的默认目录，重开时仅恢复路径并以登录用户权限读取。

本地栏也按主机独立记住最后成功打开的目录，关闭主机工作区或重启后再次打开时尝试恢复。首次打开、目录已不存在、变成文件或权限不足时使用本机用户主目录。“主目录”按钮直接打开本机用户主目录。双栏后退/前进历史仅在当前工作区内保留。切换目录读取时不展示旧条目，同目录刷新保留列表、分页与滚动位置并显示读取状态，失败恢复原路径，连续请求只接受最新结果。Windows 本地路径显示普通盘符/UNC，操作保留原始路径。

远程地址栏右侧的“目录书签”可为当前已打开的目录命名并收藏，每台主机最多 64 项，跨重启保留。同一路径只能收藏一次。选择书签以当前 SFTP 用户权限打开目录，目录已删除或无权访问时显示原因并保留书签。移除书签只删除本地记录，删除主机时一并移除其书签。

两栏地址栏均以“上一级”“根目录”“主目录”三个按钮开头，右侧紧接本地磁盘或远程目录下拉框。“上一级”打开所在栏当前目录的父目录。本地“根目录”打开当前盘符、UNC 共享或 Unix 文件系统的根，“主目录”打开本机用户的主目录。远程“根目录”打开当前 SFTP 会话可见的 `/`，“主目录”打开服务器为当前 SFTP 用户设置的起始目录。在根目录时，前两个按钮禁用。

本地栏可按磁盘选择根目录，远程地址栏可选择当前路径的祖先目录。两栏工具栏以颜色区分操作，禁用按钮降低亮度。两栏可独立切换目录树，默认关闭。开启后，上方显示目录树，下方显示当前目录内容，两块区域可独立滚动。点击箭头展开或收起分支，点击目录名或按 Enter 进入该目录。没有可见子目录时，树中只显示该目录节点。通过地址栏、历史或下方列表切换目录时，树同步定位。本地树以当前磁盘或共享为根，可在 SFTP 断开时使用。远程树与远程列表共用隐藏项开关，进入隐藏目录时保留通往当前目录的路径。再次点击目录树按钮即可恢复完整高度的列表。

远程地址栏中显示当前目录的框保持紧凑，展开的菜单按目录名称和层级缩进自动扩宽。每个目录独占一行，超出窗口可用宽度时可横向滚动查看全名。地址栏和目录树均支持键盘导航。在任一栏输入路径后按 Enter 打开目录。没有手动双栏比例、仅远程模式或远程全文搜索。

### 远程文件搜索

远程工具栏在“显示隐藏项”右侧提供搜索图标，点击打开弹窗，首次以当前目录为搜索目录，输入文件名条件后主动开始。普通关键词按名称包含匹配；含通配符时匹配完整名称，`*` 匹配任意数量字符（含零个），`?` 匹配单个字符，例如 `*.sh` 查找所有以 `.sh` 结尾的名称。匹配不区分大小写，同时返回文件、目录和链接名称；不搜索文件内容，不解析正则表达式，其他模式字符按字面处理。“包含子目录”和“包含隐藏文件”默认均关闭；关闭隐藏项时也不进入隐藏目录。搜索使用当前 SFTP 用户身份，递归不跟随符号链接。

结果在弹窗中逐步显示名称、所在目录和大小，并突出匹配词。双击结果进入其所在目录、跳至目标所在分页并高亮；键盘聚焦结果后 Enter 执行同一定位。定位前重新读取目录，文件已移动、删除或目录读取失败时保留弹窗并显示原因。弹窗没有底部提示或操作栏，右上角 X / Esc 关闭；搜索期间可停止，关闭时等待取消收尾，失败保留弹窗供重试。离开文件页会取消搜索，同一主机及 SFTP 会话内保留条件和结果，切换用户、重连或关闭主机后不继承。

每个文件连接最多一个搜索，全应用最多四个；单次上限为 1000 个结果、100000 个扫描项目、64 层、8 MiB 结果路径/名称数据或两分钟。单目录继续受 20000 项和 8 MiB 名称限制。停止或达到上限明确显示结果不完整；子目录无权访问、已消失或变化时跳过并展示未读目录数量及前 100 条原因，起始目录或连接故障显示搜索失败，不将其当作无匹配。

### 文件用户身份

终端 su/sudo 不改变 SFTP 身份。文件页可确认切换用户，通过登录账号的 sudo 权限运行目标用户外部 sftp-server；新通道真实读取成功才替换，失败保留旧连接。切换前处理文档和传输，切换后从目标主目录或 `/` 开始并清空旧历史。

sudo 密码仅在本次文件连接内存中使用，不保存、不进入命令或日志、不继承到插件。服务器须支持无 PTY sudo 和外部 sftp-server；requiretty 或仅 internal-sftp 不支持。

### 属性

本地与远程条目右键菜单的“属性”位于末尾，“删除”统一使用该名称并位于“重命名”上方。Windows 本地文件、目录及链接直接打开系统原生属性窗口，不使用内置属性弹窗；其他平台暂不支持本地原生属性。

远程属性分为通用和校验码页。通用页展示名称，基础信息区只保留位置和大小；支持编辑数字 UID/GID、拥有者/组/其他的读写执行权限、setuid/setgid/sticky 位及同步的三或四位八进制权限。特殊权限位在 R/W/X 右侧分别与拥有者、组、其他同行排列，权限区采用紧凑行距。SFTP v3 不枚举账户名称，修改受当前文件连接身份及服务端权限限制。链接和特殊文件仅展示基础属性。

目录大小按需递归计算普通文件的逻辑字节数，展示文件/子目录数和跳过的链接及特殊文件数，不计算占用空间、不跟随链接；失败或取消明确标记统计不完整。目录可确认递归应用所有者、组和权限，并按读取位为目录补对应执行位；递归根目录修改被拒绝。应用前展示目标及变更确认，完成后复验并刷新；部分失败或取消保留已应用修改及计数，不自动回退。普通文件可按需通过 SFTP 读取并计算 SHA-256，结果可选择复制。长操作支持停止，受五分钟、100000 项、128 层及路径内存限额约束。

### 传输和文件操作

远程“新建文件夹”使用名称输入和属性分组的紧凑弹窗。默认关闭“设置权限”，显示 `0755`；开启后可编辑拥有者、组、其他的 R/W/X，以及 setuid、setgid、sticky 特殊位，复选框与三或四位八进制输入同步。未填写有效名称或权限时不能确认，创建失败保留输入和错误；创建期间禁止重复提交和关闭。可选择在当前 SFTP 会话内记住权限选项，切换用户或重新连接后恢复默认；帮助按钮在弹窗内展开权限和记忆范围说明。创建请求使用所选权限，最终结果受服务端 umask 和策略约束。

支持单/多文件和递归目录上传下载、原生拖放、远程条目拖入本地栏，以及 Windows 普通文件/文件链接拖到系统文件夹。显式文件链接仅在目标为普通文件时按链接名下载，递归不跟随链接；目录不参与窗口外拖放。

冲突策略为停止、跳过、确认覆盖。任务有独立 ID、进度、取消和重试，默认每主机三个并发，可设 1–6，全局最多 12。目标同目录暂存、SHA-256 读回校验、属性复验后提交；字节满不代表完成。取消排空在途请求并关闭句柄，保留已提交文件。文件页上传按普通文件保留断点，断线、取消或重启后重新选择源与目标，会自动核对匹配断点的已有内容并补传剩余数据。源或目标快照变化、暂存大于源文件时，需确认才会丢弃旧进度并从头传，取消则保留断点。同名正式文件仍遵循所选冲突策略。服务器无法创建私有暂存目录时使用普通上传，中断后须从头重试。下载和远程复制仍从头重试。

上传新文件默认请求权限 `0644`，新建目录默认请求 `0755`，服务端 umask 或策略可进一步收紧；合并已有目录不修改其权限。上传普通文件保留源 mtime 至 SFTP v3 支持的整秒；覆盖保留目标基本权限和属主，时间设置/复验失败保留原目标。目录合并不保证目录时间。传输弹窗集中显示本主机任务，点击 × 或按 Esc 会收起弹窗并继续传输，可从页头重开。“取消传输”会请求取消点击时弹窗内的全部任务，并等待收尾。切页继续，新增任务打开弹窗，轮询不反复打扰；页头可查看记录及重试。传输用时与速度只累计数据阶段，校验和提交单独显示。Windows 外拖以系统最终复制结果为准。

远程创建、重命名和确认删除使用真实权限及 SFTP。本地和远程栏单选文件或文件夹后按 F2，或右键选择“重命名”，在文件名所在行编辑；文件默认选中扩展名前部分，文件夹选中全名，Enter 或失焦保存，Esc 取消。失焦保存保留用户新选中的行和焦点，重命名只刷新对应栏并保持分页和滚动位置；失败保留输入并提示，目标重名时拒绝覆盖。切换目录、主机或远程身份取消未提交编辑。Windows 本地重命名不依赖 SSH 连接，仅修改当前目录中的项目名称，其他平台暂不支持。目录递归删除不跟随链接，禁止删除根。Windows 本地 Delete/菜单删除经确认移入系统回收站，失败不回退永久删除，其他平台不提供该能力。确认绑定原主机、身份、目录及路径；部分失败必须如实显示，输入框和不可操作状态不触发删除。

### 远程复制

选择目标主机后自动在后台连接，已有连接直接复用，不提供“连接”按钮；连接期间显示状态，首次连接仍须核对指纹，真实失败在主机区域显示并可重试，不自动循环重连。目标目录使用不可输入的下拉选择框，新复制任务须从树形菜单选择后才能确认，不自动填入目标连接的当前目录。目标连接就绪后，点击选择框在当前窗口展开下拉树，默认只展开根目录及其第一层子目录，点击箭头时按需读取下一级；点击目录名称回填路径并收起菜单。目录树仅列出目录，支持展开、折叠、刷新及键盘导航，Esc 或点击菜单外关闭，关闭或读取失败保留已选路径。切换目标主机或重新选用连接后，新任务须重新选目录，旧读取响应不回填新目标；原文件页及两端浏览目录保持不变。复制重试自动准备原目标主机，保留原目标路径并禁用目录选择。弹窗采用紧凑布局，底部仅提供取消和“确认”，不显示红色条件提示；条件不满足时禁用确认并在按钮提示中说明，真实提交错误在窗口上方反馈。展开和选择目录均不提交。

远程条目右键提供“远程复制”，本地及远程右键菜单均不提供“复制绝对路径”。支持 1–256 个选中项目；对话框展示冻结的源路径、源主机和目标目录，单选可同时指定新名称，多选保留各自名称。须从已保存主机中选择目标，可选择当前主机或其他服务器，显示目标地址及实际连接用户；未连接的目标自动连接，首次连接须核对指纹，不切换源主机页面。两端各自使用已有认证及文件用户身份，不向另一端传递凭据。目标必须是已有远程绝对目录，名称按字面处理，不提供通配操作掩码。

冲突策略为停止、跳过或明确确认覆盖。复制目录可合并已有目录，普通文件覆盖使用原子替换。源之间重叠及目标相互冲突均拒绝，同一主机还拒绝源与目标相同或互为祖先；不同主机允许相同绝对路径。根目录不能复制。复制只处理普通文件和目录，递归跳过链接及特殊文件。

复制通过 SFTP 经客户端内存流式中转，不在本地落盘；普通文件经 SHA-256、大小和属性复验后提交，保留源 mtime，新目标保留源基本权限，覆盖保留目标属主和权限。新目录保留源基本权限，不承诺目录时间、ACL、扩展属性或硬链接关系。

复制共用后台任务队列、进度、取消、关闭保护和记录，按数据字节显示进度，无数据字节时按项目显示。跨主机复制在两端显示同一任务，并占用两端的主机并发额度；任一端关闭或切换文件用户均受在途任务保护。扫描受 100000 项、64 层和 16 MiB 路径上限约束。失败或取消不回退已完成项目，两端仍为原连接的目录在终态刷新；可重新确认后从头重试，重试窗口重新准备原目标连接。弹窗内连接身份变化后须重新选择主机或重新打开重试窗口。断线导致提交结果不明时须核对源与目标。

### 文本编辑和终端联动

远程工具栏在“新建文件夹”旁提供“新建文件”。点击打开紧凑的“编辑文件”弹窗，输入当前目录内的新文件名后确定，直接打开内置编辑器；取消不创建文件，帮助在弹窗内展开。确认时以排他方式创建空白文件，默认请求权限 `0644`，同名文件、目录或链接均拒绝覆盖；服务器缺少原子保存能力时不创建。创建期间禁止重复确认和关闭，主机、目录或身份变化取消未提交输入。创建或打开失败保留文件名与错误，若空文件已经创建则明确提示并保留该文件；成功或失败后只刷新原会话仍停留的原目录。已有内置或外部编辑文档时先结束当前编辑；名称不跨重启保存。

内置编辑器在独立原生窗口中编辑单个严格 UTF-8 普通文件，上限 2 MiB，无 NUL。支持保存、重读、查找、换行和状态栏，当前主题/字号在打开时应用；读取和保存互斥，失败保留草稿，关闭/重读审核未保存内容，不提供崩溃恢复或跨重启草稿。

保存检查原文 SHA-256、大小、时间及 mode/uid/gid，经暂存和基础元数据复验后 OpenSSH 原子替换；不具备原子能力时只读，不降级截断。替换改变 inode，不能保证 ACL/xattr/硬链接，SFTP v3 无服务端 CAS，最终检查至提交仍有竞态。编辑器打开时阻止所属连接关闭、切用户、迁移和页面重载；断线保留本地草稿。

Windows 本地文件可选择系统应用；远程普通文件可下载为独立本地副本交外部应用，二进制和大文件不转换编码，用户明确确认后才回传并复用冲突/原子保存。内外部编辑不能同时进行，结束或失败保留副本并提示路径，不自动清理或恢复授权。其他平台可自行下载后打开。

文件页本地和远程工具栏在目录树按钮右侧各提供终端图标。点击后直接打开并聚焦内置终端的新会话，以当前栏已加载的目录为起始路径。远程终端使用该主机配置的 SSH 登录账号；切换 SFTP 用户后，仍需该登录账号有权进入目标目录。当前目录未加载或正在切换时，对应入口不可用。右键菜单仅提供文件和目录操作。

## 插件平台与内置能力

### 平台契约与管理

插件以独立 Vue UI 和 WASM 承载业务，平台只提供通用原语、权限、审批和资源管理。当前 API、UI 和 ABI 版本统一见[版本约定](../plugins/PLUGIN_API_VERSIONING.md)，精确契约见[公开 SDK](../plugins/PLUGIN_SDK.md)。

系统与上传插件共用标准包和安全边界。内置源码构建后随客户端分发，首次默认启用并预置声明权限；升级保留既有启停、配置及卸载选择。上传包默认禁用且未授权，同 ID 不获得系统来源。包无密码学签名验证，安装须确认开发来源风险；作者与摘要不能证明身份。

设置支持安装预览、升级/回滚、启停、权限及目录、配置、确认卸载，以及在默认浏览器打开官网“开发者中心”。列表展示来源、启用状态、版本与包构建时间；详情分基本信息和插件配置。运行期复用列表，管理操作后更新，应用外修改需刷新。卸载内置插件可显式恢复当前嵌入包，保留未清除配置并默认禁用；损坏或旧契约记录隔离，有当前内置替代时可先备份再重装，不继承旧授权、不阻断其他插件。

独立开发包统一由官网按 SDK 版本提供 ZIP 下载，各版本保留独立地址；开发者中心首页和“第一个插件”教程提供当前版本直达入口及版本选择页。客户端不内置或导出开发包。开发者须核对所用客户端与 SDK 的兼容范围，下载页仅列出实际提供的版本。

固定命令、交互命令、任务读取和文件传输预授权分别声明并授权，均绑定当前安装修订，不推断为只读。模式与模型声明不能增加基础权限。关闭、撤权、升级和取消按资源 owner 收尾；隐藏页面与保留任务的边界见[UI 生命周期](../plugins/PLUGIN_UI_EXTENSION.md)。

### Docker

- 提供真实检测、容器/镜像/Compose 项目列表、服务端版本及全局统计、搜索、容器详情、环境变量、只读启动配置、日志和 Shell。成功列表在同一主机连接内缓存，刷新/变更更新，失败保留上次值并标明原因，未知不显示为零。
- 详情按概览、启动配置、环境变量折叠，首次展开读取，明文缓存限当前弹窗；启动配置来自当前项目或 inspect 转换，列出未转换项，内联 secrets/configs 隐藏。不提供资源使用、配置编辑或部署。
- 变更由宿主确认真实对象及影响；容器可启停、重启和删除，批量重启仅处理当前主机全部 exited 容器，不受搜索影响，不提供全部重启或远程日志清空。日志可本地清屏、筛选、复制和导出，单次最多十分钟，需要 GNU timeout，关闭/隐藏等待远端退出确认。
- Compose 优先 `docker compose`，其次独立 `docker-compose`，支持 V1.29.2 及 V2 或后续版本；只管理已创建容器，提供服务状态、项目日志及整组启停/重启，不拉取、重新部署或删卷。配置缺失和业务失败明确提示，不切换入口重试，Compose 故障不影响容器和镜像。
- 镜像支持本机 `docker save` 归档导入、导出及经本机流式中转到其他登记主机后自动导入。远程传输在同名标签冲突时确认替换，load 前复验目标，导入后核对平台、配置和有序层内容；本机不落地完整归档。只保留选中标签，无标签按 ID；不更新已有容器。
- 需要实际 SSH 登录账号的 Docker/SFTP 权限及暂存空间，不自动安装或提权。取消先排空传输再清理已知暂存，不回滚 daemon 已接受的变更；失败保留恢复路径，不自动重试。标签外部并发和默认平台校验有明确限制，见[Docker 使用说明](https://ops.hiboot.cn/docs/docker.html)。

### AI 运维助手与模型

模型管理提供远程 OpenAI 兼容模型与独立授权的本地 Codex/Claude Code 来源。本地/远程分 Tab，远程默认打开，支持按 ID/名称/地址搜索及按真实注册时间倒序，历史未知时间置后。远程关键配置/Key 变更须真实无主机上下文测试，成功凭证五分钟、单次且绑定输入；Key 不回显，地址变更须重新输入或明确清除。各模型独立系统凭据、上下文窗口和输出上限。

本地 CLI 复用用户配置和登录，安装、就绪、授权分别展示；未授权不能读配置或推理。Windows x64/ARM64 可从固定官方源校验安装到应用目录，可取消，不改 PATH 或覆盖系统安装；其他平台手动准备。助手配置从已就绪来源中选择，选中立即保存，失败恢复原值，不自动选替代模型。

助手以登记目录、问题及最近成对对话匹配最多八台主机；需要来源但未另行指定时使用当前工作区。只采集相关证据，先脱敏再预算缩减，保留必要主机地址和原始身份以区分目标，自定义敏感值优先脱敏。失败、缺失及省略明确标记，普通知识问题不附目录；脱敏不保证覆盖全部业务秘密。

任务可连续查询、准备计划、授权、执行和复查，直至回答、需补充信息、失败或取消。提供 Docker/systemd 变更、远程程序与 argv、单个远程文本局部编辑（UTF-8 ≤32 KiB）、本机单文件上传和服务器间中转，以及镜像导出/导入组合。计划冻结实际目标、原文、参数和修订，五分钟内单次消费；单任务最多 32 轮推理、64 次只读工具、32 批变更，每轮最多三个查询，每批最多 32 个真实运维目标。Skill 按需读正文和资源，不授予权限、不自动运行脚本。

| 审批模式         | 当前行为                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| 请求批准（默认） | 读取和命令按宿主规则询问；计划点击执行后统一确认                                                                 |
| 帮我批准         | 已授权读取、精确模板、不覆盖传输及可信来源到空标签的导入可自动执行；删除、覆盖、保存配置、未知来源/命令仍确认    |
| 完全访问权限     | 须可信宿主首次授权，当前会话在已有能力/目录范围内持续自动执行；切换模式、新对话、关闭、撤权、停止/升级使授权失效 |

模式发送时冻结，切换不升级旧任务。首次 SSH 指纹、基础权限、目标/原文复验和取消始终保留，不自动提权。模型及远端文本不作为可信指令；输出使用真实增量并先脱敏，完整结果校验前不能执行计划，停止保留片段且不进入历史。不支持流式时明确失败，不模拟打字或自动重试计费请求。

运行期展示准备、查询、待审、执行、传输、复查及真实终态，最多保留 32 项；回答结束不代表业务目标完成，失败/未确认停止后续步骤并保留已完成项。切换页面可继续已授权的工作，需新审批时等待返回；关闭所属工作区取消并排空自有任务。对话、任务和资源不跨重启恢复，不提供 MCP、运行时 Skill 管理或持久任务中心。完整操作与限制见[助手指南](https://ops.hiboot.cn/docs/assistant.html)及[助手实现](../architecture/ASSISTANT_AGENT.md)。

## 设置、数据与安全

通用、终端、快捷键及数据与存储的普通偏好修改后自动保存，合并连续输入、拒绝无效值，失败保留草稿供重试；页头右上角的“恢复默认”仅作用于当前分类。模型和插件独立保存，数据根目录使用单独的“迁移并重启”预览/确认，不随普通保存迁移。保存、迁移或插件管理中阻止离开，关闭设置先提交有效偏好，剩余草稿明确审核。

设置内的操作结果由字段、列表和页面状态呈现，普通成功不弹出全局通知，失败仍按原入口反馈。日志级别旁标明重启后生效。数据目录变更请求指向当前目录时，在数据与存储页显示无需重启。

语言保存后桌面与内置插件立即更新，不重建连接，用户内容和原始输出不翻译；独立编辑器下次打开采用新偏好。关于页介绍主机管理、终端、SFTP、插件及本地数据存储，显示实际应用版本、固定构建时间（北京时间）、本地环境和软件更新。使用文档、发布记录和问题反馈在系统默认浏览器打开。本地环境在启动时自动读取，读取失败时在“本地环境”区域显示原因和“重试”按钮。

Windows x64 正式 NSIS 安装版可从固定 GitHub Releases 检查、下载并安装更高正式版本。更新说明以 Markdown 展示标题、列表、加粗、代码和表格。GitHub 自动生成的正式版本对比链接显示为「完整更新日志」，HTTP/HTTPS 链接点击后由默认浏览器打开。原始 HTML 仅作为文本显示，不加载远程图片，解析失败时提示并保留原文。自动检查默认开启，每次启动后在后台检查一次，支持关闭。用户也可手动检查。失败不显示为最新，下载可取消、切页继续，包只驻留当前运行期。内置公钥签名及签名版本校验成功后才能安装，安装先审核并排空工作，再启动安装器。开发版、独立 EXE 和其他平台不执行应用内更新。更新不自动降级、覆盖用户数据或回退数据库；分发见[更新说明](../release/UPDATES.md)。

自动检查发现新版本时弹窗展示当前版本、新版本和更新说明。用户可从弹窗下载并发起安装确认，也可选“稍后”收起，从“设置 → 关于”继续处理。下次启动发现该版本时仍会提醒。“忽略此版本”会在本机保存版本号，同一版本的后续自动检查跳过弹窗，手动检查仍能查看和下载。发现更新的版本时可以再次弹出提示。

用户数据默认位于标准应用目录，不写安装目录。主动迁移数据根须空的专用目标、足够空间和确认重启，复制、清单/摘要及数据库校验、新目录启动确认后才逐项安全清理源；失败保留数据及诊断，系统凭据不复制。迁移成功仅在完成时通知一次，启动后的迁移或清理失败提示保留在数据与存储设置页。

已支持数据库/偏好启动前安全升级，模型配置按需独立升级且故障隔离。先取得写锁、保存包含 WAL 的一致备份，再事务修改和校验；失败停止，不清库、不重置，备份不覆盖或自动清理。未知/未来/损坏格式拒绝，既有值和秘密引用保留，不继承失效插件授权。恢复或降级须正常退出后另行明确授权，支持范围见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

日志有界轮转，不记录密码、私钥、Key 或终端/文件/模型正文；前端仅能调用授权 IPC。无默认用户数据上传；远程模型按明确授权发送上下文，更新只请求固定公开 HTTPS 分发源。风险见[安全说明](../release/SECURITY.md)。

## 性能、稳定性与验收要求

工程目标为冷启动三秒内可交互、空闲进程树内存尽量控制在 150 MB、至少 20 个活动 SSH 终端；须记录真实机器及条件，未测不承诺。传输数据阶段接近 100 MB/s 是可控千兆环境的测量目标，不能代替目标网络、PTY 或整体含校验耗时的结果。

输出、任务和缓冲有界，终端、传输、插件和模型故障应隔离；内部采样使用真实 SSH 数据，CPU/网络由连续计数差计算，首次和失败为未知，不用零掩盖错误。监控采样不代表独立页面。
