# ServerDeck 产品功能需求说明书（PRD）

## 2026-11-08 桌面工作台导航

使用“简洁侧栏＋多主机标签”的组合布局。顶部保留产品标识、侧栏开关、全局搜索，移除主机管理/插件/设置模块切换。本地终端固定在主机树上方，不参与主机筛选；主机树标题显示总数并提供新建入口，底部只保留设置。沿用紧凑列表、分组、搜索和拖动操作。移除右上角省略号菜单，插件管理和关于归入设置。

收起侧栏时保留 52px 图标栏，上方依次为展开主机列表、本地终端，下方仅保留设置，悬浮显示名称并提供可访问名称。全局搜索统一使用右上角入口或快捷键。图标入口可直接使用，主机列表展开后恢复搜索、分组和选择；收起、展开均不创建或关闭会话。窄窗口同样保留图标栏，展开主机树使用浮层。收起状态不新增持久化配置。

本地终端、远程主机和全局插件功能共用一排工作区标签，不再显示“全部主机”分组标签，插件管理不创建标签。标签栏移除加号搜索入口，全局搜索从顶栏或快捷键打开。主机内部按工具、终端会话分层，每台主机保留最近工具、插件页面和会话。右键“关闭右侧”作用于统一标签顺序；关闭主机仍须处理活动传输、未保存文件和资源释放。

设置使用统一弹窗，包含通用、终端、快捷键、数据与存储、模型管理、插件和关于。插件分类复用现有安装、升级、卸载和权限管理；点击列表配置或功能页“插件设置”，在同一窗口显示插件详情，可返回原筛选列表。开发包下载移到列表底部。快捷键、全局搜索和插件的模型管理入口均复用此窗口，不创建设置标签，不改变背后的主机和活动工具。前四类共用草稿，切换到模型、插件或关于均保留；关闭时复用未保存确认和字号预览回滚。模型及插件配置独立保存，安装和启停不受通用设置的放弃修改影响。插件保存或管理操作期间不能关闭或切换设置分类。关闭后焦点返回入口。小窗口与大字号下导航、滚动内容和保存按钮可达。本节替代下文旧模块和设置标签的导航约定。

## 2026-11-08 全平台清理开发期兼容

平台只使用当前数据和接口契约，不兼容历史开发版本。删除旧应用标识/凭据服务迁移、旧模型与已删价格字段转换、旧设置默认补齐和字号别名、任务快捷键过滤、无调用方的终端工作区持久化接口及主机 tags 字段。内置智能体要求当前严格 JSON 协议，格式错误明确失败，不降级为旧建议格式。当前通用 AI 分析与命令审核、OpenAI 协议适配、OpenSSH 导入与私钥路径、主动数据目录迁移和正常失败恢复保留。

数据库使用等价的 schema 9 基线初始化；已有当前数据库正常打开，旧/未知版本拒绝且不改写，不删除原文件或历史附加表。仅清理源码和接口中的无用维护路径，不清库、不删除 OS 凭据、不自动搬移用户目录。本节替代下文开发阶段的历史兼容要求。

## 2026-11-08 内置插件自动发现

在 `plugins/system` 增加符合当前 SDK/UI 契约的完整插件目录后，客户端构建自动发现、打包并嵌入；启动按原有内置安装与授权流程显示到插件管理，不再逐个维护构建、Rust 注册和发布依赖清单。输出目录 `packages` 不参与发现，缺失输入、重复 ID 和目录链接明确失败。已有升级、设置、启停、卸载选择、上传来源隔离与危险操作确认保持；源码目录变化不热加载到运行中的应用，不自动删除已安装插件或用户数据。

## 2026-11-08 插件仅使用当前契约

平台尚未正式 release，无历史发行包兼容要求。插件只接受 Host/SDK 4.0.0 和自带前端的 UI v4；删除 UI v1–v3、旧 API 协商、宿主兼容界面及旧插件身份/目录/退役归档迁移。当前 Docker、AI 助手和独立上传插件继续使用统一 SDK/WASM/授权链；正常安装升级、回滚、启停、配置和卸载保护保留。不自动重置或清理用户数据。不兼容记录明确报错。本节替代下文开发阶段有关旧包兼容和迁移的要求。

## 2026-11-07 本地 AI 工具缺失与安装

选择本地 Codex 或 Claude Code 时先检测工具是否存在；未安装和未授权、未登录、配置错误分别展示。未安装提供“下载并安装”和“重新检测”，聊天页已有本地绑定但工具丢失时也显示安装提示。Windows x64/ARM64 可在应用内从固定官方源安装到应用数据目录，不依赖 Node/npm，不覆盖系统工具或用户配置。显示下载中状态，允许取消和失败重试；校验并验证启动后才视为安装成功。安装不自动授权使用登录信息，已有本地授权仍保留。其他平台显示手动安装命令。

## 2026-11-07 AI 助手模型绑定布局

模型绑定按“本地服务、模型管理”分组。本地 Codex 与 Claude Code 并排显示，状态行集中显示连接结果、当前模型及授权操作；注册模型采用紧凑列表。底部固定当前绑定、未保存提示与取消/保存。设置分类使用页签，内容仅保留一个滚动区，小窗口与大字号下操作可达。保存、授权和撤销规则沿用现有行为。

## 2026-11-07 AI 运维助手使用本地 Claude Code

助手模型绑定增加“本地 Claude Code”，与“本地 Codex”和模型管理中的注册模型同列可选。首次在可信宿主确认本地访问授权，之后由本机原生 Claude Code CLI 直接使用已有用户配置和登录；无需把订阅登录转换为 API Key，也不重复浏览器登录。两个本地来源独立授权和撤销，保留原来源绑定与模型管理。未安装、未登录、配置变化和调用失败显示真实结果。沿用现有上下文脱敏、查询、计划、执行确认及取消流程。

## 2026-11-07 AI 运维助手使用本地 Codex

助手设置在原注册模型列表旁提供“本地 Codex”。首次使用通过可信宿主弹窗明确授权启动本机 Codex CLI，复用其用户级模型、Provider 和登录信息。授权保存在本机，之后可直接使用并随时撤销；未授权时不启动 CLI 或读取其配置。未安装、登录失效、配置无效或额度失败时显示真实状态，用户处理后可刷新。保存来源沿用所有主机共用的绑定，旧模型绑定直接读取。

请求继续经过现有脱敏、主机匹配、SSH 只读查询、固定计划、宿主变更确认和逐项复查。切换来源、撤销本地授权或配置版本变化会使旧请求或计划失效；失败由用户重试。原模型管理和注册模型调用继续可用。本地 Codex 使用其配置的实际服务及计费方式，聊天上下文只按当前助手请求发送。

## 2026-11-07 设置关闭前提醒保存

通用、终端、快捷键和数据与存储继续共用草稿、统一保存。关闭最后一个设置分类标签时，若偏好或数据根目录有未保存更改，弹出“设置尚未保存”，提供“继续编辑”和“放弃更改并关闭”。右上角关闭和 Esc 均继续保留草稿。切换菜单或仍有其他设置分类标签时不提示；修改后还原或保存成功后不提示。保存失败仍视为未保存，保存或迁移处理中不关闭最后一个设置标签。关闭右侧、其它、所有及全部主机组菜单若会关闭全部设置分类标签，应先确认，取消时不关闭本批任何标签。

## 2026-11-07 数据与存储移除凭据维护入口

「数据与存储」提供数据目录、下载、传输和日志设置。SSH、代理和模型继续使用系统凭据库。应用在相关保存或删除操作后清理不再使用的凭据，并重试此前失败的清理。

## 2026-11-07 插件开发包下载

插件管理在「安装插件」旁提供「下载插件开发包」。点击后打开系统保存对话框，保存完成提示文件位置。ZIP 随客户端分发，包含配套的 Rust 和 TypeScript SDK、快速入门、SDK 接口与包格式文档，以及独立的 Vue 和 WASM 样例。开发者在仓库外修改样例后可生成 `.sdplugin`，通过原有安装、授权和启用流程打开样例页面。

## 2026-11-07 模型管理移至设置

顶部模块为「主机管理、插件、设置」。移除「资产管理」，将「模型管理」移到设置侧栏，位于「数据与存储」和「关于」之间。从菜单、全局搜索或 AI 助手配置进入时复用同一个模型管理标签，并高亮「设置 → 模型管理」。模型注册与编辑沿用原页面的保存流程。

## 2026-11-07 SFTP 文件列表与传输面板高度

SFTP 的本地和远程列表填满文件工作区，两张表独立滚动。连接状态显示在页头，双栏上方移除连接信息条、手动断开入口和目录跟随选项。当前主机有排队或进行中的上传、下载时，底部显示源项目、进度和取消入口，列表自动让出面板所需空间。活动传输结束后列表恢复高度。已结束的任务可在页头“传输记录”查看或重试。

切换本地或远程目录时，地址栏立即显示目标路径，表头保持原位，旧条目暂时隐藏，在列表中央显示加载图标和文字。加载成功后显示实际路径和内容；失败时恢复原路径和目录并沿用错误提示。连续切换时只接受最新请求的结果。

两栏名称列使用图标区分目录、普通文件、符号链接和特殊条目。目录使用黄色文件夹。普通文件按扩展名显示脚本、压缩包或图片图标，其他文件显示通用图标。图标随界面字号缩放。

## 2026-11-06 SFTP 本地路径显示与表头排序

Windows 本地文件地址栏、「复制本地路径」、文件右键「复制绝对路径」和上传确认框的源项目使用标准盘符路径或 UNC 共享路径，文件操作沿用后端原始路径。传输确认框的同名文件策略为停止并提示冲突、跳过和确认覆盖。本地和远程文件列表的类型列紧跟大小列。直接点击列标题排序，同一列再次点击切换升降序，两栏独立显示排序方向。

远程文件列表默认隐藏名称以点开头的文件和文件夹。远程工具栏可切换显示隐藏项。关闭显示时，将隐藏项从当前选中列表移除。

## 2026-11-06 新建和编辑主机须通过 SSH 连接测试

新建和编辑主机表单底部提供“测试连接”和“保存主机”。测试使用表单的地址、端口、用户名、认证信息及代理和跳板设置，完成 SSH 握手和登录认证。首次接触某个端点时，用户核对并确认服务器指纹后继续测试。已知服务器的密钥变化时阻止连接。

测试成功后，当前表单可在五分钟内保存。修改表单、测试失败或测试过期后需重新测试。编辑时保留原认证方式并留空，可用已有凭据或 Agent 测试。移动主机文件夹、复制主机和 OpenSSH Config 导入沿用各自规则。

## 2026-11-06 主机表单直接填写 SSH 认证

移除资产管理中的安全凭据菜单。新建和编辑主机可直接填写 SSH 密码，或选择“公钥认证（PublicKey）”并粘贴私钥或选择本机私钥文件。加密私钥可填写解锁口令。服务器授权公钥，本机使用配对的私钥生成签名。

同一认证方式下，编辑留空时沿用已有密码、已导入私钥或旧式私钥路径。填写新认证信息只修改当前主机。代理密码从 SSH 高级设置或默认代理设置添加。

## 2026-11-06 AppImage 本地终端 Python 环境

Linux AppImage 创建本地终端时，从子进程的 `PYTHONHOME`、`PYTHONPATH`、`PATH` 和 `LD_LIBRARY_PATH` 中移除当前 `APPDIR` 下的路径，避免包内 Python 配置污染系统解释器和项目虚拟环境。保留用户的其他路径与 Shell 配置，不修改应用自身环境、用户文件或已有会话；更新应用后新建本地终端生效。

## 2026-11-06 Linux 终端下划线完整显示

Linux 终端须完整显示 `knowledge_base` 等文本中的下划线。渲染时的有效行高最低为 110%，避免 WebKitGTK 在紧凑行盒中裁掉字形下沿；用户设置更大行高时沿用该值，不改写已保存的字体或行高。字号缩放、切页恢复、选择及复制继续保留原始字符，Windows/macOS 沿用既有行高。

## 2026-11-06 本地终端使用用户 Shell

Linux 本地终端以交互模式启动用户默认 Shell，优先使用有效的 `$SHELL`，缺失或不可执行时查询系统账户配置，最终回退到 `/bin/sh`。Bash 正常加载 `~/.bashrc` 中的提示符、别名等交互配置；应用不覆盖用户提示符。初始目录仍为用户目录，已有会话不自动重启。Windows 继续使用系统 PowerShell。

## 2026-11-07 Docker 工作区布局

Docker 管理页与主机工作区左右边缘对齐。容器和镜像表格填满工具栏与底部操作反馈之间的空间，长列表在表格内滚动并保留表头。窗口过矮时页面可滚动，底部操作仍可访问。

## 2026-11-06 Docker 容器详情标签

容器详情弹窗提供「概览、资源使用、端口映射、挂载、环境变量」五个标签。概览用带标签的字段展示状态、时间和重启策略，端口和挂载分别展示映射方向与访问模式。内置 Docker 的环境变量在进入该标签时直接读取并按名称和值展示，切换标签或关闭详情时清除明文。

## 2026-11-06 Docker 列表操作

容器列表通过「详情」在同一弹窗查看资源使用和容器信息。操作列直接显示「启动」或「停止」以及「删除」，移除折叠菜单和重启入口，保留独立的日志和 Shell 入口。镜像列表操作按钮简称「删除」。容器操作及镜像删除沿用各自的确认流程。

## 2026-11-06 主机管理标题与工作区标签分层

顶部模块与左侧标题统一为「主机管理」。左侧「全部主机」和总数所在行的最右侧提供本地终端图标，点击打开或切回本地终端。存在本地或远程主机工作区时，右侧「全部主机」与安全凭据、模型管理等已打开的二级页面并列显示。只切换顶部模块时保留右侧活动页及标签。点「全部主机」返回最近使用的主机工作区，下方显示具体主机标签，再下一行显示当前主机的会话和工具。打开其他二级页面时保留「全部主机」入口，收起主机标签行。关闭最后一个主机工作区时移除「全部主机」。

「全部主机」的右键菜单提供关闭主机工作区组、关闭右侧二级页面、关闭其它二级页面和关闭所有工作区。关闭右侧或其它页面后，若原活动页已关闭，则返回最近使用的主机工作区。会话标签右键菜单移除，新建会话的加号紧跟会话标签，双击改名、拖动和标签关闭按钮继续可用。

移除主机树底部的筛选数量与已连接数量统计行，列表滚动区延伸到侧栏底部。主机总数显示在「全部主机」标题旁，连接状态显示在各主机行。

## 2026-11-06 插件配置弹窗

所有已安装插件均使用同一个无主机上下文的设置弹窗。点击管理卡片的插件名称或齿轮、功能页的“插件设置”，或未就绪插件的设置入口，均在当前工作区打开弹窗。已启用并授权的插件可在窗内切换自有配置和“权限与详情”；其余插件直接显示来源、启停、权限、访问目录和包信息。

AI 运维助手在弹窗内选择全局模型绑定，底部保存与取消保持可见。保存成功关闭弹窗并让当前助手重新读取绑定，失败保留所选值及错误提示。取消放弃本次编辑，继续原工作区。此节更新下文有关插件配置标签和模型绑定入口的描述。

## 2026-11-06 主机 JSON 导入导出下线

“全部主机”标题旁显示主机总数，下方保留搜索和主机树。移除 ServerDeck 主机 JSON 文件导入、导出及专用接口。已有主机和文件夹继续从 SQLite 读取，根目录菜单仍提供 OpenSSH Config 导入。

## 2026-11-06 私钥导入和模型上下文窗口

安全凭据的 SSH 私钥模式使用本机文件选择器。加密文件可填写口令完成校验和导入，密钥保存到系统凭据库。导入后，SSH 认证直接使用库中的密钥。已有路径凭据可继续使用，编辑时选择文件即可原位升级并保留主机关联。

模型管理在“上下文与输出”中设置每个模型的上下文窗口和最大输出 Token。窗口包含输入与输出预留。旧模型默认使用 131072 Token，保留注册信息和 API Key。移除输入、输出单价，聊天继续显示实际 Token 用量。请求预算采用现有的保守估算，超过预算时优先缩减可选明细和较早历史。

## 2026-11-06 应用配置备份与恢复下线

资产管理仅提供安全凭据和模型管理。删除备份与恢复页面、全局搜索入口和备份 JSON 的导出、预览与恢复。根目录菜单提供 OpenSSH Config 导入，数据根目录可在数据与存储中迁移。

## 2026-11-06 资产管理页面排版

单主机插件直接在当前主机工作区显示功能，与 SSH、SFTP 共用同一个设备标签；从当前主机入口打开时不再选择主机。主机无上下文时由宿主统一选择一次，再进入该主机工作区。功能入口不再进入插件详情；未启用或未授权时显示不可用状态及设置入口，无功能页面的包不列入工具菜单。

顶部“运维工具”侧栏用于查看所有已安装插件的配置，包含禁用、未授权及无功能页面的包；点击名称直接打开配置，不选主机、不连接主机、不执行插件业务。详情、来源、启停、权限及插件声明的 settings 页面也可从“设置 → 插件管理”或功能页“插件设置”进入。返回功能保留原页面实例、草稿及结果。主机工作区按插件/页面/主机分别保留本次运行内状态；切换主机或 SSH/SFTP 不关闭其他主机插件，也不将草稿或操作目标改绑到新主机。关闭设备工作区处理该设备全部插件的未保存编辑和终端，失败时保留工作区。

批量与自动化仍使用全局工作区，首次从主机打开时预选入口主机，保留多目标选择；返回已有页面不覆盖草稿与目标。AI 从主机打开时默认使用该主机，跨主机分析需主动勾选；全局助手保留自动匹配。网络诊断从主机打开时默认以该主机执行，不再选择远程主机，仍可填写诊断目标和显式切换本机来源。

隐藏页面保留界面状态，但不能提交操作或消费过期结果；切换时撤销交互请求并停止原日志流，保留已读输出，返回后重建监控等上下文资源。隐藏页释放 WASM 运行实例，保留内存界面草稿；返回时先重新激活再开放请求，准备期间显示明确等待状态，不能显示可点击却无响应的旧页面。连续使用九个插件不能耗尽八个活动实例配额，原有请求/实例限额保持。相同上下文数据不得造成重复请求循环。已经提交的任务/计划继续由宿主管理，指纹核验、上传授权及危险操作确认保持。系统包升级至 1.1.2，启动时仅升级更低版本的 system 安装，保留启停、配置及卸载选择；不覆盖上传安装，也不降级较新版本。本节替代下文历史记录中独立单主机插件标签、页面内选主机和详情/功能混合入口的描述。

# 1. 项目背景

## 1.1 产品概述

ServerDeck 是一款基于 Rust 开发的轻量级服务器运维桌面客户端。

产品面向软件开发人员、Linux 运维人员、DevOps 工程师和中小型技术团队，集成 SSH 终端、SFTP 文件管理、服务器资源监控、远程命令执行等能力，并逐步增加 Docker、日志分析、网络诊断、批量运维和自动化等功能。

ServerDeck 采用 Local-First（本地优先）设计，核心能力不依赖云端服务。

首个版本以 Agentless（无需在远程服务器安装 Agent）方式工作，通过 SSH 和 SFTP 管理 Linux 服务器。

## 1.2 产品定位

**产品定位：现代化、一体化、轻量级的服务器运维工作台。**

参考产品：

- SecureCRT：成熟的终端与会话管理能力。
- Xshell：SSH 连接和多会话操作体验。
- Xftp：远程文件管理。
- FinalShell：SSH、文件和资源监控整合。
- Termius：现代化连接管理与客户端体验。
- 1Panel：服务器管理能力和功能组织方式。

ServerDeck 不以完整复制上述产品为目标，而是重点优化服务器日常运维操作的连续性。

## 1.3 产品目标

1. 减少 SSH、SFTP、监控和其他运维工具之间的切换。
2. 提供稳定、流畅、现代化的跨平台终端。
3. 让服务器管理围绕统一的主机上下文展开。
4. 降低多服务器日常运维操作成本。
5. 保持本地优先、模块化和较低资源占用。
6. 为未来增加商业授权、团队功能和插件生态预留扩展空间。

## 1.4 目标用户

### 个人开发者

管理 1～20 台 Linux 服务器，日常需要 SSH、文件上传下载、Docker、日志查看等功能。

### DevOps 工程师

管理 10～100 台服务器，希望集中维护连接配置、快速切换服务器并简化重复操作。

### 小型技术团队

需要共享操作流程、统一服务器管理方式，未来可能需要团队权限和操作审计。

MVP 首先满足前两类用户的日常使用需求。

# 2. 产品设计原则

## 2.1 核心原则

### 一台服务器，一个工作区

用户选中一台服务器后，该服务器相关的终端、文件、资源监控和快捷操作使用统一主机上下文。

### 本地优先

服务器配置、连接历史、用户偏好等数据优先保存在本地。

MVP 不需要用户注册或登录云端账号。

### Agentless 优先

远程 Linux 服务器无需安装额外程序即可使用基础能力。

### 安全优先

服务器认证信息、私钥及远程操作必须受到保护。

### 模块化

SSH、SFTP、监控、存储、自动化等模块应保持清晰边界。

### 不为了功能数量牺牲核心体验

终端可靠性、连接稳定性、文件传输正确性优先于扩展功能数量。

# 4. 整体界面需求

## 4.1 主窗口布局

采用“顶部大模块 + 左侧模块菜单 + 中央工作区标签”的两级导航布局。

主要区域：

**顶部：**

- 保留系统标题栏及窗口控制。应用内容顶部为功能模块栏，左侧显示 ServerDeck，右侧提供主机运维、资产管理；“设置”独立贴齐顶栏最右侧，不显示重复版本信息。不再提供独立运维工具或插件模块。
- 顶部模块菜单及工作区标签通过文字和背景区分选中状态，不显示选中项的强调色横线。
- 点击顶部大模块只切换模块高亮和左侧菜单，中央保留当前已打开的页面：终端继续显示终端，设置或其他功能也保持原内容；尚未打开页面时继续显示欢迎页。不显示“请选择功能”提示卡片，不清空当前页面，不自动选择默认页或恢复另一个页面。点击左侧功能、已打开标签、搜索或快捷入口时才切换中央页面并同步所属模块；已有连接与后台任务继续运行。

**左侧：**

- 左侧仅显示当前模块的菜单：主机运维包含主机管理、本地终端及主机树；资产管理包含安全凭据和模型管理；设置包含通用、终端、快捷键、工作区与连接、插件管理、关于。插件配置统一由设置中的插件管理进入，插件功能从当前主机的工具菜单进入，SFTP 传输记录仅在当前主机文件页临时展示，关闭该主机后清除。
- “设置”模块的左侧菜单依次为“通用、终端、快捷键、工作区与连接、插件管理、关于”，原设置页内分类提升为侧栏菜单，不再显示重复分类 Tab。各分类分别打开并复用工作区标签，共用一份草稿；切换菜单、页面标签或其他页面保留草稿，统一保存全部分类，校验失败自动打开无效字段所属菜单并聚焦。关闭全部设置分类标签后释放草稿。“关于”位于该菜单末尾，点击后在中央工作区打开独立页面，合并展示产品说明、实际应用版本、技术栈和本地环境（IPC 状态、SQLite 版本、数据目录、日志目录），提供“重新检查”并显示读取中与后端未就绪状态；不再提供独立本地环境菜单，使用现有工作区标签切换与关闭，不再使用弹窗；重复点击复用同一个关于标签，菜单同步选中状态。其他模块不显示此入口，侧栏底部不再常驻。切换或关闭关于页面不关闭已有终端和后台任务。版本由本地后端提供，初始化中或不可用时明确提示状态。
- “主机管理”为无图标、不可点击的静态标题，不触发导航或连接；主机配置的增删改查集中在工作区主机树，不提供独立配置列表页。
- 主机列表仅在主机运维模块中显示，切换其他模块时隐藏并保留搜索、分组等状态。全局工具在各自页面内明确选择目标，不跟随主机树执行。
- 主机列表
- 主机总数显示在静态标题“全部主机”后，随主机新增/删除刷新，不随搜索变化；主导航“主机管理”不再显示终端数量徽标。
- “本地设备 / 本地终端”固定在“全部主机”标题上方，搜索框紧接“全部主机”标题下方；三者均不随列表滚动。进入欢迎页、切换远程主机或搜索后本地入口始终显示。点击“本地终端”显式打开本地终端，已有会话复用；当前远程主机工具显示在中央工具栏右侧。
- 主机分组
- 在线连接状态
- 左侧菜单顶部显示当前模块入口或名称及收起按钮；收起后，在主机和全局工具的工作区标签栏均可重新展开。顶部模块栏始终可见，保留原侧栏宽度偏好及拖动/键盘调整。
- 主机搜索（输入框内保留搜索图标）
- 在文件夹上右键新建主机

**中央：**

- 页面统一铺满中央显示区域，沿用现有响应式内边距；各设置分类和关于页不使用独立的固定最大宽度及水平居中限制。
- 一级标签切换已打开的主机工作区；独立工具拥有自己的导航标签。
- 当前远程主机的 SSH 终端、SFTP 文件及插件工具按钮平铺在中央工具栏右侧；插件紧接 SFTP，按名称显示已启用且有功能页面的插件，每个插件一项，当前插件高亮，窄窗口自动换行，未启用或没有功能页面的包隐藏。点击打开当前主机的对应插件功能页面，权限不足时显示不可用状态及设置入口。本地设备只提供本地终端。全部安装身份均可从设置中的插件管理进入自身设置。
- Shell 会话标签、新建会话和主机工具菜单位于终端内容上方的紧凑工具栏。加号紧跟会话标签，会话多时标签独立横向滚动。窄窗口允许工具按钮换行。会话标签可双击改名、拖动和关闭，终端内容区可分屏。
- 移除终端旁的文件面板及其开合状态，SFTP 菜单和终端右键文件入口统一打开完整文件页；终端入口继续传递来源目录和窗格。切换工具保留各主机已有文件连接、路径、传输和终端会话。关闭设备工作区会关闭该设备的全部终端会话；指纹验证和危险操作确认继续沿用。

**底部：**

- 当前连接状态
- 操作提示
- 不提供任务中心入口或任务专用快捷键。SFTP 页按当前主机展示临时传输记录；关闭主机时对未完成传输先确认取消，等待安全收尾，关闭成功后清除记录，重新打开为空。切换工具或主机不清理，失败时保留工作区和记录。

## 4.2 工作区

每台服务器对应一个逻辑工作区。

应用启动后只显示欢迎页，终端会话及分屏列表为空，不自动打开终端或创建本地 Shell。终端标签和分屏仅保留在本次运行内，不自动保存或跨重启恢复，也不读取旧版已保存的终端布局。用户点击本地终端或主机时创建一个新会话；同一次运行内再次点击则复用已有会话。

工作区可包含：

1. Terminal
2. Files
3. 服务器管理（资源监控与 Linux 运维）

服务器管理提供标准服务器插件入口，各插件贡献资源概览、磁盘、网络、Docker 容器、镜像、进程、监听端口、systemd 服务、日志九类功能；插件页每次仅显示当前分类。概览提供 CPU、内存、Swap、负载与两张趋势图，系统信息、核心明细、采集警告及运维详情按需弹窗。进程详情展示常用字段，完整状态默认折叠。列表限制高度并在表内滚动，窄窗口分类条可横向滚动；选中项使用背景与文字高亮，不添加下划线。

服务器功能由五个独立标准 WASM 插件提供：资源监控（概览、磁盘、网络）、Docker（容器、镜像）、进程与端口、systemd 服务、日志。内置与上传使用同一标准包、仓库、运行时和能力校验。插件管理列表仅卸载；各自页内设置启停和权限，页面铺满可用区域，来源只在自身页展示。全部插件不再设置主机白名单，能力适用于所有主机，实际操作仍绑定当前目标。内置包新安装默认启用，声明权限和必要操作/目录预置且不可修改，已有禁用选择保留；上传包默认禁用且需显式授予能力和路径，上传相同 ID 不获得系统权限。卸载后重启不恢复。工具下拉只显示已启用插件，进程/日志联动仍寻找兼容提供者。危险操作逐次确认；禁用清理自身资源，不停止远端工作负载、共享连接或已有终端。

同一服务器允许创建多个终端会话。

默认会话名称按主机独立计数，本地设备单独计数。只要该设备仍有未关闭会话，新会话继续递增，已分配编号固定；例如打开会话 1、2、3，删除 2 后显示 1、3，再新增为 4。该设备的最后一个会话成功关闭后重置计数，重新打开从会话 1 开始；关闭失败则保留原编号和计数。拖动、自定义名称及其他设备的编号不受影响，重启后首次创建会话从 1 开始。

允许同时打开多台服务器。

切换服务器时，已经建立的终端会话默认保持连接。

主动点击主机树或已有主机的 Shell 工作区标签时，直接进入并连接当前选中的空闲 Shell，无需再点击窗格“连接”；没有 Shell 会话时新建一个。已连接或连接中的会话继续复用，不因重复点击创建会话；多会话/分屏仅连接当前选中的窗格。启动时不恢复终端布局或连接远端；从主菜单返回已有主机工作区或自动切换相邻标签不启动连接，SFTP/监控等工具仍恢复本次运行内的原上下文。认证失败保留错误和显式重试，首次主机指纹确认继续执行。

2026-11-02 布局调整：日常操作先进入主机工作区，再选择工具。每台主机保留最近使用的工具、服务器管理分类、终端会话和远端文件路径；从主机列表或已打开的一级标签切回时恢复该主机上下文，不将其他主机的功能标签改成新目标。

批量运维、自动化和网络诊断是全局独立工具，在功能内部显式选择目标或诊断来源。全局工具标签保持打开时，切换主机后再返回应保留其草稿和目标。终端操作菜单中的“诊断连接异常”和自动化快捷入口可显式预填目标，但不自动执行。主机功能入口位于中央工具栏右侧，终端上方保留会话和主机工具菜单，不重复显示主机连接信息及诊断入口；终端窗格也不保留常驻信息/按钮栏，主机信息可在终端操作菜单中查看，连接状态仍由会话标签显示。关闭设备工作区标签会关闭该设备的全部终端会话及分屏，成功后移除标签；失败时保留未关闭会话与工作区并提示错误。其他设备、SFTP 连接、后台传输和任务不受影响；关闭最后一个工作区显示欢迎页。

自动运维的“常用模板”采用纵向折叠抽屉列表，每个模板默认收起，仅显示名称及展开箭头；点击标题展开完整正文和“使用模板”按钮，再次点击收起，各模板独立控制。支持键盘 Enter/空格展开收起，长正文可滚动。使用模板仍只打开保留完整正文和参数的编辑草稿，不自动保存或执行。

## 4.3 标签页

支持：

- 创建标签页
- 关闭标签页
- 重命名标签页

- 标签页右键菜单

一级工作区标签的右键菜单提供“关闭、关闭右侧、关闭其它、关闭所有”，以右键点击的标签为基准，右键本身不切换当前页。无右侧标签或其他标签时禁用对应操作；范围内每个设备工作区都先关闭其全部终端会话及分屏，失败的工作区保留，其他目标继续关闭。关闭全部成功后显示欢迎页，保留文件连接、后台传输和任务。标签关闭按钮、中键与右键菜单使用相同逻辑，关闭期间避免同一目标重复提交。菜单支持点击外部或 Esc 收起，以及 Shift+F10 / 菜单键打开。

关闭最后一个标签页时，不应自动删除主机配置。

工作区标签栏不提供独立的“打开本地工作区”图标按钮。欢迎页保留“打开本地终端”入口；已有本地工作区继续通过对应标签切换，主机栏展开入口保持可用。

退出应用时应清理活动连接和后台任务。

## 5.1 功能要求

应用支持：

- 单实例策略，第二次启动聚焦已有窗口。
- 应用配置初始化。
- SQLite 数据库初始化和迁移。

2026-11-03 错误提示统一：所有页面、终端窗格、弹窗和表单校验的错误文案只在右下角气泡显示，不再在页头、表单或任务详情中重复显示。气泡支持手动关闭，同一条正在显示的错误去重；轮询得到未变化的错误时不反复弹出。弹窗打开时气泡仍须可见、可关闭。气泡文字可用鼠标拖动选中，并通过 Ctrl+C 复制；长文案换行和弹窗内提示同样支持。连接/任务失败状态、重试入口、监控样本过期标记、主机密钥确认及危险操作风险确认保留；终端、日志及命令结果的原始输出仍作为业务数据保留。

## 5.2 关闭行为

默认关闭主窗口即退出应用。

确认退出后结束全部 SSH 与本地终端会话，不保留终端标签、名称或分屏供下次恢复。取消退出则保留本次运行的会话。主机、分组、凭据及应用偏好继续保存，文件传输和未保存文档仍沿用原退出确认保护。

退出确认分行说明连接与会话、未完成任务和未保存修改。底部仅提供「确认」，点击右上角关闭或按 Esc 可取消退出。短窗口内正文可滚动，底部退出操作始终可见。

未来可增加托盘常驻功能，但不属于 MVP 必需范围。

退出前应：

1. 终止正在运行的监控采样任务。
2. 关闭 SSH 连接。
3. 停止或取消后台传输。
4. 保存非敏感应用状态。
5. 释放资源。

存在未完成文件传输时，应提示用户，避免静默中断。

# 6. M02：主机连接管理

## 6.1 新建主机

支持填写：

| 字段 | 说明 |
|---|---|
| 名称 | 用户自定义名称，可选 |
| 地址 | IP 或域名 |
| 端口 | 默认 22 |
| 用户名 | SSH 登录用户 |
| 认证方式 | SSH 密码（默认）、公钥认证（PublicKey） |
| 认证信息 | SSH 密码，或私钥内容/文件及可选解锁口令 |
| 连接超时 | 默认 15 秒，可配置 |

主机名称可留空（仅空白也视为未填写）。未填写时，主机树以地址作为显示名称：SSH 端口为 22 时只显示 IP / 域名，其他端口显示 `地址:端口`；IPv6 非默认端口使用 `[地址]:端口`。名称与地址相同时显示一行，有不同的自定义名称时在第二行显示地址。文件夹和主机行采用紧凑间距，行高随界面字号调整。

编辑使用系统 SSH Agent 的主机时，表单显示当前认证方式。保存其他字段时沿用该方式，也可改用密码或私钥。OpenSSH Config 导入沿用原认证规则。

主机表单不再提供分组选择。新建主机使用右键目标文件夹作为归属，从根目录或欢迎页新建则直接归属根目录；编辑时保留原文件夹，移动主机通过树内拖动完成。保存失败保留草稿和明确错误，不回退到根目录。

2026-11-03：主机管理移除标签、备注和收藏功能。新建/编辑表单不再提供这些字段，主机树不显示收藏标记或标签/收藏筛选；搜索仅匹配名称、地址和用户名。旧数据库中的对应字段兼容保留，编辑其他配置时不清空历史数据。

地址必须符合合法 IP 或主机名格式。

端口范围为 1～65535。

## 6.2 主机文件夹

支持：

- 默认显示不可删除或重命名的“根目录”，已有未分组主机直接显示其中
- 将已有分组保留为根目录下的文件夹，支持创建多级子文件夹
- 编辑文件夹名称；沿用现有名称全局唯一约束
- 删除文件夹前确认，主机和子文件夹保留并移动到父目录
- 将主机拖动到任意文件夹或根目录。悬停时显示箭头，按住左键准备拖动时显示手掌，拖动中显示握拳，松开或取消后恢复。
- 展开和折叠文件夹，搜索结果显示完整祖先路径
- 按名称、地址和用户名搜索

文件夹关系持久化，父目录缺失或循环必须拒绝。根目录为内置树节点，普通文件夹使用各自的持久化 ID。

## 6.3 主机操作

主机配置统一在工作区主机树管理，列表沿用默认名称顺序。固定区域依次显示“全部主机”、总数及搜索框。主机行展示名称、地址和连接状态，单击恢复该主机工作区。

点击“导出”直接下载 ServerDeck 主机 JSON 文件。点击“导入”选择该文件后直接恢复主机、文件夹层级和非敏感 SSH 连接设置，显示新增和跳过数量。恢复合并已有目录，按主机 ID 跳过已有主机，避免覆盖或重复添加。无效文件或文件夹冲突导致整次导入回滚。文件不携带密码、私钥、凭据引用或主机信任记录，需要凭据的主机恢复后须重新关联。

主机行不再显示编辑和删除图标，包括悬停与键盘焦点状态；编辑/删除统一由右键菜单进入，名称区域不再预留行内操作按钮空间。右键菜单按目标类型提供操作：根目录提供“新建主机、新建文件夹、导入 SSH 配置…”，导入项与新建项之间用分隔线区分；普通文件夹提供新建、重命名和删除操作；主机提供“连接、编辑、复制、删除”。复制主机在原文件夹生成独立配置副本，保留连接参数和凭据引用。

打开右键菜单本身不改变选中主机、连接或当前工作区，所有动作绑定右键目标。空白区域、本地设备和主机节点不提供新建文件夹；根目录不能删除或重命名。支持 Shift+F10/菜单键打开、方向键选择、Esc/Tab 关闭及焦点恢复，菜单限制在可见窗口内；切换模块、窗口失焦/缩放或列表滚动时关闭。管理操作不自动连接；仅显式点击“连接”或原左键行为进入连接流程。主机和文件夹删除均先确认，失败保留数据并提示原因。终端及文件页面各自的菜单不受影响。

删除主机时必须显示确认提示。

## 6.4 连接状态

每台主机至少包含以下状态：

- 未连接
- 连接中
- 已连接
- 正在重连
- 连接失败

状态应准确反映真实连接生命周期。

不得仅依靠 TCP 建立成功就认定 SSH 登录成功。

## 6.5 连接复用

同一主机允许多个逻辑会话。

基础设计：

- 主机配置与活动连接分离。
- 一个 SSH Transport 可复用多个 Channel。
- 不同终端拥有独立 PTY Channel。
- 允许根据认证及安全上下文建立多个 Transport。
- 单个终端异常不应导致其他独立终端全部关闭。

## 6.6 OpenSSH Config

支持导入常见字段：

- Host
- HostName
- Port
- User
- IdentityFile
- ProxyJump（具备支持能力时）
- 其他常见字段按兼容范围处理

导入时显示预览，允许选择主机。

不得直接覆盖已有主机。

对于尚不支持的 SSH Config 配置项，应明确提示，而不是静默忽略后错误连接。

# 7. M03：SSH 终端

此模块是整个产品最关键的模块。

## 7.1 基础能力

必须支持：

- SSH 连接。
- 交互式 Shell。
- PTY 分配。
- 终端窗口大小同步。
- UTF-8 文本。
- ANSI 控制序列。
- 256 色和 True Color。
- 鼠标交互。
- Ctrl+C、Ctrl+Z 等组合键。
- 复制和粘贴。
- 文本选择。
- 终端滚动。
- 会话断开提示。
- 手动重新连接。

终端渲染优先使用 xterm.js。

SSH 终端支持 `rz` 的 ZMODEM 上传：识别远端握手后自动打开原生多文件选择器，用户选择后通过当前终端通道上传到远端命令指定的位置。显示进度，支持取消、中文文件名、二进制及空文件；取消选择结束握手，断线或重连不得继续读取旧选择或向新会话发送数据。传输期间隔离普通输入与粘贴，Ctrl+C / Ctrl+X 可取消。每批最多 100 个普通文件，单文件小于 4 GiB；远端拒收或同名跳过必须如实提示。当前不提供 `sz` 下载，下载使用 SFTP。

## 7.2 多终端

支持：

- 多标签终端。
- 同一主机多个 Shell。
- 同时连接不同主机。
- 水平和垂直分屏。
- 分屏拖拽调整大小。
- 独立滚动区域。

每个终端必须具有唯一 Session ID。

终端工作区采用紧凑布局。新建按钮紧跟可横向滚动的会话标签，右侧平铺 SSH、SFTP 与插件工具按钮，窄窗口可换行。加号在当前主机新建独立会话，沿用连接验证和窗格数量限制。会话标签支持双击重命名、拖动排序、关闭按钮和中键关闭，新建与分屏快捷键继续可用。终端画面紧接会话栏，内容区右键菜单仅提供复制和粘贴，右侧显示当前设置的快捷键，默认为 Ctrl+Shift+C 和 Ctrl+Shift+V。开启快捷粘贴时，普通右键仍粘贴，Shift+右键、Shift+F10 或菜单键打开操作菜单。标签和分屏仅保留在本次运行内，错误及主机密钥确认继续显示。

关闭某一个终端不能错误关闭其他终端。

## 7.3 终端设置

支持：

- 字体
- 字号
- 行高
- 光标样式
- 光标闪烁
- 滚动缓冲区大小
- 主题配色
- 粘贴确认策略
- 选中即复制、右键即粘贴：在“设置 → 终端”的“终端显示与输入”中提供一个联动开关，默认关闭，保存后对已打开的终端生效；仅终端内容区处理右键，继续保留连接状态、单次大小和大文本确认保护。

桌面端复制与粘贴通过原生系统剪贴板接口读取/写入纯文本，终端右键、菜单、快捷键和选中即复制统一使用该接口，文件路径、诊断/批量结果、自动化输出与日志复制也保持一致。Windows 桌面端不再触发网页剪贴板授权提示；不自动读取剪贴板、不回退网页 Clipboard API，纯浏览器预览明确不可用。2 MiB 粘贴上限、大文本/多行确认、Bracketed Paste 和断线/重连保护继续有效。

终端内容区支持 Ctrl+鼠标滚轮调整字号：向上滚动放大、向下滚动缩小，每次调整 1，范围 10–32。沿用全局终端字号设置并保存，已打开的终端同步更新并适配 PTY 尺寸；普通滚轮保留终端滚动和鼠标上报，不缩放整个界面。连续滚动合并尚未保存的目标字号，保存失败沿用错误气泡并保留已保存字号。

| 粘贴 | Ctrl+Shift+V |
| 放大字体 | Ctrl++ |
| 缩小字体 | Ctrl+- |

在 macOS 上应适配平台习惯。

终端应用快捷键不得无意拦截远程程序依赖的按键。

## 7.5 断线重连

SSH 连接异常断开后：

1. 显示断开原因。
2. 标记连接状态。
3. 提供重新连接按钮。
4. 保留本地终端历史显示内容。
5. 重连后创建新的远程 Shell 会话。

不得假装恢复已经失效的远程 Shell、进程状态或交互上下文。

默认不自动重新执行用户之前输入的命令。

## 7.6 终端安全

- 默认启用 SSH 主机密钥校验。
- 首次连接显示主机密钥指纹。
- 主机密钥发生变化时必须阻止静默连接。
- 禁止自动接受发生变化的主机密钥。
- 禁止把密码和私钥记录到应用日志。
- 密码输入不得回显。
- 大文本粘贴应提供可配置确认。
- 支持终端 Bracketed Paste 行为。

## 7.7 性能要求

- 大量终端输出不得导致 UI 长时间无响应。
- 终端输出必须使用流式传输。
- 有限缓冲与背压控制必须明确。
- 关闭会话后必须取消对应异步任务。
- 终端 resize 不应导致 Shell 重启。
- 高并发会话不能使用一个全局锁串行处理所有输出。

# 8. M04：认证与凭据管理

## 8.1 认证方式

支持：

1. 用户名 + 密码。
2. SSH 私钥。
3. 系统 SSH Agent（已有主机和 OpenSSH Config 导入）。

私钥格式和加密算法应在技术选型阶段验证兼容性。

不应为了支持更多算法而降低安全标准。

## 8.2 凭据存储

主机信息保存在 SQLite。

密码、私钥口令和其他秘密信息通过操作系统安全存储机制管理，或采用具备明确密钥管理方案的加密保险库。

不得将明文密码保存在 SQLite、JSON 配置或日志中。

主机配置只保存 Credential ID 或安全引用。

## 8.3 SSH 主机信任

应独立维护可信主机密钥信息，并考虑与用户现有 OpenSSH known_hosts 配置的兼容。

必须区分：

- 首次连接未知主机。
- 已信任且密钥匹配。
- 已信任但密钥发生变化。
- 不支持的主机密钥算法。

## 8.4 凭据使用

用户打开已保存主机时：

1. 获取主机配置。
2. 根据凭据引用获取所需认证信息。
3. 建立 SSH 连接。
4. 不向前端发送不必要的明文秘密。
5. 在不再需要时释放敏感信息。

# 9. M05：SFTP 文件管理

## 9.1 页面布局

采用双栏布局：

左侧：本地文件系统。

右侧：远程文件系统。

支持调整左右宽度。

也允许切换到仅远程文件视图。

## 9.2 文件浏览

支持：

- 目录导航
- 鼠标后退与前进侧键按指针所在的本地或远程面板切换已访问的目录。两栏历史独立，远程历史随连接保留。成功访问新目录后清除对应的前进历史。
- 返回上级目录
- 刷新
- 路径输入
- 文件排序
- 显示文件大小
- 显示修改时间
- 显示文件权限
- 新建目录
- 重命名
- 删除
- 搜索当前目录文件名

MVP 不实现远程全文内容搜索。

## 9.3 文件传输

支持：

- 上传文件
- 下载文件
- 批量上传
- 批量下载
- 递归目录传输
- 拖放上传
- 将远程列表中的条目拖入本地栏，预填本地栏当前目录并打开传输确认。拖动已选中条目时传输当前选区。
- 在 Windows 上可将远程普通文件或指向普通文件的符号链接拖出窗口，松手后复制到桌面或资源管理器中的目标文件夹。支持多选，目录和目录链接不参与窗口外拖放。
- 下载直接选中的文件符号链接时，以链接名保存目标普通文件内容。目录链接和递归扫描中遇到的链接不跟随。
- 传输进度
- 当前速度
- 已传输字节
- 取消任务
- 失败提示

SFTP 传输正常完成不弹出成功通知或完成横幅；失败及临时文件清理异常仍需提示。完成后自动刷新目录，进度、校验和跳过统计在当前主机的 SFTP 页临时保留，关闭该主机成功后清除。

传输任务应有独立 Task ID。

所有传输不能在 UI 主线程执行。

## 9.4 文件冲突

目标文件存在时提供：

- 跳过
- 覆盖
- 重命名

批量传输时可以选择应用于本批次剩余冲突。

MVP 不承诺所有上传下载均具备可靠断点续传。

如果尚未实现断点续传，必须在界面中明确任务失败后需要重新传输。

## 9.5 远程文本编辑

支持：

- 打开 UTF-8 文本文件。
- 编辑内容。
- 保存到远程服务器。
- 检测保存前文件是否被外部修改。
- 保存失败提示。
- 常见文件权限问题提示。

编辑器可采用 Monaco。

对二进制文件、超大文件和无法正确解码的文件，应阻止直接文本编辑或显示明确警告。

优先采用临时文件写入、校验及安全替换策略；需要考虑权限、属主和跨文件系统限制。

## 9.6 删除操作

删除文件或目录必须确认。

确认弹窗显示待删除对象。确认后递归删除所选目录。

不得使用拼接未经转义的 Shell 命令实现普通 SFTP 删除操作。

# 10. M06：服务器资源监控

## 10.1 工作模式

MVP 通过 SSH 远程命令采集 Linux 服务器资源信息。

不要求服务器安装 Agent。

支持常见 Linux 发行版，优先兼容：

- Ubuntu
- Debian
- Rocky Linux
- CentOS
- AlmaLinux

## 10.2 监控指标

| 指标 | 说明 |
|---|---|
| CPU | 总体使用率 |
| 内存 | 总量、已用、可用、使用率 |
| Swap | 总量和使用情况 |
| 系统负载 | 1、5、15 分钟 |
| 磁盘 | 挂载点、总量、剩余、使用率 |
| 网络 | 接口收发速率 |
| 运行时间 | 系统 Uptime |
| 系统信息 | 主机名、发行版、内核、架构 |

## 10.3 采样规则

默认采样间隔：3 秒。

支持：

- 3 秒
- 5 秒
- 10 秒
- 30 秒

当监控页面不可见时，应降低采样频率或暂停非必要采样。

采样失败不得影响正常 SSH 终端使用。

## 10.4 指标计算

CPU 使用率需要根据连续采样的 CPU 时间差计算，不能直接把 `/proc/stat` 累计值作为百分比。

网络速率根据连续采样的接口字节计数器计算。

对于第一次采样，应显示待计算状态。

应处理计数器异常、接口消失和时间间隔过短等情况。

## 10.5 历史数据

MVP 保存当前会话内有限的监控历史，用于绘制短时趋势图。

例如保留最近 30 分钟的样本。

不实现长期时序数据库。

关闭程序后无需保留完整指标历史。

## 10.6 监控失败

当出现：

- SSH 连接断开。
- 远程命令不可用。
- 权限不足。
- 数据格式不兼容。

必须显示明确错误。

不得将采集失败显示为 CPU 0% 或内存 0%。

# 14. 非功能需求

## 14.1 性能

以下作为 MVP 的工程目标，需在明确测试机器和测试条件下验证。

- 冷启动目标：3 秒内可交互。
- 空闲内存目标：尽量控制在 150MB 以内。
- 支持同时维护至少 20 个活动 SSH 终端会话。
- 正常终端输入应无明显额外卡顿。
- 文件传输不得阻塞终端交互。
- 监控采样不得阻塞文件传输。

注意：WebView、操作系统、终端缓冲区、运行环境会影响内存和启动时间，因此目标不能作为未经测试的性能承诺。

## 14.2 稳定性

- SSH 连接错误不导致应用崩溃。
- 单个终端错误不影响其他终端。
- SFTP 操作失败不影响已有终端。
- 远程监控异常不影响 SSH 会话。
- 后台任务必须可取消。
- 不允许无限增长的异步队列。

## 14.3 安全性

- 默认进行 SSH 主机密钥验证。
- 敏感信息不得明文持久化。
- 不允许绕过连接安全校验。
- 不直接拼接不可信输入生成 Shell 命令。
- 前端不能无约束执行任意本地系统命令。
- Tauri 权限应按最小权限原则配置。
- 文件传输遵循目标权限限制。
- 不私自上传用户服务器信息。
- 自动更新如果实施，必须使用可信签名与安全更新机制。

## 14.4 兼容性

首个开发目标为 Windows 11 x64。

架构应具备 Windows、macOS、Linux 适配能力，但未经完整测试的平台不得宣称已经正式支持。

# 18. 验收标准

## 18.1 SSH 验收

- 使用密码可以登录测试 Linux 服务器。
- 使用私钥可以登录。
- 不正确的凭据显示明确错误。
- 首次连接能确认主机指纹。
- 主机密钥变化会被检测。
- `vim`、`top` 等交互程序正常工作。
- `Ctrl+C` 可中断前台命令。
- 调整窗口大小可以同步 PTY。
- 多个终端并行操作不互相干扰。
- SSH 断开不会导致程序崩溃。

## 18.2 SFTP 验收

- 可以浏览远程目录。
- 可以上传和下载文件。
- 文件内容通过哈希校验保持一致。
- 中文文件名正常显示。
- 文件名包含空格及特殊字符时操作正常。
- 文件权限不足时有明确提示。
- 可以取消传输。
- 大文件传输不阻塞界面。
- 已确认删除的目标正确，未选中文件不受影响。

## 18.3 监控验收

- CPU 使用率计算合理。
- 内存统计与 Linux 系统指标基本一致。
- 磁盘容量与系统查询结果一致。
- 网络速率为采样差值计算。
- 监控失败不会显示伪造的正常指标。
- 停止监控后没有持续后台采样任务。
- 监控开启时 SSH 终端仍可正常交互。

## 18.4 数据与安全验收

- 重启应用后主机配置保留。
- 重启应用后分组保留。
- 数据库中不出现明文 SSH 密码。
- 日志中不出现明文私钥和密码。
- 导出的主机配置不包含秘密凭据。
- 非法输入不导致程序异常退出。

# 22. 开发约束

Codex 实施本项目时，应遵循：

1. 优先保证核心功能正确，不得以模拟数据冒充已实现的真实服务能力。
2. 代码使用 Rust、TypeScript，保持统一项目风格。
3. 采用模块化设计，但避免无实际用途的抽象。
4. Rust 错误必须可追踪，不允许大量使用 `unwrap()` 掩盖可恢复错误。
5. 长时间任务必须支持取消和资源释放。
6. SSH 安全校验不可省略。
7. 敏感信息不可写入普通日志。
8. 所有异步任务必须有明确生命周期。
9. 关键模块必须提供自动化测试。
10. 每完成一个开发阶段，都要进行构建、测试和真实功能验证。
11. 不得未经确认就增加 PRD 范围之外的大型模块。
12. 不得为了快速实现而牺牲数据安全和基础连接可靠性。

# 24. 后续技术决策原则

本说明书定义产品需求基线，不要求开发者机械照搬所有技术建议。

遇到以下情况时应输出技术决策记录：

- SSH 库不满足核心功能。
- SFTP 库存在兼容性问题。
- 前端终端渲染性能不达标。
- 操作系统安全存储存在平台差异。
- Tauri IPC 高频消息性能不足。
- Agentless 模式无法可靠取得某个指标。

技术决策记录至少包含：

1. 当前问题。
2. 可选解决方案。
3. 安全性与兼容性影响。
4. 性能与维护成本。
5. 推荐方案。
6. 验证方式。

未经验证的设计假设不得描述为已经完成的功能。
