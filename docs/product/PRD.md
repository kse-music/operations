# ServerDeck 产品基线（PRD）

本文定义当前产品的功能、交互和使用边界，是后续需求的起点。实现见[总体架构](../architecture/ARCHITECTURE.md)，操作见[使用说明](../guides/USER_GUIDE.md)，上线验收见[发布检查表](../release/RELEASE_CHECKLIST.md)。功能已实现不等于候选安装包已经通过验收。

## 产品定位与范围

ServerDeck 面向个人开发者、DevOps 和小型团队，是通过 SSH/SFTP 管理服务器的本地桌面工作台。无需云账号或远端 Agent；主机、偏好和插件配置保存在本机，密码、私钥和模型 Key 交给操作系统凭据库。

| 产品入口         | 当前能力                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| 首页与主机工作区 | 工具启动台、多级主机目录、主机标签、搜索、SSH/SFTP 和插件入口            |
| 本地终端与 SSH   | 多会话、分屏、查找、剪贴板、快捷键、重连、rz 和当前 Shell 拖放上传       |
| SFTP 文件        | 双栏浏览、目录操作、后台传输、校验、切换用户、内置与外部编辑             |
| Docker 插件      | 容器、镜像、Compose 项目、启动配置、环境变量、日志、Shell 和镜像归档传输 |
| AI 运维助手      | 主机关联、证据采集、流式回答、按模式审批的工具任务和执行后复查           |
| 设置             | 通用、终端、快捷键、数据与存储、模型、插件、关于与软件更新               |

Windows x64 是首要发布验收平台。macOS、Linux 和其他架构须分别完成原生验收；构建配置和单项测试不构成完整平台支持承诺。界面支持简体中文和 English。应用版本以根 [Cargo.toml](../../Cargo.toml) 的工作区版本为准；SDK、插件包和持久格式独立管理版本。

发布流程为同一版本构建 Windows x64 安装包、Linux x86_64 的 deb/AppImage，以及 macOS Intel、Apple Silicon（M 系列）的 DMG 和应用 ZIP，收集完整附件后上传到同一个 Release 草稿，经过验收再手动公开。Linux、macOS 使用手动下载安装升级，应用内自动更新仍仅面向 Windows x64 正式 NSIS 安装版。macOS 尚未接入 Apple 开发者证书签名和公证，打包与上传成功不代表已通过系统信任或安装运行验收。

当前不提供云同步、团队权限、插件市场、独立监控/系统服务页面、集中式时序或日志平台。宿主内部的监控、运维和执行能力不代表存在相应产品入口或插件领域 API。

## 桌面工作台与交互

### 导航与工作区

- 主窗口使用自定义标题栏，提供全局搜索和原生窗口控制；关闭进入退出审核。工作台固定三栏：52px 全局导航、可调宽度的菜单/会话栏、内容区。第二栏始终可见，各栏独立滚动。
- 全局入口为首页、本地终端和设置。首页保留固定“首页”标签及已打开的主机/全局插件标签；本地会话从独立入口访问。切换入口保留当前内容、连接、分屏、路径、筛选、滚动和设置草稿。
- 工具启动台提供本地终端、新建主机、导入 SSH 配置，以及目标主机的 SFTP、Docker、助手和模型绑定入口。零主机显示添加引导；单主机显示名称；多主机优先使用当前选择，否则按显示名称选首台。删除目标后选择仍有效的主机。未加载、加载、读取失败和成功空目录分别处理。
- 首页选择目标或渲染卡片不创建连接。插件快捷入口按实际安装、启用及当前 UI 授权路由到业务页或插件管理/配置；不自动安装、启用、授权或绑定模型。插件读取失败保留重试，SFTP 仍可使用。
- 启动只加载已保存的本地会话元数据，不自动启动 Shell 或连接主机。主机树单击选择，双击、Enter/空格或菜单连接打开工作区；重复打开复用现有连接，失败明确重试。每台主机在本次打开期间保留最近工具、会话和文件路径。
- 标签菜单支持关闭、关闭右侧、关闭其他和关闭所有，按菜单目标及可见顺序确定范围；不影响本地终端。右键不切换活动页，关闭后选中相邻标签，没有可见标签时回首页。
- 插件功能页的“插件设置”在设置页面中打开，返回首页复用原业务实例和状态。

### 关闭与资源保护

关闭主机工作区前审核未保存内容、插件草稿、文档及传输；取消保留全部工作。确认后停止接收新任务，等待传输安全提交/清理，再关闭所属文件连接、终端和插件资源。失败保留工作区和记录；成功后清除该主机的临时传输记录，不删除用户文件。

关闭主窗口申请退出，确认页说明连接、任务和未保存内容，Esc 或关闭确认页取消退出。确认后取消并排空后台工作、终端和转发，完成持久化及日志刷新。不提供托盘常驻。独立编辑文档须按提示关闭或明确放弃，保存/读取中阻止退出。

### 显示、通知与可访问性

默认窗口为 1280×820，最小 960×600 逻辑像素，恢复尺寸与最大化状态。默认深色，支持浅色和系统主题；界面字号为小/标准/大/特大/超大，比例为 95%/100%/115%/130%/145%，终端字号独立。最小窗口、超大字号和弹窗中，内容可滚动且关键操作可达。

桌面和内置插件统一控件、菜单、图标与主题样式；控件保留常规边框，主机树、菜单和搜索使用背景提示键盘定位。右键菜单受视口约束，连续右键切换到新目标，同一时刻只显示一个业务菜单。所有原生窗口及插件 iframe 屏蔽浏览器默认菜单，业务菜单、文本选择和剪贴板仍可用。

错误通知保留供手动关闭，普通通知默认三秒关闭；通知支持复制、去重，并在弹窗中可操作。连接测试使用独立结果弹窗。输入、正文和输出可选择，标题、导航和按钮不使用浏览器文字选择。

全局搜索默认 Ctrl+K，设置默认 Ctrl+Shift+P，可修改。搜索本地公开目录与功能，不检索私密终端输出；初次打开和修改关键词不默认选择结果，选择后 Enter 跳转，Esc 关闭。对话框中不触发全局导航。

## 主机与 SSH 认证

### 主机目录

主机包括可选名称、合法地址、端口（默认 22）、用户名、密码/公钥认证、连接超时（默认 15 秒）及代理/跳板。无名称显示地址，非标准端口和 IPv6 使用无歧义格式。搜索匹配名称、地址和用户名；不提供标签、备注或收藏。

根目录不可删除或重命名，支持多级文件夹、全局唯一文件夹名称和拖动移动，拒绝循环或无效父目录。删除文件夹需确认，将主机和直接子目录提升至父级。主机支持编辑、复制和确认删除，复制不连接。右键和 Delete 绑定实际行；输入框、忙碌、拖动、弹窗、组合输入及连发不触发删除，失败保留数据。

### 连接测试与保存

新建/编辑直接填写密码、粘贴或选择私钥，支持加密私钥口令；取消文件选择保留表单和草稿。编辑同一认证方式留空沿用原凭据；已有 Agent 配置可继续使用。认证变更不改写其他共享凭据的主机。

测试使用完整草稿及真实路由完成握手、指纹核验和认证。成功凭证五分钟有效、单次消费，绑定主机、草稿、路由与凭据修订；修改、失败或过期后重新测试才能保存。首次指纹通过独立弹窗展示目标、算法及 SHA-256，须带外核对后信任；拒绝保留草稿。密钥变化硬拒绝。测试结果显示真实成功或错误原因。

### 信任、凭据与路由

- 密码、导入私钥及口令在系统凭据库，SQLite 仅保留引用和修订；不可用时失败，不回退明文。支持 Ed25519/ECDSA/RSA；RSA 要求服务器声明 SHA-2 签名，不回退 SHA-1。
- 每跳验证主机身份，支持受管跳板及 SOCKS5/HTTP CONNECT。HTTP CONNECT 本身不提供 TLS，代理认证仅适合可信网络。不执行 ProxyCommand。
- OpenSSH Config 导入支持文件/粘贴、预览、目标目录树和选择确认；提交重新校验、事务去重，不覆盖已有主机。支持明确别名和受限 ProxyJump，无法安全判断的配置拒绝。精确范围见[连接实现](../architecture/CONNECTIONS_TERMINALS.md#主机目录测试和导入)。
- 系统 known_hosts 的哈希、CA、证书和撤销语义未接入。TCP 可达不能显示为认证成功。

## 终端

### 交互与会话

提供真实本地/SSH PTY、UTF-8、ANSI、256 色/True Color、鼠标、Ctrl+C/Z、选择、查找、滚动和 resize。同一主机可有多个会话，可排序、改名和分屏；每标签最多八窗格，全应用最多 32 窗格，几何变化不重建 Shell。

会话菜单支持复制、重命名、重连、断开和关闭。断开保留显示历史、禁输入并停止光标闪烁；重连仅在目标标签全部窗格已结束/失败时可用，保留名称和分屏，创建新 Shell 前清空旧终端状态。复制创建普通新 Shell，不克隆进程、分屏、固定动作或一次性票据；主机配置变化须从主机树重新打开。关闭失败保留会话，不误关其他终端或 SFTP。

输出中的 HTTP/HTTPS 和 OSC 8 网页链接经校验由本机默认浏览器打开；拖动仍选择文本，其他协议拒绝。底部状态栏显示当前可见窗格的真实 SSH 算法或本地 Shell、光标、行列尺寸、仿真类型及本机 CAP/NUM 状态；未知不伪装为关闭，不额外执行远程命令。

### 偏好与输入保护

支持字体、10–32 字号（默认 16）、行高、光标、主题、缓冲和快捷键。原生文本剪贴板仅由用户动作触发，单次最多 2 MiB；超过字符阈值或 50 行先确认并使用 Bracketed Paste，但不能保证远端禁用该协议时换行不执行。“选中即复制、右键即粘贴”默认关闭。内容菜单提供复制/粘贴，分屏、查找和会话操作使用快捷键；默认值和改键步骤见[使用说明](../guides/USER_GUIDE.md#ssh-与本地终端)。

Windows 使用 PowerShell，Linux 使用用户交互 Shell，不修改用户启动配置。Windows 可显式新建管理员会话，每次创建、分屏、复制或重连均重新经 UAC，只提升专用 Shell 代理。取消或失败不降级为普通 Shell，关闭回收受管进程，插件无提权入口。

Windows 本地会话在重命名弹窗点击“保存”，手动保存名称、各窗格当前文件系统目录和分屏布局；双击、菜单或本地 Ctrl+S 打开同一弹窗。最多保存 32 项，不随目录、布局变化或退出自动更新。进入本地终端时复用已打开会话，否则启动第一个保存项；无保存记录时首次进入新建普通会话，其余保存项由用户点选启动。新建/复制/新增分屏从主目录启动，保存目录不可用时回主目录且保留记录。

关闭或“删除会话”结束 Shell 并删除对应保存记录；最后一个分屏关闭才删除整项，关闭全部后保持空列表。Shell 关闭或记录删除失败保留可重试条目；普通退出保留保存记录。不恢复终端正文、运行命令或管理员授权。Linux/macOS 不提供本地会话保存，自定义提示符和嵌套 Shell 内部目录不保证可追踪。

### 转发与 rz 上传

底层转发按会话管理，默认回环地址，公共绑定需确认，断线释放且不跨重启恢复；当前终端不提供转发管理、按目录打开 SFTP 或正文导出入口。

远端 rz 握手触发原生多文件选择，经当前 PTY 上传；每批最多 100 个普通文件，单文件小于 4 GiB。选择期间只显示系统选择器，选好后显示进度；不推测 ZMODEM 未提供的账户和目录。取消停止读取、排空在途批次及取消帧并释放授权，无法确认时关闭原会话。支持中文、二进制和空文件，不提供 sz 下载。

### 终端拖放上传

普通 Linux SSH 窗格可接收文件、目录及混合多选，确认后经原 PTY 上传到当前 Shell 真实身份与目录，支持 sudo/su 后的用户。须处于空白提示符，要求兼容 GNU 基础工具，无需 rz。本地、插件、容器/固定动作和备用屏幕不接收；拒绝链接、重解析点及特殊文件。

每批 1–256 个顶层项目，递归最多 100000 项、128 层。单文件直接分块读源并累计 SHA-256；多选/目录先准备临时 tar，保留结构与空目录并可取消。普通文件 0644、目录 0755，再受 umask 限制，不复制本地属主或特殊权限。

上传隔离原窗格输入，显示真实接收用户/UID、目录、阶段、确认字节和速度；协议与接收脚本不进入终端显示。私有暂存经校验后提交，同名文件、目录或链接均停止，不合并/覆盖。取消排空数据并恢复终端，无法确认恢复则关闭会话，保留已提交项目和恢复路径；其他窗格继续工作。不支持续传或跨重启恢复。

拖放和 rz 均保留源文件修改时间至 Unix 秒，拖放归档保留目录时间；不复制创建时间或 ctime。时间无效或设置失败明确拒绝，拖放不提交暂存文件。传输速度和剩余时间不包含后续校验、解包及提交，不承诺固定带宽。

## SFTP 文件与文本编辑

### 浏览与布局

本地/远程双栏按空间并排或上下布局，各自提供地址、父目录、刷新、名称筛选、排序、多选、隐藏文件、属性和业务菜单。每主机保留独立路径及后退/前进历史，关闭主机后清除，不跨重启恢复。读取中不展示旧条目，失败恢复原路径，连续请求只接受最新结果。Windows 本地路径显示普通盘符/UNC，操作保留原始路径。

本地栏按实际磁盘选择根目录，远程栏展示当前已确认路径的祖先目录树；保留键盘导航及视口边界。没有手动双栏比例、仅远程模式或远程全文搜索。

### 文件用户身份

终端 su/sudo 不改变 SFTP 身份。文件页可确认切换用户，通过登录账号的 sudo 权限运行目标用户外部 sftp-server；新通道真实读取成功才替换，失败保留旧连接。切换前处理文档和传输，切换后从目标主目录或 `/` 开始并清空旧历史。

sudo 密码仅在本次文件连接内存中使用，不保存、不进入命令或日志、不继承到插件。服务器须支持无 PTY sudo 和外部 sftp-server；requiretty 或仅 internal-sftp 不支持。

### 传输和文件操作

支持单/多文件和递归目录上传下载、原生拖放、远程条目拖入本地栏，以及 Windows 普通文件/文件链接拖到系统文件夹。显式文件链接仅在目标为普通文件时按链接名下载，递归不跟随链接；目录不参与窗口外拖放。

冲突策略为停止、跳过、确认覆盖。任务有独立 ID、进度、取消和从头重试，默认每主机三个并发，可设 1–6，全局最多 12。目标同目录暂存、SHA-256 读回校验、属性复验后提交；字节满不代表完成。取消排空在途请求、关闭句柄并清理，保留已提交文件，清理失败显示恢复路径。不提供续传或跨重启恢复。

上传新文件默认请求权限 `0644`，新建目录默认请求 `0755`，服务端 umask 或策略可进一步收紧；合并已有目录不修改其权限。上传普通文件保留源 mtime 至 SFTP v3 支持的整秒；覆盖保留目标基本权限和属主，时间设置/复验失败保留原目标。目录合并不保证目录时间。传输弹窗集中显示本主机任务，支持后台隐藏、页头重开、记录和重试；X/Esc 请求取消当前弹窗任务并等待收尾。切页继续，新增任务打开弹窗，轮询不反复打扰；传输用时与速度只累计数据阶段，校验和提交单独显示。Windows 外拖以系统最终复制结果为准。

远程创建、重命名和确认删除使用真实权限及 SFTP，目录递归删除不跟随链接，禁止删除根。Windows 本地 Delete/菜单删除经确认移入系统回收站，失败不回退永久删除，其他平台不提供该能力。确认绑定原主机、身份、目录及路径；部分失败必须如实显示，输入框和不可操作状态不触发删除。

### 文本编辑和终端联动

内置编辑器在独立原生窗口中编辑单个严格 UTF-8 普通文件，上限 2 MiB，无 NUL。支持保存、重读、查找、换行和状态栏，当前主题/字号在打开时应用；读取和保存互斥，失败保留草稿，关闭/重读审核未保存内容，不提供崩溃恢复或跨重启草稿。

保存检查原文 SHA-256、大小、时间及 mode/uid/gid，经暂存和基础元数据复验后 OpenSSH 原子替换；不具备原子能力时只读，不降级截断。替换改变 inode，不能保证 ACL/xattr/硬链接，SFTP v3 无服务端 CAS，最终检查至提交仍有竞态。编辑器打开时阻止所属连接关闭、切用户、迁移和页面重载；断线保留本地草稿。

Windows 本地文件可选择系统应用；远程普通文件可下载为独立本地副本交外部应用，二进制和大文件不转换编码，用户明确确认后才回传并复用冲突/原子保存。内外部编辑不能同时进行，结束或失败保留副本并提示路径，不自动清理或恢复授权。其他平台可自行下载后打开。

文件页目录/less/tail 动作经确认打开独立 PTY，不向现有 Shell 注入命令。

## 插件平台与内置能力

### 平台契约与管理

插件以独立 Vue UI 和 WASM 承载业务，平台只提供通用原语、权限、审批和资源管理。当前 API、UI 和 ABI 版本统一见[版本约定](../plugins/PLUGIN_API_VERSIONING.md)，精确契约见[公开 SDK](../plugins/PLUGIN_SDK.md)。

系统与上传插件共用标准包和安全边界。内置源码构建后随客户端分发，首次默认启用并预置声明权限；升级保留既有启停、配置及卸载选择。上传包默认禁用且未授权，同 ID 不获得系统来源。包无密码学签名验证，安装须确认开发来源风险；作者与摘要不能证明身份。

设置支持安装预览、升级/回滚、启停、权限及目录、配置、确认卸载和独立开发包下载。列表展示来源、启用状态、版本与包构建时间；详情分基本信息和插件配置。运行期复用列表，管理操作后更新，应用外修改需刷新。卸载内置插件可显式恢复当前嵌入包，保留未清除配置并默认禁用；损坏或旧契约记录隔离，有当前内置替代时可先备份再重装，不继承旧授权、不阻断其他插件。

固定命令、交互命令、任务读取和文件传输预授权分别声明并授权，均绑定当前安装修订，不推断为只读。模式与模型声明不能增加基础权限。关闭、撤权、升级和取消按资源 owner 收尾；隐藏页面与保留任务的边界见[UI 生命周期](../plugins/PLUGIN_UI_EXTENSION.md)。

### Docker

- 提供真实检测、容器/镜像/Compose 项目列表、服务端版本及全局统计、搜索、容器详情、环境变量、只读启动配置、日志和 Shell。成功列表在同一主机连接内缓存，刷新/变更更新，失败保留上次值并标明原因，未知不显示为零。
- 详情按概览、启动配置、环境变量折叠，首次展开读取，明文缓存限当前弹窗；启动配置来自当前项目或 inspect 转换，列出未转换项，内联 secrets/configs 隐藏。不提供资源使用、配置编辑或部署。
- 变更由宿主确认真实对象及影响；容器可启停、重启和删除，批量重启仅处理当前主机全部 exited 容器，不受搜索影响，不提供全部重启或远程日志清空。日志可本地清屏、筛选、复制和导出，单次最多十分钟，需要 GNU timeout，关闭/隐藏等待远端退出确认。
- Compose 优先 `docker compose`，其次独立 `docker-compose`，支持 V1.29.2 及 V2 或后续版本；只管理已创建容器，提供服务状态、项目日志及整组启停/重启，不拉取、重新部署或删卷。配置缺失和业务失败明确提示，不切换入口重试，Compose 故障不影响容器和镜像。
- 镜像支持本机 `docker save` 归档导入、导出及经本机流式中转到其他登记主机后自动导入。远程传输在同名标签冲突时确认替换，load 前复验目标，导入后核对平台、配置和有序层内容；本机不落地完整归档。只保留选中标签，无标签按 ID；不更新已有容器。
- 需要实际 SSH 登录账号的 Docker/SFTP 权限及暂存空间，不自动安装或提权。取消先排空传输再清理已知暂存，不回滚 daemon 已接受的变更；失败保留恢复路径，不自动重试。标签外部并发和默认平台校验有明确限制，见[Docker 使用说明](../guides/DOCKER.md)。

### AI 运维助手与模型

模型管理提供远程 OpenAI 兼容模型与独立授权的本地 Codex/Claude Code 来源。本地/远程分 Tab，远程默认打开，支持按 ID/名称/地址搜索及按真实注册时间倒序，历史未知时间置后。远程关键配置/Key 变更须真实无主机上下文测试，成功凭证五分钟、单次且绑定输入；Key 不回显，地址变更须重新输入或明确清除。各模型独立系统凭据、上下文窗口和输出上限。

本地 CLI 复用用户配置和登录，安装、就绪、授权分别展示；未授权不能读配置或推理。Windows x64/ARM64 可从固定官方源校验安装到应用目录，可取消，不改 PATH 或覆盖系统安装；其他平台手动准备。助手配置从已就绪来源中选择，选中立即保存，失败恢复原值，不自动选替代模型。

助手以登记目录、问题及最近成对对话匹配最多八台主机；需要来源但未另行指定时使用当前工作区。只采集相关证据，先脱敏再预算缩减，保留必要主机地址和原始身份以区分目标，自定义敏感值优先脱敏。失败、缺失及省略明确标记，普通知识问题不附目录；脱敏不保证覆盖全部业务秘密。

任务可连续查询、准备计划、授权、执行和复查，直至回答、需补充信息、失败或取消。提供 Docker/systemd 变更、远程程序与 argv、单个远程文本局部编辑（UTF-8 ≤32 KiB）、本机单文件上传和服务器间中转，以及镜像导出/导入组合。计划冻结实际目标、原文、参数和修订，五分钟内单次消费；单任务最多 32 轮推理、64 次只读工具、32 批变更，每轮最多三个查询，每批最多 32 个真实运维目标。Skill 按需读正文和资源，不授予权限、不自动运行脚本。

| 审批模式         | 当前行为                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| 请求批准（默认） | 读取和命令按宿主规则询问；计划点击执行后统一确认                                                                 |
| 帮我批准         | 已授权读取、精确模板、不覆盖传输及可信来源到空标签的导入可自动执行；删除、覆盖、保存配置、未知来源/命令仍确认    |
| 完全访问权限     | 须可信宿主首次授权，当前会话在已有能力/目录范围内持续自动执行；切换模式、新对话、关闭、撤权、停止/升级使授权失效 |

模式发送时冻结，切换不升级旧任务。首次 SSH 指纹、基础权限、目标/原文复验和取消始终保留，不自动提权。模型及远端文本不作为可信指令；输出使用真实增量并先脱敏，完整结果校验前不能执行计划，停止保留片段且不进入历史。不支持流式时明确失败，不模拟打字或自动重试计费请求。

运行期展示准备、查询、待审、执行、传输、复查及真实终态，最多保留 32 项；回答结束不代表业务目标完成，失败/未确认停止后续步骤并保留已完成项。切换页面可继续已授权的工作，需新审批时等待返回；关闭所属工作区取消并排空自有任务。对话、任务和资源不跨重启恢复，不提供 MCP、运行时 Skill 管理或持久任务中心。完整操作与限制见[助手指南](../guides/AI_ASSISTANT.md)及[助手实现](../architecture/ASSISTANT_AGENT.md)。

## 设置、数据与安全

通用、终端、快捷键及数据与存储的普通偏好修改后自动保存，合并连续输入、拒绝无效值，失败保留草稿供重试；恢复默认仅作用于当前分类。模型和插件独立保存，数据根目录使用单独的“迁移并重启”预览/确认，不随普通保存迁移。保存、迁移或插件管理中阻止离开，关闭设置先提交有效偏好，剩余草稿明确审核。

语言保存后桌面与内置插件立即更新，不重建连接，用户内容和原始输出不翻译；独立编辑器下次打开采用新偏好。关于页显示真实应用版本、固定构建时间（北京时间）、本地环境和软件更新；环境刷新与更新检查独立。

Windows x64 正式 NSIS 安装版可从固定 GitHub Releases 检查、下载并安装更高正式版本。自动检查默认开启，距上次尝试至少 24 小时，支持关闭；手动检查不限。失败不显示为最新，下载可取消、切页继续，包只驻留当前运行期。内置公钥签名及签名版本校验成功后才能安装，安装先审核并排空工作，再启动安装器。开发版、独立 EXE 和其他平台不执行应用内更新。更新不自动降级、覆盖用户数据或回退数据库；分发见[更新说明](../release/UPDATES.md)。

用户数据默认位于标准应用目录，不写安装目录。主动迁移数据根须空的专用目标、足够空间和确认重启，复制、清单/摘要及数据库校验、新目录启动确认后才逐项安全清理源；失败保留数据及诊断，系统凭据不复制。持久结果留设置页，仅本次新结果弹通知。

已支持数据库/偏好启动前安全升级，模型配置按需独立升级且故障隔离。先取得写锁、保存包含 WAL 的一致备份，再事务修改和校验；失败停止，不清库、不重置，备份不覆盖或自动清理。未知/未来/损坏格式拒绝，既有值和秘密引用保留，不继承失效插件授权。恢复或降级须正常退出后另行明确授权，支持范围见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

日志有界轮转，不记录密码、私钥、Key 或终端/文件/模型正文；前端仅能调用授权 IPC。无默认用户数据上传；远程模型按明确授权发送上下文，更新只请求固定公开 HTTPS 分发源。风险见[安全说明](../release/SECURITY.md)。

## 性能、稳定性与验收要求

工程目标为冷启动三秒内可交互、空闲进程树内存尽量控制在 150 MB、至少 20 个活动 SSH 终端；须记录真实机器及条件，未测不承诺。传输数据阶段接近 100 MB/s 是可控千兆环境的测量目标，不能代替目标网络、PTY 或整体含校验耗时的结果。

输出、任务和缓冲有界，终端、传输、插件和模型故障应隔离；内部采样使用真实 SSH 数据，CPU/网络由连续计数差计算，首次和失败为未知，不用零掩盖错误。监控采样不代表独立页面。

上线前以同一候选产物完成[发布门禁](../release/RELEASE_CHECKLIST.md#发布门禁)和[模块原生验收](../release/NATIVE_VALIDATION.md)，包括正常、加载、空、失败、取消、撤权、重启、数据保留和未知结果保护。实际命令、环境、结果和限制随 QA/发布产物记录；本文件不记录开发阶段或历史测试通过情况。开发约束见 [AGENTS.md](../../AGENTS.md)。
