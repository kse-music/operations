# ServerDeck 实施计划

本文件按模块维护当前交付状态、剩余工作和依赖；不追加逐次改动或测试流水。功能范围以[PRD](PRD.md)为准，接口和职责见[总体架构](../architecture/ARCHITECTURE.md)，具体命令、产物摘要、失败及环境限制见[验证索引](../validation/README.md)。

## 当前基线与状态口径

- 应用版本以根目录 [Cargo.toml](../../Cargo.toml) 的 `[workspace.package].version` 为准，尚未正式 release；Host/Rust/TS SDK 5.0.0、UI v4、ABI/wire 1，数据库 schema 10、应用偏好/模型注册格式 v2。
- 当前内置 Docker 与 AI 助手；外部 MySQL 为独立上传包。已移除模块列入下方范围表，不作为待恢复任务。
- “已实现”表示有真实调用链；“已有验证”仅指链接记录中的版本、平台和场景。旧测试数量、旧安装包或已移除功能的通过记录不证明当前完整版本已验收。
- 普通 Windows Debug EXE 已有构建记录；SDK5、Nginx 移除及 Docker 预授权后的完整安装器/跨平台/长期矩阵未完成。

## 阶段依赖与推进规则

主机/信任/凭据是 SSH 路由基础；SFTP、内部监控/运维和通用执行在独立租约上复用它。插件包/权限/owner 与平台原语先于业务插件，模型配置/修订和真实账号先于助手端到端验收。所有功能汇合后才能关闭当前发布门禁。

每阶段交付真实功能、修改文件、实际检查结果、未完成项、风险和下一阶段依赖；完成已授权阶段后停止，不自动启动表中后续工作。阶段验证更新对应报告，本表只更新状态、缺口和证据链接。
