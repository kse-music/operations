# 插件版本约定

| 契约                               | 当前版本 |
| ---------------------------------- | -------- |
| Host 语义 API / Rust SDK / Vue SDK | 5.6.0    |
| Manifest schema / sdplugin format  | 1        |
| WASM ABI / wire                    | 1        |
| UI                                 | 4        |

宿主按 manifest 的 `apiVersion` SemVer 范围及实际权限、包格式和 UI 契约校验插件。使用模型流和文本进度的包至少声明 `^5.4.0`，仅使用相应基础原语的包可以声明同主版本内适用的范围。不支持的主版本、权限、格式或 UI 明确拒绝，不通过兼容解码或自动迁移取得执行权。

SDK、源码 manifest、下载开发包、示例、两端类型、测试和说明须同步维护。破坏性公开接口变化提高 API 主版本；向后兼容的能力扩展提高次版本；修复提高补丁版本。WASM ABI、wire、包格式和 UI 分别按实际契约变化管理，不随产品版本机械改号。

业务 action/input/DTO 和插件自身版本由插件维护。新增业务优先使用现有通用原语，只有确有跨业务基础能力缺口才扩展平台，不为单个服务增加宿主特判。权限绑定当前安装修订，新能力须显式声明和授权，不向既有上传包补授权，来源不改变执行语义。本机文件选择与远程文件下载要求 API `^5.5.0`，独立文件传输预授权要求 API `^5.6.0`，具体契约见[公开 SDK](PLUGIN_SDK.md#文件与传输)。
