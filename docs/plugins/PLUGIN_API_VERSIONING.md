# 插件版本约定

| 协议                              | 当前版本 |
| --------------------------------- | -------- |
| Host语义API / Rust SDK / Vue SDK  | 5.4.0    |
| manifest schema / sdplugin format | 1        |
| WASM ABI / wire                   | 1        |
| UI                                | 4        |

使用新传输原语的包声明 `apiVersion: "^5.4.0"`；仅使用5.0原语的 `^5.0.0` 包仍在同主版本范围内。5.1增加owner绑定传输任务、文件读取确认和保存后复查；5.2增加审批模式绑定、独立读取预授权及同动作固定请求集合确认；5.3增加三种模式、严格argv读取参数和完全访问的可信宿主首次授权；5.3.1将Full策略改为会话内持续生效，request/assist撤销Full，request允许降权清理。5.4增加通用模型流与插件文本进度资源，在既有权限内实现助手增量回答，原模型完成请求保持；普通96次调用预算不变，模型轮询/进度发布另有1024次有界预算。新增permission/operation使用现有清单和授权记录字段，ABI/UI、包/record格式保持不变；不向旧上传包grant补入新权限，新能力包由旧Host按API范围拒绝。SDK5移除Docker/AI助手等领域能力、旧tools/server视图、私有Store和专属桥，统一显式hostId与平台原语、结构化action input、async续接和owner资源。属于破坏性主版本变化。

平台尚未release，不提供SDK4兼容层或自动迁移开发包。旧包会被API/权限/UI校验拒绝，须用配套SDK重新构建并提高插件自身版本；不重置用户数据或伪造旧包升级成功。源码manifest、SDK、下载开发包、测试与宿主同步更新。

新增业务在插件内部演进自己的action/input/DTO和版本，不改变平台API。只有跨业务可复用的基础能力确有缺口时才讨论平台扩展；不能为单个新服务添加SDK枚举或宿主分支。包来源不影响API语义或执行特权。
