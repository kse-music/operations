# 插件安全边界（SDK5）

## 授权与身份

上传包默认禁用/未授权；开发包安装确认、启用、权限授权、单次执行审批分别处理。授权绑定插件ID、版本、包摘要、安装修订、权限/operation及文件读写根。只能授予manifest声明的平台权限，未知业务权限直接拒绝。

系统来源只由宿主发行写入，预置声明权限；用户上传同ID不能自称system，也不继承授权。两者使用同样的平台请求、审批、fuel、owner、取消和目标验证，没有Docker/助手专用执行分支。当前没有密码学签名验证，作者/publisher/SHA256不能证明可信身份。

## 审批与目标

SSH命令默认须原生单次审批；仅当独立授予 `ssh.execute.preapproved` 权限及 operation，且 Execute 的完整程序、参数、超时与包内 `preapprovedCommands` 完全相同时，使用该安装版本的预授权。上传插件需核对权限页的完整命令并单独选择；该授权不代表宿主能判定任意命令只读。流启动和 PTY 可另行声明、授予 `ssh.interactive.preapproved` 权限及 operation，允许当前安装修订启动任意交互命令；不受固定命令清单限制，上传包默认不授予，仍需基础 SSH 权限及 operation。交互预授权不能代替 Execute 审批。文件保存、本机TCP连接始终单次审批。宿主从已验证的SSH租约取得实际username/host/port。普通审批展示冻结命令或文件路径/字节/摘要；提供易读说明且存在原生目标时，仅显示实际目标与业务说明，不展示命令或执行详情，但原生仍绑定完整请求。不相信Guest的目标标题、confirmed或风险声明，业务说明不证明命令安全。单次审批绑定完整请求/owner/安装代/VM代/SSH配置摘要，60秒、一次消费。所有执行路径保留配置复验、可见性、owner、配额和取消校验，变化明确拒绝；执行后的变化提示可能已发生操作，必须复查。

WASM审批保存原Future及请求，批准/拒绝原地续接。用户取消以USER_CANCELLED进入插件，支持保留部分报告与清理；生命周期关闭强制取消。模型消息由插件生成，models.use明确授权其外发；密钥仍在Native，插件负责业务脱敏和可读预览，平台不宣称能自动识别全部敏感数据。

## 资源隔离

文档、结果、上传片段、流、PTY票据、修订绑定及在途动作按插件/安装修订/VM代/页面owner隔离。终端票据单次、60秒，核验期待主机和原SSH配置；owner不能借用另一页票据。隐藏禁止新动作/审批并关闭流/PTY，关闭owner取消/排空自有工作；撤权、禁用、升级、卸载取消整个插件并汇总清理故障。

文件读写进行规范路径/授权根/真实目标复验，文本≤32KiB，保存检查原始摘要，使用已有原子编辑器和恢复路径。保存失败保留草稿；安全提交开始后排空，不用简单timeout丢弃写入Future冒称未写入。共享SSH连接和远端服务不因插件关闭而被强杀。

## 沙箱与数据

WASM没有WASI或原生导入，受线性内存/fuel/消息/并发限制。UI在无same-origin的受限iframe，包资源需摘要验证，认证MessageChannel绑定真实iframe；桥拒绝任意原生IPC和旧AI/系统业务API。公开资产DTO不含凭据/认证/代理/租约，模型Key和CLI登录数据不进入Guest。主机Key始终通过可信父页面显式核验。

输出、模型消息、通知、队列、结果池均有界，详见[SDK](PLUGIN_SDK.md)。记录错误码和安全原因，不记录密码/私钥/模型Key/敏感载荷。stdout/stderr超限标记截断，不能当成功；取消/断线无法保证远端程序绝未执行，不自动重试变更。

此机制不提供独立OS进程隔离，不抵御同用户进程改写仓库或运行时漏洞。Web UI没有CPU/内存硬限额，原生Windows之外的平台尚需单独验收。真实模型账号、远端工具版本/权限由部署环境决定。
