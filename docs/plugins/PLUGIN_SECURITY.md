# 插件安全边界

## UI v4 的页面隔离与原生能力

UI v4 执行摘要校验过的包内 JS/CSS，运行在 `sandbox="allow-scripts allow-forms"` iframe，不含 allow-same-origin。其来源为 null，不能读取父页面 DOM/Store、取得宿主连接或直接调用 Tauri。主页面仅允许 sdplugin 本地 frame，子页面 CSP 为 default-src none、connect-src none、frame-src none、object-src none、base-uri none、form-action none；脚本/样式只来自专用本地协议，样式允许 inline、图片仅 data。allow-forms 使 Vue preventDefault 表单事件可用，网络提交仍被 CSP 拒绝。Windows WebView 可能存在注入的 Tauri 全局对象，安全判断依据实际 IPC/来源校验和副作用拒绝，不能以对象是否存在作为保证。

资源协议只接受主 WebView 的 GET 和四段路径，绑定 id/revision/page，重新检查启用、授权、摘要，仅返回可信 HTML 壳及声明的 JS/CSS。响应 no-store/nosniff，最多八个并发文件读。包格式和文件配额保持。父桥验证 ready 消息来自实际 iframe.contentWindow、null origin 和协议版本，再分配专属 MessageChannel；后续绑定插件身份和安装代，不相信消息中自报 ID。每帧最多 32 在途、40 请求/秒、1 MiB 输入，SDK 180 秒超时、最多 64 事件回调，Host 最多 32 个连接状态监听（不降低原 32 个连接总限额），失败/关闭回收；原 WASM 消息/fuel/能力并发配额仍在下一层生效。

SDK 只能调用显式白名单能力，管理/授权/模型 Key 修改及任意 native command 不开放。主机目录不包含凭据表/私钥路径；凭据引用、连接租约、认证路由以 frame 专属不透明引用替代。可选择的业务资料和远端输出仍按已授权能力提供，不能宣称所有元数据都已脱敏。公共原生实现继续保管密钥、主机指纹和文件提交，插件业务不能绕过这些检查。

包内 UI 的 confirmed 或自述风险信息不构成批准。Host bridge 先冻结输入；Rust 从真实 AI 预览/命令、系统操作目标和严格类型输入生成宿主独立弹窗，必要时核对确认短语，再将单次票据送入 WASM。AI 资产匹配和发送分别显示实际外发阶段；敏感变更继续确认；自动运维、批量运维及本地文件分发票据已移除。剪贴板及下载只接受白名单且有界的数据。

UI v1 保持原表单，旧 v2/v3 通过兼容资源进入同一隔离框架。以下固定可信表单/无 JS 的描述只代表旧协议；当前 Host 桥仍是唯一批准边界。Web UI 没有独立 OS 进程、CPU/fuel 或内存硬上限，恶意页面仍可能消耗 WebView 资源；不能把浏览器隔离等同 WASM 执行配额。已验证 Windows WebView2 的父 DOM 和实际 host_create IPC 副作用拒绝，macOS/Linux 原生边界未验收。

## SDK 2.1 工具输入与任务边界

可信主窗口才能准备严格类型的工具输入；Guest 的 tool_invoke 只携带不透明票据和封闭操作。Host 校验插件、安装代、上下文代、权限/操作、精确操作、TTL 和单次消费，不能伪造确认、修改已确认载荷或借用其他插件输入。stage/cancel_request/abort_input 均仅向本地主窗口授予。输入大小/并发有界，错误不回显敏感载荷，未开放模型 Key 管理能力或任意原生 IPC。

AI 路由使用宿主生成的独立内部请求 ID，预览/建议以当前插件/上下文代登记。取消只能撤销自有请求根或精确输入，不能影响其他插件、后续请求或整个 VM。停止先撤销自有 AI/输入，再排空原有安全提交；业务结果仍逐次复验并使用有界分块。SSH、文件和 AI 命令沿用既有目标、风险、确认和真实错误链。

插件交互资源和明确提交给共享引擎的工作区别处理：禁用/卸载不删除或悄悄停止已提交网络诊断任务；任务中心独立提供停止，远端进程停止的不确定性仍需提示。不会失去卸载插件后的管理入口。

上传包默认拒绝。安装开发包、启用代码、授予能力、确认本次高风险操作是分别处理的状态；系统分发的三个包预置声明权限。发布者字符串和 SHA256 不是数字签名；当前包全部标为 local_development_unverified，没有可信发布者验证实现。

授权文件位于 `plugins/authorizations/<id>.json`，绑定 API 授权版本、插件 ID、包摘要、安装代 revision、插件版本/发布者、权限、具体操作类型和读写目录范围。只能授予 manifest 声明的权限。全部插件不再配置主机白名单，旧 hostIds 兼容读取但忽略，新输入可省略且输出不含该字段；远端能力必须有可信主界面选择的当前主机。上传包初始禁用/未授权，升级需重新授权。系统分发的三个包预置全部声明权限和所需目录，页面只读，grant/revoke IPC 拒绝改写；禁用和卸载继续可用。上传相同包或 ID 不自动授权。卸载删除授权，用户配置可按既有策略保留。

Rust 每次请求前后核验授权及上下文。ContextInput 中的现有运维/SFTP 租约只能由主窗口设置，必须属于所选主机，并匹配当前配置/认证 revision/路由。Guest 的 Request 没有身份、主机或 Session 字段，未知字段会拒绝。脱敏主机对象只有五个基本字段；SSH 密码、私钥路径/内容、凭据引用、API Key、Agent 句柄和内部 Session 均不传入 Guest。远程文件/命令输出可能包含远端配置的敏感信息；上传插件应只授予所需能力与最窄目录，不宣称可以自动判断所有远端秘密。

命令能力与本次执行独立。Host 以精确白名单判定少量只读命令，其他命令必须同时具备相应操作范围和一次性批准；写文件也独立批准。批准摘要覆盖安装代、上下文代及完整操作（包括命令/超时或文档/内容），60 秒有效，单次消费；改变主机、版本或载荷不能复用。SDK/Guest 没有批准接口，管理/批准 IPC 仅授予本地主窗口。等待确认返回明确错误码，不表示执行成功。主界面提示 60 秒有效期；确认过期或已失效时批准 IPC 返回 `PLUGIN_CONFIRMATION_EXPIRED`，提示重新点击原操作再次确认，保留当前草稿，不自动重试或延长批准。

远程文件同时检查原始与规范路径，父目录链接不能逃出授权目录。复用原有 SFTP 文本编辑器的普通文件、大小、UTF-8、摘要/属性冲突和原子替换校验。文档 token 包装成绑定本插件/上下文的随机句柄，不接受其他插件的 token。设置只能读写本插件 settings.json，不能访问授权文件或其他插件数据。

WASM 无 WASI/原生导入，Host 能力通过显式消息 yield/resume，不把 Session 放进 Store。普通 UI 输入只能 invoke，不能伪造专用 resume 消息。所有消息和并发有上限，权限拒绝与通知只写入有界内存事件列表，不记录命令正文、配置内容或秘密。13A-4 通过严格 JSON 和固定可信组件渲染，不执行包内 HTML/JS、不开放资源/导航地址、不向 Guest 提供 Tauri API；未知字段、原型键、未声明动作及超限消息拒绝。

取消令牌独立于 VM/IO 锁。停止先阻止新请求，再排空在途操作；命令取消会使用现有 TERM/Channel 关闭策略，已进入 SFTP 保存的操作安全收尾。后台任务/日志在上下文变更、禁用/升级/卸载时取消或关闭，正常任务历史留在既有任务中心。失败保留错误原因链和恢复信息，不回退到截断远程原文件。

限制：没有 OS 进程隔离、全进程内存硬上限或抢占式壁钟保障；没有数字签名验证；同用户恶意本地进程的 TOCTOU、解释器自身漏洞、远端拒绝停止的进程、服务器并发写入的最终竞态不被消除。SDK 文件限额 32 KiB，远端命令受 30 秒和输出配额限制。尚未执行 macOS/Linux 原生桌面验证。具体测试证据见 [PLUGIN_TEST_REPORT.md](../validation/plugins/PLUGIN_TEST_REPORT.md)，不能以已有代码代替这些保障的验收。

## SDK 1.1 服务器能力

内置系统包与上传包执行同一授权检查。system/manage 封闭请求、采样器、结构化日志和分块结果都绑定当前插件/上下文/安装代；停止时仅清理自有资源。文件日志额外校验 SFTP 权限和规范根。敏感环境、状态修改/信号和容器终端需要逐次批准，Guest 不能注入 confirmed。终端单次票据还绑定主机/容器/Shell/连接配置并限制 60 秒，仅可信主窗口可交接事件通道。上传同包不获得系统来源或权限。

超过 1 KiB 的结构化结果不进入 Guest JSON 负载，改用限额结果句柄，避免提高全体插件的执行预算。每结果最多 4 MiB、总 8 MiB、八项/每插件两项、TTL 60 秒；32 KiB 分块检查归属、范围和安装代，读取后释放。UI v2 只增加封闭声明，仍拒绝脚本、资源地址或动态组件。详情见 [内置标准插件](BUILTIN_PLUGINS.md)。
