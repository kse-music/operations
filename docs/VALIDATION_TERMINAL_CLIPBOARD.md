# 终端快捷复制粘贴验收（2026-11-02）

## 完成功能与修改范围

- 全局设置 → 终端显示与输入，新增“选中即复制，右键即粘贴”联动开关。新配置和缺少该字段的旧配置默认关闭，统一保存后对当前终端生效，切换设置 Tab 不丢失草稿。
- `apps/desktop/src/types/preferences.ts`、`crates/core/src/terminal.rs` 同步增加 `quickCopyPaste` / `quick_copy_paste` 布尔偏好，沿用版本 1 JSON 和现有 SQLite 设置存储，不需要数据库结构迁移。
- `apps/desktop/src/components/TerminalPane.vue`：监听 xterm 非空选区变化，开启后复制活动窗格选区；仅终端内容区域捕获右键按下及菜单事件，避免 xterm 同时选词或发送鼠标事件，复用原粘贴入口。全局原生菜单抑制不阻止此处理，工具栏和其他区域不触发快捷粘贴。
- 保留剪贴板安全错误提示、连接检查、2 MiB 单次上限、字符阈值/超过 50 行确认、取消不发送以及 Bracketed Paste 和有界队列。剪贴板读取绑定连接 generation，重连/卸载后不发送旧读取结果；重连时清除旧待确认粘贴。
- 新增终端组件回归及 Rust 持久化集成测试，补充设置页测试和浏览器布局检查；同步 PRD、架构和实施计划。保留工作区其他任务修改。

## 未验证、风险与依赖

本轮未运行真实 WebView2/系统剪贴板、SSH 或远端交互式程序端到端测试，也未执行 macOS/Linux 实机验收；组件边界测试与浏览器设置页检查不能替代这些验证。实际读写剪贴板仍依赖系统权限，失败会在终端中提示。没有绕过既有确认或宣称所有平台通过。无新增阶段依赖，本阶段完成，不开始后续功能。
