# 主机优先布局验证（2026-11-03）

## 本阶段交付

- 单侧栏整合主机工作区、主机树、全局工具及资产/设置；独立工具隐藏主机树，保留导航。整体收起后所有工作区均可展开，原宽度配置及键盘/拖动调整继续使用。
- 主机工具与 Shell 会话共用工具栏；会话标签独立横向滚动，保留菜单、改名、重排、关闭、复制及分屏。新建按钮复用现有会话创建入口。PTY 不因移动工具栏或收起文件面板重新挂载。
- Shell 中的可收起文件面板复用真实 FilesView/useFilesStore；按主机保留本次运行的开合状态和已有文件路径。完整文件页与面板互斥挂载，保持上传下载、文本编辑、目录操作、指纹与危险操作确认；收起不关闭连接/取消任务。
- 宽窗口左右排列，1100px 及以下上下排列。600px 高窗口压缩全局导航，必要时主机树独立滚动，筛选后的最后一台主机仍可到达。
- 未新增 IPC、依赖、数据库迁移或持久配置；已有连接仍使用实际端点，配置变化时提示并要求显式重连。

## 主要修改文件

- `apps/desktop/src/App.vue`：侧栏组合、稳定的会话工具栏容器、文件面板及主机上下文协调。
- `components/AppNavigation.vue`、`components/HostSidebar.vue`：合并导航与主机树；`views/TerminalsView.vue`：仅移动会话控件，不移动 PTY。
- `views/FilesView.vue`：compact 展示复用既有文件功能；`stores/workspace.ts`：每主机的运行内开合状态。
- `styles/main.css`、`product.css`、`hosts.css`、`terminal.css`、`files.css`：双列应用壳、紧凑工具栏及响应式文件面板。
- App、导航、主机树测试及 `views/files-panel.test.ts`；相关浏览器/原生 UI 验证工具。
- PRD、ARCHITECTURE、DECISIONS、IMPLEMENTATION_PLAN、USER_GUIDE 同步更新。

## 未验证、限制与已知风险

- 本轮未使用真实远端进行 SSH/SFTP 上传、下载及编辑端到端回归；未测试 macOS/Linux。已有后端实现保持复用，不据此宣称全平台或完整远端验收通过。
- 面板开合只在本次运行、当前主机导航标签内保留，不跨重启保存；文件连接/路径沿用现有 store。面板内不显示本地文件列和全部传输列表，分别从完整文件页、全局任务入口访问。
- 小高度窗口中，即使只有少量主机，分组标题与固定导航也可能使主机树需要滚动；已验证末项可见与操作入口可达。
- 全量格式检查的既有问题及 Monaco 包体提示未在本阶段扩大修复。
