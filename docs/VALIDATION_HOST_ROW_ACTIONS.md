# 主机行操作精简与悬停显示验收

日期：2026-11-02。范围为移除主机树复制操作，并将编辑和删除按钮改为按需显示。

## 已完成行为与主要文件

- `apps/desktop/src/components/HostTreeControls.vue`：移除复制按钮、图标导入和对应前端处理函数，仅保留编辑与确认删除。继续绑定对应主机，保存失败保留草稿，删除必须确认，取消及失败不丢失数据。
- `apps/desktop/src/styles/hosts.css`：操作区默认透明且禁止鼠标命中；悬停对应主机行时显示，移开后隐藏。键盘可见焦点进入行或操作按钮时也显示，支持 Tab 依次访问编辑和删除；普通选中状态不使按钮常驻。名称右侧预留空间由三个按钮缩为两个，显隐不改变名称位置。
- `components/host-tree-controls.test.ts`：将已移除的复制流程测试改为只暴露编辑/删除、无复制入口的目标断言，保留编辑、删除确认/取消、失败反馈和会话隔离测试。
- `tools/ui-layout-e2e.mjs`、`tools/native-ui-e2e.mjs`：增加真实样式、鼠标悬停/离开、非目标行隐藏、Tab 焦点及名称位置检查；调整原生流程为先悬停再编辑/删除，并更新移除复制后的记录数量和清理范围。
- 同步 PRD、架构及实施计划。本次不修改 Rust、IPC、数据库结构、权限或依赖，保留共享工作区中的已有修改。

显隐使用 `opacity` 与 `pointer-events` 配合 `:hover` / `:focus-visible`。初版使用 visibility，浏览器和原生检查发现焦点离开行进入操作按钮时可能跳过按钮；修正后保留 Tab 顺序，隐藏状态无法被鼠标点击，所有目标断言保持并通过。
