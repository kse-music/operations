# 原生功能验收

本文展开[发布检查表](RELEASE_CHECKLIST.md)的模块检查项和执行入口。每项针对同一候选产物、明确环境和已授权资源执行，未勾选项保持待验；脚本、协议夹具和浏览器检查不能代替安装产物的真实链路。

## 执行前提

使用复制后的 EXE、独立 QA 数据目录和测试凭据，保留候选提交与产物摘要。远程变更须明确测试主机和资源范围；不清理用户数据、不强杀正常应用。正常、加载、空、失败、取消及未知结果均应有目标行为断言。

## 桌面与主机

- [ ] 主机收藏：启动后确认“主机管理”标题下默认选中“全部”。通过星标收藏分组内的主机，折叠原分组后切换到“收藏”连接该主机，核验右键及键盘操作绑定同一主机。重启后核验收藏保留，取消收藏后确认主机从“收藏”移除且仍在原分组。

- [ ] 固定三栏：第一栏首页/本地终端/设置与第二栏始终可见，检查主机树、本地会话列表、设置分类和第三栏联动；覆盖切换后 SSH/本地会话与分屏不重建、草稿保留、保存/迁移时禁止离开、退出未保存保护、插件配置 owner 与活动状态，以及最小窗口/超大字号下滚动和操作可达。

- [ ] 首页工具启动台：针对候选 EXE 与安装产物，检查零主机添加引导、单主机名称、多主机选择及删除目标后的回落；列表未加载/读取失败不得冒充空目录。核对本地终端、新建/导入、SFTP、Docker、助手和模型绑定进入正确目标，渲染首页或切换目标不自动建立连接。覆盖插件缺失、禁用、当前版本授权不可用与读取失败/重试，保持原认证、安全确认和插件授权流程；检查深浅主题、中英文、最小窗口与超大字号，浏览器隔离测试不能代替真实连接和安装包验收。

- [ ] 一体化标题栏：针对候选 EXE 与安装产物，核验深色/浅色/系统主题、鼠标拖动、双击最大化/还原、边缘缩放、最小化及恢复、系统快捷键与贴靠行为；覆盖最小窗口、超大字号、显示缩放与多显示器。新关闭按钮和 Alt+F4 均须进入现有退出确认，取消保留连接/任务/草稿，确认后排空资源；独立编辑器与插件不获得主窗口控制权限。macOS/Linux 须独立验收，触控和笔输入未实测不得宣称通过。

- [ ] 浏览器默认右键菜单：针对候选 EXE 与安装产物，检查主窗口空白、输入框、设置页面、Docker/助手及上传插件 iframe、独立文本编辑窗口，覆盖 Shift+右键、键盘菜单键与页面重新加载；不得出现返回、刷新、另存为或打印菜单。主机、工作区标签、会话、终端、SFTP 和编辑器的业务菜单，以及键盘、选择与剪贴板操作保持可用。macOS/Linux 须分别验收。

- [ ] 主机树菜单：覆盖主机、文件夹和列表空白处之间的连续右键切换，验证“全部”和“收藏”的空白处都提供新建、统一导入和备份导出，空目录及搜索无结果时也可使用。验证导入对话框默认选中主机备份、可切换到 SSH 配置，取消备份文件选择后可继续操作。列表外空白与输入框再次右键关闭旧菜单；与 SFTP 两侧文件菜单切换时始终只显示新目标菜单，连接、创建及删除仍绑定新目标。验证键盘菜单键/Shift+F10、方向键、Esc 焦点恢复、滚动关闭和卸载监听清理。

- [ ] RSA 私钥：针对候选 EXE 与已授权服务器，验证原 OpenSSH RSA 私钥的文件选择、粘贴、加密口令、测试后保存及重新打开连接；核验取消私钥文件选择后主机表单与已有草稿保留，正常 Esc/关闭按钮及忙碌保护仍有效，取消 OpenSSH 导入文件选择也不关闭导入弹窗；覆盖 SHA-256/512、错误口令、未授权公钥和仅支持 SHA-1 的服务器拒绝。检查最终锁文件仍使用修复 RUSTSEC-2023-0071 的 RSA 版本，不能用协议夹具替代真实服务器及安装产物验收。

## 终端与上传

- [ ] Windows 管理员本地终端：普通权限启动宿主，右键本地会话列表空白处，分别选择“新建”和“新建(管理员)”。取消菜单不创建会话，侧栏无独立新建按钮，右键会话行只打开该行的操作菜单。分别核验宿主/普通 Shell 未提权和管理员 Shell 已提权。验收 UAC 取消及重试、分屏/复制/重连重新授权、输入/输出/resize/ACK、关闭单窗格与退出、主程序或代理意外结束时的进程回收；确认插件和其他窗口不能调用提权 IPC。须针对候选 EXE 与安装产物实测，自动化协议检查不代替 UAC 验收。

- [ ] SSH 会话保存与恢复。在两台主机上分别保存多个分屏，验证关闭工作区和重启后逐窗格恢复远端目录、可编辑的最近命令，手动回车执行一次、Ctrl+C 取消、目录失效留空、主机身份变更拒绝恢复。检查未支持的 Shell、系统凭据库不可用、失败重试，以及删除单项不影响其他主机或会话。
- [ ] Windows 手动保存本地会话：针对候选 EXE 与安装产物，分别使用右键“保存”和 Ctrl+S 保存多个目录及分屏，检查快捷键提示、行内改名、保存标记、行末关闭按钮、中英文窄侧栏和失败保留草稿。核验中文、空格、方括号等路径、再次保存只更新目标、普通新建/复制/新增分屏从主目录启动、之后改目录/布局或退出不会自动保存。重开时逐窗格验证可编辑的最近命令、Ctrl+C 取消、手动回车执行一次、历史过滤、失效目录回退及管理员窗格再次请求 UAC。重启只加载保存记录，首次进入时复用已有会话或新建普通 Shell；经右键菜单选择才恢复指定保存项。核验损坏及未来版本记录拒绝覆盖，旧自动目录不影响新建。
- [ ] 本地与 SSH 会话管理：核验关闭单项、最后一个窗格及关闭所有只结束对应 Shell，保存记录在关闭后、重进和重启仍可恢复；关闭失败保留相应标签和记录。检查从标签及会话栏空白处进入“已保存会话”，无打开标签时仍可使用；悬停及键盘展开、窄窗口位置和滚动、名称恢复和切换已有会话均可用。逐项验证右侧 × 直接删除、失败及重试；已运行会话保留输入输出、布局和名称并变为未保存。核对本地与各 SSH 主机的列表和操作范围。

- [ ] 终端二进制拖放：在候选 Release 验证普通用户、sudo/su 后的身份与当前目录，全部字节值、中文和空目录、同名文件/目录/链接拒绝、权限失败、SHA-256 失败；传输、校验和解包期间取消后终端设置恢复且可继续输入，提交边界保留已提交项目。确认文件载荷不经过前端或 Base64，协议及命令回显不进入终端显示，进度只按远端确认字节推进；断线、关闭、重连、无效帧及恢复失败不把旧二进制数据发送给 Shell 或新会话，其他窗格不受影响。通过 `node tools/terminal-drop-e2e.mjs --release --throughput` 验证真实 Linux PTY；还须用 Bash 4.2、GNU coreutils 8.22、tar 1.26 的旧 Shell 与工具组合验证正常上传、取消和写盘失败后的排空及终端恢复；同一入口同时验证生产 SSH 引擎到隔离 OpenSSH 的完整上传、校验及取消链路。可将 `SERVERDECK_TEST_DROP_TOOLS` 设置为隔离旧版命令目录、`SERVERDECK_TEST_DROP_SHELL` 设置为旧 Shell 启动器的 WSL 绝对路径（仅用于测试，不替换系统命令）。设置 `SERVERDECK_TEST_DROP_LARGE=1` 后以 `--release` 完整传输 5 GiB 单文件，确认准备不读取或复制载荷、分块累计摘要且远端校验一致；覆盖最后一块读取后源变化、零字节、特殊文件名及严格 umask。另核验多选仍保留归档结构与准备期间取消。以同一服务器、文件和磁盘实测终端与 SFTP 的数据阶段及多选归档/校验总耗时；隔离自动化不代替目标机器速度验收。

- [ ] 上传修改时间：针对候选 Release 核对终端单文件拖放、多选/目录拖放、rz 和 SFTP 上传，使用已知旧日期、空文件及中文名称，按 Unix 秒核对远端实际 mtime；覆盖上传仍保留原目标权限和属主，SFTP 目录合并不保证目录时间。覆盖 Bash 4.2/GNU coreutils 8.22、sudo/su、时区显示差异；设置时间失败或服务器忽略时间属性时保留原目标并安全恢复终端，不显示上传成功。已有错误日期不自动改写。

- [ ] SSH 与终端基础：真实密码、公钥、Agent、代理和跳板逐跳验证；拒绝变化密钥。验证多会话/分屏、重连重置、断开历史、独立连接不互扰、vim/top、Ctrl+C/Z、resize、原生剪贴板/大粘贴、快捷键改键及输入法冲突、HTTP/HTTPS 打开和无效协议拒绝。

- [ ] SSH 本地端口转发：在主机工作区添加规则并访问已授权测试主机的回环服务，核对返回内容、实际监听地址为 `127.0.0.1` 及活动连接数。覆盖端口冲突、不可达目标、首次指纹拒绝/信任、两台主机切换、关闭终端仍可转发、停止单条规则和断线后手动重试。核对关闭工作区、重新加载主窗口和退出后的端口释放；重新进入及重启后规则仍在且均为已停止，手动启动前无 SSH 转发会话或监听。移除规则、删除主机后重开确认对应规则已清理。候选 EXE 和安装版分别验证。

## 文件与传输

- [ ] SFTP 目录书签：在两台测试主机分别保存自定义名称，确认切换主机、关闭工作区和应用重启后的隔离与保留。选中书签验证路径、目录树和后退历史；切换 SFTP 用户后访问不可读目录，核对错误、原目录和书签均保留。用键盘打开、确认及 Esc 关闭，覆盖最小窗口和超大字号。移除书签后确认远端目录仍存在。

- [ ] SFTP 最近目录：在两台测试主机打开不同远程目录，关闭工作区后重新打开，再正常退出并重启，核验各自恢复最后成功打开的路径。验证尝试读取失败不覆盖记录、已删除或不可访问的目录回到 SFTP 默认目录、后台复制连接不覆盖记录，以及切换文件身份后重启仍以原登录用户权限读取路径。

- [ ] SFTP 两侧删除及菜单：核验本地删除菜单只显示“删除”，确认弹窗保留回收站提示；菜单打开后在界面任意位置右键关闭旧菜单，右键两侧文件或目录时替换为新目标菜单，始终只保留一个菜单且操作绑定新目标。在候选程序验证本地与远程列表的 Delete、多选、取消、失败及焦点栏隔离；路径输入删字、加载、拖动、弹窗和连发不触发删除。Windows 本地右键“删除”与 Delete 均须能在系统回收站找到并恢复文件、目录及中文/空格名称，链接不影响目标；回收站不可用、空间或权限不足时拒绝且不回退永久删除。远程仍为确认后的 SFTP 永久删除；切主机、目录或连接身份后不得误删新目标，未信任窗口不得调用本地回收 IPC。

- [ ] 文件页传输弹窗和计时：核验路径分行、全宽进度条、两列统计和窄屏单列、新任务自动弹出、多任务滚动、页头数量入口、× 或 Esc 收起后任务继续、“取消传输”取消当前弹窗任务并等待清理、部分取消失败可重试、轮询不重复弹出、全部结束自动收起及历史重试。覆盖主机隔离、确认后打开、上传/下载的已用时间、平均速度估算的剩余时间、排队及零速度、校验和失败状态；字节传完即显示校验中，校验、关闭句柄和提交不增加传输用时或改变平均速度，多文件任务恢复累计，未经校验提交不得计为完成；切换主机或工具不重置计时，历史记录固定最终传输用时。核验普通下载和 Windows 外拖均使用应用进度，描述符不请求系统复制进度，外拖暂存仍受活动任务和退出保护；针对候选程序在 Windows 验收实际桌面/资源管理器拖放、取消及最终文件结果。覆盖小时进位、窄窗口换行和中英文，不将数据传输预计时间当作校验及提交的倒计时。

- [ ] 文件页上传断点：用大文件分别断网、正常退出并重启。重新连接同一身份后选择原文件及目录，验证匹配断点自动续传且只写剩余内容；源文件变化时，确认从头上传会重写全部内容，取消则保留旧进度。核对最终 SHA-256、已存在目标的保护、源变化、链接替换和不同 SFTP 用户隔离。

- [ ] 传输吞吐：文件页使用 MiB/s，插件镜像传输使用 MB/s（十进制），比较时统一单位。在可控延迟和实际目标网络上比较串行与有界窗口上传、下载及中转，核对目标读回 SHA-256、动态长度文件、在途请求及提交前校验阶段取消、句柄关闭与暂存清理。针对 Release 候选产物，在同一主机、目录和大文件上分别测量千兆内网上传/下载，目标为数据传输阶段接近 100 MB/s，单独记录校验及整体耗时，并检查终端 ACK 背压。协议夹具的性能比值不能替代实际千兆链路、桌面中转路径和端点磁盘/CPU 测量。

- [ ] SFTP 与编辑保护：中文/空格/特殊名称、目录历史、隐藏项、排序及主机隔离；sudo 切用户成功/失败保留原连接且插件不继承；链接边界、冲突策略、源/目标变化、SHA-256、取消和清理恢复路径。内置与外部编辑核对 UTF-8/大小、原文冲突、权限/属主、缺少原子扩展只读、草稿和关闭保护、外部副本保留及明确回传。

## Docker

- [ ] Docker 日志生命周期：候选插件不再提供清空容器日志入口，旧 clear_logs 请求明确拒绝。日志弹窗提供本地「清屏」：清除后旧内容不因取消过滤而恢复，新日志继续接收，复制/导出仅含剩余可见内容；清屏不发起远端命令或改变暂停/错误状态。使用本机隔离 OpenSSH/Compose 夹具核对容器与 Compose 日志的实际输出及远端进程：窗口关闭/隐藏、页面关闭、SSH 会话/主机断开、应用正常退出均结束对应客户端，并保留其它共享 SSH 窗口；覆盖暂停、等待 ACK、消费者失败、并发关闭、取消关闭调用者、断开期间打开新流、服务端忽略 SSH signal、子进程忽略 TERM 和无法确认退出的提示。检查 GNU timeout 缺失时明确拒绝、单次 10 分钟时限及重新打开，不以回环协议或源码构建代替候选 EXE 验收。

- [ ] Docker 镜像远程传输：针对候选插件包与两个已授权测试主机，检查行内入口、目标选择排除来源、自动连接与指纹审核、空目标/同 ID/冲突确认、确认后标签变化拒绝，以及带标签/无标签的内容核对。覆盖经典存储与 containerd 存储间显示 ID 不同但配置及层一致的导入，以及内容不同拒绝、空默认配置字段差异、无标签目标实际 ID 解析、同一轮输出与失败事件、错误详情只通知一次。实测经本机中转、SHA-256、目标自动加载、MB/MB/s 与校验/加载/清理阶段；覆盖源打包失败、目标空间/权限不足、校验失败、取消、隐藏/关闭、断线及两端清理失败。确认无自动重试、不更新已有容器，错误保留两端恢复路径；界面与 Shell 夹具不能替代真实 SSH/SFTP/Docker 验收。

- [ ] 容器与 Compose：实际 daemon/权限失败、全局统计与缓存、概览/启动配置/变量的按需读取与清除、未转换项、敏感值、退出结果语义、单项及 exited 批量变更真实计数。覆盖 Compose V1.29.2 与 V2 的项目发现、已有服务/profile、只读配置、日志、整组启停/重启；入口缺失和业务失败不自动切换重试，不拉取/部署/删卷。验证本机镜像导入/导出的校验、同名风险、不覆盖下载、取消、隐藏及暂存清理。

## 助手与模型

- [ ] 通用运维智能体：针对候选产物及已授权测试主机，验证无 Skill 的跨工具新组合、Skill 摘要/正文/资源按需加载、按模式逐批授权和累计限额；核对真实命令、文件局部修改、镜像 save、普通 SHA-256 传输、load 与业务复查。覆盖跨主机目标、伪造资源引用、未知结果、取消/断线、撤权、句柄到期、清理失败后重试及不重放已完成步骤。命令退出码不能替代业务验收，单元模型夹具不能替代真实模型和原生链路。

- [ ] 智能体自动审批与后台：针对候选产物核对普通不覆盖传输、可信单标签归档到空目标的导入自动执行；删除、覆盖、未知来源/命令仍确认。切换至SFTP或其他工作区后保留命令流、归档及连续任务，高风险计划等待返回；关闭工作区、撤权、断线时取消并排空，未知结果不重放。

- [ ] 模型与流式：远程模型真实连接测试、凭证五分钟/单次/输入绑定、地址修改需新 Key 或清除、注册时间与搜索、本地 CLI 安装/登录/独立授权及取消。验证模型绑定保存失败恢复、真实 SSE/CLI 增量、跨片脱敏、断流、片段不可执行及不进入历史、迟到结果隔离、预算缩减和真实用量；分别验证 request/assist/full、退出 full 撤销、首次指纹和原文冲突不能绕过。

## 数据、退出与更新

- [ ] 按[数据升级契约](../architecture/DATA_MIGRATIONS.md)覆盖所有支持历史版本、跨版本、幂等重开、并发写锁、WAL、备份失败、中途失败/回滚重试、历史校验、未来/损坏格式拒绝与业务启动；安装升级保留主机、关联、偏好、指纹、秘密引用和插件数据。模型、会话及更新偏好故障按当前边界隔离。

- [ ] 数据目录迁移与退出：空目标、嵌套/链接/重解析点拒绝、空间不足、句柄占用、复制与清单/数据库校验失败、启动确认和逐项安全清理；系统凭据不复制。退出取消保留工作，确认等待提交/清理和所有受管资源结束，独立编辑器和安装/UAC 等待可诊断，重启不重放任务或丢失已保存数据。

- [ ] 软件更新：按[更新分发](UPDATES.md)检查同一候选版本的公开清单、版本固定下载地址、公钥及签名版本，实际从旧版安装升级；覆盖取消确认保留会话、下载中断/取消/重试、错误签名/错误版本拒绝、资源排空、重启与数据保留。GitHub Secret、草稿上传及国内目标网络下载须分别核对，未实测不得标为通过。

- [ ] Windows 图标刷新：在旧版 EXE、快捷方式和任务栏图标已缓存的环境，分别通过普通安装与应用内更新覆盖安装；确认新图标自动出现、原有固定项保留，覆盖中文和空格安装路径、已有自定义开始菜单目录及未创建快捷方式的情况。不得以钩子编译或通知调用成功代替目标机器的显示验收。

Windows 图标钩子的隔离回归入口为 `npm run test:installer-icons`；Tauri NSIS 工具不在默认位置时，通过 `npm run test:installer-icons -- <makensis.exe 绝对路径>` 指定。该回归检查实际 Shell 缓存事件、图标读取、数据保留、缺失快捷方式及关闭钩子的对照，但不代替候选安装器在目标机器上的视觉验收。

## 执行入口

桌面和系统凭据验收使用隔离目录；涉及远程变更的测试须先授权测试主机与资源范围。原生 E2E 使用复制的 EXE、测试进程专用 loopback 调试端口及独立凭据，普通应用不开放调试端口。

```powershell
npm run test:native
node tools/native-titlebar-e2e.mjs
npm run test:terminal-latency -- --profile
cargo test -p serverdeck-security -p serverdeck-application --lib --no-run --message-format=json
```

系统凭据测试须将 Cargo 输出中的测试 EXE 复制到隔离 QA 目录，再运行副本。安全模块副本分别以 `--ignored --exact tests::native_store_roundtrip_update_and_delete` 和 `--ignored --exact tests::native_store_large_secret_roundtrip` 验证旧单条条目及 2560/2561 字节等分块边界。应用模块副本以 `--ignored --exact hosts::native_tests::native_rsa_4096_save_reopen_and_authenticate` 验证 RSA 4096 的 OpenSSH、加密 OpenSSH 和 PKCS#1 PEM 输入，经真实系统凭据库保存、重开、回环 SSH 再认证及删除；此项需要 Windows OpenSSH 的 `ssh-keygen`，只转换自行生成的测试密钥。协议测试不替代候选桌面产物的文件选择、粘贴和已授权服务器验收。

本地终端延迟入口构建隔离的 Release EXE 并恢复根目录的正常构建配置，通过真实 WebView2、ConPTY 和带写出时间的 loopback HTTP 日志，比较 1/8/16 个空闲会话及 3/15 个后台输出会话。须检查全部前台日志标记到达、所有后台生产者实际输出并结束，以及隐藏焦点隔离、历史、切页和输入恢复。指标和可选 CPU 剖析保存在 `.local/qa/terminal-latency/`；剖析在延迟采样结束后执行。DOM 就绪及下一帧调度机会不是物理屏幕呈现时间，不替代 SSH、UAC、安装器或其他平台验收。复用历史 EXE 时仅接受该 QA 目录内的 `--exe` 副本。

SSH 测试从进程环境读取 `SERVERDECK_TEST_HOST`、`SERVERDECK_TEST_USER`、`SERVERDECK_TEST_PIN`、`SERVERDECK_TEST_PASSWORD`。PIN 通过带外渠道核对；密码通过隐藏输入仅放入本次进程环境，不进入命令行、文件或日志，使用后清除。先阅读测试入口的前置条件和实际操作，不能把只读检查视为对远端变更的授权。

| 范围                       | 入口                                  |
| -------------------------- | ------------------------------------- |
| SSH 真实终端               | `npm run test:terminal`               |
| 分屏、标签、路由与底层转发 | `npm run test:terminal -- --advanced` |
| SFTP、传输与编辑           | `npm run test:terminal -- --sftp`     |
| Docker 与宿主运维服务      | `npm run test:terminal -- --ops`      |
| 主机工作区与插件流程       | `npm run test:terminal -- --product`  |

测试入口在 `tools/`，插件和协议夹具在 `tests/fixtures/`；按用例检查实际覆盖范围，测试夹具不等同于真实模型账号或真实 Docker/外部服务。终端端到端输出位于 `.local/terminal-e2e/`，桌面验收位于 `.local/native-e2e/`。诊断输出须去敏，保留当前候选产物的必要证据。

## 安装版复验

将候选安装器装入专属 QA 目录。使用隔离且没有主机/凭据的测试配置，禁止清除实际用户数据来满足前置条件。以下占位路径替换为实际值：

```powershell
node tools/release-startup-bench.mjs <installed-serverdeck-desktop.exe> <artifact-directory>
node tools/native-terminal-e2e.mjs --release --installed-exe <installed-serverdeck-desktop.exe> --release-qa
```

安装版可组合 `--advanced`、`--sftp`、`--ops` 复验模块；`--exit-transfer` 检查传输中的确认退出。`--modules-only` 不算完整产品回归，短时脚本不能代替 24 小时稳定性门禁。确认退出后核对所有进程和资源释放，不把 kill 当正常退出。CI 生成候选产物不代替签名、可信发布或各平台原生验收。
