# ServerDeck 安全说明

本文说明当前实现的信任边界及发布前需要复核的风险，不构成独立安全审计结论。候选产物的检查要求见[发布检查表](RELEASE_CHECKLIST.md)。

## 主机身份与凭据

- SSH 首次连接须带外核对 SHA-256 指纹，跳板逐跳校验；已知密钥变化硬拒绝，不静默覆盖。系统 known_hosts 的哈希、CA、证书和撤销语义尚未接入。
- 密码、导入私钥、模型 Key 通过系统凭据库管理，SQLite 只存引用和修订。系统库不可用时明确失败，无明文降级。Rust 秘密使用 Zeroizing，前端临时输入提交/卸载清空，不承诺操作系统或 JavaScript 的所有副本绝对清零。
- 新秘密先写入新引用，SQLite 事务切换，提交后清理失去引用的秘密；失败保留可重试的清理意图。不自动删除其他主机仍在使用的凭据。
- 本地 RSA 私钥签名被禁用，优先使用 Ed25519/ECDSA；系统 Agent 的签名由其实现。路径型身份按实际权限读取，不放宽文件校验。

## 原生权限与命令

主窗口和独立编辑器分别使用受限 Tauri capability，编辑器仅能访问绑定文档。前端及插件没有任意本地 exec、通用 Shell 或凭据读取接口。用户主动选择的本地文件、目录浏览和下载通过专用业务 IPC 处理。

程序和参数按 POSIX 规则逐项引用，固定脚本中的动态值先校验，不执行 ProxyCommand，不自动 sudo、修改 sshd 或开启 Docker 明文 TCP API。HTTP CONNECT 代理本身没有 TLS，Basic 凭据只适合可信代理网络。端口转发默认回环，公共绑定须确认，并受服务端策略约束。

危险操作由可信宿主按冻结目标和完整请求授权，插件文字或模型自述不能批准操作。取消、超时和断线不保证远端进程未运行，未知结果需复查，不能自动重放变更。

## 文件与数据保护

Windows 管理员本地终端仅由主窗口显式发起并经过系统 UAC，不复用或保存批准结果，不向插件提供本地提权接口。专用 PTY 代理不初始化业务资源，双向进程身份校验、仅本机的私有命名管道、禁止管理员令牌模拟与进程 Job 约束通信和生命周期。管理员 Shell 可执行用户输入的高权限命令；关闭会话会回收受管进程，不能撤销已完成的系统变更。实现边界见[SSH 和终端](../architecture/ARCHITECTURE.md#ssh-和终端)。

SFTP 验证规范路径、真实权限和授权根，禁止删除根目录，递归不跟随符号链接。文件传输使用同目录临时文件、SHA-256 校验和受控提交；取消保留已提交内容，失败保留恢复路径。

文本保存检查原文摘要和属性，保留可验证的 mode/uid/gid，要求 OpenSSH 原子替换；失败不降级为截断原件。替换改变 inode，不保证 ACL、扩展属性和硬链接，SFTP v3 无服务端 CAS，仍存在最终检查至提交的竞态。外部编辑副本可能含敏感文件，结束后保留在本地，用户须按需要自行管理。

桌面 SFTP 切用户仅使用本次连接内存中的 sudo 密码，不落库、不自动继承到插件。终端拖放上传继承当前 Shell 的真实用户和目录，通过一次性本地授权、拒绝链接、私有暂存及校验提交控制范围。

数据库和持久配置分别管理版本。受支持版本先做包含 WAL 的一致备份，再事务升级；未知/未来版本、损坏内容或升级失败保留原件，不清库、不重置。升级不读取秘密或重新授权插件。备份、定位文件和数据目录拒绝不安全链接/重解析点，恢复或降级须正常退出后另行明确选择。完整规则见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

## 插件隔离与授权

独立 UI 运行于无 same-origin 的受限 iframe，认证 MessageChannel 绑定实际窗口，资源按安装修订和摘要校验。WASM 不使用 WASI/原生导入，限制线性内存、fuel、消息、时间、并发和结果池。插件不能直接访问父页面 Store、原生 IPC、认证材料或内部租约。

上传包默认禁用且未授权，授权绑定包摘要、版本、安装修订、权限和目录。system 来源只决定分发和预置授权，不能由上传包自称。撤权、停止、升级、卸载和关闭页面按所属 owner 取消资源；隐藏禁止新动作/审批并关闭流和 PTY，已开始的允许工作可安全收尾。

固定命令和交互会话预授权是独立能力，前者精确匹配完整命令，后者允许当前安装版本启动任意交互命令，均不能推断为只读。任务读取预授权只在对应模式和严格规则下生效。完全访问须宿主首次授权，当前会话内持续有效；切换模式、新建对话、关闭会话、撤权、停止或升级即撤销，不扩大基础权限、目录或目标范围。

当前插件包没有密码学签名验证，作者、publisher、SHA-256 都不能证明来源。iframe/WASM 不提供独立 OS 进程隔离，Web UI 没有 CPU/内存硬配额，也不能抵御同用户进程改写仓库。精确契约见[插件安全边界](../plugins/PLUGIN_SECURITY.md)和[公开 SDK](../plugins/PLUGIN_SDK.md)。

## 模型与 AI 运维

远程模型关键配置和 Key 变更须真实连接测试，凭证单次、五分钟且绑定输入与编辑身份。更改 API 地址须重新输入或明确清除原 Key；Key 和本地 CLI 登录材料不进入插件。HTTPS 保留证书验证，HTTP 需显式选择且会明文传输。

本地 Codex/Claude Code 来源分别授权，CLI 管理自身登录。平台通过临时会话、有界输入输出、进程取消及禁用工具/hooks/MCP 等参数收敛执行面，安装器只从固定官方源校验并原子安装，不改 PATH 或覆盖用户安装。

助手负责主机关联、数据选择、提示词、工具循环与脱敏。模型和远端输出均是不可信内容，严格参数与宿主授权约束真实目标；Markdown 不执行 HTML 或加载远程图片。流式片段先脱敏，完整结果校验前不能执行计划，中断片段不进入后续历史。自动脱敏不等于完整 DLP，也不能保证第三方服务不保留数据；使用者应审核发送内容并选择适当服务。

## 日志、依赖与发布

运行日志只记录操作类别、结果及安全原因，不记录密码、私钥、Key、终端/文件/模型正文。用户主动复制或导出的命令、配置、环境变量和日志可能含秘密，不能依赖自动脱敏。SQLite 不是加密保险库；卸载默认保留用户数据及系统凭据。

发布前必须重新审计锁定依赖，重点核对 RSA 相关通告、Linux GLib unsoundness 以及停止维护依赖的实际引入路径。禁用本地 RSA 签名只是缓解，不表示依赖风险已经消除；不同平台须分别评估，不通过忽略规则伪装通过。审计要求及签名、原生平台、长期稳定性和许可复核均见[发布检查表](RELEASE_CHECKLIST.md)。

应用没有自动更新组件；引入更新须先具备可信来源、签名验证和回滚保护。报告问题请提供最小复现、版本及去敏错误码，不公开密码、私钥或远端敏感输出。
