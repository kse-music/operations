# 安全边界与本次审计

## 2026-11-04 插件 UI v4

包内独立 JS/CSS 进入无 same-origin 权限的 sandbox iframe，通过公开 SDK/WASM 调用公共服务；主窗口不直接执行插件页面脚本。资源复验安装代、授权和摘要，子页面禁止网络/表单导航/原生 IPC。AI 外发、批量及自动化等敏感操作由宿主根据冻结输入和真实预览再次确认，旧版“发送后无需二次批准”不适用于 UI v4。Web UI 没有独立 OS/CPU/内存硬隔离，Windows 实测及跨平台限制见[插件安全边界](../plugins/PLUGIN_SECURITY.md)和[本次验证](../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-04插件源码归属与-ui-v4)。

模型注册先真实连接测试；配置或 Key 变更后须重测，保存由后端校验单次/五分钟的配置与 Key 摘要绑定凭证。测试消息固定且不含服务器数据，无工具、无建议执行；Key 只用于本次网络请求，保存前不写 OS 凭据库，摘要不写磁盘/日志。测试失败不能创建模型。

## 2026-11-05 插件模型绑定

内置助手的 modelId 保存在插件自己的设置中，API Key 仍只在系统凭据库。配置保存验证模型存在，绑定变更/解除撤销本插件旧票据、预览与命令建议；stage 与执行前复验持久绑定，无绑定或已删除模型不自动换用其他服务。新增的 settings.read/write 只访问本插件配置，不取得主应用设置或 Key。

## 2026-11-03 AI 辅助诊断补充

模型管理升级后，每个注册模型独立关联系统 Key，列表与助手无秘密读回。仅接受当前模型列表和设置字段，损坏内容不静默重置；编辑/删除需匹配版本，删除需确认。预览绑定模型 ID/版本，修改/删除撤销本模型的在途请求及旧审批，切换选择不允许沿用预览，删除当前模型不自动改用其他服务。

AI 不拥有工具调用权。按最新授权，全部已登记资产的最小目录默认关联，点击发送后脱敏上传，命中项包含实际连接端点；系统内置助手按用户授权默认读取命中主机的信息、即时指标、进程、Docker 和最近 100 行系统 journal，无右侧配置面板；读取失败明确标注，自动脱敏固定开启。没有发送/费用二次批准。当前会话最近六轮问题与回答会一同脱敏并携带，不回传执行输出；模型/授权/脱敏变化清空，同一资产会话的自动命中变化保留历史。远程提示注入只能成为不可信文本，不能授予权限；模型工具调用被拒绝，HTML 按文本展示、Markdown 只映射固定 Vue 节点，命令须匹配后端固定规则与当前连接的单次审批。受控变更另外输入命令专属确认语句，无自动批量执行、提权或重试。

主机匹配优先在本地完成；语义路由只接收最小脱敏目录和当前问题/上次命中 ID，不接收服务器日志、SSH 凭据/私钥路径或完整配置。资产名称、分组与模型输出均不可信；严格 schema、已登记 ID 校验和最多八台限制约束连接目标，模型不能提供新端点、连接参数、命令或工具调用。自动连接复用 SSH 认证与主机密钥验证，首次指纹必须人工核对，不绕过 changed-key 拒绝。准备/发送核验所有连接身份和模型版本，命中连接失败不进入诊断。多主机命令全部人工审阅，无自动分配或批量执行。取消只关闭本次新建的未完成连接，清理失败明确报告；已有有效运维连接保留。

AI Key 只存系统凭据库，普通配置不含 Key；更换服务地址须替换或清除 Key。HTTPS 保留证书验证，HTTP 需显式选择且会明文传输。自动脱敏不是完整 DLP，内置助手会按默认范围发送脱敏数据，用户应选择合适的模型服务并自行确认服务商数据政策；store=false 不能替第三方服务保证留存行为。细节、实际测试和限制见 [AI_ASSISTANT.md](../guides/AI_ASSISTANT.md)、[VALIDATION_AI_ASSISTANT.md](../validation/ai/VALIDATION_AI_ASSISTANT.md)。

版本：0.1.0-beta.1，2026-11-02。当前仅 Windows x64 + Ubuntu 24.04 实测。不是独立渗透测试或稳定版安全背书。

## 审计覆盖与可信边界

- **主机身份**：首次连接显示 SHA256 指纹，用户带外核对后才认证；已存密钥变化立即阻止，不允许确认覆盖；跳板每一跳均校验。没有默认接受、自动重连、自动导入系统信任或证书降级。证书/CA/撤销列表、hashed known_hosts 尚未实现。
- **认证与私钥**：支持密码、普通及加密 Ed25519/ECDSA 和外部 Agent。本机私钥导入限 1 MiB，阻塞线程校验格式、算法和口令。密钥经规范化后存入系统凭据库，口令仅用于导入时解锁，数据库只保存随机引用。旧式路径凭据继续按原权限读取文件。SSH 认证使用内存中的密钥并保留本地 RSA 拒绝策略，Rust 秘密输入和读取结果使用 Zeroizing。
- **凭据**：SQLite 只有元数据和不可回读引用；系统存储不可用时明确失败，无明文降级。更新使用新引用、事务切换和清理意图，可重试清理。Windows Credential Manager 真实回归；macOS Keychain/Linux Secret Service 尚未原生验收。
- **IPC**：仅本地 main 窗口的逐命令白名单；无远程 origin、无通用 shell 插件、无任意本地 exec。文件面板/上传具备受限业务 IPC；本地目录枚举和用户选择的上传源本就是应用权限，不能表述为没有任何本地文件访问。CSP 禁外站、frame/object/form，前端不渲染远端 HTML、不使用 v-html。
- **Shell**：系统采集/运维使用固定命令和校验参数；路径按 POSIX 引用，不执行 ProxyCommand。自动化脚本正文是用户明确授权的 Shell，参数单独经 stdin JSON 进入 positional argv，不插入模板；用户自己 eval/拼接仍有风险。禁止自动 sudo、改 sshd、默认 Docker 明文 TCP API。
- **插件任务模式**：请求批准逐次询问；帮我批准仅自动处理经授权的固定/严格参数化读取。完全访问须用户在可信宿主首次授权，当前会话内持续自动执行已有权限范围内的写入、删除、传输和命令，不设计时过期；不绕过目录、主机身份、原文/修订检查或资源限制，切换模式/新建对话/关闭会话/撤权/停止/升级时撤销，隐藏后返回保留；撤销清除旧Full句柄与待批准项，迟到批准不能恢复旧授权。普通页面及其他插件的原审批规则不变。
- **模型流与进度**：SDK5.4模型流绑定插件/owner/VM及模型修订，显示进度绑定原插件/owner/VM；有界通道与文本缓冲不落日志或数据库，关闭/撤权/停止会取消并等待收尾。助手在WASM增量提取及脱敏后发布可见文本，未完成片段不授予执行、不进历史；原模型/命令权限和审批不变。详见[流式契约](../plugins/PLUGIN_SDK.md#模型流与文本进度54)。
- **操作确认**：普通页面的 Docker 写操作、指定 PID 信号、systemd 写操作、递归删除、公共端口绑定及批量目标均明确确认；后端仍校验类型、会话/主机、目标、风险选项。超时/取消的远端进程状态 Unknown，不伪装为停止或成功。
- **SFTP**：根目录保护、组件/path 检查、不递归跟随符号链接；有界扫描、临时文件和校验提交，失败保留恢复路径。文本写入保留可验证的 mode/uid/gid，要求 OpenSSH posix-rename；ACL/xattr/hardlink/inode 不保证保留，需要确认。SFTP v3 无原子 CAS，外部写入窄竞争窗口仍存在。
- **日志与数据库**：运行日志仅类别/错误码，限长轮转；默认不录制 SSH、Docker/日志输出、密码或私钥口令。自动化秘密参数不持久化且禁输出采集；普通执行输出只有明确选择才限长保存。命令正文、普通参数、备注和用户主动导出的终端/日志可能包含用户自行输入的秘密，无法可靠自动脱敏。数据库非加密保险库。
- **代理与转发**：默认回环，暴露接口需确认；HTTP CONNECT 无代理 TLS，Basic 凭据仅适合可信代理网络；不宣称链路代理认证本身加密。单窗格关闭只回收其转发，Transport 引用计数独立。

## 数据保护、升级与报告

默认路径由 Tauri 用户目录提供，见应用诊断。当前 schema 10、偏好/模型注册 v2，已知旧版本先保存包含 WAL 的一致升级备份，再事务升级并验证；未知/未来版本或故障不清库、不重置，原数据及备份保留。备份和原数据同等保护，拒绝链接/重解析点，不包含系统凭据正文。主动目录迁移仍复制、校验并保留失败恢复路径。支持范围和恢复约束见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

卸载默认保留用户数据和系统凭据库条目，数据库保留原引用。应用内删除主机或模型时会尝试清理已无引用的秘密。清理失败会保留待清理记录，由后续相关保存或删除操作重试。

没有自动更新组件，没有未签名更新通道。未来引入更新前必须有签名、可信来源和回滚保护。发现安全问题时请私下提供最小复现、版本和已去敏错误码，不公开密码、私钥或远端敏感输出。
