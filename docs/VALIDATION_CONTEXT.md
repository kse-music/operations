# 主机上下文一致性验收

日期：2026-11-02。范围为本轮主机切换交互调整。

## 已完成的行为

1. 顶部是统一的当前主机入口，功能页签每模块一个，不追加主机名称。进入全局设置或切换功能不改变当前主机；主机列表单击仍可直接进入对应终端。
2. 文件、监控、运维、网络诊断跟随当前主机，移除重复主机选择器和 SFTP 跨主机连接页签。本地设备对应空 HostId，远程功能连接按钮禁用并提示从顶部选择，不回退到上次远程目标。
3. 终端子页签只展示当前主机的会话，默认显示“会话 N”，自定义名称保留。切回主机恢复最近会话，新建会话作用于当前主机，快捷键轮换及关闭其他/右侧只操作当前主机。
4. 切换保留其他主机连接、终端和文件传输。关闭当前主机最后一个终端不跳转到其他主机；关闭全部实际终端后保留欢迎页行为。
5. 窄窗口保留顶部主机入口。主机实际连接快照、配置变更提示、信任、危险操作与未保存文档保护沿用已有逻辑。

主要修改为 `App.vue`、`stores/workspace.ts`、`stores/terminals.ts`、`types/product.ts`、Files/Monitor/Operations/Network/Automation/TerminalsView、相关回归测试、`styles/product.css` 和 `styles/files.css`。同步架构、设计决策、实施计划及原生检查脚本；新增 `tools/ui-context-e2e.mjs`。本轮未修改 Rust、IPC、数据库或依赖，保留工作区原有其他修改。

## 未验证、风险与下一阶段依赖

真实远端 SSH/SFTP/监控/运维跨主机回归，以及 Linux/macOS 原生界面未在本轮执行；后端未改动，未重复执行 Rust 单元测试。不宣称支持全部平台。SFTP 传输保留依赖现有后台任务生命周期，浏览器测试仅断言连接状态没有被切换清除。

已知取舍是同一功能不再并排显示不同主机页签，需通过顶部或主机列表切换；其他主机的会话仍保留。批量/自动化的多目标预览与确认保留独立显式目标。没有重置用户配置、关闭现有窗口、安装或发布程序。

后续真实远端验收依赖隔离测试主机与授权凭据，其他平台验收依赖对应原生环境；本阶段结束后停止，不主动进入下一阶段。
