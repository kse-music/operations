# 根目录、多级文件夹和主机右键菜单验收

日期：2026-11-03。

## 本阶段功能

- 移除主机侧栏整条分组管理/刷新/新建工具栏，搜索框放到“全部主机”下方，导入/导出仍在该标题右侧。固定本地设备入口、统计和有界列表保留。
- 默认显示内置根目录，空目录加载成功后也可使用；旧未分组主机直接置于根目录，旧分组作为根下文件夹保留，支持持久化的多级子文件夹、展开/折叠、搜索祖先展示及主机拖动。
- 新建主机归属由右键文件夹决定，欢迎页新建默认归属根目录；新建/编辑表单移除分组选择，编辑原主机保留归属及历史字段。
- 根目录右键仅新建主机/文件夹，普通文件夹另有重命名和确认删除；主机右键提供连接/编辑/复制/确认删除，不出现新建文件夹。空白和本地设备没有创建文件夹入口，根目录不可删或重命名。
- 打开菜单不改变主机选择、连接和当前会话；复制在原文件夹生成独立配置，保留 SSH 参数和共享凭据引用，不自动连接。删除文件夹将直接子文件夹和主机提升到父目录，保留内容和连接。
- 菜单支持 Shift+F10/菜单键、方向键、Home/End、Esc/Tab 和焦点恢复，限制在窗口内，列表实际滚动、窗口失焦/缩放或模块隐藏时关闭。深层文件夹自动滚动后产生的延迟通知不会误关刚打开的菜单，已补充回归。
