# 主机列表操作入口调整验收

日期：2026-11-03。

## 本阶段功能与文件

移除主机栏三点入口、展开面板和排序设置，删除工具面板状态、排序类型/状态、地址/修改时间排序分支及专用样式。主机列表沿用原默认名称顺序，同名按 ID 保持稳定，不新增偏好或修改分组顺序。

按用户追加建议，将“全部主机”标题放到本地设备下方、远程主机列表正上方，右侧常驻“导入 OpenSSH”“导出配置”图标按钮，保留悬浮提示、可访问名称和键盘操作。标题及按钮不参与列表滚动，未加载或操作中禁用，已加载的空目录可用。继续复用原导入/导出事件、弹窗和 API，失败不伪装成功。

主要文件：`HostSidebar.vue`、`stores/hosts.ts`、`styles/hosts.css`、`styles/controls.css`、`host-tree.test.ts`、`hosts.test.ts`、`App.test.ts`；更新 `ui-navigation.mjs`、`ui-layout-e2e.mjs`、两个原生 E2E 脚本及需求、架构、决策、使用说明和实施计划。共享验收导航不再尝试打开删除的工具面板或点击静态“全部主机”标题。保留工作区其他任务的既有修改。
