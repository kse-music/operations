# ServerDeck 测试版使用说明

## 版本升级与自动备份

安装新版后，应用在启动业务前自动升级已支持的数据库和偏好配置。主机、分组、指纹、凭据引用及现有偏好保留；模型配置在首次使用时独立升级。升级前通过 SQLite 保存完整一致备份，包含 WAL 中的已提交数据；备份位于数据库旁的 `migration-backups/`，不会自动清理或覆盖。

遇到备份失败、未知/未来格式、损坏配置或升级错误时，程序或对应模型功能显示错误，不清库或重置。请保留原数据、已有 `.sqlite3` 升级备份和日志；`.partial` 是未完成备份，不能直接恢复。旧程序不能读取已升级的新库。恢复或降级前应正常退出，核对备份和升级后新增数据，再明确选择恢复方案，避免覆盖新数据。系统密码、私钥和 Key 仍由系统凭据库管理，数据库备份只包含引用。支持版本与限制见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

主窗口最小尺寸为 960×600 逻辑像素，默认 1280×820，并记住上次窗口尺寸和最大化状态。实际物理像素随系统缩放变化。较小窗口中的设置内容可在弹窗内滚动，保存、取消和关闭操作仍可访问。

## 数据目录与迁移（2026-11-05）

设置菜单现在为“通用、终端、快捷键、数据与存储、关于”。语言在通用；连接超时、Keepalive 和代理在终端；全局快捷键与终端快捷键集中在快捷键。每主机传输并发数和日志级别在数据与存储。

通用、终端、快捷键和数据与存储页的「恢复默认」只更新当前页的草稿，点击「保存设置」后记住。界面字号会实时预览。快捷键页会恢复终端与全局快捷键。数据与存储页会恢复下载、传输和日志偏好，并撤回尚未保存的数据目录变更。

在「设置 → 通用」可用「界面字号」滑杆在小、标准、大、特大、超大之间切换，也可以点击档位或用方向键。拖动时主界面立即预览，点击「保存设置」后重启仍沿用该档位。终端内容在「设置 → 终端」单独调整。

标准档的主要文字为 14px，辅助信息较小、标题较大。五档比例依次为 95%、100%、115%、130%、145%，主要文字对应 13.3、14、16.1、18.2、20.3px。内置插件同步调整；较大字号下 SFTP 需要更宽的窗口才能并排显示本地与远程列表。

打开“设置 → 数据与存储”可查看实际数据库、插件、日志和 WebView 路径，输入或选择新的空专用数据目录。点击“保存、迁移并重启”，核对源目录、目标、预计大小和任务提示；有未保存文档时先取消保存文档，或明确勾选放弃修改。确认后保存全部分类设置、安全结束任务并重启，复制校验通过且新目录启动成功后自动清理旧副本。

新安装 Windows 默认根目录为 `%APPDATA%/cn.hiboot.desktop`，数据库 serverdeck.sqlite3、插件 plugins、日志 logs、WebView 数据与缓存 webview 都归此目录。没有目录定位文件时，日志和 WebView 统一使用数据根目录下的 logs/webview；已有定位文件按其中的当前配置加载。应用安装目录不保存业务数据库。系统默认配置位置仍保留 storage-location.json 以找到新目录；不要删除该定位文件。密码、私钥秘密及 API Key 保留在系统凭据库，独立下载目录和已经下载的文件不搬迁。

迁移期间需要保留源副本和新副本的空间，并额外预留 16 MiB。链接、Junction、非空目标或新旧目录嵌套会被拒绝；同路径无需迁移。失败时按提示继续使用旧目录，失败暂存/候选副本保留供检查；新目录无法访问时会显示启动错误，不会悄悄创建空库。旧文件在复制后发生变化或清理失败时保留，使用新目录并提示下次重试。跨平台结果以实际验证记录为准。

## 运维工具与插件

终端窗格不显示底部操作栏和快捷键提示，也不提供同窗格手动重连、端口转发管理、按当前目录跳转 SFTP 或文本导出入口。断开后保留显示历史，可新建或复制普通会话重新连接；新会话不会恢复进程、重放输入或重跑文件/容器动作，一次性插件终端应从原插件重新打开。会话标签右键或 Shift+F10 可复制普通新 Shell、重命名、关闭或关闭该主机所有会话；内容区右键仍仅复制/粘贴。SFTP 从主机工具栏打开，查找和字号调整继续使用设置中的快捷键或 Ctrl+滚轮。

Docker 2.0.7 的版本检测、容器列表、镜像列表、容器详情、资源使用和环境变量使用固定命令预授权，打开、刷新列表及查看详情无需重复确认。环境变量仅在切换到对应标签时读取，离开标签或关闭详情后清除。日志和 Shell 点击直接打开；容器启动、停止、删除及镜像删除只需点击一次“确认/取消”，不再输入目标 ID。确认弹窗显示对象名称、实际主机及操作影响，不展示“执行详情”或命令脚本。内置插件自动配置所需权限；上传包需在插件权限页核对“预授权命令”并单独勾选“固定命令预授权”，直接打开日志和 Shell 还需单独授予“交互会话预授权”，两者均需 SSH 命令权限。交互会话授权允许当前安装版本启动任意流/终端命令，不保证只读；其他未预授权操作继续确认。

AI 运维助手已支持通过 SSH 查询主机、生成固定目标计划、在宿主确认后执行并复查。可提问“删除当前主机 tag 为 `<none>` 的 Docker 镜像”：先核对待删清单，点击审核，在宿主输入本次确认文字后才会删除；不会强制删除、删除卷或顺带清理父镜像。逐项结果区分成功复查、失败、未知和未执行。无需在主机安装常驻 Agent；完整范围、限制及停止行为见[AI 使用指南](AI_ASSISTANT.md#计划与执行)。下方较早的 AI 上下文布局和单条命令说明为历史行为。

系统服务插件已移除，没有独立资源监控、进程端口、systemd 或服务日志页面。可通过 SSH 或 AI 助手查询主机；AI 的系统变更继续在可信宿主确认后执行。Docker 日志和交互终端仍在当前容器弹窗中使用。

Docker 管理和 AI 运维助手为独立标准内置插件，总计两个。插件功能从当前主机 SSH/SFTP 右侧平铺的工具按钮进入，仅列已启用且有功能页面的插件，沿用当前主机。“设置 → 插件”负责安装、升级和卸载，列表可启停插件，点击插件名称或配置按钮在同一设置窗口查看配置与权限。功能页右上角的“插件设置”使用独立弹窗，关闭后保留原页面、筛选和滚动位置，不会重新查询 Docker 列表。

Nginx 内置插件已移除，新安装不再分发。已有安装和配置保留，可在“设置 → 插件”使用原有卸载流程。

独立 MySQL 巡检包位于 `D:/CodexProjects/op_plugins/mysql-inspector/dist/mysql-inspector-2.0.0.sdplugin`。在“设置 → 插件”上传后显式授予 `ui.contribute`、`hosts.read`、`ssh.execute` 及对应操作并启用，从当前主机工具栏进入。巡检调用插件自身 WASM 生成固定 SQL，通过现有 SSH 执行能力运行，命令需按宿主提示单独确认。目标服务器或容器中需已有 MySQL 客户端和只读账号登录配置；选择默认配置、登录路径或配置文件后手动采集七类巡检。插件不保存密码，不提供任意 SQL 输入，不自动修改数据库；单次输出超限明确失败。首版针对 MySQL 8.0.22+/8.4，实际验证版本及范围见[插件验证记录](../validation/plugins/PLUGIN_TEST_REPORT.md#2026-11-08-插件业务归属修正)。

任务中心已移除。SFTP 下仅展示当前主机的临时传输记录；切换工具、设置或其他主机时保留，关闭此主机成功后清空，再打开为空。若仍有未完成传输，关闭时会先确认，确认后取消并等待安全收尾，已完成文件保留；取消确认则继续传输。未保存文档须先处理，关闭失败时保留主机和记录。

在设置 → 模型 → 远程模型注册模型（默认打开此 Tab）；「本地来源」Tab 管理 Codex、Claude Code 的安装、状态与授权。填写远程连接后点击“测试连接”，通过后五分钟内保存。修改配置或 Key 需重测。测试发送固定消息，可能产生少量费用。在“上下文与输出”填写模型的上下文窗口及最大输出 Token。

## AI 运维助手

从主机打开的内置助手会在该主机标签未关闭时继续处理，切换到 SSH、SFTP、其他插件、设置或另一主机不会停止回答；返回即可查看结果和仍有效的计划。关闭所属主机标签会取消该页请求与计划，不影响其他主机。全局搜索打开的助手则随自己的标签关闭而停止。手动停止、模型修改、权限撤销及超时仍生效；后台不会启动新的执行审批，已确认的操作可继续执行和复查。此规则替代下方较早的内置助手切页释放说明，详见[后台处理规则](AI_ASSISTANT.md#页面生命周期)。

先在“设置 → 模型”注册模型，可查看、编辑、确认删除，每项独立使用系统凭据库保存 Key；旧单模型配置自动保留为“默认模型”。通过“设置 → 插件”列表中的配置按钮，或助手功能页“插件设置”的独立弹窗，选择并保存模型。点击当前主机右上角“AI 运维助手”开始聊天，支持连续追问和 Markdown 回答。Enter 发送，Shift + Enter 换行，也可停止或新建对话。

内置助手默认关联全部已登记主机，按问题自动匹配；入口主机仅作为“当前主机”线索。通过全局搜索打开助手时，可在问题中写名称、地址、分组等线索，助手匹配已登记主机并连接，连接失败显示具体主机和原因。同名需补充端口/用户名；首次 SSH 指纹仍需核对，完成后重新发送。右侧上下文面板已移除；命中主机的信息、即时指标、进程、Docker 与最近 100 行系统 journal 默认读取并脱敏，读取不可用时明确提示。匹配和发送无需弹窗确认。一次最多命中八台，多主机命令仅供人工审阅。单主机只读诊断仍须逐条批准，系统变更须独立输入确认语句，未知命令不能从助手执行。完整步骤、命令范围与限制见 [AI_ASSISTANT.md](AI_ASSISTANT.md)。

## 插件使用（2026-11-04）

先打开主机，再点击 SSH/SFTP 右侧的插件按钮，直接在这台主机的工作区使用，无需再选主机。切换到另一主机后，原主机的插件草稿和结果继续保留；切回原主机即可恢复。SSH/SFTP 切换同样保留插件页面。没有主机上下文时打开主机工具，由宿主统一提示选择一次。指纹核验、连接失败重试和主机配置改变后的显式重连仍需处理。

“设置 → 插件”集中安装、升级和卸载，列表展示图标、版本、描述、ID、来源与启停状态，可组合来源、状态和关键词筛选。点击右上角“安装插件”选择本地包，安装前须核对预览并确认；列表底部可下载插件开发包。禁用、未授权或无功能界面的包均保留在列表中。插件名称、卡片齿轮和功能页“插件设置”都在同一设置窗口打开详情，可切换配置和权限。点击“插件”返回列表时保留筛选；插件配置中的取消或保存也返回列表。关闭整个设置窗口回到原工作区并恢复入口焦点。插件保存、启停或授权期间不能关闭或切换分类。草稿为当前运行内状态，关闭设备工作区或全局工具页会处理未保存内容并释放页面，退出后不恢复。

AI 默认关联全部主机；从主机打开时，入口主机作为“当前主机”的匹配线索。

离开插件会停止该页面的交互请求和日志流，保留已读输出，返回后可重新读取；资源监控会重建采样。系统包随本次更新升级至 1.3.0，保留启停、配置与卸载记录，上传包不被自动覆盖。以下旧入口描述以本节为准。

## 安装与升级

Windows x64 安装包为 `ServerDeck_0.1.0-beta.1_x64-setup.exe`，当前用户安装，不要求管理员权限。需要 Windows 10/11 和 Microsoft WebView2；安装器在缺失时可能需联网下载官方运行时。当前包未做 Authenticode 签名，可能触发 Windows 信任提示；核对项目随包 SHA256，勿使用未知镜像。该校验只能发现文件损坏，不能替代发布者签名。

退出旧程序再安装。需要完整回滚时，在退出程序后备份整个用户数据目录，并保留系统凭据库。SQLite 当前 schema 为 9，新库直接初始化；其他版本明确拒绝且保留原文件，不执行开发期升级或降级。业务数据库位于应用数据目录。

应用标识已统一为 `cn.hiboot.desktop`，Windows 普通配置的数据目录为 `%APPDATA%/cn.hiboot.desktop`，上传插件位于其 `plugins/upload`。应用不会自动探测或迁移旧域名目录，也不读取、复制或删除旧域名下的系统凭据。当前密码、私钥和 Key 只使用当前系统凭据服务。

从系统应用列表卸载，默认保留数据和系统凭据库条目。删除相应主机或模型时，应用会尝试清理已无引用的秘密。清除数据前应备份数据库。

macOS Apple Silicon/Intel、Linux x64 暂无本轮可用安装包，仅准备 CI 配置；不宣称已构建、签名、公证或通过兼容性验证。

## 第一次连接

1. 新建主机，填写地址、端口和账号。选择 SSH 密码后直接填密码。选择“公钥认证（PublicKey）”后粘贴私钥内容或选择本机私钥文件，加密私钥需填写解锁口令。公钥部署在服务器，客户端使用对应私钥签名。保存后登录秘密位于系统凭据库。编辑已有主机时，保持原认证方式并留空即可沿用已保存的密码或密钥。
2. 按需展开 SSH 高级连接设置，配置超时、Keepalive、受管跳板或代理。全局默认值只影响新主机。
3. 点击“测试连接”。首次连接需要通过服务器控制台等可信渠道核对 SHA256 指纹，再选择“信任并继续测试”。测试通过后点击“保存主机”。修改表单或等待超过五分钟，需要重新测试。保存后可从主机树打开终端。
4. 同一主机的终端、文件、监控、运维共享上下文；工作区标签切换主机，主机工具栏按钮切换主机功能。编辑主机配置后已有连接仍代表旧端点，可关闭该主机工作区后重新打开。

编辑已有主机也须先点击“测试连接”。保持原认证方式并留空，可使用已保存的密码或私钥测试。当前修改通过 SSH 认证后即可保存，后续变动需要重新测试。

## 日常操作

### SFTP 切换用户

终端里执行 `sudo -i` 不会改变 SFTP 权限。在 SFTP 远程文件栏点击“切换用户”，目标默认 root；需要密码时输入当前 SSH 登录用户的 sudo 密码，免密 sudo 留空，点击“确认切换”。成功后远程标题显示所选用户；再次打开可勾选“切回原登录用户”。新连接验证失败时仍使用原连接。有传输或编辑文档时先结束传输、保存并关闭文档。

密码只在本次文件连接的内存中临时使用，断开/重启后需重新授权。找不到程序时填写远端 `sftp-server` 绝对路径，例如 `/usr/lib/openssh/sftp-server` 或 `/usr/libexec/openssh/sftp-server`。服务器必须允许非交互 sudo 运行 Shell 和该程序；仅 internal-sftp、requiretty 或 sudo 无授权时会拒绝，不自动修改服务器配置。插件不继承 sudo 身份，使用插件文件功能前先在文件页切回原登录用户；插件 SSH 命令不受此文件身份限制。

在 SSH 终端中先进入目标目录，再执行 `rz`。应用会自动打开本地文件选择窗口，选中文件后开始上传，可多选；上传进度和取消入口位于终端下方。取消选择会结束本次握手，Ctrl+C / Ctrl+X 或“取消上传”可停止传输；中途停止时远端可能保留部分文件，请按需自行检查。上传期间普通按键和粘贴暂停，结束后恢复。支持中文文件名、二进制及空文件，每批最多 100 个普通文件，单文件小于 4 GiB。同名文件处理由远端 rz 参数决定，跳过会单独计数；不会自动强制覆盖。该功能依附当前终端，关闭、重连或确认退出会停止传输。当前 `sz` 下载请改用 SFTP 文件页。

顶部提供侧栏开关和全局搜索。本地终端固定在主机树上方，不受主机搜索影响；主机标题旁显示总数，右侧加号可新建主机，列表独立滚动；底部只保留“设置”。也可从根目录或文件夹右键创建主机和文件夹。

本地终端、远程主机和全局插件功能共用一排工作区标签，插件管理不创建标签。切换主机时恢复该主机最近的工具、终端会话及插件页面。主机标签下方切换 SSH/SFTP/插件工具，终端会话在再下一行切换。标签可关闭或中键关闭，右键提供“关闭、关闭右侧、关闭其它、关闭所有”；范围按同一排标签的实际顺序计算。关闭主机仍会检查文件草稿及活动传输，并释放该主机的终端和插件资源；取消时保留工作区。

Ctrl+, 或侧栏底部“设置”打开统一设置窗口。分类依次为“通用、终端、快捷键、数据与存储、模型、插件、关于”，全局搜索和插件的模型设置入口也复用此窗口，不创建工作区标签。前四类共用草稿，切换到模型、插件或关于仍保留修改；“保存设置”统一保存这四类，校验失败会定位到对应分类和字段。关闭设置窗口时若有未保存更改，选择“继续编辑”保留草稿，选择“放弃更改并关闭”丢弃草稿；确认框中的 Esc 或关闭按钮继续保留草稿。保存或目录迁移期间不能关闭设置窗口。模型与插件配置独立保存。“关于”包含版本、技术栈与本地环境，可重新检查。设置窗口不会改变背后的活动主机和工具。

插件管理从“设置 → 插件”打开，直接点击插件列表项中的“启用”或“禁用”切换运行状态，禁用前会确认。点击插件名称或齿轮进入配置、权限和详情。启用不会自动授予上传插件权限，工具功能继续在主机工作区使用。插件与模型配置独立保存，安装和启停不会随通用设置的放弃更改而撤销。界面语言统一在“设置 → 通用”选择，当前只提供完整简体中文。

主机树默认显示“根目录”，旧未分组主机直接位于根目录，原分组作为根下文件夹保留。在根目录或文件夹上右键可新建主机和子文件夹；普通文件夹还可重命名和删除，文件夹名称不可与已有文件夹重名。删除前会确认，内容会移到父目录并保留。主机行不再显示编辑/删除图标，相关操作统一从右键菜单进入。主机上右键提供连接、编辑、复制和删除；复制在原文件夹生成独立副本，不会自动连接。新建主机表单不再选择分组，保存到右键所指文件夹；从欢迎页新建保存到根目录，移动可拖到目标文件夹。支持 Shift+F10/菜单键打开菜单，方向键选择，Esc/Tab 关闭，打开菜单不切换当前主机。

确认退出软件会结束全部 SSH 和本地终端会话，标签与分屏不跨重启恢复。下次进入本地终端或主机时只创建一个新会话，不再显示上次遗留的多个“未连接”标签。主机、分组、凭据和设置仍保留；取消退出则继续使用当前会话。

侧栏可以通过左上角按钮收起和展开。收起后保留窄图标栏，上方依次为主机列表和本地终端，下方仅保留设置，悬浮可查看名称。展开后搜索、分组和选择保持，现有会话继续运行。全局搜索通过右上角搜索入口或配置的快捷键打开。

### 终端、代理与端口转发

关闭顶部设备工作区标签时，会关闭该设备的全部终端会话和分屏；中键和右键关闭范围也遵循此规则，其他设备的会话不受影响。若有会话关闭失败，保留工作区并提示错误，可以重试。只要该设备仍有会话，新增编号继续递增；全部成功关闭后，再打开从“会话 1”开始。已有会话的编号和自定义名称保持不变。

终端会话标签位于内容上方，点击标签右侧的加号新建会话。标签可双击改名、拖动排序，也可用关闭按钮或中键关闭。主机功能从主机工具栏切换，终端内容区右键菜单仅提供复制和粘贴。默认 Ctrl+Shift+C/V 复制粘贴、Ctrl+Shift+F 查找，Ctrl+C/Z 发往远端。快捷键可在设置查看和修改。Windows 桌面端使用原生系统文本剪贴板，纯浏览器预览不提供原生剪贴板读写。大文本粘贴先确认，Bracketed Paste 依赖远端应用启用。重连总是新 Shell，不恢复旧远端程序。重启后不恢复标签或分屏，显式选择主机或本地终端时创建新会话。服务器 MaxSessions 会限制单条 SSH Transport 的 Channel 数，客户端不会修改 sshd 配置。

公钥认证支持 Ed25519/ECDSA 私钥，本地 RSA 私钥签名受现有安全策略限制。已有或经 OpenSSH Config 导入的 Agent 主机可继续使用系统 Agent，连接前需自行启动 Agent 并加载密钥。编辑时可沿用 Agent，或改用 SSH 密码、公钥认证。

主机编辑的高级设置支持认证超时、Keepalive、受管跳板和代理认证。代理需要认证时，可选择已有代理密码或点击“新建代理密码”。右键“根目录”，选择“导入 OpenSSH Config…”可导入常见字段、明确 Host 别名及受限 ProxyJump。重复主机跳过，复杂或不支持的配置会提示或阻止导入。HTTP CONNECT 仅支持 HTTP/1.x 和可选 Basic 认证，代理通道本身无 TLS。

终端的端口转发入口可显式启动/停止 Local、Remote 和 Dynamic 转发；默认绑定回环，公共绑定须确认，Remote 实际绑定受服务端策略约束。转发归属于窗格，关闭窗格或断线会清理，不自动恢复。

### SFTP 与远程编辑

Windows 的本地地址栏和「复制本地路径」使用常用盘符或网络共享路径。两栏的类型列紧跟大小列。点击列标题即可排序，再点同一列可切换升降序，箭头标出当前排序方向。

远程文件列表默认隐藏 `.env`、`.git` 等点开头的项目。点击远程工具栏的眼睛图标切换显示。再次关闭时，隐藏项会取消选中。

上传确认框里的本地源文件也使用常规路径。遇到同名文件，可选择停止并提示冲突、跳过或确认覆盖。

打开远程主机后，中央工具栏右侧并排提供 SSH 终端、SFTP 文件及各启用插件按钮。点击 SFTP 文件进入左本地右远程的完整文件页，其他主机页面也保留这组按钮，便于切换；终端右键文件入口同样打开完整文件页并沿用所选目录。终端旁的“文件面板”已移除。

完整文件页支持导航、排序、多选、属性、创建、改名、确认删除和文本编辑，上传可使用本地文件列、文件/目录选择按钮或拖放。切换工具或主机保留已有远程路径、SFTP 连接和后台传输；关闭设备工作区会关闭该设备的文件连接和全部终端会话，并清除临时传输记录；活动传输须先确认取消。传输进度与取消/重试在该主机的 SFTP 页查看。窄窗口下主机工具按钮自动换行。本地设备不显示远程插件按钮，新连接和危险操作继续沿用指纹或风险确认。

把鼠标移到本地或远程文件栏，按鼠标的后退或前进侧键即可切换该栏访问过的目录。远程历史按连接保留。

从远程列表拖到本地栏会预填左栏当前目录，确认传输后加入下载队列。选中指向普通文件的符号链接时，下载的是目标内容，保存名沿用链接名。删除远程项目每次都需确认。选中目录时，点击“确认删除”会一并删除其中的文件和子目录。

在 Windows 上，先让桌面或资源管理器的目标文件夹露出一部分。按住远程栏中的文件名，拖出 ServerDeck 窗口，在目标处松手即可下载。拖动已勾选的文件会下载整组选区。此入口支持普通文件和文件链接。下载目录可继续使用「下载选中」。

多文件和目录传输使用后台队列，默认每主机 3 个活动任务，可在设置调整为 1–6。任务显示进度、速度、剩余时间及取消/重试入口；冲突须选择处理策略。传输正常完成不弹出成功提示，完成后自动刷新目录；失败或临时文件清理异常仍会提示，进度与完成状态在当前主机的 SFTP 页临时展示。上传下载在提交前进行 SHA-256 校验，失败后从头重传，不支持断点续传或跨进程重启恢复。切换页面继续传输；关闭主机时须确认取消未完成传输，应用退出也保留未完成传输检查。

进行中的上传和下载显示在文件列表下方。活动任务全部结束后，文件列表恢复到可用高度。点击页头“传输记录”可查看已结束的任务，失败或取消的任务可从这里重试。

远程普通 UTF-8 文本最大 2 MiB，用 Monaco 编辑。保存检查外部变化，依赖 OpenSSH 原子替换并保留基础 owner/mode；缺少扩展、权限不足或冲突时拒绝保存。原子替换会改变 inode，不保证保留 ACL、扩展属性和硬链接关系，保存前须确认这一限制。有未保存内容时先保存或明确丢弃；网络故障留下的临时文件可按任务/编辑器提供的恢复路径处理。

文件可复制绝对路径，或经确认打开独立 Shell 或 less。从终端打开文件页时，可使用来源终端通过 OSC 7 报告的目录，进入后使用文件页手动导航。

### 服务器管理

Docker 管理和 AI 运维助手是两个独立标准插件，ID 使用 cn.hiboot.plugins 前缀。终端右上角 SFTP 文件右侧平铺的插件按钮只显示已启用且有功能页面的插件，点击在当前主机打开；所有插件均适用于所有已登记主机，无需配置允许主机。“设置 → 插件”保留全部安装名称，禁用项也可进入自己的设置启用，无功能页面的包只在此管理。内置插件预置全部声明权限、操作和必要目录，页面只读；新安装默认启用，已有禁用选择保留。上传插件仍需自行授予能力和目录权限。系统修改及写入仍逐次确认；内置 Docker Shell 点击直接进入弹窗终端，上传插件仍需单独批准。“设置 → 插件”支持选择本地包安装、升级和卸载；来源、启停和权限在各插件页内。上传内容位于应用数据目录 plugins/upload，旧配置与卸载选择保留。禁用不停止远端工作负载或已有终端。

Docker 页面及其日志弹窗使用当前主机的模块会话；权限不足不自动提权。Docker 默认使用远端 Unix Socket，不读取 Docker context 或启用明文 TCP API。删除镜像时只需在宿主弹窗核对主机和完整镜像 ID，点击“确认删除”，无需输入目标文字；取消或关闭不执行。其他状态修改保留完整目标确认；删除镜像和容器都不使用 force 或删除卷参数。

容器环境变量默认遮蔽，显式查看敏感详情和修改容器状态前须核对目标。系统服务、进程和端口信息可通过 AI 或 SSH 查询，AI 变更继续使用冻结目标计划和宿主确认。

在 Docker 行内点击“日志”查看该容器输出。日志使用弹窗，可暂停、过滤、复制和导出可见部分，最多保留 1 MiB / 5000 行；关闭弹窗、切换分类/主机或隐藏插件即停止对应流，不自动持久化日志。Docker 行内 Shell 直接打开交互式容器终端弹窗，不需要目标确认，也不切换主机 SSH 标签；关闭只释放该 PTY，不关闭主机连接。SFTP 的文件 Shell/less 快捷入口保持原流程。

系统服务、网络诊断、自动运维和批量运维插件已移除。SSH/SFTP、Docker 及 AI 的通用后端查询不受影响。旧插件和依赖被删标准系统界面的安装会归档停用，保留原包、配置和授权；第三方需升级为独立界面。

## 偏好与故障

设置可保存主题、终端、默认连接、Keepalive、采样、下载目录、传输并发、日志级别、代理和快捷键。日志级别重启生效；当前完整翻译只有简体中文。

默认 Ctrl+K 打开全局主机/模块/命令搜索，Ctrl+, 打开设置；可在设置修改。搜索主机、工作区和插件命令不自动执行远端操作。连接默认值仅影响新主机，不修改已有主机或在途连接；侧栏尺寸、窗口尺寸和最大化状态可保存。

配置、数据库和日志使用系统标准用户目录，实际路径显示在工作区；日志大小有界并轮转。关闭窗口前处理未完成传输、任务和未保存文件。若操作失败，保留错误码、任务 ID 和去敏日志；不要贴出密码、私钥或未遮蔽环境变量。

实现取舍见[技术决策](../architecture/DECISIONS.md)。测试版限制及验收结果见[测试报告](../validation/TEST_REPORT.md)、[安全说明](../release/SECURITY.md)和[发布检查表](../release/RELEASE_CHECKLIST.md)。

未使用的历史数据库附加内容原样保留，不加载、转换或执行，也不自动清空用户数据。
