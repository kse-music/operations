# ServerDeck 使用说明

## 安装与升级

Windows 安装包按当前用户安装，需要 WebView2。安装器名称中的版本以实际发布产物为准，安装包与校验文件由发布渠道提供，不随源码仓库分发。核对可信来源、发布者签名状态及 SHA-256；摘要不能代替身份验证。macOS/Linux 客户端须分别完成验收后再发布。

升级和卸载前正常退出应用，保留数据目录与系统凭据。卸载默认保留数据，不要选择删除数据来解决启动故障。

Windows x64 安装版可在“设置 → 关于 → 软件更新”检查和下载新版，分发源为 `kse-music/operations` 的 GitHub Releases。默认在启动后后台检查，每天最多尝试一次，可关闭“自动检查更新”；手动检查不受每日限制。发现新版时设置入口与“关于”显示提示点，点击设置入口直接进入关于页。检查失败会保留错误与重试入口，不表示已经是最新版本；自动检查失败不反复通知。发布方尚未发布更新清单时也会明确显示检查失败。

下载可取消，切换页面继续下载；下载完毕并通过签名与版本校验后，点击“安装并重启”，审核连接、任务和未保存内容后确认。取消确认保留原会话；确认后安全结束工作，再调用安装器。更新包仅保留在当前运行期内存中，普通退出后需重新下载。主机、设置、凭据引用和用户插件数据继续保留，启动后按现有规则升级数据。当前仅接入 Windows x64 正式版全量更新，其他平台显示限制；没有更新能力的旧客户端仍需手动安装一次新版本。GitHub 的实际可达性取决于用户网络，检查或下载失败时可稍后重试。

已支持的数据库和应用偏好在启动业务前自动升级，模型配置在首次使用时独立升级。升级先保存包含 WAL 已提交内容的一致备份，再事务修改；备份放在数据库旁 `migration-backups/`，不会覆盖或自动清理。备份失败、未知/未来格式或损坏内容会明确报错，不清库、不重置。保留原数据、完整 `.sqlite3` 备份和去敏日志；`.partial` 是未完成副本。恢复或降级需先正常退出，核对升级后新增数据，再明确选择恢复方案。数据库备份只有秘密引用，不能代替系统凭据库。支持范围见[数据升级契约](../architecture/DATA_MIGRATIONS.md)。

## 工作区与主机

启动显示欢迎页，只加载手动保存的本地会话列表，不启动终端或自动连接。工作台固定三栏：最左侧顶部为首页、本地终端，底部为设置；第二栏始终显示主机树、本地会话列表或设置分类，第三栏显示对应内容。欢迎页保留打开本地终端、新建主机、导入 SSH 配置入口及快速上手；新建主机也可右键目标文件夹。第二栏可拖动调宽，不提供收起。全局搜索默认 Ctrl+K，设置默认 Ctrl+,。

1. 在目标文件夹新建主机，填写地址、端口、用户名及密码或私钥。名称可不填，默认显示地址。私钥可粘贴或选择文件；加密私钥需解锁口令。
2. 点击“测试连接”。首次连接先通过可信渠道核对服务器指纹；密钥变化会阻断连接，不能直接覆盖。
3. 测试成功后五分钟内保存；修改连接或凭据后重新测试。编辑同一认证方式时，秘密留空沿用已有值。
4. 单击主机选中，双击、Enter/空格或右键“连接”打开工作区。使用顶部工具按钮切换 SSH、SFTP 和已启用插件。

主机和文件夹通过右键管理，可拖动移动。删除文件夹会把主机和直接子文件夹提升至父级，不递归删除；删除前需确认。主机只按名称、地址和用户名搜索。

欢迎页或右键根目录可预览导入 OpenSSH Config。点击“导入到”展开目录树，点击箭头展开或收起子目录，点击目录名称选定导入位置；根目录和空目录均可选择，选中后显示完整路径。键盘上下键移动、左右键展开收起或进入父子目录，Enter/空格选择，Esc 只关闭目录菜单。支持明确别名、常见连接字段及受限 ProxyJump；重复项跳过，不覆盖已有主机，不执行 ProxyCommand。复杂配置可能被拒绝，应按提示人工配置。代理与跳板在主机高级设置维护；HTTP CONNECT 代理通道本身不提供 TLS，Basic 凭据只应经过可信网络。

密码和私钥由系统凭据库管理，不可用时保存失败，不会写入明文替代。公钥认证支持 Ed25519/ECDSA/RSA，RSA 私钥可以直接粘贴或选择原文件，加密私钥填写解锁口令。RSA 认证要求服务器声明支持 SHA-256/512 签名；出现 `SSH_RSA_SHA2_REQUIRED` 时需升级服务器 SSH 或改用 Ed25519/ECDSA，不会回退 SHA-1。SSH Agent 需事先由用户启动并加载密钥。

关闭主机标签会审核未保存内容、编辑文档和未完成传输；取消则保留原工作，确认后等待安全收尾。切换工具、设置或其他主机不会关闭当前工作区。重启不恢复运行期会话和任务。

## SSH 与本地终端

Windows 本地终端中，点击第二栏的“新建会话”，选择“新建普通会话”或“以管理员身份运行”；Esc 或点击菜单外部可取消，不会创建会话。管理员选项在系统 UAC 中允许后打开带“管理员”标记的内嵌会话，仅该 Shell 及其专用代理提权，ServerDeck 保持原权限。第一栏“本地终端”和新建会话快捷键默认使用普通启动方式；SSH 和非 Windows 本地终端的加号直接新建普通会话。取消 UAC 不会创建普通终端，可从失败窗格重试。管理员会话分屏、复制、重连时会再次请求授权；关闭会话会结束对应 Shell 及受管子进程。系统授权窗口未响应时先选择允许或取消，再关闭会话或退出应用。

Windows 本地 PowerShell 中，先切换目录并回到提示符，再右键会话选择“重命名”（或双击名称、按 Ctrl+S），输入名称后点击“保存”，即可保存该会话及全部窗格的当前目录和分屏布局。取消弹窗不会保存。每个会话分别保存，多次保存更新同一条记录；之后切换目录或布局不会自动改写记录，需要再次打开弹窗保存。重启只加载已保存列表。进入本地终端时继续使用已打开的会话；尚无打开会话时自动启动第一个已保存会话，没有保存记录则首次进入时新建普通会话，其余保存条目点选后启动；普通新建、复制和新增分屏始终从用户主目录开始。已保存条目未运行时，也可通过同一弹窗只更新名称，不会因此启动 Shell。点击会话右侧的关闭按钮或菜单“关闭”会结束 Shell 并删除该条保存记录，下次启动不再出现；关闭最后一个分屏窗格也会删除对应记录。关闭全部会话后列表保持为空，不立即补建或启动其它会话。若删除失败，条目显示已结束并可再次关闭重试。直接退出应用仍保留已保存会话。保存目录不存在或不可访问时回到主目录，原记录保留；管理员会话仍须 UAC 授权。不恢复运行中的命令或终端内容，最多保存 32 个会话；自定义提示符、嵌套 Shell 的内部目录及 Linux/macOS 本地会话暂不保证可保存。

每台主机可新建多个会话、拖动排序、双击改名和水平/垂直分屏。会话标签右键或 Shift+F10 提供复制、重命名、重新连接、断开和关闭操作；复制创建普通新 Shell。重连仅对全部窗格均已结束的会话可用，保留标签与分屏，清空旧画面并创建新 Shell，不恢复远端进程或重放输入。断开后仍可查看和复制输出。

终端内容区右键仅提供复制/粘贴。默认 Ctrl+Shift+C/V 复制粘贴、Ctrl+Shift+F 查找，Ctrl+C/Z 发往远端；分屏、会话和字号快捷键可在设置查看修改。Ctrl+滚轮调整终端字号。大文本粘贴先确认，Bracketed Paste 仍依赖远端程序支持。

本地或 SSH 输出中的 HTTP/HTTPS 地址可左键打开本机默认浏览器，拖动仍可选择文字。SSH 输出里的 localhost/127.0.0.1 指向浏览器所在本机。

底部状态栏显示当前窗格的真实 SSH 加密算法或本地 Shell、光标行列、终端尺寸和仿真类型。CAP/NUM 表示本机锁定键，窗口失焦/重新聚焦后显示未知，收到键盘事件再同步；状态不代表远端操作系统。终端不提供转发管理或文本导出入口，SFTP 从主机工具栏进入。

### 上传到当前 Shell 目录

拖放及 rz 上传均保留源文件的“修改时间”，精度到秒；拖放文件夹也保留目录修改时间。传输按绝对时间处理，界面或 `ls` 根据所在系统时区显示。Linux `ls -l` 对较早文件通常显示年份，可用 `ls -l --full-time 文件名` 查看完整时间。源创建时间和 Unix ctime 不在保留范围；已经上传成错误时间的文件需要重新上传，不自动猜测修正。

把本地文件或文件夹拖入普通 Linux SSH 窗格，核对后确认上传。先回到空白 Shell 提示符，不要停留在 vim、top、运行中的命令或密码输入界面。目标和身份取当前 Shell；例如 sudo -i 后 cd 到目标目录，会使用该用户接收，不改变文件页的 SFTP 身份。弹窗优先显示当前账户名称，无法取得名称时显示 UID。

无需安装 rz，但服务器须有兼容的 sh、GNU tar/coreutils 等基础命令。保留目录结构、隐藏文件与空目录，拒绝链接、重解析点和特殊文件。同名项目停止，不覆盖或合并。进度弹窗显示准备、传输、校验、容量及远端已确认字节的平均速度；成功后关闭并恢复原窗格焦点，脚本和协议不显示在终端。

上传期间只隔离该窗格输入，可取消，其他终端继续工作。文件通过原终端的二进制通道由后台直接发送，保留 sudo/su 后的用户和当前目录，不进行 Base64 文件编码。单个文件不再预先复制或整文件计算校验值，检查属性后开始上传，校验值随读取计算；文件夹或多选仍需先打包到本地临时文件，大批量项目需等待准备并预留临时磁盘空间，打包期间可取消。取消会等待在途分块排空、接收进程停止及终端恢复后关闭弹窗。失败保留原因；提交失败可能已有部分项目完成。无法确认恢复时会结束该 SSH 会话并提示重新连接，应先核对已提交项目及恢复路径。字节传完后仍需远端校验，归档还需解包；不保证与 SFTP 同速，不支持断点续传或跨重启恢复。本地、容器及插件会话不接收此类拖放。

远端运行 rz 也可触发原生多文件选择，经当前 PTY 批量上传。选择期间仅显示系统文件选择器；选好文件并确认后，“终端文件上传”弹窗才显示所选文件及当前文件的容量、平均速度、剩余容量、已用时间和预计剩余数据传输时间，多文件依次更新当前文件统计。取消文件选择不会显示进度弹窗。点击“取消上传”、右上角关闭按钮或按 Esc 均取消上传，停止读取后等待在途批次与取消帧按序发送、本地文件授权释放，再关闭弹窗；完成后自动关闭并恢复原窗格焦点。发送超时或授权在写入期间失效会关闭原会话，请重新连接并核对远端文件；取消可能保留未完成的文件。目标说明为该主机的当前 Shell 目录，ZMODEM 不返回实际账户和目录。不提供 sz 下载，下载使用 SFTP。

## SFTP 文件与编辑

### 浏览和身份

从主机工具栏打开 SFTP，左本地右远程，窄窗口上下排列。两栏有独立目录历史、搜索、排序、多选、属性和右键操作；鼠标侧键作用于指针所在栏。隐藏文件可通过工具栏切换；隐藏后对应选区清除。

终端里的 su/sudo 不会改变独立 SFTP 用户。远程栏“切换用户”通过当前 SSH 账号的 sudo 权限启动目标用户的外部 sftp-server，默认 root，可切回登录用户；需要时输入本次 sudo 密码。新通道读取成功才替换旧连接，失败保留原连接。切换前处理传输和编辑文档，切换后从目标主目录或 `/` 开始。服务器须允许无 PTY sudo 和外部 sftp-server；不支持 requiretty 或仅 internal-sftp 的配置。sudo 密码不保存、不进入日志，插件也不继承该身份。

新建目录、重命名和删除遵守实际权限。删除需确认对象，确认目录删除会递归处理；不能删除根目录，不跟随目录内链接。

### 传输

SFTP 文件上传（含递归中的文件和确认覆盖）保留源文件修改时间，精度到秒，合并目录的时间不作保证。服务器无法保留时间时任务报错并保留原目标。覆盖仍保留目标权限和属主。

通过本地选择、文件/目录选择器或原生拖放上传；远程条目拖入本地栏可准备下载。Windows 可把远程普通文件或指向普通文件的链接拖到桌面/资源管理器；目录不支持窗口外拖放。显式下载文件链接时以链接名保存目标内容，递归扫描不跟随链接。

冲突处理可选停止、跳过或确认覆盖。任务后台运行，默认每主机三个活动任务，可设为 1–6；显示字节、速度、状态及取消/重试。先在目标同目录临时写入，校验 SHA-256 后提交。取消保留已提交文件，清理失败显示恢复路径；失败后从头重试，无断点续传或跨重启恢复。

单个文件自动使用分块流水线；设置里的并发数控制同时进行的任务数量。校验需要通过 SFTP 再读一遍远端文件，字节进度满后仍有网络和磁盘活动，等待任务完成后再使用目标文件。取消会等待在途请求结束并清理暂存。

任务同时显示“已用时间”和“预计剩余时间”。已用时间和平均速度只统计数据传输，不含排队、扫描、校验及提交。进度条满表示字节传完，接着显示“校验中”，此时速度和用时固定；多文件任务开始下一文件时继续累计。校验并提交成功后才算完成，记录中保留最终传输用时。预计剩余时间只估算数据传输，速度尚不可用时显示“估算中”，校验阶段显示“校验中”；该估算不包含后续校验和提交。

普通上传/下载会自动打开传输进度弹窗，同一主机的多个任务集中显示；文件与目标分行，速度、字节数和时间按列对齐。全部结束后自动关闭。右上角 X 或 Esc 取消弹窗内的当前任务，等待清理结束后收起；失败保留提示，可再次尝试。选择“后台传输”只隐藏弹窗，可从页头“传输任务（数量）”重新打开。页头“传输记录”查看及重试已结束任务。正常完成不弹成功通知，失败仍提示；切页保留任务，成功关闭主机后清除临时记录。

把远程文件拖到 Windows 桌面或资源管理器、拖入应用左侧本地文件栏或使用下载按钮时，统一使用应用自己的下载进度弹窗。外拖通过 Windows 虚拟文件机制交付内容，不请求系统复制进度窗口；应用内显示“拖放到的 Windows 文件夹”，不会显示内部暂存目录。外拖结果仍以最终系统文件复制是否成功为准，失败会报告原因。

### 内置文本编辑

远程 UTF-8 普通文本可在独立原生窗口编辑，上限 2 MiB，不支持 NUL。窗口可独立移动、缩放与最大化，一次编辑一个文件；提供保存、重新加载、查找、自动换行和状态栏。Ctrl+S（macOS 为 ⌘+S）直接按原子替换保存，无需再次勾选确认。

保存会核对原文摘要、大小、时间与基础权限/属主；冲突、缺少 OpenSSH 原子替换扩展或权限不足时拒绝写入并保留草稿。原子替换会改变 inode，不保证保留 ACL、扩展属性或硬链接关系；SFTP v3 无服务端 CAS，不能消除所有并发改写竞态。

关闭和重新加载审核未保存修改，可返回、保存后关闭或明确放弃；读取/保存中不能关闭。编辑器打开时，先关闭文档再断开所属连接、关闭主机、切换身份或迁移目录。断线保留草稿，主程序退出需明确处理未保存内容；不提供崩溃恢复或跨重启草稿。

### Windows 系统应用编辑

本地文件可用系统应用选择器打开。远程普通文件选择“使用系统应用编辑”后下载到独立本地副本，校验成功才交给系统应用；支持二进制和超过内置编辑上限的文件，不转换编码。外部保存后由用户明确确认回传，仍做原文冲突检测和原子替换，不自动上传。

外部编辑与内置编辑不能同时进行。结束、失败或退出均保留本地副本，结束时提示路径；不自动清理或恢复授权。关闭主机、身份切换和退出继续审核该编辑会话。其他平台可下载后自行打开，不承诺系统选择器集成。

## Docker 和插件

两个内置插件为 Docker 和 AI 运维助手。卸载后如需装回，在“设置 → 插件”点击“恢复内置插件”，选择对应插件并点击“恢复安装”，检查配置后启用。恢复使用应用自带的安装包，保留卸载时留下的配置；已清除的数据无法恢复，重启不会自动装回。已启用且具有功能页的插件出现在主机工具栏；“设置 → 插件”统一管理安装、升级、启停、配置、权限和卸载。功能页“插件设置”进入设置页面的插件分类，返回首页保留原业务页面、筛选和滚动。

内置插件预置声明权限和必要目录，权限只读展示；上传包默认禁用、未授权，需审核来源、权限及目录后启用。固定命令预授权和交互会话预授权分别授予，后者允许当前安装版本启动任意交互命令，不代表只读。包未提供密码学签名验证，作者字段和摘要不能证明来源。

Docker 提供容器、镜像和 Compose 项目列表、搜索、详情、资源、启动配置、环境变量、日志和容器 Shell。固定读取使用内置预授权，写操作由宿主确认真实主机、对象和影响，不自动提权或安装远端工具。

同一主机连接内，Docker 统计和访问过的列表会保留，切回页面直接显示已有内容；连接变化后重新读取。点击“刷新”或完成操作后更新数据，刷新期间保留原内容。服务器上通过其他工具修改 Docker 后，需手动刷新核对。设置中的插件列表、远程模型和本地 CLI 检测结果也会在本次运行中复用；外部修改插件目录或 CLI 登录、配置后，在对应页面点击“刷新”。

镜像行内点击「远程传输」，选择已保存的其它主机，再点「传输并导入」。目标已有指向其它镜像的同名标签时，会展示冲突及两端镜像 ID，点击「确认替换并传输」才继续。归档通过本机网络中转，无需两台服务器互通，本机不保存完整归档；两端均需当前 SSH 账号有 Docker、SFTP 权限及足够的 `/tmp` 空间。等待打包、中转、校验、自动导入与两端清理结束后，在目标主机镜像页核对结果。只保留所选标签，无标签按 ID 传输，不自动更新或重启已有容器。完成校验比较镜像平台、配置及文件层内容，两端显示 ID 不同不直接判为失败。错误详情在右下角通知中显示，弹窗保留失败状态并展开任务输出；Loaded image 表示 Docker 已加载，后续核对失败时镜像也可能已经存在。导入前目标标签发生变化会停止，需重新检查确认；取消和失败不回滚已加载镜像，按错误中的主机与暂存路径核对，不直接重复执行。

在「镜像」页点击「导入镜像」，选择本机由 `docker save` 生成的归档并点击「上传并导入」；点击后直接执行，等待上传校验及镜像加载完成，无需再次确认。同名标签可能替换，已有容器不会自动更新。镜像行内「导出」可选择本机保存目录并修改 `.tar` 文件名，等待服务器打包及下载校验，不覆盖已有文件。两者均显示 MB 进度与 MB/s 速度（两位小数）并可取消。字节进度满后会显示「正在校验并提交」，此时不再显示传输速度；导入随后显示 Docker 加载，结束前显示清理暂存。校验会通过 SFTP 回读远端文件，大归档仍需等待；点击后不再弹出传输或命令确认；大镜像需要服务器临时空间；取消不撤销已加载镜像，失败先刷新核对，断线后按提示检查远程暂存路径。

容器启动配置为只读 Compose YAML：Compose 容器读取当前项目配置，普通容器按 inspect 转换并列出未转换项。当前配置不一定等于创建时配置，也不保证独立部署。启动配置会显示环境变量值，离开或关闭清除；内联 secrets/configs 内容隐藏。详情标题和分类固定，内容独立滚动。

日志默认跟随最新输出，向上翻阅后保留阅读位置；“最新日志”或暂停后的“继续”恢复跟随。可过滤、复制和导出，缓存限 1 MiB/5000 行，关闭或隐藏释放流。Shell 弹窗支持查找、字号、清屏和最大化，显示操作不重建 PTY；断线保留输出，从原入口重新打开。

Compose 项目支持查看已有容器及项目日志，经一次确认整组启动、停止或重启；启动只启动已有容器，不拉取镜像或重新部署，不删除项目/数据卷。原始目录、配置或环境缺失会失败；超时后先刷新核对。

容器列表提供“重启已退出容器”和“清空容器日志”，范围是当前主机，不受搜索过滤影响。前者仅处理 exited，行内重启只作用于该容器；日志清理不可恢复，只截断当前 Docker 数据目录内的普通 json-file 当前日志，保留轮转文件，其他驱动跳过。操作可部分完成，不确定时核对实际状态，不自动重试。详细边界见[Docker 说明](../../plugins/system/docker/README.md)。

插件列表卡片底部以 `YYYY-MM-DD HH:mm:ss` 显示包的构建时间（北京时间），不显示文字前缀，旧包未提供时间时显示“未提供”。插件列表可下载独立开发包，开发和上传流程见[插件开发指南](../plugins/PLUGIN_DEVELOPMENT.md)。单插件安装记录故障会显示诊断并隔离，不影响其他插件；有可用内置包时可明确选择备份并重装，重新安装默认禁用且不继承旧授权。

## AI 运维助手

先在“设置 → 模型”准备远程模型或本地 Codex/Claude Code CLI，再到助手插件配置选择已就绪模型，选中后立即保存绑定；保存失败时恢复原选项并提示，可重新选择重试。远程模型新建或关键配置/Key 变更须通过真实连接测试，五分钟内保存；Key 不回显，修改 API 地址时须重新输入或明确清除原 Key。本地CLI的安装、登录和访问授权分别处理，不自动导入登录秘密。

从主机工具栏或全局搜索打开助手。输入问题后按 Enter 发送，Shift+Enter 换行，可停止、追问和新建对话。助手匹配登记主机，查询所需证据，脱敏后发给选定模型，并逐步显示真实回答。首次 SSH 指纹仍需人工核对。

输入区有“请求批准”“帮我批准”“完全访问权限”三种模式，默认为请求批准。完全访问需宿主首次授权，当前会话持续生效，切换模式、新建对话或关闭会话即撤销；任何模式都不能增加基础权限或绕过目标复验。

助手可生成固定 Docker/systemd 计划、预览并保存不超过 32 KiB 的远程文本局部修改，以及本机上传/服务器间中转单个普通文件。计划固定目标与参数，执行后复查；失败或结果未知不自动重试，取消不等于远端操作未发生。

切换工具、设置或其他主机时已开始的工作可后台收尾，隐藏页不发起新问题或审批；关闭所属工作区会取消自有任务。任务和对话不跨重启恢复。详见[AI 助手指南](AI_ASSISTANT.md)。

## 设置、数据与故障

设置包含通用、终端、快捷键、数据与存储、模型、插件、关于。通用、终端、快捷键、数据与存储的普通设置修改后自动保存，无需点击保存；连续输入会合并提交，恢复默认也自动保存当前分类。无效输入不会保存，保存失败保留修改并提示，可点击“重试”或修改后重试。下载目录、传输并发和日志级别也自动保存；数据根目录变更仍需确认迁移和重启，不因其他设置保存而搬迁。关闭设置会先保存有效偏好，剩余未保存内容仍需明确处理；放弃关闭才撤回未保存预览。模型和插件独立保存。保存、迁移或插件操作中不能关闭或切走。

语言支持简体中文和 English，保存后桌面及内置插件立即生效，不重建连接；独立编辑器下次打开采用新偏好。主题和五档字号可调整，终端内容字号独立。主窗口最小为 960×600，默认 1280×820，记住窗口尺寸与最大化状态。

“数据与存储”显示实际数据库、插件、日志和 WebView 路径。Windows 默认数据根为 `%APPDATA%/cn.hiboot.desktop`。定位文件 `storage-location.json` 保留在默认配置位置，不要删除；密码、私钥和 API Key 在系统凭据库，独立下载目录不随数据根搬迁。

更改数据根时选择空的专用目录，点击“迁移并重启”，核对源、目标、空间与任务提示。确认后窗口保持处理中并正常退出，重启期间复制和校验，新目录启动确认后才安全清理已核对的源文件。窗口关闭不代表完成，以新进程的实际路径和结果为准。迁移结果留在设置页，本次新结果才弹通知。

需要新旧副本空间及额外 16 MiB，拒绝链接/Junction、嵌套和非空目标。持续占用、复制或校验失败保留数据和诊断副本，不悄悄创建空库；正常退出后可换空目录重试，不删除旧数据或定位文件。

关闭主程序会审核任务和未保存内容，确认后安全结束资源，不提供托盘常驻。错误以可复制通知显示，日志有界轮转，不记录密码、私钥、Key 或私密正文。故障排查只提供错误码、任务 ID 和去敏日志，不公开环境变量、秘密或原始模型载荷。安全边界见[安全说明](../release/SECURITY.md)。
