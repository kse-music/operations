# ServerDeck 测试版使用说明

## 运维工具与插件

顶部“运维工具”统一列出已安装插件，原独立业务工具入口已合并。AI 助手、批量运维、自动运维、网络诊断也已成为独立标准内置插件，总计九个；终端右上角“工具”仅列启用项。设置 → 插件管理负责拖放安装和卸载，来源、启停及权限在插件自己的设置中。批量/自动化/网络标签切换保留内存草稿，关闭标签后不保留草稿。

点击底部状态栏“任务中心”以弹窗查看文件传输、网络/批量任务及自动化状态，不切换当前页面。停用或卸载插件不删除已经提交的工作或计划；在任务中心可请求停止任务、暂停计划。关闭弹窗或按 Esc 不停止任务，查看结果或重试传输时进入对应工具。请求停止在途远端命令后仍应核对服务器实际状态。AI 继续使用资产管理中的已注册模型、原有上下文授权和逐条命令审核。

模型注册：资产管理 → 模型管理，填写连接后点击“测试连接”，通过后五分钟内保存；修改配置或 Key 需重测。测试仅发送固定消息，可能产生少量费用，不包含服务器数据。输出上限与价格在表单“输出与费用估算”中设置。

## AI 运维助手

先在“资产管理 → 模型管理”注册模型，可查看、编辑、确认删除，每项独立使用系统凭据库保存 Key；旧单模型配置自动保留为“默认模型”。再进入“运维工具 → AI 运维助手”，选择已注册模型后直接聊天，支持连续追问和 Markdown 回答，没有发送预览或费用批准。Enter 发送，Shift + Enter 换行；可停止或新建对话。

所有已登记主机默认关联，无需选择主机；在问题中写名称、地址、分组等线索，助手自动匹配并连接相关主机，连接失败显示具体主机和原因。同名需补充端口/用户名；首次 SSH 指纹仍需核对，完成后重新发送。详细监控、进程、Docker、日志按右侧授权读取，不会因关联全部主机而自动读取全部内容。一次最多命中八台，多主机命令仅供人工审阅。单主机只读诊断仍须逐条批准，系统变更须独立输入确认语句，未知命令不能从助手执行。完整步骤、命令范围与限制见 [AI_ASSISTANT.md](AI_ASSISTANT.md)。

## 安装与升级

Windows x64 安装包为 `ServerDeck_0.1.0-beta.1_x64-setup.exe`，当前用户安装，不要求管理员权限。需要 Windows 10/11 和 Microsoft WebView2；安装器在缺失时可能需联网下载官方运行时。当前包未做 Authenticode 签名，可能触发 Windows 信任提示；核对项目随包 SHA256，勿使用未知镜像。该校验只能发现文件损坏，不能替代发布者签名。

退出旧程序再安装。先导出非敏感备份；需要完整回滚时，在退出程序后备份整个用户数据目录，并保留系统凭据库。SQLite 旧版按事务迁移到 schema 7，不支持旧程序直接打开新 schema。失败不会自动清库。安装目录不保存业务数据库。

应用标识已统一为 `cn.hiboot.desktop`，Windows 普通配置的数据目录为 `%APPDATA%/cn.hiboot.desktop`，上传插件位于其 `plugins/upload`。新版首次启动会在打开数据库与 WebView 前将默认旧目录改名迁移；已有新目录包含数据时使用新目录，不覆盖或自动合并旧目录。自定义/测试目录不参与迁移。系统凭据按原引用兼容读取并转存到新服务，不需要重新填写密码；旧条目保留到用户明确删除。请先退出旧版再启动新版，迁移后不要继续运行旧版。

从系统应用列表卸载，默认保留数据；不要选择清除数据，除非已完成备份并确认不再使用。系统凭据库秘密需要先在应用内删除，否则移走数据库后无法再通过引用管理残留条目。

macOS Apple Silicon/Intel、Linux x64 暂无本轮可用安装包，仅准备 CI 配置；不宣称已构建、签名、公证或通过兼容性验证。

## 第一次连接

1. 在凭据管理创建密码引用或私钥路径及解锁口令；Agent 认证须自行启动系统 Agent 并加载密钥。安全存储不可用时先解决系统服务，不存在明文保存选项。
2. 新建主机，填地址、端口、账号和凭据引用；可设置超时、Keepalive、受管跳板和代理。全局默认值只影响新主机。主机管理不再提供标签、备注和收藏，搜索支持名称、地址和用户名；历史字段保留以兼容旧数据和备份。
3. 打开终端，通过服务器控制台等可信渠道核对 SHA256 指纹再确认。变化密钥会被阻止，先核查服务器身份。
4. 同一主机的终端、文件、监控、运维共享上下文；工作区标签切换主机，中央工具栏右侧菜单切换主机功能，实际连接端点可从终端操作菜单或文件连接状态查看。编辑主机配置后已有连接仍代表旧端点，需显式断开并重新打开对应模块。

## 日常操作

在 SSH 终端中先进入目标目录，再执行 `rz`。应用会自动打开本地文件选择窗口，选中文件后开始上传，可多选；上传进度和取消入口位于终端下方。取消选择会结束本次握手，Ctrl+C / Ctrl+X 或“取消上传”可停止传输；中途停止时远端可能保留部分文件，请按需自行检查。上传期间普通按键和粘贴暂停，结束后恢复。支持中文文件名、二进制及空文件，每批最多 100 个普通文件，单文件小于 4 GiB。同名文件处理由远端 rz 参数决定，跳过会单独计数；不会自动强制覆盖。该功能依附当前终端，关闭、重连或确认退出会停止传输。当前 `sz` 下载请改用 SFTP 文件页。

顶部切换五个大模块：主机运维、运维工具、资产管理、插件、设置，其中“设置”位于顶栏最右侧。左侧只显示当前模块里的菜单，主机树位于主机运维侧栏，SSH/SFTP/服务器管理入口位于中央主机工具栏右侧；运维工具列出已安装插件，任务中心位于底部状态栏，凭据与备份属于资产管理。“设置”菜单依次为“通用、终端、快捷键、工作区与连接、插件管理、关于”，各分类直接打开工作区标签，重复点击复用已有标签；Ctrl+, 打开通用。分类共用草稿，切换菜单、标签或其他页面不会丢失未保存修改，“保存设置”统一保存全部分类；校验失败会自动定位到对应菜单及字段，关闭全部设置分类标签后放弃未保存草稿。“关于”合并展示产品说明、版本、技术栈与本地环境（后端状态、数据库版本和数据/日志目录），可重新检查，无独立本地环境菜单。切换或关闭关于页不影响终端连接与后台任务。工具的执行目标仍需在工具内部明确选择。

“插件”模块只列已安装插件，插件管理位于设置，插件自身页面提供来源和权限设置；打开插件标签时同步选中插件模块，切换顶部模块保留当前页面和连接。界面语言统一在“设置 → 工作区与连接”选择，插件管理和插件工作区跟随已保存的全局设置，当前只提供完整简体中文，不再提供独立插件语言切换。

启动后显示欢迎页，不自动打开本地终端。主机侧栏顶部原有的分组管理、刷新和新建工具栏已移除。固定本地终端入口下方是“全部主机”和导入/导出按钮，搜索框紧接该标题下方，只有主机树列表滚动。

主机树默认显示“根目录”，旧未分组主机直接位于根目录，原分组作为根下文件夹保留。在根目录或文件夹上右键可新建主机和子文件夹；普通文件夹还可重命名和删除，文件夹名称不可与已有文件夹重名。删除前会确认，内容会移到父目录并保留。主机行不再显示编辑/删除图标，相关操作统一从右键菜单进入。主机上右键提供连接、编辑、复制和删除；复制在原文件夹生成独立副本，不会自动连接。新建主机表单不再选择分组，保存到右键所指文件夹；从欢迎页新建保存到根目录，移动可拖到目标文件夹。支持 Shift+F10/菜单键打开菜单，方向键选择，Esc/Tab 关闭，打开菜单不切换当前主机。

新备份和主机配置导出使用 v2 保存文件夹层级，可恢复旧平面 v1 备份。恢复遇到同名文件夹但父目录不同会明确拒绝并回滚，请先调整本地文件夹名称；不会将多级目录静默合并为平面分组。旧程序不支持打开新 v7 数据库或导入新 v2 备份。

确认退出软件会结束全部 SSH 和本地终端会话，标签与分屏不跨重启恢复。下次进入本地终端或主机时只创建一个新会话，不再显示上次遗留的多个“未连接”标签。主机、分组、凭据和设置仍保留；取消退出则继续使用当前会话。

切换顶部大模块只更换左侧菜单，中央保持当前页面。例如正在使用终端时点击运维工具，终端继续显示且会话不变；尚未打开页面时继续显示欢迎页。只有点击功能菜单、页面标签或其他明确入口才切换页面，不显示“请选择功能”卡片或清空当前内容。点击已打开页面标签时，顶部模块和左侧菜单会同步到对应功能。收起侧栏后可从工作区标签栏左侧重新展开，顶部模块栏始终保留。

### 终端、代理与端口转发

关闭顶部设备工作区标签时，会关闭该设备的全部终端会话和分屏；中键和右键关闭范围也遵循此规则，其他设备的会话不受影响。若有会话关闭失败，保留工作区并提示错误，可以重试。只要该设备仍有会话，新增编号继续递增；全部成功关闭后，再打开从“会话 1”开始。已有会话的编号和自定义名称保持不变。

终端会话标签位于内容上方的紧凑工具栏，可用加号新建会话；主机功能从同一工具栏右侧的菜单切换。原有标签菜单、重排/改名、上下或左右分屏和尺寸拖动继续可用。默认 Ctrl+Shift+C/V 复制粘贴、Ctrl+Shift+F 查找，Ctrl+C/Z 发往远端；快捷键可在设置查看和修改。Windows 桌面端使用原生系统文本剪贴板，右键、菜单和快捷键不再弹出网页剪贴板授权；纯浏览器预览不提供原生剪贴板读写。大文本粘贴先确认，Bracketed Paste 依赖远端应用启用。重连总是新 Shell，不恢复旧远端程序。重启后不恢复标签或分屏，显式选择主机或本地终端时创建新会话；内容只在用户选择导出时落盘，默认不录制会话。服务器 MaxSessions 会限制单条 SSH Transport 的 Channel 数，客户端不会修改 sshd 配置。

本地 RSA 私钥签名被禁用，请使用 Ed25519/ECDSA 或预先加载身份的系统 Agent。系统 Agent 不可用时不会自动启动或加载密钥。

主机编辑的高级设置支持认证超时、Keepalive、受管跳板和代理凭据。OpenSSH Config 导入支持常见字段、明确 Host 别名及受限 ProxyJump；重复主机跳过，不覆盖原配置。不执行 ProxyCommand，复杂或不支持的语义会提示或阻止导入。HTTP CONNECT 仅支持 HTTP/1.x 和可选 Basic 认证，代理通道本身无 TLS。

终端的端口转发入口可显式启动/停止 Local、Remote 和 Dynamic 转发；默认绑定回环，公共绑定须确认，Remote 实际绑定受服务端策略约束。转发归属于窗格，关闭窗格或断线会清理，不自动恢复。

### SFTP 与远程编辑

打开远程主机后，中央工具栏右侧提供 SSH 终端、SFTP 文件和服务器管理。点击 SFTP 文件进入左本地右远程的完整文件页，其他主机页面也保留这组菜单，便于切换；终端右键文件入口同样打开完整文件页并沿用所选目录。终端旁的“文件面板”已移除。

完整文件页支持导航、排序、多选、属性、创建、改名、确认删除和文本编辑，上传可使用本地文件列、文件/目录选择按钮或拖放。切换工具或主机保留已有远程路径、SFTP 连接和后台传输；关闭设备工作区会关闭该设备的全部终端会话。传输进度与取消/重试从底部状态栏“任务中心”弹窗查看。窄窗口下主机工具菜单可换行及横向滚动。本地设备不显示远程主机菜单，新连接和危险操作继续沿用指纹或风险确认。

多文件和目录传输使用后台队列，默认每主机 3 个活动任务，可在设置调整为 1–6。任务显示进度、速度、剩余时间及取消/重试入口；冲突须选择处理策略。上传下载在提交前进行 SHA-256 校验，失败后从头重传，不支持断点续传或跨进程重启恢复。页面关闭不等于取消后台任务，退出时须处理未完成传输。

远程普通 UTF-8 文本最大 2 MiB，用 Monaco 编辑。保存检查外部变化，依赖 OpenSSH 原子替换并保留基础 owner/mode；缺少扩展、权限不足或冲突时拒绝保存。原子替换会改变 inode，不保证保留 ACL、扩展属性和硬链接关系，保存前须确认这一限制。有未保存内容时先保存或明确丢弃；网络故障留下的临时文件可按任务/编辑器提供的恢复路径处理。

文件可复制绝对路径，或经确认打开独立 Shell、less 或 tail -f。目录联动依赖 OSC 7，未报告时使用手动导航，不猜测 Shell 输出，也不修改远端启动文件。

### 服务器管理

资源监控、Docker 管理、进程与端口、系统服务、日志查看是五个独立标准插件，ID 使用 cn.hiboot.plugins 前缀。终端右上角 SFTP 文件右侧的“工具”菜单只显示已启用插件，点击在当前主机打开；所有插件均适用于所有已登记主机，无需配置允许主机。顶部“插件”保留全部安装名称，禁用项也可进入自己的设置启用。内置插件预置全部声明权限、操作和必要目录，页面只读；新安装默认启用，已有禁用选择保留。上传插件仍需自行授予能力和目录权限。系统修改、写入及容器终端仍逐次确认。设置 → 插件管理支持拖放/选择安装，列表仅保留卸载；来源、启停和权限在各插件页内。上传内容位于应用数据目录 plugins/upload，旧配置与卸载选择保留。禁用不停止远端工作负载或已有终端。

服务器管理合并原监控和 Linux 运维入口，使用资源概览、磁盘、网络、Docker 容器、镜像、进程、监听端口、systemd 服务和日志 Tab。每台主机在本次运行中记住最近分类。资源概览集中显示 CPU、内存/Swap、负载和趋势；磁盘、网络各自展示独立列表。系统信息、每核心 CPU、采集警告，以及进程/容器/服务详情、TCP 检测和操作反馈按需弹窗，完整进程状态默认折叠。大列表在固定高度区域滚动，分类条支持左右方向键、Home/End 和窄窗口横向滚动。

CPU/网络按连续样本计算，首次采样无速率正常；错误、过期与权限不足会单独显示。设置支持 3/5/10/30 秒采样间隔，历史仅在内存中保留，不跨重启恢复。隐藏视图暂停采样，不会关闭已有终端或 SFTP；监控依赖 Linux procfs 和常见命令，缺少工具时明确提示。伪文件系统、只读镜像及重复挂载可能没有 df 容量数据，不再因此弹出错误；真实磁盘采集失败的通知包含具体挂载路径，“查看采集警告”仍保留其他分项异常。

Docker、进程、端口、systemd 和日志入口都使用当前主机的独立模块会话；权限不足不自动提权。Docker 默认使用远端 Unix Socket，不读取 Docker context 或启用明文 TCP API。状态修改须输入完整目标确认；删除容器不使用 force 或删除卷参数。

容器环境变量默认遮蔽，进程默认不读取参数和环境。删除、停止和发送信号前核对目标，尤其注意 PID/容器 ID。进程信号依赖 Python/pidfd 身份校验，缺少依赖时明确失败。systemd 支持系统和当前用户范围。

Docker、指定文件和服务 journal 日志可暂停、过滤、复制和导出可见部分，缓存有上限；关闭日志标签、离开日志分类或切换主机会停止对应流，不自动持久化日志。

### 网络与批量操作

Network 显示本机/远端来源，缺工具或权限会明确报错。ICMP 不通不能据此认定服务器宕机。批量命令/文件分发执行前逐台核对完整目标，并选择有限并发和超时；有副作用的命令不自动重试。超时或取消运行中任务可能显示 Unknown，需自行核实远端状态。

批量任务离页后继续至完成或超时，但不跨进程重启恢复；退出时会提示未完成任务并请求取消。单文件分发沿用 SFTP 校验及冲突策略，失败目标可预览后单独重试；更改冲突策略需要新建批次。导出命令或输出前检查敏感内容。

### 自动化任务与本地计划

Automation 命令/脚本库支持分组、收藏、搜索和可编辑模板。执行前预览完整目标、正文和参数，确认目标数量；危险任务另行确认。默认并发 3，可设 1–8，最多 32 台，每台超时 1–3600 秒。

脚本使用 POSIX `/bin/sh`，远端需 Python 3；参数按顺序对应 `"$1"`、`"$2"` 等，与脚本文本分离传递。脚本由用户审查，勿对参数使用 eval，远端同账号或管理员仍可能观察进程参数。正文、普通参数和描述是本地明文数据，不应包含秘密。秘密参数不能有默认值，不落盘、不采集输出，也不能保存为计划。

执行历史可查询，输出默认仅在当前进程显示，须明确选择才保存；历史可确认删除。重启后在途任务标为 Unknown、排队任务取消，不重新执行；超时、断线或在途取消也可能留下仍在运行的远端进程，须自行核实。

本地计划支持每日、每周和五字段 Cron，使用固定 UTC 偏移，不跟随系统时区或夏令时。计划只在桌面程序运行且已有认证连接时工作，睡眠/退出/断线时不保证触发。普通计划须授权当前内容及目标，危险计划每次批准；正文、参数定义、执行选项或目标路由变化后需重新授权。错过计划可跳过或请求确认，不自动补跑。

## 偏好、备份与故障

设置可保存主题、终端、默认连接、Keepalive、采样、下载目录、传输并发、日志级别、代理和快捷键。日志级别重启生效；当前完整翻译只有简体中文。

默认 Ctrl+K 打开全局主机/模块/命令搜索，Ctrl+, 打开设置，Ctrl+Shift+J 打开“任务中心”弹窗；可在设置修改。搜索任务只打开预览，不自动执行。连接默认值仅影响新主机，不修改已有主机或在途连接；侧栏尺寸、窗口尺寸和最大化状态可保存。

备份导出主机、分组/标签、命令/脚本及公开偏好，不含凭据、私钥路径、秘密参数值、主机信任、执行历史或自动计划。导入先预览，支持跳过/复制，偏好覆盖单独选择，不会覆盖原 SSH Config。秘密和信任需另行恢复；认证代理主机在预览阻止自动恢复，需手动重新配置。备份内容可能含用户写入正文/备注的秘密，分享前自行检查，备份不是加密保险库。

配置、数据库和日志使用系统标准用户目录，实际路径显示在工作区；日志大小有界并轮转。关闭窗口前处理未完成传输、任务和未保存文件。若操作失败，保留错误码、任务 ID 和去敏日志；不要贴出密码、私钥或未遮蔽环境变量。
