# AI 运维助手

## 配置模型

「设置 → 模型」分为「本地来源」和「远程模型」两个 Tab，默认打开远程模型。远程页显示模型数量，支持注册、刷新和编辑/删除；API Key保存在系统凭据库，不进入插件。本地页管理Codex、Claude Code来源：检测安装状态、从固定官方源下载安装、取消下载及独立授权/撤销。切换 Tab 不会中断下载。CLI登录在用户自己的终端完成，平台沿用原配置和登录状态，不导入token，不改写PATH或现有安装。

打开「设置 → 插件 → AI运维助手 → 插件配置」，从本地来源卡片或远程模型列表中选择已就绪的模型，点击底部“保存绑定”。未选择已就绪模型时不能保存，不提供空绑定选项；首次未配置或原模型失效时不会自动选择其他模型。未就绪项会说明原因，可从「设置 → 模型」处理后返回并点击“刷新”。底部显示当前绑定和未保存提示；取消不会更改现有绑定，保存失败可重试。切换模型/修订会使旧预览和计划失效。「基本信息」Tab 提供包信息及可展开的权限说明，内置权限无需自行配置。

## 提问与数据

从主机工具栏或全局搜索打开助手，直接提问。插件根据资产目录和问题匹配登记主机，通过平台连接与真实指纹审核后读取相关证据；入口主机是提示，不会默默将其他主机当作同一目标。命令使用明确hostId并绑定原SSH配置。凭据、内部租约、模型Key不可被插件读取。

提示词、主机关联、数据选择、上下文采集、脱敏、历史、工具循环和计划都在助手插件内部。平台只负责通用SSH/SFTP/模型传输、授权和资源边界。密码样式、地址和自定义literal脱敏不能保证覆盖所有业务秘密；使用前审核待发送信息，模型响应和远端输出均视为不可信文本。Markdown不执行HTML或加载远程图片。

诊断只附命中的主机，普通知识问题不附主机目录，明确询问资产清单时才附目录。先脱敏再缩短明细；请求预算不足会先省略明细，再删除较早的完整对话轮次，并提示省略情况。当前问题、完整统计、采集失败及所属主机仍保留，若必需信息也超预算则提示缩小问题或主机范围；历史不会从文本中间截断。

单轮最多8台主机、6轮模型工具推理、12个查询；采集真实资源/进程/端口/Docker/systemd等相关数据，失败或未采集不当作零。CPU/网络速率用两次真实采样，不用虚构速率。历史最多6轮/48KiB，不把执行输出自动加入后续聊天。

## 计划与执行

输入框左下角提供两种审批模式，默认“请求批准”，选择仅保留在当前页面，发送时固定到本次任务，不改变已有计划：

- **请求批准**：读取按宿主规则请求批准；计划展示后点击“执行计划”，由宿主确认一次，不再勾选或输入确认文字。
- **帮我审批**：已获独立读取预授权时，自动读取授权目录内文本、检查传输元数据，并执行清单中12条固定查询/采样命令。计划准备好且页面可见时直接打开宿主确认；变更仍由用户确认一次。需要首次主机指纹核验、未列入清单的动态SSH查询或缺少预授权时仍须批准，模式不能替代权限。隐藏页准备好的计划返回页面后点击执行，不在后台弹新确认。

例如“把 /work/compose.middleware.yml 中第315行删掉”，在“帮我审批”下完成读取和差异预览后，只需在宿主确认实际目标和修改差异一次即可保存；取消不写入。读取的脱敏明细会由已选模型处理，自动脱敏不能保证覆盖所有秘密。

计划最多32项，从准备时刻起5分钟内一次消费，受模型修订、SSH配置和页面owner绑定。执行前检查原状态，在变更命令内再次约束镜像tag/容器状态/服务状态；完成逐项复查。镜像删除不强制、不删除卷、使用--no-prune。失败或结果不确定停止后续项，显示已完成/失败/未确认/跳过，不自动重放变更。

用户点击停止允许在途操作安全收尾并保留部分报告；取消不承诺远端命令未发生，也不自动回滚。断线、输出超限或目标变更必须独立核对实际状态。

## 任务状态与工具范围

聊天显示当前任务的等待审核、执行、完成、失败或结果未确认等状态。提交期间显示处理中状态，返回后使用后端快照；异常会尝试读取原任务。未知结果须独立核对，不自动重试。中间复查状态不保证实时刷新。

现有 18 项工具包括资源/进程/端口、Docker、systemd 查询与变更，以及文件读取/修改、传输准备/启动。参数及读写边界严格校验，目录不能代替宿主权限。Skill/MCP 尚未接入。

可要求“读取测试服务器 /work/x.yaml，删除原文第六行，在原文第20行后加入 x: yy”。读取依照所选模式及授权进行，随后显示路径、原文摘要及真实差异，保存计划由宿主统一确认一次。行号始终针对同一份原文；未修改内容及换行保留，文件在审批期间变化会拒绝保存。仅支持远程 UTF-8 普通文本≤32 KiB，不校验 YAML 业务语义。

上传时说明“运行 ServerDeck 的本机”及绝对源路径，指定目标服务器与已有目录；服务器间中转应明确两台服务器及源文件，例如“把 A 的 /work/xx.tar.gz 传到测试服务器 B 的 /work/”。准备依照所选模式及授权进行，预览展示真实源/目标、大小及覆盖策略，确认后宿主启动传输。默认不覆盖；同名目标存在时重新提出明确覆盖请求。只传单个普通文件，不解压，不传目录或链接。聊天显示字节、速度及最终 SHA-256，可在模型处理中单独取消传输；取消或断线后仍须查看实际结果，未确认不自动重试。文件字节不经模型；读取文本会以脱敏明细参与模型分析。

任务只在本次运行期保留，最多 32 项，不提供跨重启恢复；预览/计划过期后须重新提问，不能重复执行已提交计划。详见[工具与任务](../architecture/ASSISTANT_AGENT.md)。

## 页面生命周期

已在可见页面开始的工作，在所属工作区仍打开时可后台收尾。隐藏页不能开始新问题或审批，输出流/PTY停止；需要新的SSH确认时返回页面重新准备。其他插件与上传包使用同样规则，没有助手ID特权。

关闭所属页面取消并清理它的预览、计划和资源，其他主机页面不受影响。撤权、禁用、升级、卸载或退出会取消整个插件。绑定变更使旧命令句柄失效，已展示的文本不是可永久执行的授权。
