# AI 运维助手

## 配置模型

「设置 → 模型」分为「本地CLI」和「远程模型」两个 Tab，默认打开远程模型。远程页以实际模型 ID 为主要标识，显示名称、连接地址、上下文窗口、最大输出 Token、Key 状态与注册时间，支持注册、刷新和编辑/删除。注册时间按本机时区显示，编辑不改变该时间；历史模型没有记录时显示“未知”。列表按注册时间从新到旧排列，时间未知的模型在末尾。在列表上方输入模型 ID、名称或连接地址即可搜索，支持部分匹配且不区分大小写；无结果时点击“清除搜索”恢复完整列表。API Key保存在系统凭据库，不进入插件。本地CLI页通过 Codex、Claude Code 卡片展示安装与就绪状态及操作：检测安装状态、从固定官方源下载安装、取消下载及独立授权/撤销。切换 Tab 不会中断下载。CLI登录在用户自己的终端完成，平台沿用原配置和登录状态，不导入token，不改写PATH或现有安装。

打开「设置 → 插件 → AI运维助手 → 插件配置」，从本地CLI卡片或远程模型列表中选择已就绪的模型，选中后立即保存，页面显示保存状态，无需点击保存按钮。保存期间暂时不能切换或刷新；失败时显示原因并恢复原选项，重新选择即可重试。不提供空绑定选项；首次未配置或原模型失效时不会自动选择其他模型。未就绪项会说明原因，可从「设置 → 模型」处理后返回并点击“刷新”。切换模型/修订会使旧预览和计划失效。「基本信息」Tab 提供包信息及可展开的权限说明，内置权限无需自行配置。

## 提问与数据

从主机工具栏或全局搜索打开助手，直接提问。插件根据资产目录、问题和最近对话匹配登记主机，通过平台连接与真实指纹审核后读取相关证据。任务需要来源而未说明其他来源时，当前工作区主机就是默认来源；回复澄清问题时不必重新描述原任务或重复提供来源。命令使用明确hostId并绑定原SSH配置。凭据、内部租约、模型Key不可被插件读取。

提示词、主机关联、数据选择、上下文采集、脱敏、历史、工具循环和计划都在助手插件内部。平台只负责通用SSH/SFTP/模型传输、授权和资源边界。为区分用户指定的主机，模型请求保留登记名称、地址、端口和用户名；其他地址、邮箱、密码样式、令牌、私钥和自定义literal继续脱敏。自定义值也可覆盖已登记地址的保留，但脱敏不能保证覆盖所有业务秘密。使用前审核待发送信息，模型响应和远端输出均视为不可信文本。Markdown不执行HTML或加载远程图片。

诊断只附命中的主机，普通知识问题不附主机目录，明确询问资产清单时才附目录。先脱敏再缩短明细；请求预算不足会先省略明细，再删除较早的完整对话轮次，并提示省略情况。当前问题、完整统计、采集失败及所属主机仍保留，若必需信息也超预算则提示缩小问题或主机范围；历史不会从文本中间截断。

单任务最多8台主机、32轮模型工具推理、64次只读工具及32批变更；采集真实资源/进程/端口/Docker/systemd等相关数据，失败或未采集不当作零。CPU/网络速率用两次真实采样，不用虚构速率。历史最多6轮/48KiB，新问题不自动复用上一任务的原始执行输出。当前任务内，命令和其他工具的脱敏执行结果会交给所选模型继续推理；脱敏不能保证覆盖全部业务秘密。

询问“硬件信息”时，助手会先采集CPU型号、核数、内存及相关系统信息。`/proc`、`/sys`中的动态系统文件可能报告0字节或与实际内容不同的大小，不能作为可编辑文档读取；助手会保留查询失败说明，并依据已有采样继续回答，缺少的证据不会伪装成已获取。

## 流式回答

发送后，准备和工具查询显示当前处理状态；模型开始生成回答或计划说明时，正文会逐步出现，完整返回后显示最终回答与可执行计划。尚在生成的文本不能授权或执行操作。

点击停止会保留已显示内容并标记已停止；断流会保留片段并显示错误，片段不会作为完整回答带入后续问题。新对话、切换模型或关闭会话后，旧片段不会写入新对话。远程模型须支持Chat Completions SSE，本地来源须提供对应CLI文本增量；不支持时明确报错，不自动重试计费请求。

## 计划与执行

输入框左下角提供三种审批模式，默认“请求批准”，选择仅保留在当前页面，发送时固定到本次任务；退出完全访问会使旧的完全访问计划失效：

- **请求批准**：访问外部文件、网络和执行命令时按宿主规则询问；计划准备好后点击执行，再由宿主确认一次。
- **帮我批准**：已获授权且安全校验通过的读取直接执行，包括进程PID、容器ID和服务名称变化的详情查询。不覆盖文件的普通传输和来源已验证、目标标签为空的导入自动执行；删除、覆盖、配置保存、未知来源和未知命令等高风险操作请求批准。
- **完全访问权限**：首次使用由宿主确认授权，当前会话持续生效，不设时间上限，不再逐项确认读取、修改、删除或传输。仍限于插件已经拥有的能力、目录和主机权限；不自动提权。切换到其他模式、新建对话或关闭会话立即撤销，旧的完全访问计划不能继续执行；撤权、插件停止/升级也会失效。切换页面后返回仍保持授权，新建对话恢复“请求批准”。

首次主机指纹、目标及原文复验、取消和执行后复查保持。工作区仍打开时，帮我批准/完全访问可在后台继续常规步骤；需确认的后续计划等待返回助手，隐藏页不弹新确认。

例如“把 /work/compose.middleware.yml 中第315行删掉”，在“帮我批准”下完成读取和差异预览后，只需在宿主确认实际目标和修改差异一次即可保存；取消不写入。读取的脱敏明细会由已选模型处理，自动脱敏不能保证覆盖所有秘密。

每批运维计划最多32项，从生成时起5分钟内一次消费，受模型修订、SSH配置和页面owner绑定。执行前检查原状态，在变更命令内再次约束镜像tag/容器状态/服务状态；完成逐项复查。镜像删除不强制、不删除卷、使用--no-prune。失败或结果不确定停止后续项，显示已完成/失败/未确认/跳过，不自动重放变更。

用户点击停止允许在途操作安全收尾并保留部分报告；取消不承诺远端命令未发生，也不自动回滚。断线、输出超限或目标变更必须独立核对实际状态。

## 任务状态与工具范围

聊天区分“回答已结束”“需要补充信息”和运维任务的等待审核、执行、完成、失败或结果未确认等状态。文字回答结束不代表镜像已导入或其他变更已执行。提交期间显示处理中状态，返回后使用后端快照；异常会尝试读取原任务。未知结果须独立核对，不自动重试。中间复查状态不保证实时刷新。

模型使用12项工具入口，包括指定主机查询、Docker/systemd 变更、文件读写、传输、远程程序执行、镜像导出/导入及 Skill 资源读取。主机查询包含资源、进程、端口、容器、镜像和服务等11种读取操作。参数及读写边界严格校验，目录不能代替宿主权限。当前不提供 MCP 接入。

可要求“读取测试服务器 /work/x.yaml，删除原文第六行，在原文第20行后加入 x: yy”。读取依照所选模式及授权进行，随后显示路径、原文摘要及真实差异，保存计划按当前审批模式授权。行号始终针对同一份原文；未修改内容及换行保留，文件在审批期间变化会拒绝保存。仅支持远程 UTF-8 普通文本≤32 KiB，不校验 YAML 业务语义。

上传时说明“运行 ServerDeck 的本机”及绝对源路径，指定目标服务器与已有目录；服务器间中转需要源文件和目标服务器，例如“把 /work/xx.tar.gz 传到测试服务器 B 的 /work/”，未另行指定来源时使用当前工作区主机。准备依照所选模式及授权进行，预览展示真实源/目标、大小及覆盖策略，按当前审批模式授权后宿主启动传输。默认不覆盖；同名目标存在时重新提出明确覆盖请求。只传单个普通文件，不解压，不传目录或链接。聊天显示字节、速度及最终 SHA-256，可在模型处理中单独取消传输；取消或断线后仍须查看实际结果，未确认不自动重试。文件字节不经模型；读取文本会以脱敏明细参与模型分析。

可以直接提出需要多种工具的目标，例如“读取配置，局部修改后核对服务状态”或“把当前主机的 stock 镜像导入到 192.168.1.159”。助手会查询事实，准备下一批操作，执行并取得真实结果后继续推理；请求批准模式下每批新变更等待你点击，辅助/完全访问模式仍由宿主按当前授权处理。聊天保留已执行工具记录，发生失败、取消或未确认结果时停止后续步骤，不重放已提交操作。

镜像搬运由独立的查询、导出、普通传输、导入和核对组合完成。多个仓库/标签候选或目标有歧义时才追问。“帮我批准”模式下，符合已授权固定模板的镜像导出自动执行，无需额外确认；不覆盖文件的传输和来源已验证、目标标签为空的导入也自动执行；覆盖、未知来源和未知命令仍需确认。同名标签可能被替换，已有容器不会自动更新。任务临时导出归档会在收尾时清理，需要持久保存时明确最终位置；目标传输文件默认保留，需要删除时另经批准。可切换至SFTP或其他页面，任务和归档继续保留；关闭所属工作区会取消。双端需要现有 Docker、sha256sum、SFTP、目录空间和权限，不自动提权。取消不承诺回滚 daemon 已接受的变更。

助手初始只读取 Skill 名称和用途摘要，在相关任务中按需加载正文和引用资源；查询记录会显示 Skill 加载。内置 remote-operations 和 docker-images 提供操作经验，没有合适 Skill 时也会组合已有工具。Skill 不能提供额外权限或自动执行脚本。当前 Skill 随插件打包，没有运行时安装/管理页；开发者可在插件 skills 目录增加含 name、description 的 SKILL.md 及 UTF-8 参考资源，再重新构建插件，无需修改 Rust 工具实现。格式与限制见[助手架构](../architecture/ASSISTANT_AGENT.md#skill-发现与按需加载)。

任务只在本次运行期保留，最多 32 项，不提供跨重启恢复；预览/计划过期后须重新提问，不能重复执行已提交计划。详见[工具与任务](../architecture/ASSISTANT_AGENT.md)。

## 页面生命周期

已在可见页面开始的工作，在所属工作区仍打开时可后台收尾。隐藏页不能开始新问题、交互窗口或审批；宿主保留命令流与任务，PTY关闭。已授权常规步骤可继续，需确认的计划等返回助手。新的SSH指纹仍须由用户在可见页面核验。其他插件与上传包使用同样规则，没有助手ID特权。

关闭所属页面取消并清理它的预览、计划和资源，其他主机页面不受影响。撤权、禁用、升级、卸载或退出会取消整个插件。绑定变更使旧命令句柄失效，已展示的文本不是可永久执行的授权。

## 限制

远端须具备相应 Linux 工具和 SSH 用户权限，平台不自动提权或安装远端软件。真实模型账号、本地 CLI、工具版本和原生客户端平台须分别验收；运行期任务不提供持久恢复。当前版本来自各插件 manifest 和 SDK，不能从文档推断已完成账号或全平台测试。

接口和安全细节见[SDK](../plugins/PLUGIN_SDK.md)和[安全说明](../release/SECURITY.md)。

传输进度中的大小使用MB，速度使用MB/s（1 MB = 1,000,000字节）。服务器间使用SFTP，经运行ServerDeck的电脑中转；本机网络也参与传输。完成前还会读回目标文件核对SHA-256，千兆链路不能单独保证端到端速度。
