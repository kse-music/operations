# AI 运维助手

## 配置模型

在「设置 → 模型管理」配置并测试模型。远程API Key保存在系统凭据库，不进入插件。平台同时管理本地Codex、Claude Code来源：检测安装状态、从固定官方源下载安装、取消下载及独立授权/撤销。CLI登录在用户自己的终端完成，平台沿用原配置和登录状态，不导入token，不改写PATH或现有安装。

打开「设置 → 插件 → AI运维助手 → 插件配置」，选择平台已就绪的模型并保存绑定。模型未就绪时点击“打开平台模型设置”。选择未保存不会更改现有绑定，保存失败可重试；切换模型/修订会使旧预览和计划失效。

## 提问与数据

从主机工具栏或全局搜索打开助手，直接提问。插件根据资产目录和问题匹配登记主机，通过平台连接与真实指纹审核后读取相关证据；入口主机是提示，不会默默将其他主机当作同一目标。命令使用明确hostId并绑定原SSH配置。凭据、内部租约、模型Key不可被插件读取。

提示词、主机关联、数据选择、上下文采集、脱敏、历史、工具循环和计划都在助手插件内部。平台只负责通用SSH/SFTP/模型传输、授权和资源边界。密码样式、地址和自定义literal脱敏不能保证覆盖所有业务秘密；使用前审核待发送信息，模型响应和远端输出均视为不可信文本。Markdown不执行HTML或加载远程图片。

单轮最多8台主机、6轮模型工具推理、12个查询；采集真实资源/进程/端口/Docker/systemd等相关数据，失败或未采集不当作零。CPU/网络速率用两次真实采样，不用虚构速率。历史最多6轮/48KiB，不把执行输出自动加入后续聊天。

## 计划与执行

例如“查询Docker镜像，为删除无标签镜像生成计划，确认后执行并复查”。先显示真实查询记录、固定目标及操作。点击审核，在插件中核对计划和确认文字；真正执行时平台还会展示由实际连接生成的目标与通用SSH命令，逐次确认。查询命令也按平台规则审核，不因内置助手或自述只读而免审。

计划最多32项，10分钟内一次消费，受模型修订、SSH配置和页面owner绑定。执行前检查原状态，在变更命令内再次约束镜像tag/容器状态/服务状态；完成逐项复查。镜像删除不强制、不删除卷、使用--no-prune。失败或结果不确定停止后续项，显示已完成/失败/未确认/跳过，不自动重放变更。

用户点击停止允许在途操作安全收尾并保留部分报告；取消不承诺远端命令未发生，也不自动回滚。断线、输出超限或目标变更必须独立核对实际状态。

## 页面生命周期

已在可见页面开始的工作，在所属工作区仍打开时可后台收尾。隐藏页不能开始新问题或审批，输出流/PTY停止；需要新的SSH确认时返回页面重新准备。其他插件与上传包使用同样规则，没有助手ID特权。

关闭所属页面取消并清理它的预览、计划和资源，其他主机页面不受影响。撤权、禁用、升级、卸载或退出会取消整个插件。绑定变更使旧命令句柄失效，已展示的文本不是可永久执行的授权。

## 本次版本与限制

助手包2.0.0，使用SDK5；Docker2.0.0、Nginx1.1.0及外部MySQL2.0.0使用相同平台。SDK4开发期包须重新构建。远端须具备相应Linux工具及SSH用户权限，平台不自动提权或安装远端软件。Windows已进行本轮验证；真实模型账号调用、本地CLI账号费用、macOS/Linux客户端和其他工具版本需在实际环境另行验证。

接口和安全细节见[SDK](../plugins/PLUGIN_SDK.md)、[插件验证](../validation/plugins/PLUGIN_TEST_REPORT.md)。
