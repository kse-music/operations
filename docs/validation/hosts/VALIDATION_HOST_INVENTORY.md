# 主机管理列表精简验收

日期：2026-11-02。范围为本轮用户追加的主机管理列表调整，替代此前仅禁用两列右键的行为。

## 已完成的真实功能

- 主机管理列表全部列不再触发自定义右键菜单，系统菜单继续由原有全局监听禁用；移除“更多”按钮。
- 整体移除选中主机后的详情面板及其按钮、凭据/超时/备注等展示，不再保留空白面板或占位内容。
- 列表依次展示主机、地址、用户名、认证/分组、最近修改、操作。地址为 hostname:port，用户名独立显示；最近修改使用已有 updatedAt，按本机时区显示，time 属性和悬浮提示保留原始时间，空值显示“—”。
- 行操作为编辑、进入终端、删除，绑定所在行主机。进入终端复用原有 connect 逻辑创建新会话，保留其他主机会话；按后续追加要求，主机名改为普通文本，点击不导航、不创建会话，表格不显示选中高亮。删除复用现有确认弹窗和 hostsApi.remove，取消不写入，失败保留列表并显示错误。
- 清理随详情区移除而不再使用的事件、凭据计算及样式。六列表格最小宽度 920px，使用既有表格内部横向滚动容器；侧栏、自定义终端菜单及连接所有权沿用现有逻辑。

没有新增依赖、Rust/IPC/数据库/配置变更，未关闭用户现有窗口、重置配置或安装发布程序。工作区原有其他修改保留。

## 主要修改文件

- `apps/desktop/src/views/HostsView.vue`：列表展示、事件及行操作。
- `apps/desktop/src/App.vue`：移除 HostsView 已不再使用的事件绑定，复用原有删除确认和终端入口。
- `apps/desktop/src/App.test.ts`：整表无菜单、六列/时间/无详情、目标主机终端、取消/成功/失败删除回归。
- `apps/desktop/src/styles/{hosts,controls,product}.css`：六列表格宽度、时间显示及移除详情专用规则。
- `tools/native-ui-e2e.mjs`：新增真实列表及 SQLite 删除验收；`native-e2e.mjs`、`native-terminal-e2e.mjs`、`native-product-e2e.mjs` 同步新入口，复制配置验收改走仍保留的侧栏菜单。
- `docs/product/PRD.md`、`docs/product/IMPLEMENTATION_PLAN.md` 及本记录。
