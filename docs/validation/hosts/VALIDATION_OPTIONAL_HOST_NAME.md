# 主机名称可选验收

日期：2026-11-02。范围为新建/编辑主机名称可留空，以及主机树的地址/端口显示规则。

## 已完成行为与主要文件

- `components/HostDialog.vue` 将名称标为可选，移除 required，保留最大长度；地址、用户名、端口等必要字段仍校验。编辑时保留原始空名称。
- `types/hosts.ts` 的 `hostDisplayName` 与 `core/src/hosts.rs` 的 `display_name` 优先使用自定义名称，否则使用 IP / 域名；22 端口省略，其他端口显示 `地址:端口`，IPv6 使用 `[地址]:端口`。仅空白名称归一化为空字符串。
- `HostSidebar.vue`、主机操作确认、工作区/终端标题、搜索排序、文件/运维/批量/自动化目标和跳板选择使用一致的显示名称，防止空标签或空白确认内容。修改主机地址或端口后，未命名主机树节点按新端点显示。
- `core/src/lib.rs`、`storage/src/lib.rs` 和 `migrations/006_optional_host_name.sql` 将 SQLite 升至 v6，在既有事务中迁移 hosts，保留 ID、创建/更新时间、分组/凭据关联、SSH 选项及索引。分组/凭据名称仍必填，其他有效性检查不放宽。
- `storage/src/hosts.rs` 复制未命名主机时以显示名称加“副本”命名；`storage/src/backup.rs` 和 `automation/src/lib.rs` 同步处理空名称。备份按非空名称或端点判重，避免不同端点的空名称互相冲突；恢复往返保留空名称。
- 同步主机表单定位脚本、PRD、架构、实施计划、设计决策和回归测试。保留工作区中并行的设置页修改，没有覆盖既有用户配置或主机数据。
