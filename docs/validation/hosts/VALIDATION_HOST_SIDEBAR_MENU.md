# 移除侧栏主机菜单验收

日期：2026-11-02。范围：移除侧栏每台主机的右键功能与其右侧三点操作入口。

## 已完成的真实功能

`HostSidebar.vue` 不再向父组件发送主机 menu 事件，右键仅取消系统菜单默认行为；移除每行三点按钮与对应定位样式，并收回原为按钮预留的右侧空隙。顶部“主机树工具”的导入、导出、标签筛选与排序保留，主机左键切换、分组拖动、搜索、分组折叠和状态展示沿用已有逻辑。

`App.vue` 移除主机菜单弹层、遮罩、事件绑定、位置/焦点状态和只被此菜单引用的配置操作及弹窗。新建主机、保存后在树中显示、顶部工具、应用退出确认和其他模块的菜单保留。工作区标签菜单为工作区现有独立功能，终端标签与文件菜单不属于本轮移除范围。

主机编辑、复制、收藏、删除和关闭全部连接等原主机菜单入口随菜单一并移除，不新增替代入口。底层 IPC、Rust、数据库、已有主机/凭据/配置/连接生命周期均未修改，没有实际删除用户数据或关闭现有用户窗口。保留工作区其他任务已有修改，包括独立主机管理页移除及工作区标签菜单。

## 主要修改文件

- `apps/desktop/src/components/HostSidebar.vue`、`src/styles/hosts.css`：移除主机菜单入口及样式。
- `apps/desktop/src/App.vue`：移除应用壳中的主机菜单和专属状态/回调/弹窗。
- `apps/desktop/src/App.test.ts`、`src/components/host-tree.test.ts`：以菜单不存在、无副作用及保留功能断言替换已移除入口的旧回归。
- `tools/ui-navigation.mjs`、`ui-layout-e2e.mjs`、`native-ui-e2e.mjs`：移除旧主机菜单导航，检查菜单与每行三点不存在，保留新建、导入/导出与拖组验收。
- `tools/native-terminal-e2e.mjs`、`native-product-e2e.mjs`：改为主机左键与已有终端工具入口；`native-e2e.mjs` 的配置协议检查改用真实 IPC 并明确标记，不将其写成菜单 UI 验收。
- `docs/product/PRD.md`、`docs/product/IMPLEMENTATION_PLAN.md` 与本记录。

## 未验证、已知风险与后续依赖

其余完整 native-e2e、SSH/产品原生套件以及修改的浏览器尺寸套件仅同步入口并检查语法，本轮没有运行其完整流程。真实远端 SSH/SFTP/监控/运维、系统剪贴板和 Linux/macOS 原生未重测；Rust 未改，未重复执行 Rust 单元测试。不把这些检查写为通过。

未发现新增功能风险。用户要求移除的主机菜单动作不再有该快捷入口，原数据和后端接口保留。后续真实远端与跨平台验收依赖授权测试主机和对应原生环境；没有本轮待实现内容，本阶段完成后停止。
