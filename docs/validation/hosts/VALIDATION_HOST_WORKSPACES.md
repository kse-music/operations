# 主机工作区布局验收

日期：2026-11-02。范围为用户确认的主机工作区草图，不增加远端业务功能。

## 已实现的行为

- 一级标签按主机组织，每主机一个工作区；Shell、SFTP、监控、Linux 运维放在工作区内的二级导航。本地设备仅提供 Shell，并有独立打开入口。
- 主机列表和一级标签都恢复各主机最近使用的工具；Linux 运维分类、既有文件路径、终端会话分别保留。激活已有空工作区不补建 Shell，首次打开主机或明确新建会话才创建终端。
- 全局功能栏只提供工作区、独立工具及资产/设置入口。进入全局页收起主机栏和二级工具，返回后恢复侧栏偏好。
- 批量运维、自动化和网络诊断的目标独立于当前主机。工具标签打开期间缓存页面，跨主机往返保留草稿、目标和结果；关闭标签释放页面缓存，原后台任务继续。
- 网络诊断在页内显式选择来源主机；主机快捷入口可预填目标端点，重复同一主机的明确诊断请求也会生效。自动化仅接受明确入口的目标预填，保留执行预览和确认。
- 关闭工作区与关闭实际会话分离，中键关闭、键盘标签切换和最终欢迎页行为保留。监控隐藏暂停、日志离页结束、传输后台继续；原有信任、危险操作和未保存文件保护继续沿用。

## 主要文件

`App.vue`、`stores/workspace.ts`、`types/product.ts`、`components/AppNavigation.vue`、`components/GlobalSearch.vue`、新增 `components/HostTools.vue`，以及相关页面、样式和回归测试。搜索主机恢复其工作区，搜索“主机管理”进入全局资产页，两个入口分别验证。验收脚本通过 `tools/ui-navigation.mjs` 复用新导航路径；同步 PRD、架构、实施计划和设计决策。未修改 Rust、IPC、数据库、依赖或用户配置，保留工作区其他已有修改。
