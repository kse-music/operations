## 2026-11-09 已知结构与配置自动升级

### 实现范围

数据库当前 schema 10，应用偏好和模型注册格式 v2。新库与 schema 1–9 使用连续 SQL 链；历史 SQL 从 Git `bbe2c13` 恢复，版本 5 只保留已有退役数据，独立夹具另保存真实旧 `005_automation.sql` 和 schema 9 快照。schema 10 增加名称/规范化换行 SHA256 的历史表，不清理旧附加表或闲置数据。

升级持有 SQLite 写事务锁，通过单独只读连接和 Backup API 保存包含 WAL 的已提交快照；副本检查、关闭、同步并发布成功后才修改原库。结构、应用偏好、历史和版本同事务提交，提交前完整性/外键检查必经；未知重建字段/索引/触发器、损坏及未来版本拒绝。失败副本保留 `.partial`，完整备份在数据库旁 `migration-backups/`，不覆盖、不自动清理。

应用配置在存储边界升级已知 v1 可缺省字段、字号别名及退役快捷键，保留显式值和原更新时间，当前 DTO/IPC 仍严格。历史默认值固定在独立 JSON 和模型 v1 上下文常量，每步固定目标版本，不因未来 Default/版本常量变化跳过步骤。模型注册/旧单模型首次使用时独立备份和事务升级，保留模型身份、修订、系统秘密引用及原单模型行；损坏模型不阻断主机启动。迁移不读取 OS 秘密、不执行远端操作、不升级旧插件权限或旧身份目录。

启动日志调整为数据库升级前初始化，升级成功后应用持久日志级别；阶段、SQLite/IO 类别和安全原因可诊断，原因链留在 Rust，不输出配置正文或秘密。同步根 AGENTS、当前 PRD/架构/计划、数据升级契约、使用与发布/安全说明，新增 ADR 0028 并标明 ADR 0017 的部分替代关系。

主要文件：`crates/storage/src/{migrations,config_migrations,ai,lib}.rs`、`crates/storage/migrations/`、`crates/core/src/lib.rs`、`crates/application/src/logging.rs`、`apps/desktop/src-tauri/src/lib.rs`、当前 IPC 类型/前端与 UI 脚本夹具，以及存储/应用升级专项测试。旧 `schema.sql` 移为独立 schema 9 回归夹具，正式初始化与升级不再维护两套建表入口。

### 限制和下一步依赖

本记录验证 Windows 上真实 SQLite/文件系统/应用层及前端测试，未使用日常数据库，未连接截图服务器。尚未执行真实 NSIS 安装升级/恢复、最终桌面点击或 macOS/Linux 原生升级验收；Unix 私有文件/目录权限分支保留但本轮未实测。旧应用不能直接打开新库，不提供自动降级或启动失败覆盖恢复。完整备份占额外磁盘，失败重试可留下多份证据；后续恢复/清理须另行明确授权。

后续结构/格式变更必须追加迁移、提高相应版本并执行保留数据回归，规则见 [AGENTS](../../../AGENTS.md#10-数据库与配置升级) 和[数据升级契约](../../architecture/DATA_MIGRATIONS.md)。本阶段完成后停止，安装器及跨平台矩阵继续作为发布门禁。
