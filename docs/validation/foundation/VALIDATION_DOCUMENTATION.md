### 检查与证据

检查脚本、整理前快照和结果保存在 `.local/docs-maintenance/`；包括 `baseline.json`、`check.py` 和 `checks.json`。脚本用于本次文档核验，不作为业务回归测试或新运行依赖。

1. 对所有本次修改/新增 Markdown 运行 Prettier；使用独立空 ignore 文件覆盖现有忽略规则，确保原被忽略的 PRD 和 AGENTS 也实际检查，不修改仓库 `.prettierignore`。
2. 检查本次文档的本地文件链接/标题锚点，以及未改文档指向这些文件的入站链接；修正原导航中已不存在的 13A 任务文件引用和验证索引中 SFTP 标题的失效锚点。
3. 将 11 份迁出的原 ADR 正文与整理前内容逐段比对，只容许 Markdown 相对链接基址和排版空白变化；检查所有独立 ADR 均有索引入口。
4. 检查固定归档各历史段落来自旧实施计划，保留原失败、未执行项及证据路径；检查已有验证报告未被改写。
5. 检查当前说明中无日期流水标题、历史覆盖声明或无效 UTF-8 字符；运行 `git diff --check`，确认修改范围仅为文档。

没有运行 Rust/前端构建、业务单元测试、原生 UI 或远端验收，因为没有业务变更；上述历史通过项没有在本阶段重跑。检查针对本地 Markdown 路径/锚点，不验证外部网站可用性，也不证明每条历史原始产物仍在磁盘。
