# 一级工作区标签右键菜单验收

日期：2026-11-02。范围：用户截图中的顶部一级工作区标签。

## 行为与主要修改

右键任意已打开标签显示“关闭、关闭右侧、关闭其它、关闭所有”。操作以点击的标签及可见顺序为基准，右键不改变活动页；保留仍存在的活动页，活动页被移除后选择相邻页或保留页。全部关闭后显示欢迎页，不补建终端或删除主机。

沿用导航和实际连接的所有权边界：只移除导航及其原有页面缓存，不调用终端关闭、文件断开或任务取消。菜单无右侧或其他目标时禁用对应项，菜单位置限制在视口内。点击外部、Esc、窗口调整和外部滚动均可收起；菜单键 / Shift+F10 打开，方向键、Home/End 导航，Esc 返回触发标签。

主要文件：

- `apps/desktop/src/App.vue`：菜单、鼠标和键盘入口、焦点及事件清理。
- `apps/desktop/src/stores/workspace.ts`：扩展原有 close，支持四种范围并拒绝失效目标。
- `apps/desktop/src/styles/product.css`：菜单视口尺寸约束，复用既有菜单主题样式。
- `apps/desktop/src/App.test.ts`、`stores/workspace.test.ts`：范围、活动标签、独立连接保留及交互回归。
- `tools/ui-workspace-tabs-e2e.mjs`：仅浏览器页面中的隔离夹具，不写用户数据或访问远端。
- `docs/product/PRD.md`、`docs/product/IMPLEMENTATION_PLAN.md` 与本记录。

没有新增依赖、IPC、数据库或配置项，保留工作区已有的其他修改。本轮检查中发现并行移除主机菜单后 openFiles 残留旧 menu 引用，改为收起当前页签菜单，恢复类型及静态检查。

普通配置 Windows debug 程序另存为 `.local/workspace-tab-menu/ServerDeck.exe`，与本轮构建输出核对 SHA256 一致；未安装、发布或替换正在运行的应用。

## 未验证、风险与后续依赖

本轮未执行原生 WebView 鼠标端到端、真实远程 SSH/SFTP 或 Linux/macOS 原生测试，不宣称这些实测通过；没有修改 Rust，未重复执行 Rust 测试。连接保留由应用集成测试检查既有终端 Session 和文件连接仍存在、未调用终端关闭；浏览器测试只验证前端交互。
