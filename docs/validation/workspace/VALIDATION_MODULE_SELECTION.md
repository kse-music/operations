# 顶部模块不自动打开默认菜单（2026-11-03）

## 已完成行为

- 首次切换顶部模块时，仅切换模块高亮和左侧菜单，中央显示功能选择提示；不自动选中第一个菜单、不新建任何页面标签。
- 最近打开的页面已关闭时，不自动选择同模块剩余页，也不补建默认页。关闭其他非活动标签不会意外激活空模块中的页面。
- 已有最近页面仍存在时继续恢复，原标签、全局草稿、主机会话及文件连接保留。点击左侧菜单、主机树或已打开标签后才进行对应导航。
- 主机运维空状态保留原欢迎页和主机树；其他空模块不显示主机树。原有启动本地终端和关闭最后标签显示欢迎页的行为不变。

## 主要修改

- `stores/workspace.ts`：删除默认页及任意剩余页回退，增加运行内空模块选择状态，保留最近标签恢复；关闭非活动标签不填充空模块。
- `types/navigation.ts`：移除不再使用的 defaultView 元数据。
- `App.vue`、`components/AppNavigation.vue`：无活动页面时仍显示正确模块菜单，展示选择提示，不默认高亮主机管理。
- workspace、App、导航测试和浏览器/原生 UI 检查；同步 PRD、架构、实施计划、决策与使用说明。
