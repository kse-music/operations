# 移除标签栏本地工作区按钮验收

日期：2026-11-02。范围为移除截图红框中的显示器图标按钮，即工作区标签栏的“打开本地工作区”入口。

## 已完成行为与主要文件

- `apps/desktop/src/App.vue`：移除目标按钮及其显示条件，保留欢迎页“打开本地终端”和已有本地设备标签；主机栏展开按钮继续可用。
- `apps/desktop/src/styles/product.css`：将剩余按钮样式改名为 workspace-sidebar-button。窄窗口回归发现收起主机栏后的焦点交接会将当前标签滚出视野，因此将展开按钮固定在标签栏左侧；聚焦使用 preventScroll，再复用 revealActiveTab 定位当前标签。
- `apps/desktop/src/App.test.ts`：增加目标入口不存在的断言，将原图标操作改为从欢迎页打开本地终端，保留远端窗格、文件连接和本地标签复用断言。
- `tools/ui-navigation.mjs`：已有本地标签直接选择；没有本地标签时，通过既有菜单关闭导航到欢迎页，再使用实际“打开本地终端”按钮。关闭导航保留实际会话，不以调用生产 store 代替 UI 入口。
- `tools/ui-layout-e2e.mjs`、`tools/ui-context-e2e.mjs`、`tools/native-ui-e2e.mjs`：检查图标移除、保留入口、活动标签可见性及导航/会话回归；同步 PRD、架构和实施计划。本次不修改 Rust、IPC、数据库结构或用户配置。

## 完成标准与实际验证

1. 欢迎页和远端工作区均无目标图标：应用测试、四组浏览器布局及原生 DOM 检查通过，已人工核对最终浏览器截图，原按钮位置为空。
2. 欢迎页仍可创建本地终端，已有本地标签可复用：应用测试与实际 Windows PowerShell 输入输出、退出重启检查通过。
3. 主机栏可展开/收起，窄窗口当前标签可见：修正焦点交接引起的横向滚动后，四组布局及四组上下文检查通过；保留原可见性条件并等待实际异步滚动完成。
4. 移除入口不关闭实际会话：应用、浏览器上下文及原生导航检查继续验证远端窗格、文件连接、草稿和终端归属。
