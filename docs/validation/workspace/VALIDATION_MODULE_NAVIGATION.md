# 顶部模块与左侧菜单验证（2026-11-03）

本记录保留该阶段的验收结果。随后取消默认菜单打开的行为变更与验证见 [VALIDATION_MODULE_SELECTION.md](VALIDATION_MODULE_SELECTION.md)。

## 本阶段功能

按用户提供的参考图，将应用改为顶部大模块、左侧模块菜单、中央已打开页面标签的结构。本阶段替代上一版导航排列，保留已有业务功能和 SFTP 伴随面板。

| 顶部模块 | 左侧菜单                                                                                    |
| -------- | ------------------------------------------------------------------------------------------- |
| 主机运维 | 主机管理、当前主机 SSH 终端/SFTP 文件/服务器监控/Linux 运维及主机树；本地设备仅显示本地终端 |
| 运维工具 | 批量运维、自动运维、网络诊断                                                                |
| 资产管理 | 安全凭据、备份恢复                                                                          |
| 系统设置 | 全局设置、本地环境                                                                          |

顶部选中模块从实际活动视图推导，直接打开页面标签、快捷键或搜索入口时同步模块与菜单。每个模块在本次运行中记住最近打开的标签；返回已有主机页只激活页面，不重建或重连 SSH。关闭最近标签后，切回模块选择剩余页或现有默认页。已打开标签仍统一显示，标签关闭范围和后台会话/任务所有权不变。

- `components/AppModules.vue`、`types/navigation.ts`：顶部模块导航及穷举视图归属。

- `stores/workspace.ts`：运行内最近模块页面恢复，不新增持久化或连接调用。
- `styles/main.css`、`product.css`：模块栏、菜单、工作区和小窗口排列。
- App、导航组件和 workspace 测试，以及 `tools/ui-navigation.mjs`、两组浏览器检查和原生 UI 检查。
- PRD、ARCHITECTURE、IMPLEMENTATION_PLAN、DECISIONS、USER_GUIDE 同步到本次结构。
