## 完成标准与实际验证

1. 右键未选中的中间标签，菜单顺序与要求一致；关闭其它只保留并选中该目标，同主机原活动标签关闭，其他主机会话保留。
2. 右键未选中的标签执行关闭所有，关闭同主机全部会话及分屏；成功后清空该主机当前标签和焦点，显示没有打开终端的状态。
3. 关闭失败时保留失败标签并显示错误，继续处理其他目标；关闭其它仍以右键目标为当前标签。所有标签关闭后自动保存空布局。
