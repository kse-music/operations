# 运维自动化验收

2026-11-02。按用户追加授权实现可复用命令、Shell 脚本、持久任务历史和本地计划。读取并保留现有 PRD、架构、代码与配置；目录仍未初始化 Git，未重置已有用户数据。没有开发 DAG、独立调度服务、云端执行或自动修复。

## 交付功能

- 命令/脚本 CRUD、单层分组、收藏、搜索、描述、普通/危险风险、默认超时/并发及八项可查看正文的模板；保存后从当前主机快速执行，也可选择多主机。模板覆盖系统、磁盘、端口、进程、Docker、服务、日志、TCP 连通性，不自动执行或伪造历史。
- 参数定义、顺序位置参数、文本/整数/端口/绝对路径/主机校验、必填和普通默认值；秘密无默认值。固定 SSH bootstrap，从 stdin 接收独立脚本/argv，通过 execv 运行 `/bin/sh`，参数不拼入正文。UI 明示正确引用、任意 Shell 风险及远端进程参数可见性。
- 完整目标和实际执行内容预览，绑定条目 revision 与全部目标的路由/账号/凭据版本，防止预览后换目标。全部手动任务输入目标数量确认，危险任务额外确认；目标已有认证连接才执行，未连接目标明确失败。
- 单/多主机任务，1–32 个目标、默认 3 并发（1–8）、最多 4 活动批次并共享全局 8 执行槽，每台 1–3600 秒；Pending/Running/Success/Failed/Cancelled/Unknown，独立结果、退出码、时间和失败原因。排队取消与请求停止在途任务分开，不自动重试。
- SQLite v4→v5 事务迁移，保留既有主机、配置、信任和凭据。执行前写 Running，revision 防止旧快照覆盖。历史按名称/状态/计划过滤、每页 50 条，持续保存且不会自动清理；用户确认后可删除已结束记录。默认只保存元数据/普通参数，输出落盘需明确选择。
- 每流 stdout/stderr 最多 8 KiB，UTF-8 边界裁剪并计数；内存最近最多 8 个任务控制器，等待 worker 完成再释放。秘密条目始终不展示/缓存/保存输出，即使勾选了保存输出；不使用容易漏掉变形或分块回显的替换方案。
- 每日、每周、五字段 Cron；启用/停用/编辑/删除、固定 UTC 偏移、下次运行、逐计划历史、全局失败/未知/待确认提示。普通计划授权后执行，危险计划每次只创建 Pending，手动批准后才执行。
- 错过策略为跳过并记录或生成待确认任务，不自动补跑；已有在途/待批准任务时不积压。重启恢复在途为 Unknown、未开始为 Cancelled，历史及明确选择的输出仍可查，不重放命令。修改执行内容/目标配置使计划失效，必须重新授权。

## 真实应用和 Linux 验收

入口 `npm run test:terminal -- --automation`，使用用户授权的普通账号和已带外核对的 Ed25519 指纹。密码仅通过隐藏输入进入本次测试进程，不写入源码、文档、日志或 argv。原生应用为独立测试 EXE、数据库和 WebView profile，启动后核对实际数据目录；没有 IPC mock。

在已有 Ubuntu 24.04/OpenSSH 9.6/Docker 测试服务器，通过两个 UUID 所属、独立 sshd 的 Linux 容器验证多主机。容器 CPU/内存/pids/网络和权限受限，端口仅远端回环，生成的只读测试密钥仅用于这些容器；自动化 fixture 添加 Python 3 及标准库以运行真实 bootstrap。测试没有自动提权、修改宿主 sshd、拉取外部镜像或读取不相关资源。

成功产物：`.local/terminal-e2e/1793553833717-12b833fc-136f-4982-b2cb-d756b0c63b97/`。`result.json` 记录 **19 项通过、limitations 为空**（这表示本次脚本预期均通过，不等同于所有平台验证完成）：

1. 11 项原有真实 SSH 回归：严格指纹确认、独立多标签、关闭单 Channel、vim、top、Ctrl+Z、隔离 htop、less、2 MiB 输出背压、搜索、手动重连。
2. 命令库新增/编辑/分组/收藏/搜索、当前主机关联，真实 hostname/uname 结果显式保存。
3. 两台独立 Linux 主机执行分离位置参数，中文、空格、引号、分号、`$(...)` 按字面值返回；检查注入哨兵未产生。
4. 一台成功、一台 exit 7 的结果归属、退出码和部分失败正确。
5. 随机秘密由脚本主动回显，但 UI、任务缓存、历史和 SQLite 均不包含该值；保留输出选项不能绕过保护。

8. 在长任务已持久化 Running 后终止**自己启动的测试进程**，跨越下次触发时间重启：任务 Unknown、既有历史/选择保存的输出可读、skip 为 Cancelled、ask 为 Pending，未自动补跑。此项是崩溃恢复，不称为 OS 关闭按钮或真实睡眠/关机测试。

## 限制与下一阶段依赖

- 本地计划只在应用运行、系统未休眠且已有可信运维连接时有机会执行；未连接目标失败，不会读取秘密进行无人值守登录。退出/关机/休眠期间不保证执行；错过仅 skip/ask。真实关机/休眠、系统时间跳变和多实例 OS 场景尚未做原生矩阵，协议/日历测试覆盖相应边界。
- 远端需 Python 3、POSIX `/bin/sh` 和模板使用的具体工具；不自动安装。不是交互脚本、Bash 解释器选择器或 DAG。八项模板正文可审查，但未在所有发行版及权限组合逐一实测。
- Cron 是五字段数字子集，固定 UTC 偏移，无命名时区/夏令时；无秒级计划、自动重试或无限补跑。当前最多 256 条库条目、64 分组/计划、64 待确认任务，达到上限明确报错。
- 秘密参数不持久化，不能定时调度，相关执行完全隐藏输出；用户必须正确将参数标记为秘密，勿把秘密写入正文、描述或普通默认值。非秘密内容、可选输出及用户主动导出都可能含敏感信息；SQLite 不是加密保险库，不提供硬盘/OS 层秘密保护。
- 超时/断线/取消/应用中断不能证明远端停止，用户需核对实际状态；不自动恢复执行或修复系统。应用清理只关闭自己的 Channel/租约，不终止不相关 SSH 会话。
- 历史持续保存在 SQLite 且不自动删除，输出有界但累计记录仍会占用磁盘；没有本轮未要求的时序数据库、保留周期管理或加密历史系统。
- macOS/Linux 客户端、其他发行版、长期定时/负载、签名发布及依赖通告修复仍待后续授权验收，不将 Windows/Ubuntu/同一宿主容器结果宣称为跨平台发布通过。建议下一步先做这些稳定性与发布门禁，当前阶段至此停止。
