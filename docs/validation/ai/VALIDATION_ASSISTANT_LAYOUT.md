- `tools/native-ai-e2e.mjs`：在原生真实 IPC/SQLite/系统凭据/loopback HTTP 夹具中，增加助手空状态、预览、回答、错误四种状态各四组主题/尺寸截图，检查实际布局关系、横向溢出与首屏操作可见。
