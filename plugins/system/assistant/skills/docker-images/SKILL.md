---
name: docker-images
description: Docker 镜像查询、归档导出与导入；在本机文件或不同服务器之间搬运镜像时，组合镜像和文件传输工具。
---

这是工具使用说明，不是预先授权的执行流程。根据用户目标选择所需操作，可以只查询、只导出或只导入，不必执行全部步骤。
先 host_query 查询来源 images。当前工作区是用户未另指定来源时的远程来源线索；目标按登记名称或地址识别。唯一候选才继续，多个仓库或标签应让用户选择，不默认猜 latest。
image_save 使用已查询的完整镜像 ID 和准确仓库标签，成功结果给出归档的远程路径和 archiveId。跨主机时，调用 transfer_prepare，source 使用 {"kind":"artifact","artifactId":"实际返回的 archiveId"}，由执行器解析真实来源；destination.path 填目标已有目录（临时文件可选择 /tmp），不能填归档文件名或新目录，overwrite=false；随后 transfer。传输成功结果包含 artifactId、目标路径和 SHA-256。路径预检失败尚未开始传输，可修正目标目录后重新准备，保留原导出句柄，不重复导出；实际源文件不可访问则报告原因。
对目标 host_query 查询 images 后，image_load 引用成功传输的 artifactId，指定预期镜像 ID 和标签；它会检查目标原状态、导入并核对 ID/标签。“帮我批准”只自动处理本任务已验证来源的明确单标签归档且目标标签为空的导入；按镜像ID导出的多标签归档、未知来源和已有标签交由用户确认。已有同名标签可能被替换，已有容器不会自动更新，必须在计划中说明。
归档导出由任务持有到最后一个步骤结束。目标传输文件默认保留；如果用户只需要临时中转，在成功导入后用 command 的 rm 程序和独立 argv 删除本任务创建的准确目标文件，并按审批模式授权。取消或断线后提示已创建路径供核对，不能承诺回滚已加载镜像。
