# Nginx 管理

内置 UI v4 / WASM 插件，使用公开 SDK 的现有能力。Nginx 输入类型、命令、容器目标校验及结果处理全部位于本插件；前端 invoke 自有动作，WASM 通过既有 Execute 请求执行，不依赖 Nginx 专用 SDK/宿主接口。支持服务器直接安装和 Docker 容器的版本检测、配置校验、确认重载、配置编辑和日志。容器必须运行，使用完整 ID；不自动安装 Nginx 或提权。

命令操作使用 `ssh.execute`，保留宿主单次确认；文件/日志/容器发现沿用各自授权。Execute 每路输出最多 4 KiB，超限明确失败，不显示不完整结果。插件升级至 1.0.1，旧包不再作为当前交付。

主配置路径用于 `nginx -t -c` 及重载；编辑文件路径可以是主配置或单独站点配置。保存仅写文件，重载另行确认，执行前重新校验。发送重载信号成功不等同于站点验收完成，应核对实际响应与日志。

配置编辑沿用 SFTP 权限与原子保存，单文件最多 32 KiB；权限不足和外部改动明确失败，草稿保留。容器配置需以目录 bind mount 持久化：按最长匹配的挂载目标映射到服务器路径。只读挂载不可保存；单文件 bind mount 仅支持读取，避免原子替换改变 inode 后容器仍持有旧文件。无绑定挂载的容器仍可检测、校验、重载和查看 Docker 标准输出日志，配置编辑提示先挂载目录。

切页保留当前运行内的草稿；返回后旧句柄失效，保存前重新读取摘要，有冲突时拒绝覆盖。关闭主机工作区、卸载/升级和退出应核对放弃草稿提示。日志离页关闭，不影响 Nginx 服务或其他会话。
