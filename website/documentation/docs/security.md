# 安全与隐私

## SSH 连接先核对身份

首次连接需要通过可信渠道核对 SHA-256 主机指纹。已知密钥变化会拒绝连接，跳板路径逐跳验证。不要仅凭 TCP 连通就判断认证成功。

系统 known_hosts 的 CA、证书、撤销与哈希语义尚未完整接入；复杂 OpenSSH 配置不能据此认为自动支持。

## 秘密保存在系统凭据库

密码、导入私钥和模型 Key 由操作系统凭据库管理，不回退明文配置。数据库备份主要保留引用，不能代替凭据库备份。普通前端和插件不能任意读取秘密或调用本地 Shell。

## 文件写入需要完整结果

SFTP 传输使用暂存、SHA-256 读回校验及提交检查。取消会清理已知暂存，保留已提交文件；清理失败必须核对恢复路径。

文本编辑检查原文与元数据后进行原子替换，但仍受服务端能力和最终检查到提交之间的并发竞态限制。ACL、扩展属性和硬链接不保证完整保留。

## AI 上下文可能离开设备

远程模型会接收授权范围内的相关上下文。脱敏与预算缩减不能保证覆盖全部业务秘密，使用前应选择符合实际数据要求的服务。

本地 Codex / Claude Code 来源表示通过本机 CLI 调用，它仍可能连接对应提供方；不能将其理解为离线模型承诺。

## 插件权限和执行审批

上传包默认禁用、未授权。目录、操作和资源绑定安装修订；撤权、关闭和升级会使旧资源或授权失效。审批模式不能跳过首次 SSH 指纹、基础权限或目标复验。

当前插件包没有密码学签名验证，摘要和作者信息不能证明可信身份。安装前核实来源，更新后重新审核必要权限。[开发者安全契约](/developers/reference/security.html)提供完整细节。

## 官网与反馈

文档由本站静态发布，不需要账户或上传主机信息。官网与文档的外观偏好保存在浏览器本地，不用于访客分析；搜索查询仅在浏览器处理。下载、源码和问题反馈会访问相应外部服务。

完整网站数据说明见[隐私与数据](/privacy.html)。在公开反馈中不要附带密码、私钥、模型 Key 或未脱敏业务数据。
