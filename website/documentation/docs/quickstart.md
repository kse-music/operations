# 连接第一台主机

准备服务器地址、SSH 端口、用户名，以及密码或私钥。需要跳板或代理时，先确认完整连接路径。

## 1. 添加连接信息

在首页点击“新建主机”，或右键主机目录中的目标文件夹新建主机。

| 字段       | 填写方式                               |
| ---------- | -------------------------------------- |
| 名称       | 可选；留空时显示地址                   |
| 地址与端口 | 使用实际服务器地址；默认 SSH 端口为 22 |
| 用户名     | SSH 登录账户，不是本机用户名           |
| 认证       | 密码或公钥认证；私钥可粘贴或选择文件   |
| 私钥口令   | 加密私钥需要对应的解锁口令             |

密码和导入私钥由系统凭据库管理。取消选择文件会保留当前表单。

## 2. 测试并核对身份

点击“测试连接”。首次连接会展示服务器算法与 SHA-256 主机指纹。

拒绝或关闭指纹弹窗会保留主机草稿；测试结束弹窗提示成功或真实失败原因，关闭成功提示后再保存。

::: warning 先核对，再信任
通过服务器控制台、管理员或其他可信渠道核对指纹，再选择信任。已保存主机的密钥发生变化时会拒绝连接，应先排查服务器或网络变化。
:::

测试进度、成功提示和失败原因统一显示在表单底部、操作按钮上方，不再弹出结果提示；失败后可直接修改信息或重新测试。测试成功凭证五分钟内有效且只能使用一次；修改连接信息、认证内容或超时后，需要重新测试才能保存。

## 3. 打开工作区

保存后，单击主机用于选择，双击、Enter / 空格或右键“连接”打开主机工作区。重复打开会复用当前连接。

- **SSH 终端**：开始命令行工作，可新增会话和分屏。
- **SFTP 文件**：浏览本地与远程目录，传输和编辑文件。
- **Docker**：使用已启用插件查看当前主机上的 Docker。
- **AI 助手**：配置并绑定模型后，结合主机上下文分析问题。

工具入口的可用性取决于插件安装、启用与授权状态。Docker 仍需远端环境和账户权限，AI 助手仍需可用模型。

## 4. 结束本次工作

切换工具或其他主机不会自动关闭工作区。关闭标签时先审核未保存内容、编辑文档与传输，确认后等待安全收尾。运行中的连接、命令和任务不会跨应用重启恢复。
