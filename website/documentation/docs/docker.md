# Docker 与 Compose

从首页主机工具或主机工作区打开 Docker。插件状态及权限在“设置 → 插件”管理，参阅[安装和管理插件](/docs/plugins.html)。

## 前置条件

远端需要 Linux Shell、Docker CLI、当前 SSH 登录账号可访问的 Docker Unix socket；日志需要 GNU coreutils `timeout`。镜像归档另需 SFTP、可写且非链接的 `/tmp` 和足够空间。插件不会安装软件、执行 sudo 或修改 Docker 权限，也不继承文件页切换的用户。

内置包预置固定读取、交互命令和文件传输的独立预授权。作为上传包装入时须自行核对并授予相应能力和目录范围。交互预授权允许当前安装修订启动任意远程流/终端命令，不能视为只读。一般变更仍由可信宿主确认真实主机、对象和影响。

## 列表、统计与容器

容器、镜像、Compose 项目共用一组统计：Docker 服务端版本、按 ID 去重的本地镜像数、running 容器数、可发现的 Compose 项目数。项目数不是服务器配置文件总数。未知显示“—”，读取失败有明确原因，成功空列表才显示零。

各页签支持搜索和刷新。同一主机连接内保留成功统计和已访问列表；切页不清空重读，主机/连接变化后重新读取。操作完成更新当前列表和统计，其他缓存列表下次显示时更新。应用外修改 Docker 后点击“刷新”；刷新失败保留旧数据并提示。

容器行可启停、重启、删除、查看详情、日志和 Shell；行内重启会启动已经停止的容器。工具栏“重启已退出容器”针对当前主机所有 exited 容器，不受搜索过滤影响。批量结果列出匹配、成功、失败和跳过数，超时或部分失败后先刷新核对，再决定是否重试。

## 详情与启动配置

详情分为“概览、启动配置、环境变量”三个折叠组，默认仅展开概览。配置和变量首次展开读取，折叠保留本次弹窗结果；失败可重试，需要最新值时关闭重开。关闭详情、隐藏页面或连接变化清除明文缓存，不提供资源使用分组。

启动配置为只读 Compose YAML：Compose 容器读取当前项目配置，普通容器按 inspect 转换，并提示未转换的有效设置，卷和网络保留 external 引用。项目读取失败时可显式改用容器信息转换。当前文件可能不同于创建时配置，转换不能保证独立部署，也不提供编辑或执行。

展开启动配置会显示环境变量值，收起仅隐藏内容；复制/导出前审核敏感信息。内联 secrets/configs 内容隐藏，不读取它们引用的文件。

“退出结果”将未启动、尚未退出、正常结束和异常退出分开显示。只有已经退出且代码为 0 才显示正常结束；异常退出保留实际代码，未知值不伪装成功。

## 日志与 Shell

日志默认跟随最新，向上翻阅后继续接收但保留阅读位置。“最新日志”或暂停后的“继续”恢复跟随；过滤、窗口/字号变化保持当前阅读模式。可纯文本过滤、复制和导出，缓存限 1 MiB/5000 行。

“清屏”只清除本窗口已接收的本地缓存，新日志继续追加；过滤条件、暂停/错误状态保留。复制/导出只包含清屏后剩余的可见内容，不清理 Docker 远端日志。远端日志保留与轮转由 Docker 管理。

单次查看最多十分钟，结束后从原入口重新打开。关闭/隐藏日志窗口、关闭页面、主动断开 SSH 或正常退出应用会停止对应远端命令，并等待退出确认，不影响共享连接的其他窗口。未确认退出会明确报错，恢复连接后核对进程；网络硬中断或强制结束应用不能保证即时清理。缺少 GNU timeout 时拒绝启动，不回退无监督命令。

容器 Shell 使用独立 PTY，显示容器名称、短 ID、`/bin/sh` 及真实 SSH 目标。支持查找、字号、清屏、最大化、复制粘贴；显示操作不重建 PTY，清屏不向远端发送命令。断线保留输出，从原入口重新打开，不重放一次性票据。

## Compose 项目

优先使用 `docker compose` CLI 插件，否则检测独立 `docker-compose`，支持 V1.29.2、V2 及后续版本。可运行相应的 `version --short` 检查。业务命令失败不换入口重试；Compose 不可用时容器和镜像管理仍可使用。

发现已有项目后，可看服务容器状态、镜像、退出结果和项目日志，经一次确认整组启动、停止或重启。启动仅作用于已创建容器，包含 profile 服务，不拉取镜像或重新部署，不删除项目或卷。已经删除全部容器的项目、一次性运行容器和未创建服务不在管理范围。

操作须恢复并复核原项目目录、配置文件和已有服务；必要配置或环境缺失时失败。V1 项目从容器标签发现，配置由 V1 合并为 YAML；V1 启动拒绝以减号开头、无法安全传入的服务名。超时后先刷新核对，不自动重放。

## 镜像导入与导出

在镜像页点击“导入镜像”，选择本机 `docker save` 归档，点击“上传并导入”。归档上传到当前主机私有暂存目录，经 SHA-256 校验后执行 load。同名标签可能替换，已有容器不会更新。

在镜像行点击“导出”，选择本机目录和 `.tar` 文件名。服务器按所选标签 save，无标签按完整 ID，校验下载后提交，不覆盖已有本机文件。内置包点击导入/导出后直接执行，不再逐次弹出传输或命令确认。

进度依次区分打包/传输、校验与提交、Docker 加载和清理。大小使用 MB，速度使用 MB/s（十进制，保留两位小数）；字节达到 100% 后隐藏速度，仍须等待远端读回校验及后续阶段，整体成功以最终结果为准。

## 镜像远程传输

1. 在来源镜像行点击“远程传输”，从已登记的其他主机中选择目标。
2. 核对所选标签与目标快照。同名标签指向不同镜像时查看两端完整 ID，明确“确认替换并传输”后继续；目标变化后须重新检查。
3. 等待来源打包、经本机 SFTP 中转、SHA-256、目标自动 load、内容核对及两端清理。
4. 在目标镜像页核对结果。Loaded image 只表示 Docker 已加载，后续核对失败时镜像也可能已经存在。

来源和目标无需互通或互配 SSH；本机不保存完整归档，但承担中转流量。两端均需 Docker、SFTP、权限和暂存空间。只保留所选标签，无标签按 ID，不更新或重启已有容器。

完成核对使用镜像平台、配置和有序文件层的内容摘要，不要求不同 Docker 存储实现的显示 ID 相等；核对针对 inspect 默认平台，不证明多平台索引全部一致。load 前复查目标标签，但 Docker 没有原子标签锁，最后检查至加载之间仍有外部并发竞态。

## 取消与故障

取消或关闭/隐藏本页会停止本页镜像操作：先排空文件传输，再停止归档命令流，清理已知文件和空暂存目录。取消不回滚已经加载的镜像，不自动重试。错误详情在通知中显示，任务弹窗保留失败状态及输出。

归档位于参与主机的 `/tmp/serverdeck-image-<nonce>/`。断线、撤权或异常退出可能留下文件，错误会提供两端主机和恢复目录；核对任务已经结束后再自行清理，勿递归删除不明内容。实际吞吐取决于两端磁盘、加密和本机网络，字节满或命令退出码均不能代替最终业务核对。
