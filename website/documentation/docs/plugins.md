# 安装和管理插件

ServerDeck 随客户端提供 Docker 与 AI 运维助手，也支持本地安装标准 `.sdplugin` 包。官网的[插件市场](/marketplace.html)目前为静态展示页，下载按钮统一提示“建设中”；客户端暂不支持从市场在线下载安装插件。

## 安装本地插件包

1. 向可信开发者获取 `.sdplugin` 文件。
2. 在 **设置 → 插件** 上传，核对包信息与声明权限。
3. 确认来源风险后安装，再按需要授予权限并启用。
4. 从声明的入口进入页面，完成模型或必要配置。

安装、启用、授予权限与单次执行确认是不同步骤。包升级和回滚均通过插件管理进行，授权绑定安装修订；相同 ID 或旧授权不能自动取得执行权。关闭、撤权、升级或卸载会取消并收尾所属资源。

## 内置插件与恢复

两个内置插件为 Docker 和 AI 运维助手。卸载后如需装回，在“设置 → 插件”点击“恢复内置插件”，选择对应插件并点击“恢复安装”，检查配置后启用。恢复使用应用自带的安装包，保留卸载时留下的配置；已清除的数据无法恢复，重启不会自动装回。已启用且具有功能页的插件出现在主机工具栏；“设置 → 插件”统一管理安装、升级、启停、配置、权限和卸载。功能页“插件设置”进入设置页面的插件分类，返回首页保留原业务页面、筛选和滚动。

## 权限与来源

内置插件预置声明权限和必要目录，权限只读展示；上传包默认禁用、未授权，需审核来源、权限及目录后启用。固定命令预授权和交互会话预授权分别授予，后者允许当前安装版本启动任意交互命令，不代表只读。包未提供密码学签名验证，作者字段和摘要不能证明来源。

## 缓存、诊断与开发包

插件列表、远程模型和本地 CLI 检测结果在本次运行中复用。应用外修改插件目录、CLI 登录或配置后，在对应设置页点击“刷新”；展示缓存不替代后端权限与配置检查。

插件列表卡片底部以 `YYYY-MM-DD HH:mm:ss` 显示包的构建时间（北京时间），不显示文字前缀，旧包未提供时间时显示“未提供”。“开发者中心”链接会在默认浏览器打开官网，独立开发包统一[按 SDK 版本下载](/developers/downloads.html)，开发和上传流程见[第一个插件](/developers/quickstart.html)。单插件安装记录故障会显示诊断并隔离，不影响其他插件；有可用内置包时可明确选择备份并重装，重新安装默认禁用且不继承旧授权。

分别核对安装、启用、UI 授权、配置和远端环境，不能把“无法读取”当作“没有插件”。日常操作见[Docker](/docs/docker.html)与[AI 助手](/docs/assistant.html)。
