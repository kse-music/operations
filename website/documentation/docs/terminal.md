# 终端与快捷键

## 新建与管理员会话

点击终端上方标签栏的加号新建会话。Windows 本地终端会弹出“新建”和“新建(管理员)”两项。按 Esc 或点击菜单外部可退出菜单。在系统 UAC 中允许后会打开带“管理员”标记的会话，仅该 Shell 及其专用代理提权，ServerDeck 保持原权限。取消 UAC 不会创建普通终端，可从失败窗格重试。管理员会话分屏、复制、重连时会再次请求授权。关闭会话会结束对应 Shell 及受管子进程。系统授权窗口未响应时先选择允许或取消，再关闭会话或退出应用。

## 保存与重命名会话

右键会话标签选择“保存”，或在终端中按 Ctrl+S，保存当前名称、分屏布局以及各窗格的目录和最近命令。默认名称后会显示焦点窗格可恢复的最近命令，例如“会话 1 · npm run dev”；没有焦点窗格时取首个窗格。再次保存会更新这一个会话。右键选“重命名”、按 F2 或双击标签名可直接编辑，Enter 或失焦提交，Esc 取消。给已保存的会话改名会保留上次保存的目录、命令和布局。

Windows 本地 PowerShell，以及登录 Shell 为 Bash 4.2 及以上且支持 Readline 和 base64 的普通 SSH 会话，都可以恢复目录和最近命令。Bash 4.2–4.3 已配置 DEBUG 钩子时，仍可保存目录和布局。打开本地终端或相应主机时，已打开的会话继续运行，默认新建的会话使用普通 Shell。重开保存项会启动新的 Shell，并将最近一次可记录的单行命令放入可编辑的输入行。可以修改后按回车执行，也可以按 Ctrl+C 取消。目录不可用时会回到主目录并留空输入行。其他远端 Shell 可保存名称和分屏，保存后会提示仅能恢复布局的窗格数量。管理员窗格重开时需要 UAC 授权，SSH 恢复要求相同的主机、端口、登录用户和主机密钥。

会话末尾的 × 关闭会话。关闭最后一个窗格、关闭所有、关闭工作区或退出时，保存记录均会保留。“本地会话”侧栏默认展开。取消固定后，将鼠标移到左侧导航右缘的短线即可临时展开。SSH 则右键相应主机，悬停“已保存会话”展开列表。点击名称恢复保存项或切换到已打开的标签。点击保存项右侧的删除图标可删除该项，列表保持展开。正在运行的会话会继续运行，并变为未保存。本地最多保存 32 项，每台 SSH 主机也可分别保存 32 项。

## 多会话与分屏

会话名称前的绿色勾号表示所有窗格已连接。红底白减号表示有窗格已断开、已关闭或连接失败。

每个标签最多八个窗格，全应用最多 32 个窗格。每台主机可新建多个会话、拖动排序、双击改名和水平/垂直分屏。会话标签右键或 Shift+F10 提供复制、保存、重命名、重新连接、断开连接和关闭所有操作；复制创建普通新 Shell。重连仅对全部窗格均已结束的会话可用，保留标签与分屏，清空旧画面并创建新 Shell，不恢复远端进程或重放输入。断开后仍可查看和复制输出。

## 复制、粘贴与查找

终端内容区右键仅提供复制/粘贴。默认 Ctrl+Shift+C/V 复制粘贴、Ctrl+Shift+F 查找，Ctrl+C/Z 发往远端；分屏、会话和字号快捷键可在设置查看修改。Ctrl+滚轮调整终端字号。大文本粘贴先确认，Bracketed Paste 仍依赖远端程序支持。

Claude Code、vim 等程序启用鼠标交互后，可按住 Shift 拖选画面中的文字，再按 Ctrl+Shift+C 复制，用 Ctrl+Shift+V 粘贴。普通拖选可能由远端程序处理，未必产生 ServerDeck 的本地选区。“设置 → 终端”中的“选中即复制，右键即粘贴”默认关闭；开启后只对本地选区生效，Shift+右键仍可打开菜单。

Claude 等程序通过 OSC 52 发送选中文字时，ServerDeck 直接写入本机剪贴板，不弹复制确认；无需开启本地“选中即复制”开关。之后可按 Ctrl+Shift+V 粘贴，Ctrl+Shift+C 在没有本地选区时保留已复制的内容，自定义按键以设置为准。单次最多 2 MiB，只处理当前可见且聚焦的已连接终端；后台、其他弹窗或上传期间的请求不处理，不允许程序读取或清空本机剪贴板。按住 Shift 拖选仍可直接取得本地选区，开启“选中即复制”后自动复制。大文本粘贴仍需确认。

## 默认快捷键

当前新配置的默认终端快捷键如下；已有配置以设置页为准，默认值变化不会自动改写用户绑定：

| 操作                    | 默认快捷键                         |
| ----------------------- | ---------------------------------- |
| 复制 / 粘贴             | Ctrl+Shift+C / Ctrl+Shift+V        |
| 查找                    | Ctrl+Shift+F                       |
| 上下 / 左右分屏         | Ctrl+Shift+H / Ctrl+Shift+L        |
| 新建会话 / 关闭当前窗格 | Ctrl+Shift+T / Ctrl+Shift+W        |
| 下一个 / 上一个会话     | Ctrl+Shift+Right / Ctrl+Shift+Left |
| 放大 / 缩小终端字号     | Ctrl+Shift+= / Ctrl+Shift+-        |

使用终端快捷键前先点击本地或 SSH 终端输入区。Ctrl+Shift+L 左右分屏，Ctrl+Shift+H 上下分屏；Ctrl+Shift+T 新建当前设备的终端会话，Ctrl+Shift+左右方向键切换当前设备的会话，不切换主机工作区。Ctrl+Shift+W 关闭当前窗格并结束对应 Shell。插件终端弹窗不支持分屏、新建和切换会话，按这些快捷键会提示限制；复制、粘贴、查找和字号调整仍可使用，关闭窗格快捷键关闭插件终端弹窗。其他确认对话框打开时不会操作底层终端。

在“设置 → 快捷键”点击按键框后，直接按新的组合键即可修改，保存成功后使用新按键；无效或冲突组合按提示修正。“恢复默认”重置本页的终端及全局快捷键，修改只保存在此设备。Ctrl+K 打开应用内全局搜索，Ctrl+Shift+P 打开设置，对话框中不触发这两个导航操作。输入法或其他程序占用的组合键可在此处改键避让；已有配置保留原绑定，不因默认值变化自动替换。

## 打开输出中的链接

本地或 SSH 输出中的 HTTP/HTTPS 地址可左键打开本机默认浏览器，拖动仍可选择文字。SSH 输出里的 localhost/127.0.0.1 指向浏览器所在本机。

## 状态栏

底部状态栏显示当前窗格的真实 SSH 加密算法或本地 Shell、光标行列、终端尺寸和仿真类型。CAP/NUM 表示本机锁定键，窗口失焦/重新聚焦后显示未知，收到键盘事件再同步；状态不代表远端操作系统。SFTP 从主机工具栏进入。

## 通过本地端口访问远端服务

在主机工作区打开“端口转发”。例如远端 Web 服务只监听服务器的 `127.0.0.1:8080`，可填写本地端口 `18080`、远端地址 `127.0.0.1` 和远端端口 `8080`，点击“添加”后启动。确认显示“正在监听”后，在自己电脑的浏览器打开 `http://127.0.0.1:18080`。

“正在监听”表示本地端口已打开，浏览器接入时 SSH 服务器才连接远端服务。连接失败可查看规则中的提示。切换工具时转发继续，点击“停止”可释放对应端口。规则按主机保存在本机，关闭工作区或退出后，下次进入仍可看到规则，状态为“已停止”。需要转发时点击“启动”。

## 上传到当前 Shell 目录

拖放及 rz 上传均保留源文件的“修改时间”，精度到秒；拖放文件夹也保留目录修改时间。传输按绝对时间处理，界面或 `ls` 根据所在系统时区显示。Linux `ls -l` 对较早文件通常显示年份，可用 `ls -l --full-time 文件名` 查看完整时间。源创建时间和 Unix ctime 不在保留范围；已经上传成错误时间的文件需要重新上传，不自动猜测修正。

把本地文件或文件夹拖入普通 Linux SSH 窗格，核对后确认上传。先回到空白 Shell 提示符，不要停留在 vim、top、运行中的命令或密码输入界面。目标和身份取当前 Shell；例如 sudo -i 后 cd 到目标目录，会使用该用户接收，不改变文件页的 SFTP 身份。弹窗优先显示当前账户名称，无法取得名称时显示 UID。

无需安装 rz，但服务器须有兼容的 sh、GNU tar/coreutils 等基础命令。保留目录结构、隐藏文件与空目录，拒绝链接、重解析点和特殊文件。同名项目停止，不覆盖或合并。进度弹窗显示准备、传输、校验、容量及远端已确认字节的平均速度；成功后关闭并恢复原窗格焦点，脚本和协议不显示在终端。

上传期间只隔离该窗格输入，可取消，其他终端继续工作。文件通过原终端的二进制通道由后台直接发送，保留 sudo/su 后的用户和当前目录，不进行 Base64 文件编码。单个文件检查属性后直接上传，校验值随读取计算；文件夹或多选仍需先打包到本地临时文件，大批量项目需等待准备并预留临时磁盘空间，打包期间可取消。取消会等待在途分块排空、接收进程停止及终端恢复后关闭弹窗。失败保留原因；提交失败可能已有部分项目完成。无法确认恢复时会结束该 SSH 会话并提示重新连接，应先核对已提交项目及恢复路径。字节传完后仍需远端校验，归档还需解包；不保证与 SFTP 同速，不支持断点续传或跨重启恢复。本地、容器及插件会话不接收此类拖放。

远端运行 rz 也可触发原生多文件选择，经当前 PTY 批量上传。选择期间仅显示系统文件选择器；选好文件并确认后，“终端文件上传”弹窗才显示所选文件及当前文件的容量、平均速度、剩余容量、已用时间和预计剩余数据传输时间，多文件依次更新当前文件统计。取消文件选择不会显示进度弹窗。点击“取消上传”、右上角关闭按钮或按 Esc 均取消上传，停止读取后等待在途批次与取消帧按序发送、本地文件授权释放，再关闭弹窗；完成后自动关闭并恢复原窗格焦点。发送超时或授权在写入期间失效会关闭原会话，请重新连接并核对远端文件；取消可能保留未完成的文件。目标说明为该主机的当前 Shell 目录，ZMODEM 不返回实际账户和目录。不提供 sz 下载，下载使用 SFTP。
