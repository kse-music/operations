# 工作区与主机

## 认识工作台

启动显示工具启动台，只加载手动保存的本地会话列表，不启动终端或自动连接。工作台固定三栏：最左侧顶部为首页、本地终端，底部为设置；第二栏始终显示主机树、本地会话列表或设置分类，第三栏显示对应内容。首页上方可打开本地终端、新建主机或导入 SSH 配置；新建主机也可右键目标文件夹。第二栏可拖动调宽，不提供收起。全局搜索默认 Ctrl+K，设置默认 Ctrl+Shift+P。

尚未添加主机时，“主机工具”显示添加第一台主机的引导，本地终端仍可使用。添加后显示 SFTP、Docker 和 AI 运维助手入口；只有一台时直接显示名称，多台时先选择“目标主机”，切换选择不会自动连接。点击工具进入所选主机的工作区，继续沿用连接认证和安全确认。插件未安装时从卡片进入插件管理，未启用或授权不可用时进入插件设置；“插件已启用”只表示本地插件状态，不代表远端安装了 Docker 或助手模型已经可用。助手的“模型绑定”进入插件设置。列表读取失败可点击重试，不会显示成“没有主机”或自动安装/启用插件。

添加和首次连接的完整步骤见[连接第一台主机](/docs/quickstart.html)。

## 整理与删除主机

主机和文件夹通过右键管理，可拖动移动。菜单打开后，在界面任意位置再次右键会关闭旧菜单；右键其他主机、文件夹或 SFTP 文件时切换到新目标的菜单。点击或用键盘聚焦主机、文件夹行后，按 Delete 可打开该对象的删除确认；搜索框内的 Delete 只编辑文字，根目录不可删除。删除文件夹会把主机和直接子文件夹提升至父级，不递归删除；删除前需确认。主机只按名称、地址和用户名搜索。

## 导入 SSH 配置、跳板与代理

欢迎页或右键根目录可预览导入 OpenSSH Config。点击“导入到”展开目录树，点击箭头展开或收起子目录，点击目录名称选定导入位置；根目录和空目录均可选择，选中后显示完整路径。键盘上下键移动、左右键展开收起或进入父子目录，Enter/空格选择，Esc 只关闭目录菜单。支持明确别名、常见连接字段及受限 ProxyJump；重复项跳过，不覆盖已有主机，不执行 ProxyCommand。复杂配置可能被拒绝，应按提示人工配置。代理与跳板在主机高级设置维护；HTTP CONNECT 代理通道本身不提供 TLS，Basic 凭据只应经过可信网络。

## 认证与凭据

密码和私钥由系统凭据库管理，不可用时保存失败，不会写入明文替代。公钥认证支持 Ed25519/ECDSA/RSA，RSA 私钥可以直接粘贴或选择原文件，加密私钥填写解锁口令。RSA 认证要求服务器声明支持 SHA-256/512 签名；出现 `SSH_RSA_SHA2_REQUIRED` 时需升级服务器 SSH 或改用 Ed25519/ECDSA，不会回退 SHA-1。SSH Agent 需事先由用户启动并加载密钥。

编辑时，相同认证方式留空沿用已有凭据；改变共享凭据的认证方式不会改写其他主机。

## 标签与关闭

标签菜单支持关闭当前、右侧、其他或全部主机标签，右键不切换当前页面。

关闭主机标签会审核未保存内容、编辑文档和未完成传输；取消则保留原工作，确认后等待安全收尾。切换工具、设置或其他主机不会关闭当前工作区。重启不恢复运行期会话和任务。
