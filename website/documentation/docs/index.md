## 阅读范围

ServerDeck 是通过 SSH / SFTP 连接服务器的本地桌面工作台，无需云账号或远端 Agent。远端工具、实际账户权限和模型服务仍需由你准备。

文档介绍当前产品基线，公开安装包、源码基线与 SDK 分别标注版本。安装前请阅读[版本与适用范围](/docs/versions.html)。当前没有云同步、团队权限或插件市场。
