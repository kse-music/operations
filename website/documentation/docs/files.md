# SFTP 文件管理

## 浏览和身份

从首页主机工具或主机工作区工具栏打开 SFTP，左本地右远程，窄窗口上下排列。两栏有独立目录历史、搜索、排序、多选、属性和右键操作；鼠标侧键作用于指针所在栏。隐藏文件可通过工具栏切换；隐藏后对应选区清除。

本地磁盘下拉框和远程目录下拉框左侧都有三个图标，从左到右依次为“上一级”“根目录”和“主目录”。带箭头的文件夹返回父目录。带斜杠的文件夹在本地打开所在磁盘或网络共享的根目录，在远程打开 `/`。小房子在本地打开本机用户的主目录，在远程打开当前 SFTP 用户的起始目录。

在本地或远程地址栏输入路径后，按 Enter 打开目录。展开远程目录下拉框，可以看到从根目录到当前目录的每一级名称。菜单会自动加宽，每个名称占一行。如果名称比窗口还宽，可以横向滚动查看全名。

点击任一栏工具栏末尾的金色目录树图标，可在该栏文件列表上方打开目录树。点击箭头展开或收起分支，点击文件夹名称即可在下方查看内容。通过地址栏跳转或双击下方列表中的文件夹时，目录树也会定位到打开的目录。再次点击图标即可收起该栏目录树。本地导航和目录树可以在未连接 SFTP 时使用。

终端里的 su/sudo 不会改变独立 SFTP 用户。远程栏“切换用户”通过当前 SSH 账号的 sudo 权限启动目标用户的外部 sftp-server，默认 root，可切回登录用户；需要时输入本次 sudo 密码。新通道读取成功才替换旧连接，失败保留原连接。切换前处理传输和编辑文档，切换后从目标主目录或 `/` 开始。服务器须允许无 PTY sudo 和外部 sftp-server；不支持 requiretty 或仅 internal-sftp 的配置。sudo 密码不保存、不进入日志，插件也不继承该身份。

在本地或远程列表选中文件、文件夹后按 Delete，可删除当前聚焦栏的选区，支持多选并先确认；路径输入框中的 Delete 仍用于编辑文字。Windows 本地也可右键选择“删除”，确认弹窗会提示移入系统回收站，确认后执行，可从回收站恢复；回收站不可用时会报错，不会改为永久删除。其他平台暂不支持本地回收站操作。

文件菜单打开后，在界面任意位置再次右键会关闭旧菜单；右键列表中的文件、目录时，会显示该目标的新菜单。

本地和远程栏单选文件或文件夹后按 F2，或右键选择“重命名”，可直接在文件名所在行输入。普通文件默认选中扩展名前的名称，文件夹选中全名；按 Enter 或点击输入框外保存，按 Esc 取消。提交期间不能重复操作，失败保留输入并显示原因，同名目标不会被覆盖。保存后只刷新对应栏，保持原分页和滚动位置；点击另一行保存时保留刚选中的行和焦点。切换目录、主机或远程 SFTP 身份会取消未提交的编辑。Windows 本地重命名不需要连接 SSH，其他平台暂不支持本地重命名。

远程新建目录、重命名和删除遵守实际权限。远程删除为永久删除，确认目录删除会递归处理；不能删除根目录，不跟随目录内链接。批量删除或移入回收站失败时，可能已有部分项目完成，请刷新并核对剩余列表及回收站。

## 传输

以下新建权限适用于 v0.9.3 代码基线，不能作为 v0.9.2 安装包的承诺，详见[版本与适用范围](/docs/versions.html#sftp-新建权限)。SFTP 上传新文件默认请求权限 `0644`，新建目录默认请求 `0755`，服务器的 umask 或策略可进一步收紧。覆盖已有文件保留目标权限和属主，合并已有目录不改变其权限。文件上传（含递归中的文件和确认覆盖）保留源文件修改时间，精度到秒，合并目录的时间不作保证。服务器无法保留时间时任务报错并保留原目标。

通过本地选择、文件/目录选择器或原生拖放上传；远程条目拖入本地栏可准备下载。Windows 可把远程普通文件或指向普通文件的链接拖到桌面/资源管理器；目录不支持窗口外拖放。显式下载文件链接时以链接名保存目标内容，递归扫描不跟随链接。

冲突处理可选停止、跳过或确认覆盖。任务后台运行，默认每主机三个活动任务，可设为 1–6，全局最多 12；显示字节、速度、状态及取消/重试。先在目标同目录临时写入，校验 SHA-256 后提交。取消保留已提交文件，清理失败显示恢复路径。

文件页上传中断、取消或关闭软件后，在同一台电脑重新连接原主机，使用原 SFTP 用户，再把源文件上传到原目录。检测到匹配的断点后会自动核对已有内容并补传剩余部分，传输面板显示已复用的字节数。多选和目录上传逐文件处理，已存在的正式文件仍按所选冲突策略处理。如果源文件、原目标属性已变化，或暂存文件比源文件大，会提示是否从头上传。选择“取消”可保留已有进度。服务器无法提供私有暂存目录时会提示此文件只能从头重试。

单个文件自动使用分块流水线；设置里的并发数控制同时进行的任务数量。校验需要通过 SFTP 再读一遍远端文件，字节进度满后仍有网络和磁盘活动，等待任务完成后再使用目标文件。上传复用的字节单独显示，速度只统计本次传输。

任务同时显示“已用时间”和“预计剩余时间”。已用时间和平均速度只统计数据传输，不含排队、扫描、校验及提交。进度条满表示字节传完，接着显示“校验中”，此时速度和用时固定；多文件任务开始下一文件时继续累计。校验并提交成功后才算完成，记录中保留最终传输用时。预计剩余时间只估算数据传输，速度尚不可用时显示“估算中”，校验阶段显示“校验中”；该估算不包含后续校验和提交。

普通上传/下载会自动打开传输进度弹窗，同一主机的多个任务集中显示；文件与目标分行，速度、字节数和时间按列对齐。全部结束后自动关闭。右上角 X 或 Esc 取消弹窗内的当前任务，等待清理结束后收起；失败保留提示，可再次尝试。选择“后台传输”只隐藏弹窗，可从页头“传输任务（数量）”重新打开。页头“传输记录”查看及重试已结束任务。正常完成不弹成功通知，失败仍提示；切页保留任务，成功关闭主机后清除临时记录。

把远程文件拖到 Windows 桌面或资源管理器、拖入应用左侧本地文件栏或使用下载按钮时，统一使用应用自己的下载进度弹窗。外拖通过 Windows 虚拟文件机制交付内容，不请求系统复制进度窗口；应用内显示“拖放到的 Windows 文件夹”，不会显示内部暂存目录。外拖结果仍以最终系统文件复制是否成功为准，失败会报告原因。

## 内置文本编辑

远程 UTF-8 普通文本可在独立原生窗口编辑，上限 2 MiB，不支持 NUL。窗口可独立移动、缩放与最大化，一次编辑一个文件；提供保存、重新加载、查找、自动换行和状态栏。Ctrl+S（macOS 为 ⌘+S）直接按原子替换保存，无需再次勾选确认。

保存会核对原文摘要、大小、时间与基础权限/属主；冲突、缺少 OpenSSH 原子替换扩展或权限不足时拒绝写入并保留草稿。原子替换会改变 inode，不保证保留 ACL、扩展属性或硬链接关系；SFTP v3 无服务端 CAS，不能消除所有并发改写竞态。

关闭和重新加载审核未保存修改，可返回、保存后关闭或明确放弃；读取/保存中不能关闭。编辑器打开时，先关闭文档再断开所属连接、关闭主机、切换身份或迁移目录。断线保留草稿，主程序退出需明确处理未保存内容；不提供崩溃恢复或跨重启草稿。

## Windows 系统应用编辑

本地文件可用系统应用选择器打开。远程普通文件选择“使用系统应用编辑”后下载到独立本地副本，校验成功才交给系统应用；支持二进制和超过内置编辑上限的文件，不转换编码。外部保存后由用户明确确认回传，仍做原文冲突检测和原子替换，不自动上传。

外部编辑与内置编辑不能同时进行。结束、失败或退出均保留本地副本，结束时提示路径；不自动清理或恢复授权。关闭主机、身份切换和退出继续审核该编辑会话。其他平台可下载后自行打开，不承诺系统选择器集成。
